## 软件架构

### C/S 架构（Client / Server）

例如：QQ、微信

| 特点 | 说明 |
|------|------|
| 部署方式 | 需要下载安装 |
| 更新升级 | 需要重新下载 |
| 安全性 | 相对较高 |
| 跨平台 | 无法跨平台 |
| 成本 | 相对较高 |

### B/S 架构（Browser / Server）

例如：浏览器应用

| 特点 | 说明 |
|------|------|
| 部署方式 | 不需要下载，一个浏览器即可 |
| 更新升级 | 可以同时更新 |
| 安全性 | 相对较低 |
| 跨平台 | 可以跨平台 |
| 成本 | 较低 |

---

## 软件开发流程

- **前端**：与用户交互
- **后端**：处理数据与逻辑
- **数据库**：储存数据
- JS 可以写前端也可以写后端 → **全栈工程师**

### 开发时间分配

| 阶段 | 时间占比 |
|------|----------|
| 需求分析 | 1/3 |
| 开发 | 1/6 |
| 测试 | 1/2 |
