# 2、第一个网页

## 网页文件后缀名

网页文件的后缀名为 **`.htm`** 或 **`.html`**，两种都是网页文件，效果完全一样。

> 💡 **提示**：如何隐藏/显示文件扩展名？
> 组织 → 文件夹选项 → 隐藏已知文件的扩展名

## 前端发展简史

1. **网景公司**（Netscape）最早推出浏览器，最终在竞争中输给微软
2. 微软的 **IE 浏览器**有自己的解析标准
3. 每个浏览器对 HTML 的解析方式不同，按自己的理解去解析页面，导致**兼容性很差**
4. **W3C**（万维网联盟）重新制定标准，但很多浏览器厂商已习惯自己的标准，不愿更改
5. 程序员在书写标签时需要处理兼容性问题

### HTML5 标准

- **H5 标准**是目前前端的主流标准
- 相比之前加入了很多新内容（新标签、新 API 等）
- 为了让浏览器知道我们用哪个标准去解析网页，需要在开头声明

---

## DOCTYPE 声明

在网页开头告诉浏览器使用哪个标准来解析：

```html
<!DOCTYPE html>
```

> ⚠️ 如果没有写 DOCTYPE，浏览器会按照自己的理解（怪异模式）去解析，可能导致页面显示异常。

## 第一个网页示例

创建一个最简单的网页，只需要一个 `.html` 文件：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    今天开始学习前端了，好开心！
</body>
</html>
```

### 步骤

1. 新建一个文本文件，将后缀改为 `.html`
2. 用编辑器（如 VS Code）打开
3. 输入上面的代码
4. 用浏览器打开查看效果
