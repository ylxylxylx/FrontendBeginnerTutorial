# 3、网页结构

## HTML 執义

**HTML** = **H**yper **T**ext **M**arkup **L**anguage（超文本标记语言）

- 它是一种**标记语言**，不是编程语言
- 通过**标签**来描述网页的结构和内容
- 浏览器解析 HTML 标签后渲染出可视化的页面

---

## 标签分类

HTML 标签分为两种：

| 类型 | 形式 | 示例 |
|------|------|------|
| **双标签**（成对标签） | `<xxx> </xxx>` | `<p>段落</p>`、`<div></div>` |
| **单标签**（自结束标签） | `<xxx>` | `<br>`、`<img>`、`<input>` |

> ⚠️ 标签名规定使用**小写**，写大写浏览器也可以解析，但不推荐。

---

## 网页基本结构

每个 HTML 网页都有固定的骨架结构：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>网页标题</title>
</head>
<body>
    <!-- 页面内容写在这里 -->
</body>
</html>
```

---

## 各部分详解

### `<!DOCTYPE html>`

- 文档类型声明，告诉浏览器使用 **H5 标准**解析
- 必须写在第一行
- 如果不写，浏览器会按自己的标准解析（怪异模式），导致兼容性问题

### `<html>` 根标签

- 所有标签都写在根标签内
- 一个网页由一个 `<html>` 标签包裹
- `lang` 属性：指定页面语言，`en` 为英语，`zh` 为中文

### `<head>` 头部标签

- 主要给**浏览器**看的，内容不直接显示在页面中
- 常包含以下子标签：

| 标签 | 说明 |
|------|------|
| `<meta charset="UTF-8">` | 编码格式，UTF-8 支持中文 |
| `<meta name="viewport">` | 移动端窗口设置，适配响应式 |
| `<title>` | 罏页标题，显示在浏览器标签栏 |

### `<body>` 罏页标签

- 页面中**可见的内容**都写在这里
- 用户能看到的一切都在 `<body>` 内

## 注释

```html
<!-- 这是注释内容，浏览器不会解析显示 -->
```

- 快捷键：**Ctrl + /** 
- 注释不会在页面中显示
- **不能嵌套**使用注释
- 养成写注释的好习惯，尤其初学者可以通过注释来学习和理解代码
