# 4、常用标签

## 标签的语义化

为了让搜索引擎更好地理解我们的网页，应尽量使用**语义化标签**。

> 💡 什么是语义化？就是用有意义的标签来描述内容，而不是全部用 `<div>` 和 `<span>`。

| 标签 | 语义 | 说明 |
|------|------|------|
| `<p>` | paragraph | 段落 |
| `<h1>`~`<h6>` | heading | 标题（1~6级） |
| `<img>` | image | 图片 |
| `<ul>` | unordered list | 无序列表 |
| `<ol>` | ordered list | 有序列表 |
| `<a>` | anchor | 超链接 |

---

## 文本相关标签

### 标题标签 `<h1>` ~ `<h6>`

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<!-- 四级以下很少使用 -->
```

- `<h1>` 会自带样式：**加粗加黑**，字号最大
- `<h6>` 字号最小
- 一个页面建议只用一个 `<h1>`（SEO 优化）

### 段落标签 `<p>`

```html
<p>这是一个段落</p>
```

- 表示一个段落，自带上下间距
- 块级元素，独占一行

### 行内容器 `<span>`

```html
<span>这是在 span 中的文字</span>
```

- 用于设置文本样式
- 行内元素，不会换行
- 没有语义，纯粹用于样式控制

---

## 布局标签

### `<div>` 分割块

```html
<div>内容区域</div>
```

- **division**（分割），用于将网页分割成一个个块
- 块级元素，独占一行
- 最常用的布局容器

---

## 超链接 `<a>`

```html
<a href="http://www.zhiyou100.com">智游</a>
```

| 属性 | 说明 |
|------|------|
| `href` | 跳转目标网址 |
| `target="_blank"` | 在新窗口/新标签页中打开 |

---

## 图片标签 `<img>`

```html
<img src="图片路径" alt="图片描述">
```

| 属性 | 说明 |
|------|------|
| `src` | 图片资源地址，默认使用**相对路径** |
| `alt` | 图片无法加载时显示的描述文字；搜索引擎根据此描述搜索图片 |

> 💡 图片默认显示原始大小，单位是**像素（px）**。像素是组成图片的最小单元，每个像素点的大小与屏幕尺寸有关。

---

## 文本样式标签

| 标签 | 效果 | 语义 |
|------|------|------|
| `<strong>` | **加粗** | 有加强语气的作用（语义化推荐） |
| `<b>` | **加粗** | 仅仅是加粗效果，无语义 |
| `<i>` | *倾斜* | 文字倾斜 |
| `<em>` | *倾斜* | 强调语气（语义化推荐） |
| `<del>` | ~~删除线~~ | 删除的内容 |
| `<u>` | <u>下划线</u> | 下划线 |

> ⚠️ 优先使用 `<strong>` 而非 `<b>`，优先使用 `<em>` 而非 `<i>`，因为前者有语义。

## 列表标签

### 无序列表 `<ul>`

```html
<ul>
    <li>列表项1</li>
    <li>列表项2</li>
    <li>列表项3</li>
</ul>
```

- 每项前面有圆点标记
- 最常用的列表形式

### 有序列表 `<ol>`

```html
<ol>
    <li>第一项</li>
    <li>第二项</li>
    <li>第三项</li>
</ol>
```

- 每项前面有数字序号

### `<li>` 列表项

- 必须放在 `<ul>` 或 `<ol>` 内部使用
