# 5、实体（转义字符）

## 为什么需要转义字符？

有些特殊字符在 HTML 中有特殊含义（如 `<`、`>` 用于标签），如果要**在页面中显示**这些字符，就需要使用**转义字符**（也叫**实体**）。

转义字符以 `&` 开头，以 `;` 结尾。

---

## 常用转义字符

| 转义字符 | 显示效果 | 说明 |
|----------|----------|------|
| `<` | < | less than，小于号 |
| `>` | > | great than，大于号 |
| `&nbsp;` | 空格 | non-breaking space，不换行空格 |
| `&emsp;` | 大空格 | 中文全角空格 |
| `&` | & | ampersand，& 符号本身 |
| `&copy;` | © | 版权符号 |

---

## 空格的特殊处理

> ⚠️ 浏览器会将**多个连续空格**只显示为**一个空格**。

如果需要多个空格，必须使用 `&nbsp;`：

```html
<!-- 只会显示一个空格 -->
<p>段   落</p>

<!-- 显示多个空格 -->
<p>段 &nbsp; &nbsp; &nbsp; &nbsp; 落</p>
```

---

## 使用示例

```html
<!-- 显示大于号和小于号 -->
< >

<!-- 显示版权符号 -->
&copy;

<!-- 显示 & 符号本身 -->
&
```
