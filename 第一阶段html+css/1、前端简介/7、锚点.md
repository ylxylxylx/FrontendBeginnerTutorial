## 什么是锚点？

锚点是页面内的**跳转链接**，点击后可以跳转到当前页面的指定位置。

类似于书的目录——点击目录项，直接翻到对应页。

---

## 锚点的使用方法

### 第一步：给目标位置设置 `id`

```html
<p id="top">第一章内容</p>
<p id="two">第二章内容</p>
<p id="end">最后一章内容</p>
```

- `id` 是属性名，值在页面中必须**唯一**
- `id` 值不能以数字开头

### 第二步：用 `<a>` 标签链接到锚点

```html
<a href="#top">第一章</a>
<a href="#two">第二章</a>
<a href="#end">最后一章</a>
```

- `href` 值为 `#` + 目标元素的 `id` 值
- 点击链接后，页面自动滚动到对应 `id` 的位置

---

## 完整示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>锚点示例</title>
</head>
<body>
    <!-- 导航链接 -->
    <a href="#top">第一章</a>
    <a href="#two">第二章</a>
    <a href="#end">最后一章</a>

    <!-- 第一章 -->
    <p id="top">第一章内容</p>
    <p>撑开页面...</p>
    <p>撑开页面...</p>

    <!-- 第二章 -->
    <p id="two">第二章内容</p>
    <p>撑开页面...</p>
    <p>撑开页面...</p>

    <!-- 最后一章 -->
    <p id="end">最后一章内容</p>
    <p>撑开页面...</p>
</body>
</html>
```

---

## 特殊用法：回到顶部

```html
<a href="#">回到顶部</a>
```

- `href="#"` 会跳转到页面顶部，相当于刷新本页面
- 常用于"回到顶部"按钮
