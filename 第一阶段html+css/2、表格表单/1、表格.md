# 1、表格

## 表格简介

表格最早用于**页面布局**，现在已被 CSS 布局方式（如 Flex、Grid）替代，目前主要用于**展示数据**。

- 表格是**块级元素**，独占一行
- 宽度和高度默认由内容撑开
- 表格可以**嵌套**使用

---

## 基本结构

表格由以下标签组成：

| 标签 | 说明 |
|------|------|
| `<table>` | 表格容器 |
| `<tr>` | 表格行（table row） |
| `<td>` | 表格单元格（table data） |

```html
<table border="1">
    <tr>
        <td>1</td>
        <td>2</td>
        <td>3</td>
    </tr>
    <tr>
        <td>4</td>
        <td>5</td>
        <td>6</td>
    </tr>
</table>
```

---

## `<table>` 标签属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `border` | 表格边框宽度 | `border="1"` |
| `width` | 表格宽度 | `width="40%"` |
| `align` | 表格对齐方式 | `align="center"` |
| `cellpadding` | 内边距（内容到 td 边框的距离） | `cellpadding="10"` |
| `cellspacing` | 外边距（单元格之间的距离） | `cellspacing="10"` |

```html
<table border="1" width="40%" align="center" cellpadding="10" cellspacing="10">
    <tr>
        <td>1</td>
        <td>2</td>
    </tr>
</table>
```

---

## 单元格合并

### 跨行合并 `rowspan`

纵向合并，一个单元格占据多行：

```html
<tr>
    <td rowspan="2">1</td>  <!-- 占两行 -->
    <td>2</td>
    <td>3</td>
</tr>
<tr>
    <!-- 这里少一个 td，因为被上面的 rowspan 占了 -->
    <td>4</td>
    <td>5</td>
</tr>
```

### 跨列合并 `colspan`

横向合并，一个单元格占据多列：

```html
<tr>
    <td>7</td>
    <td colspan="2">8</td>  <!-- 占两列 -->
    <!-- 这里少一个 td，因为被 colspan 占了 -->
</tr>
```

> ⚠️ 合并后，被占的单元格要**删掉**，否则表格会多出格子。

---

## 单元格内容对齐

```html
<td align="center">居中</td>
```

| 值 | 效果 |
|------|------|
| `left` | 左对齐（默认） |
| `center` | 居中 |
| `right` | 右对齐 |

---

## CSS 样式：合并边框

默认表格边框是双线的，可以用 CSS 合并为单线：

```css
table {
    border-collapse: collapse;  /* 合并边框 */
}
```
