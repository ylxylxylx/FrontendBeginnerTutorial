# 3、表单

## 表单简介

表单的作用是**收集并提交用户信息到服务器**。

```html
<form action="服务器路径" method="GET">
    <!-- 表单控件写在这里 -->
</form>
```

### `<form>` 标签属性

| 属性 | 说明 |
|------|------|
| `action` | 服务器路径（提交目标地址） |
| `method` | 请求方式：`GET` 或 `POST` |

---

## `<input>` 输入框

`<input>` 是**单标签**，通过 `type` 属性改变输入类型。

默认宽度为 **25 个字符**。

### 文本与密码

```html
<!-- 文本输入框 -->
<input type="text">

<!-- 数字输入框 -->
<input type="number">

<!-- 密码框（输入内容显示为圆点） -->
<input type="password">
```

### 日期与时间

```html
<!-- 日期选择 -->
<input type="date">

<!-- 时间 -->
<input type="datetime">
```

### 其他类型

```html
<!-- 调色板 -->
<input type="color">

<!-- 邮箱（自带格式验证） -->
<input type="email">
```

---

## 选择控件

### 多选框 `checkbox`

```html
<input type="checkbox"> 篮球
<input type="checkbox"> 足球
<input type="checkbox"> 乒乓球
```

- 可以同时选中多个
- 适合"兴趣爱好"等场景

### 单选框 `radio`

```html
<input type="radio"> 男
<input type="radio"> 女
```

- 同一组只能选一个
- 需要相同的 `name` 属性实现分组（详见下一课）

---

## 按钮类型

### `<input>` 按钮

```html
<!-- 普通按钮 -->
<input type="button" value="按钮">

<!-- 提交按钮：将表单内容上传到服务器 -->
<input type="submit" value="提交按钮">

<!-- 重置按钮：清空表单所有内容 -->
<input type="reset" value="重置按钮">
```

| type | 说明 |
|------|------|
| `button` | 普通按钮，需配合 JS 使用 |
| `submit` | 提交按钮，提交整个表单 |
| `reset` | 重置按钮，清空所有输入 |

### `<button>` 标签

```html
<!-- 提交按钮 -->
<button type="submit">提交</button>

<!-- 重置按钮 -->
<button type="reset">重置</button>

<!-- 普通按钮（默认也会提交表单） -->
<button>按钮</button>
```

> ⚠️ `<button>` 默认行为是提交表单，如果不希望提交，需设置 `type="button"`。

---

## `<input>` type 速查表

| type 值 | 控件类型 | 说明 |
|---------|----------|------|
| `text` | 文本框 | 默认类型 |
| `password` | 密码框 | 输入显示为圆点 |
| `number` | 数字框 | 只能输入数字 |
| `date` | 日期选择 | 弹出日历 |
| `datetime` | 日期时间 | 日期+时间 |
| `color` | 调色板 | 颜色选择器 |
| `email` | 邮箱框 | 自带格式验证 |
| `checkbox` | 多选框 | 可选多个 |
| `radio` | 单选框 | 同组选一个 |
| `button` | 普通按钮 | 需配合 JS |
| `submit` | 提交按钮 | 提交表单 |
| `reset` | 重置按钮 | 清空表单 |

---

## 完整示例

```html
<form action="1、表格.htm" method="GET">
    <input type="text" placeholder="请输入姓名">
    <input type="password" placeholder="请输入密码">
    <input type="number" placeholder="请输入年龄">
    <input type="date">
    <input type="email" placeholder="请输入邮箱">
    <br>
    <input type="checkbox"> 篮球
    <input type="checkbox"> 足球
    <br>
    <input type="radio"> 男
    <input type="radio"> 女
    <br>
    <input type="submit" value="提交">
    <input type="reset" value="重置">
</form>
```
