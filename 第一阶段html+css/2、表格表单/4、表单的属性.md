# 4、表单的属性

## 核心属性

### `name` — 提交数据的键名

表单提交时，数据以 **键值对** 形式发送到服务器：

```
name属性值 = value值
```

> ⚠️ 没有 `name` 属性的控件，**数据不会被提交**！

```html
<input type="text" name="username" value="张三">
<!-- 提交数据：username=张三 -->
```

### `value` — 控件的值

- 对于输入框：`value` 是默认显示的值，用户输入后会覆盖
- 对于按钮：`value` 是按钮上显示的文字

```html
<input type="text" name="name" value="默认值">
<input type="submit" value="提交">
```

### `placeholder` — 提示文字

输入框为空时显示的灰色提示文字，用户输入后自动消失：

```html
<input type="text" placeholder="请输入姓名">
<input type="password" placeholder="请输入密码">
```

---

## `<label>` 标签 — 扩大点击区域

`<label>` 可以让文字也变成可点击的区域，提升用户体验。

**关联方式**：`label` 的 `for` 属性值 = 目标控件的 `id` 值

```html
<label for="psd">密码</label>
<input id="psd" type="password" name="password">
```

> 💡 点击"密码"文字，输入框自动获得焦点，无需精确点击输入框。

---

## 单选框分组 — `name` 的分组作用

相同 `name` 的 `radio` 属于同一组，**同组只能选一个**：

```html
<!-- 同一组 name="gender"，只能选一个 -->
<input type="radio" name="gender" value="female"> 女
<input type="radio" name="gender" value="male"> 男
```

> ⚠️ 如果 `name` 不同，两个单选框都能选中，就失去了"单选"效果。

---

## 默认选中 — `checked`

```html
<!-- 默认选中男 -->
<input type="radio" name="gender" value="male" checked="true"> 男

<!-- 多选框默认选中 -->
<input type="checkbox" name="hobby" value="write" checked="true"> 写代码
```

- `checked="true"` 或简写 `checked` 即可默认选中
- 适用于 `radio` 和 `checkbox`

---

## 下拉列表 `<select>`

```html
<select name="sel">
    <optgroup label="前端">
        <option value="h5">h5</option>
        <option value="css3">css3</option>
        <option value="js">js</option>
    </optgroup>
    <optgroup label="后端">
        <option value="java">java</option>
        <option value="db">数据库</option>
        <option value="framework">框架</option>
    </optgroup>
</select>
```

| 标签 | 说明 |
|------|------|
| `<select>` | 下拉列表容器 |
| `<optgroup>` | 选项分组，`label` 为组名 |
| `<option>` | 单个选项，`value` 为提交值 |

> 💡 `<optgroup>` 的 `label` 只是分组标题，不可选。

---

## 文本域 `<textarea>`

多行文本输入框：

```html
<textarea name="text" cols="30" rows="10"></textarea>
```

| 属性 | 说明 |
|------|------|
| `cols` | 列数（宽度，字符数） |
| `rows` | 行数（高度） |
| `name` | 提交数据的键名 |

---

## 完整示例：注册表单

```html
<form action="target.html" method="GET">
    <!-- 姓名 -->
    <label for="userName">姓名</label>
    <input id="userName" type="text" name="userName" placeholder="请输入姓名">
    <br>

    <!-- 性别（单选分组） -->
    性别
    <input type="radio" name="gender" value="male"> 男
    <input type="radio" name="gender" value="female"> 女
    <br>

    <!-- 爱好（多选） -->
    爱好
    <input type="checkbox" name="hobby" value="write" checked="true"> 写代码
    <input type="checkbox" name="hobby" value="look"> 看别人写代码
    <input type="checkbox" name="hobby" value="help"> 帮别人找bug
    <br>

    <!-- 下拉选择 -->
    <select name="sel">
        <optgroup label="前端">
            <option value="h5">h5</option>
            <option value="js">js</option>
        </optgroup>
        <optgroup label="后端">
            <option value="java">java</option>
        </optgroup>
    </select>
    <br>

    <!-- 个人特长 -->
    个人特长<br>
    <textarea name="hobby" cols="30" rows="10"></textarea>
    <br>

    <input type="submit" value="提交">
</form>
```

---

## 属性速查表

| 属性 | 适用控件 | 说明 |
|------|----------|------|
| `name` | 所有控件 | 提交数据的键名，radio 同名分组 |
| `value` | 所有控件 | 控件的值/按钮文字 |
| `placeholder` | text/password/email | 空状态提示文字 |
| `checked` | radio/checkbox | 默认选中 |
| `id` | 所有控件 | 唯一标识，配合 label 的 for |
| `for` | label | 关联目标控件的 id |
| `cols`/`rows` | textarea | 列数/行数 |

---

## 小结

```
表单属性速记：
name 提交必须有，value 值随输入走
placeholder 灰提示，checked 默认选中项
label for 配 id，扩大点击更友好
select 下拉 optgroup 分组，textarea 多行文本域
