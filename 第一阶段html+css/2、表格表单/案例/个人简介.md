# 案例：个人简介表单

## 案例说明

综合运用表单知识，制作一个个人简介信息采集表单。练习 `form`、`input` 各种类型、`radio`、`checkbox`、`textarea`、`label` 以及表单提交。

---

## 效果描述

一个包含以下字段的注册/个人简介表单：

- 姓名（文本框）
- 性别（单选）
- 出生年月（日期选择）
- 现居住地（文本框）
- 联系方式（电话输入）
- 证件号（数字输入）
- 专业技能（多选：h5、css3、js、ps）
- 学历（文本域）
- 个人特长（文本域）

---

## 代码实现

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>个人简介</title>
</head>
<body>
    <form action="target.html" method="get">
        <!-- 姓名 -->
        <label for="userName">姓名</label>
        <input id="userName" type="text" name="userName" value="">
        <br>

        <!-- 性别（单选，name 相同实现分组） -->
        性别
        <input type="radio" name="gender" value="male"> 男
        <input type="radio" name="gender" value="female"> 女
        <br>

        <!-- 出生年月 -->
        出生年月 <input type="date" name="data" value="">
        <br>

        <!-- 现居住地 -->
        现居住地 <input type="text" name="address" value="">
        <br>

        <!-- 联系方式 -->
        联系方式 <input type="tel" name="tel" value="">
        <br>

        <!-- 证件号 -->
        证件号 <input type="number" name="id" value="">
        <br>

        <!-- 专业技能（多选） -->
        专业技能
        <input type="checkbox" name="skill" value="html"> h5
        <input type="checkbox" name="skill" value="css3"> css3
        <input type="checkbox" name="skill" value="js"> js
        <input type="checkbox" name="skill" value="ps"> ps
        <br>

        <!-- 学历 -->
        学历<br>
        <textarea name="xueli" cols="30" rows="10"></textarea>
        <br>

        <!-- 个人特长 -->
        个人特长<br>
        <textarea name="hobby" cols="30" rows="10"></textarea>
        <br>

        <!-- 水平线分隔 -->
        <hr>

        <!-- 提交按钮 -->
        <input type="submit" value="提交">
    </form>
</body>
</html>
```

---

## 知识点回顾

| 知识点 | 本案例中的应用 |
|------|------|
| `<form>` | 表单容器，`action` 指向提交页面 |
| `method="get"` | GET 请求方式，数据附在 URL 后 |
| `<label>` | "姓名"文字可点击聚焦输入框 |
| `type="text"` | 姓名、现居住地 |
| `type="radio"` | 性别单选，`name="gender"` 分组 |
| `type="date"` | 出生年月 |
| `type="tel"` | 联系方式（电话） |
| `type="number"` | 证件号 |
| `type="checkbox"` | 专业技能多选 |
| `<textarea>` | 学历、个人特长（多行文本） |
| `<hr>` | 水平线分隔 |
| `name` 属性 | 每个控件都有 name，确保数据提交 |

---

## 提交目标页面

表单提交后跳转到 `target.html`，显示提交成功：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>提交成功</title>
</head>
<body>
    <h1>表单提交成功了</h1>
</body>
</html>
```

## 练习建议

1. 给输入框添加 `placeholder` 提示文字
2. 给单选框添加 `checked` 默认选中
3. 用 `<select>` 下拉列表替换"现居住地"文本框
4. 添加 CSS 样式美化表单
