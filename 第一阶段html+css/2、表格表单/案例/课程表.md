# 案例：课程表

## 案例说明

使用表格制作一个周课程表，练习 `<table>`、`<tr>`、`<td>`、`<th>`、`<caption>` 以及 `rowspan` 跨行合并。

---

## 效果描述

| | 周一 | 周二 | 命周三 | 周四 | 呫周五 | 呶周六 | 周日 |
|------|------|------|------|------|------|------|------|
| 第一节 | 语文（跨2行） | 数学 | 体育 | h5 | css | js | 历史 |
| 第二节 | | jQuery | VUE | nodejs | c语言 | c# | c++ |
| 第三节 | 体育 | 数学 | 化学 | 物理 | 生物 | 班会 | 历史 |
| 第四节 | 体育 | 数学 | 化学 | 物理 | 生物 | 班会 | 历史 |

---

## 代码实现

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>课程表</title>
</head>
<body>
    <table border="1" width="50%" align="center">
        <!-- 表名 -->
        <caption>课程表</caption>
        <tr>
            <td></td>
            <td>周一</td>
            <td>周二</td>
            <td>周三</td>
            <td>周四</td>
            <td>周五</td>
            <td>周六</td>
            <td>周日</td>
        </tr>
        <tr>
            <td>第一节</td>
            <td rowspan="2">语文</td>  <!-- 跨行合并2行 -->
            <td>数学</td>
            <td>体育</td>
            <td>h5</td>
            <td>css</td>
            <td>js</td>
            <td>历史</td>
        </tr>
        <tr>
            <td>第二节</td>
            <!-- 此处少一个 td，被语文 rowspan 占据 -->
            <td>jQuery</td>
            <td>VUE</td>
            <td>nodejs</td>
            <td>c语言</td>
            <td>c#</td>
            <td>c++</td>
        </tr>
        <tr>
            <td>第三节</td>
            <td>体育</td>
            <td>数学</td>
            <td>化学</td>
            <td>物理</td>
            <td>生物</td>
            <td>班会</td>
            <td>历史</td>
        </tr>
        <tr>
            <td>第四节</td>
            <td>体育</td>
            <td>数学</td>
            <td>化学</td>
            <td>物理</td>
            <td>生物</td>
            <td>班会</td>
            <td>历史</td>
        </tr>
    </table>
</body>
</html>
```

---

## 知识点回顾

| 知识点 | 本案例中的应用 |
|------|------|
| `<caption>` | 表格标题"课程表" |
| `border` | 边框宽度为 1 |
| `width` | 表格宽度 50% |
| `align` | 表格居中显示 |
| `rowspan` | "语文"跨两行合并 |

---

## 绫习建议

1. 尝试用 `<th>` 替换第一行的 `<td>`，让表头加粗居中
2. 尝试用 `<thead>`、`<tbody>` 划分长表格结构
3. 给表格添加 CSS 样式：`border-collapse: collapse` 合并边框
