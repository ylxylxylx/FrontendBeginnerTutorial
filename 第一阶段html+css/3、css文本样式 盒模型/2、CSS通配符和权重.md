# 2、CSS 通配符和权重

## 通配符选择器 `*`

通配符选择器选中**所有元素**：

```css
* {
    font-size: 30px;
}
```

- 格式：`* { 样式 }`
- 页面中**每一个元素**都会应用该样式
- 常用于清除默认样式（如去掉默认 margin/padding）

---

## 选择器权重（优先级）

当多个选择器的样式**冲突**时，根据权重决定最终生效的样式。

### 权重表

| 选择器 | 权重 | 说明 |
|--------|------|------|
| `!important` | 10000 | 最高优先级，一般很少使用 |
| 行内样式 `style=""` | 1000 | JS 控制样式都是行内样式 |
| ID 选择器 `#id` | 100 | |
| 类选择器 `.class` | 10 | |
| 元素选择器 `标签名` | 1 | |
| 通配符 `*` | 0 | |

### 权重规则

1. **权重高的优先**：当样式冲突时，权重高的选择器生效
2. **权重可以相加**：多个选择器组合时，权重相加
3. **不会超过数量级**：10 个元素选择器（10）不会升为 100
4. **同级看顺序**：权重相同时，**后写的样式**生效

---

## `!important` 提升权重

在样式值后加 `!important`，可将权重提升到最高：

```css
#author {
    font-style: italic !important;  /* 权重 10000，最高 */
    color: pink;
}
```

> ⚠️ `!important` 尽量少用，会使样式难以维护和覆盖。

---

## 权重计算示例

```css
/* 权重 = 10（类选择器） */
.title {
    color: red;
    background-color: green;
}

/* 权重 = 100（ID选择器） */
#author {
    color: pink;
}

/* 权重 = 1（元素选择器） */
h1 {
    color: blue;
}

/* 权重 = 0（通配符） */
* {
    font-size: 30px;
}
```

```html
<!-- h1: .title(10) vs h1(1) → .title 生效，红色 -->
<h1 class="title">悯农</h1>

<!-- h2: .title(10) vs #author(100) → #author 生效，粉色 -->
<h2 class="title" id="author">李绅</h2>
```

---

## 选择器分组（并集选择器）

用逗号 `,` 分隔多个选择器，让它们共享同一段样式：

```css
h1, h2 {
    text-align: center;
}
```

等价于：

```css
h1 { text-align: center; }
h2 { text-align: center; }
```
