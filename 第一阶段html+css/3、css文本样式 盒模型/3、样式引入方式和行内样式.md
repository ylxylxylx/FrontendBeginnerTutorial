# 3、样式引入方式和行内样式

## CSS 的三种引入方式

### 1. 外部样式表（推荐）

将 CSS 写在独立的 `.css` 文件中，通过 `<link>` 标签引入：

```html
<!-- 在 <head> 中引入 -->
<link rel="stylesheet" href="css外部样式.css">
```

```css
/* css外部样式.css */
* {
    color: aquamarine;
}

#author {
    color: brown;
}
```

**优点**：结构（HTML）与外观（CSS）分离，减少耦合，便于统一管理。

---

### 2. 内部样式表

将 CSS 写在 `<style>` 标签中，放在 `<head>` 内：

```html
<head>
    <style>
        h2 {
            color: blue;
        }
    </style>
</head>
```

**特点**：样式和结构在同一个文件中，适合小型页面。

---

### 3. 行内样式

直接在标签的 `style` 属性中写样式：

```html
<p style="color: chartreuse; background-color: darkblue;">床前明月光</p>
```

- 多个样式用**分号**隔开
- 样式名和值用**冒号**连接

**缺点**：结构和外观耦合，只针对当前元素，难以维护。

---

## 三种方式对比

| 方式 | 写法 | 权重 | 优缺点 |
|------|------|------|--------|
| 外部样式表 | `<link>` 引入 `.css` 文件 | 最低 | ✅ 推荐，结构与外观分离 |
| 内部样式表 | `<style>` 标签 | 最低 | 适合小型页面 |
| 行内样式 | `style=""` 属性 | 1000（高） | ❌ 耦合高，难维护 |

---

## 样式优先级

当三种方式对同一元素设置相同样式时：

1. **行内样式** > 内部样式表 > 外部样式表（相同权重时，后引入的覆盖先引入的）
2. 权重高的选择器始终优先（如 `#id` > `.class`）

---

## 完整示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>样式引入方式</title>
    <!-- 方式1：外部样式表 -->
    <link rel="stylesheet" href="css外部样式.css">
    <!-- 方式2：内部样式表 -->
    <style>
        h2 { color: blue; }
    </style>
</head>
<body>
    <h1>静夜思</h1>
    <h2 id="author">李白</h2>
    <!-- 方式3：行内样式 -->
    <p style="color: chartreuse; background-color: darkblue;">床前明月光</p>
    <p>疑是地上霜</p>
    <p>举头望明月</p>
    <p>低头思故乡</p>
</body>
</html>
```
