# 4、常用的字体样式

## font-size 字体大小

```css
p {
    font-size: 20px;   /* 设置字体大小为 20px */
}
```

- 浏览器默认字体大小：**16px**
- 常用单位：`px`（像素）、`em`（相对父元素）、`rem`（相对根元素）

---

## font-weight 字体粗细

```css
p {
    font-weight: bold;   /* 加粗 */
    font-weight: 700;    /* 等同于 bold */
    font-weight: normal; /* 正常粗细（默认） */
    font-weight: 400;    /* 等同于 normal */
}
```

| 值 | 说明 |
|------|------|
| `normal` | 正常（400） |
| `bold` | 加粗（700） |
| `100` ~ `900` | 数字值，越大越粗 |
| `bolder` | 比继承值更粗 |
| `lighter` | 比继承值更细 |

> ⚠️ 实际显示效果取决于字体是否支持对应的粗细等级。

---

## font-family 字体族

```css
p {
    font-family: "楷体", "Microsoft YaHei", sans-serif;
}
```

- 多个字体用**逗号**隔开，浏览器从左到右查找可用字体
- 含空格的字体名需要加**引号**
- 最后通常写一个**通用字体族**（`serif`、`sans-serif`、`monospace`）作为兜底

**常见中文字体**：

| 字体名 | 英文名 | 说明 |
|--------|--------|------|
| 宋体 | SimSun | Windows 默认衬线字体 |
| 微软雅黑 | Microsoft YaHei | Windows 常用无衬线字体 |
| 楷体 | KaiTi | 手写风格 |
| 黑体 | SimHei | 粗壮无衬线 |

---

## font-style 字体风格

```css
p {
    font-style: italic;  /* 斜体 */
    font-style: normal;  /* 正常（默认） */
    font-style: oblique; /* 倾斜（强制倾斜） */
}
```

| 值 | 说明 |
|------|------|
| `normal` | 正常 |
| `italic` | 斜体（使用字体的斜体版本） |
| `oblique` | 倾斜（强制将正常字体倾斜） |

> 💡 `italic` 和 `oblique` 在大多数情况下效果相同，但 `italic` 优先使用字体设计的斜体字形。

---

## font-variant 字体变体

```css
p {
    font-variant: small-caps; /* 小型大写字母 */
    font-variant: normal;    /* 正常（默认） */
}
```

- `small-caps`：将小写字母显示为小型大写字母（常用于英文标题）

---

## font 简写属性

```css
p {
    /* 顺序：style variant weight size/line-height family */
    font: italic small-caps bold 20px/1.5 "Microsoft YaHei", sans-serif;
}
```

**简写规则**：

1. `font-size` 和 `font-family` **必须写**，其他可省略
2. `font-size` 和 `line-height` 用 `/` 连接，如 `20px/1.5`
3. 其他属性顺序可变，但建议按规范顺序书写

```css
/* 最简写法（仅必填项） */
font: 20px "Microsoft YaHei";
```

---

## 属性总览

| 属性 | 作用 | 常用值 |
|------|------|--------|
| `font-size` | 字体大小 | `16px`、`20px`、`2em` |
| `font-weight` | 字体粗细 | `bold`、`normal`、`700` |
| `font-family` | 字体族 | `"楷体", sans-serif` |
| `font-style` | 字体风格 | `italic`、`normal` |
| `font-variant` | 字体变体 | `small-caps`、`normal` |
| `font` | 简写 | `bold 20px "微软雅黑"` |
