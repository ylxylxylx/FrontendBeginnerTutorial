# 5、文本样式

## text-align 文本对齐

```css
p {
    text-align: center;  /* 居中对齐 */
    text-align: left;    /* 左对齐（默认） */
    text-align: right;   /* 右对齐 */
    text-align: justify; /* 两端对齐 */
}
```

- 控制块级元素内**文本的水平对齐方式**
- 只对**块级元素**生效，行内元素需先转换为块级

---

## text-indent 首行缩进

```css
p {
    text-indent: 2em;  /* 首行缩进两个字符 */
    text-indent: 40px; /* 首行缩进 40 像素 */
}
```

- `em` 是相对单位，`2em` 表示缩进 2 个字符宽度
- 中文段落常用 `2em` 实现首行缩进

---

## text-decoration 文本装饰

```css
p {
    text-decoration: underline;     /* 下划线 */
    text-decoration: overline;      /* 上划线 */
    text-decoration: line-through;  /* 删除线 */
    text-decoration: none;          /* 无装饰（默认） */
}
```

| 值 | 效果 | 常见用途 |
|------|------|--------|
| `none` | 无装饰 | 去除链接默认下划线 |
| `underline` | 下划线 | 强调文本 |
| `overline` | 上划线 | 较少使用 |
| `line-through` | 删除线 | 原价标注 |

> 💡 常用 `a { text-decoration: none; }` 去除超链接默认下划线。

---

## text-shadow 文本阴影

```css
p {
    text-shadow: 5px 0px 1px gold;
    /* 参数：x偏移 y偏移 模糊距离 颜色 */
}
```

| 参数 | 说明 | 示例值 |
|------|------|--------|
| x 偏移 | 水平偏移，正右负左 | `5px` |
| y 偏移 | 垂直偏移，正下负上 | `0px` |
| 模糊距离 | 值越大越模糊 | `1px` |
| 颜色 | 阴影颜色 | `gold` |

```css
/* 多重阴影用逗号隔开 */
text-shadow: 1px 1px 2px red, -1px -1px 2px blue;
```

---

## text-transform 文本转换

```css
p {
    text-transform: capitalize;  /* 每个单词首字母大写 */
    text-transform: uppercase;   /* 全部大写 */
    text-transform: lowercase;   /* 全部小写 */
    text-transform: none;        /* 无转换（默认） */
}
```

> 主要用于**英文文本**，对中文无效。

---

## word-spacing 单词间距

```css
p {
    word-spacing: 10px; /* 单词之间的间距增加 10px */
}
```

- 控制英文**单词**之间的间距
- 对中文无效（中文无"单词"概念）

---

## letter-spacing 字母/字符间距

```css
p {
    letter-spacing: 10px; /* 字母/字符间距增加 10px */
}
```

- 控制字母或**汉字**之间的间距
- **对中文有效**，常用于中文排版调整

---

## line-height 行高

```css
p {
    line-height: 50px;  /* 行高 50px */
    line-height: 1.5;   /* 行高为字体大小的 1.5 倍 */
    line-height: 200%;  /* 行高为字体大小的 200% */
}
```

**行高公式**：`行高 = 行间距 + 字体大小`

- 当 `line-height` 等于容器高度时，**单行文本垂直居中**
- 无单位值（如 `1.5`）是推荐写法，子元素继承的是比例而非固定值

---

## text-overflow 文本溢出

```css
p {
    text-overflow: clip;     /* 裁剪溢出文本（默认） */
    text-overflow: ellipsis; /* 显示省略号 */
}
```

> ⚠️ `text-overflow: ellipsis` 需配合以下属性才能生效：
> ```css
> white-space: nowrap;    /* 不换行 */
> overflow: hidden;       /* 隐藏溢出 */
> text-overflow: ellipsis; /* 省略号 */
> ```

---

## 并集选择器（选择器分组）

```css
/* 多个选择器共享相同样式 */
h1, h2, h3 {
    color: red;
}
```

- 用**逗号**隔开多个选择器
- 减少重复代码，提高可维护性

---

## 属性总览

| 属性 | 作用 | 常用值 |
|------|------|--------|
| `text-align` | 水平对齐 | `center`、`left`、`right` |
| `text-indent` | 首行缩进 | `2em` |
| `text-decoration` | 文本装饰 | `underline`、`none` |
| `text-shadow` | 文本阴影 | `x y blur color` |
| `text-transform` | 文本转换 | `capitalize`、`uppercase` |
| `word-spacing` | 单词间距 | `10px` |
| `letter-spacing` | 字符间距 | `10px` |
| `line-height` | 行高 | `1.5`、`50px` |
| `text-overflow` | 文本溢出 | `ellipsis` |

transform 转大小写，letter 中文也生效
