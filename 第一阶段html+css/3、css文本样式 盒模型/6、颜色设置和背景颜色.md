# 6、颜色设置和背景颜色

## CSS 颜色表示方式

### 1. 颜色关键字

```css
p {
    color: red;        /* 红色 */
    color: blue;       /* 蓝色 */
    color: gold;       /* 金色 */
    color: aquamarine; /* 碧绿色 */
}
```

- 直接使用英文颜色名称，简单直观
- CSS 支持约 140 种命名颜色

---

### 2. rgb() 函数

```css
p {
    color: rgb(255, 0, 0);     /* 红色 */
    color: rgb(0, 0, 0);       /* 黑色 */
    color: rgb(255, 255, 255); /* 白色 */
}
```

- **R**ed、**G**reen、**B**lue 三原色，取值范围 `0 ~ 255`
- `rgb(0,0,0)` = 黑色，`rgb(255,255,255)` = 白色

---

### 3. rgba() 函数（带透明度）

```css
p {
    color: rgba(255, 0, 0, 1);   /* 完全不透明红色 */
    color: rgba(255, 0, 0, 0.5); /* 半透明红色 */
    color: rgba(255, 0, 0, 0);   /* 完全透明 */
}
```

- 第 4 个参数 **a**（alpha）控制透明度，取值 `0 ~ 1`
- `0` = 完全透明，`1` = 完全不透明

---

### 4. 十六进制表示法

```css
p {
    color: #ff0000;  /* 红色 - 完整6位 */
    color: #f00;     /* 红色 - 缩写3位 */
    color: #fba;     /* 缩写：#ff bbaa → #fba */
}
```

| 格式 | 示例 | 说明 |
|------|------|------|
| 6 位 | `#ff0000` | 每两位代表 R、G、B |
| 3 位缩写 | `#f00` | 每位重复一次，`#f00` = `#ff0000` |
| 8 位（带透明度） | `#ff000080` | 后两位代表 alpha，`00`=透明，`ff`=不透明 |
| 4 位缩写 | `#f008` | `#f008` = `#ff000088` |

> 💡 缩写规则：当每两位相同时可缩写，如 `#aabbcc` → `#abc`，`#ff0000` → `#f00`

---

## 颜色表示方式对比

| 方式 | 示例 | 优点 | 缺点 |
|------|------|------|------|
| 关键字 | `red` | 直观易读 | 颜色有限 |
| rgb() | `rgb(255,0,0)` | 精确控制 | 不支持透明度 |
| rgba() | `rgba(255,0,0,0.5)` | 支持透明度 | 写法较长 |
| 十六进制 | `#ff0000` | 最常用、简洁 | 不直观 |

---

## background-color 背景颜色

```css
div {
    background-color: red;           /* 关键字 */
    background-color: rgb(202, 12, 12); /* rgb */
    background-color: rgba(0,0,0,0.5);  /* 半透明黑 */
    background-color: #ff0000;       /* 十六进制 */
}
```

- 背景颜色同样支持所有颜色表示方式
- 背景颜色填充元素的**内容区 + 内边距区 + 边框区**

---

## 样式继承

```css
body {
    color: red; /* body 设置的文字颜色会被子元素继承 */
}
```

**可继承的样式**：`color`、`font-size`、`font-family`、`line-height`、`text-align`、`text-indent` 等

**不可继承的样式**：`background-color`、`border`、`margin`、`padding`、`width`、`height` 等

> ⚠️ 继承的样式权重最低（权重为 0），任何直接设置的样式都会覆盖继承的样式。
