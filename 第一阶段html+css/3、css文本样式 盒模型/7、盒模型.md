# 7、盒模型

## 盒模型概念

CSS 盒模型是网页布局的基础，每个元素都可以看作一个矩形盒子，由四部分组成：

```
┌─────────────────────────────────┐
│            margin               │
│  ┌───────────────────────────┐  │
│  │         border            │  │
│  │  ┌─────────────────────┐  │  │
│  │  │      padding        │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │   content     │  │  │  │
│  │  │  │   内容区       │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

**盒子总宽度** = `margin-left` + `border-left` + `padding-left` + `content-width` + `padding-right` + `border-right` + `margin-right`

---

## div 块元素特点

```css
div {
    /* div 是块元素，具有以下默认特点 */
    /* 1. 独占一行 */
    /* 2. 默认宽度 = 父元素宽度 */
    /* 3. 可以设置宽度和高度 */
    /* 4. 可以设置 margin/padding/border */
}
```

---

## border 边框

### 边框三要素

```css
div {
    border: 10px solid rgb(202, 12, 12);
    /* 宽度 样式 颜色 */
}
```

| 属性 | 说明 | 常用值 |
|------|------|--------|
| border-width | 边框宽度 | `1px`、`10px` |
| border-style | 边框样式 | `solid`、`dotted`、`dashed` |
| border-color | 边框颜色 | `red`、`#f00`、`rgb()` |

---

### 边框样式值

```css
border-style: solid;   /* 实线 */
border-style: dotted;  /* 点线 */
border-style: dashed;  /* 虚线 */
border-style: double;  /* 双线 */
border-style: groove;  /* 3D 凹槽 */
border-style: ridge;   /* 3D 凸脊 */
border-style: inset;   /* 3D 内嵌 */
border-style: outset;  /* 3D 外凸 */
border-style: none;    /* 无边框 */
```

---

### 单边边框

```css
div {
    border-top: 10px solid red;       /* 上边框 */
    border-bottom: 5px dashed blue;   /* 下边框 */
    border-left: 3px dotted green;    /* 左边框 */
    border-right: 8px double orange;  /* 右边框 */
}
```

---

## padding 内边距

```css
div {
    /* 4 种写法 */
    padding: 20px;              /* 四边相同 */
    padding: 10px 20px;         /* 上下 10px，左右 20px */
    padding: 10px 20px 30px;    /* 上 10px，左右 20px，下 30px */
    padding: 10px 20px 30px 40px; /* 上 右 下 左（顺时针） */
}
```

| 写法 | 值数量 | 含义 |
|------|--------|------|
| 1 个值 | `padding: a` | 四边相同 |
| 2 个值 | `padding: a b` | 上下=a，左右=b |
| 3 个值 | `padding: a b c` | 上=a，左右=b，下=c |
| 4 个值 | `padding: a b c d` | 上=a，右=b，下=c，左=d |

> 💡 顺时针记忆：**上 → 右 → 下 → 左**

### 单边内边距

```css
div {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}
```

---

## margin 外边距

```css
div {
    /* 写法与 padding 相同，支持 1~4 个值 */
    margin: 20px;                /* 四边相同 */
    margin: 10px 20px;           /* 上下 10px，左右 20px */
    margin: 10px auto;           /* 上下 10px，左右自动居中 */
}
```

### 块元素水平居中

```css
div {
    width: 200px;
    margin: 0 auto;  /* 上下 0，左右自动 = 水平居中 */
}
```

> ⚠️ `margin: auto` 居中只对**块级元素**有效，且必须设置**固定宽度**。

---

## 盒模型属性总览

| 属性 | 作用 | 简写支持 |
|------|------|----------|
| `border` | 边框 | `border: 宽度 样式 颜色` |
| `padding` | 内边距 | 支持 1~4 值简写 |
| `margin` | 外边距 | 支持 1~4 值简写 |
| `width` | 内容宽度 | - |
| `height` | 内容高度 | - |

---

## 完整示例

```css
.box {
    width: 200px;          /* 内容宽度 */
    height: 100px;         /* 内容高度 */
    padding: 20px;         /* 内边距 20px */
    border: 5px solid red; /* 边框 5px 实线红色 */
    margin: 10px auto;     /* 外边距：上下10px，水平居中 */
}
/* 盒子总宽度 = 10 + 5 + 20 + 200 + 20 + 5 + 10 = 270px */
```

## 小结

```
盒模型速记：
盒子四层从内到外：内容填充边框距
border 三要素：宽度样式和颜色
solid 实线 dotted 点，dashed 虚线 double 双
padding 简写顺时针，上右下左四个值
margin auto 居中法，块元素加固定宽
总宽计算要记牢：margin 加 border 加 padding 加 width
