# 8、外边距重合和穿透问题

## 一、外边距重合（Margin Collapse）

### 什么是外边距重合？

当两个**垂直相邻**的块元素上下排列时，它们之间的外边距不会叠加，而是**取较大的值**。

```
┌─────────────┐
│   元素 A     │ margin-bottom: 50px
└─────────────┘
       ↕ 实际间距 = max(50, 30) = 50px（不是 80px）
┌─────────────┐
│   元素 B     │ margin-top: 30px
└─────────────┘
```

### 示例

```css
.box1 {
    margin-bottom: 50px; /* 下外边距 50px */
}

.box2 {
    margin-top: 30px; /* 上外边距 30px */
}
/* 实际间距 = 50px（取较大值），不是 80px */
```

---

### 重合规则

| 情况 | 结果 |
|------|------|
| 两个正数 | 取较大值 |
| 一正一负 | 取两者之和 |
| 两个负数 | 取绝对值较大的（即更小的值） |

```css
/* 两个正数 */
margin-bottom: 50px; + margin-top: 30px; → 间距 = 50px

/* 一正一负 */
margin-bottom: 50px; + margin-top: -30px; → 间距 = 20px

/* 两个负数 */
margin-bottom: -50px; + margin-top: -30px; → 间距 = -50px
```

> ⚠️ 外边距重合**只发生在垂直方向**（上下），水平方向（左右）不会重合。

---

### 解决方法

1. **只设置一个方向的外边距**（推荐）
   ```css
   .box1 { margin-bottom: 50px; }
   .box2 { margin-top: 0; } /* 不设 margin-top */
   ```

2. **给父元素添加边框或内边距**（破坏重合条件）

3. **使用浮动或绝对定位**（脱离文档流后不重合）

---

## 二、外边距穿透（Margin Penetration）

### 什么是外边距穿透？

当子元素设置 `margin-top` 时，如果父元素**没有边框（border）**或**没有内边距（padding）**，子元素的 `margin-top` 会"穿透"到父元素外部，导致父元素一起被推下来。

```
┌─────────────────────┐ ← 父元素被一起推下（穿透）
│ ┌─────────────────┐ │
│ │   子元素         │ │ margin-top: 100px
│ └─────────────────┘ │
└─────────────────────┘
```

### 示例

```html
<div class="father">
    <div class="son">子元素</div>
</div>
```

```css
.father {
    width: 200px;
    height: 200px;
    background-color: pink;
    /* 没有设置 border 和 padding */
}

.son {
    width: 100px;
    height: 100px;
    background-color: skyblue;
    margin-top: 100px; /* 穿透！父元素也被推下 */
}
```

---

### 有边框时的情况

```css
.father {
    border: 1px solid black; /* 添加边框后 */
}

.son {
    margin-top: 100px; /* 不再穿透，子元素在父元素内部向下偏移 */
}
```

> 💡 边框就像一堵"墙"，阻止了 margin-top 的穿透。子元素的 margin-top 以父元素的边框为参照。

---

### 解决穿透的方法

| 方法 | 代码 | 说明 |
|------|------|------|
| 给父元素加边框 | `border: 1px solid transparent` | 最常用，可用透明边框 |
| 给父元素加内边距 | `padding-top: 1px` | 1px 即可阻止穿透 |
| 给父元素设置 overflow | `overflow: hidden` | 触发 BFC |
| 使用浮动 | `float: left` | 脱离文档流 |
| 使用绝对定位 | `position: absolute` | 脱离文档流 |

> 💡 **推荐方法**：给父元素加 `border: 1px solid transparent`（透明边框）或 `padding-top: 1px`，简单有效。

---

## 三、重合 vs 穿透 对比

| 特性 | 外边距重合 | 外边距穿透 |
|------|-----------|-----------|
| 发生对象 | 兄弟元素之间 | 父子元素之间 |
| 方向 | 垂直方向 | margin-top |
| 原因 | 相邻外边距合并 | 父元素无边界约束 |
| 核心规则 | 取较大值 | 穿透到父元素外部 |

---
