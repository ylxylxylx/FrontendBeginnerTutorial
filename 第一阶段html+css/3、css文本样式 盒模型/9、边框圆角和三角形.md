# 9、边框圆角和三角形

## 一、border-radius 圆角

### 基本用法

```css
div {
    border-radius: 50px;  /* 四个角都是 50px 圆角 */
}
```

- 值为圆角的**半径**
- 值越大，角越圆

---

### 画圆形

```css
div {
    width: 200px;
    height: 200px;
    border-radius: 50%;  /* 50% = 宽高的一半 = 圆形 */
    background-color: red;
}
```

> 💡 正方形 + `border-radius: 50%` = 圆形；矩形 + `border-radius: 50%` = 椭圆

---

### 单独设置每个角

```css
div {
    /* 分别设置四个角 */
    border-top-left-radius: 50px;     /* 左上角 */
    border-top-right-radius: 50px;    /* 右上角 */
    border-bottom-right-radius: 50px; /* 右下角 */
    border-bottom-left-radius: 50px;  /* 左下角 */
}
```

---

### 简写规则

```css
div {
    border-radius: 10px;              /* 四角相同 */
    border-radius: 10px 20px;         /* 左上右下=10px，右上左下=20px */
    border-radius: 10px 20px 30px;    /* 左上=10px，右上左下=20px，右下=30px */
    border-radius: 10px 20px 30px 40px; /* 左上 右上 右下 左下（顺时针） */
}
```

| 写法 | 值数量 | 含义 |
|------|--------|------|
| 1 个值 | `10px` | 四角相同 |
| 2 个值 | `10px 20px` | 对角线相同：左上右下=10px，右上左下=20px |
| 3 个值 | `10px 20px 30px` | 左上=10px，右上左下=20px，右下=30px |
| 4 个值 | `10px 20px 30px 40px` | 左上→右上→右下→左下（顺时针） |

> 💡 简写顺序与 padding/margin 相同：**顺时针**，从左上角开始。

---

### 圆角胶囊按钮

```css
.button {
    height: 40px;
    padding: 0 20px;
    border-radius: 20px; /* 值 = 高度的一半 → 胶囊形状 */
    background-color: #4CAF50;
    color: white;
}
```

## 二、CSS 三角形

### 原理

利用 `border` 的特性：当元素宽高为 0 时，四条边框会形成四个三角形。

```css
.triangle {
    width: 0;
    height: 0;
    border-top: 100px solid black;      /* 上方三角形（朝下） */
    border-right: 100px solid transparent;  /* 右侧透明 */
    border-bottom: 100px solid transparent; /* 下方透明 */
    border-left: 100px solid transparent;   /* 左侧透明 */
}
```

### 不同方向的三角形

```css
/* 朝下的三角形 ▼ */
.arrow-down {
    width: 0;
    height: 0;
    border-top: 100px solid red;
    border-right: 100px solid transparent;
    border-left: 100px solid transparent;
}

/* 朝上的三角形 ▲ */
.arrow-up {
    width: 0;
    height: 0;
    border-bottom: 100px solid blue;
    border-right: 100px solid transparent;
    border-left: 100px solid transparent;
}

/* 朝右的三角形 ▶ */
.arrow-right {
    width: 0;
    height: 0;
    border-left: 100px solid green;
    border-top: 100px solid transparent;
    border-bottom: 100px solid transparent;
}

/* 朝左的三角形 ◀ */
.arrow-left {
    width: 0;
    height: 0;
    border-right: 100px solid orange;
    border-top: 100px solid transparent;
    border-bottom: 100px solid transparent;
}
```

---

### 三角形方向规律

| 想要的方向 | 有颜色的边框 | 透明边框 |
|-----------|-------------|---------|
| 朝下 ▼ | `border-top` | left + right |
| 朝上 ▲ | `border-bottom` | left + right |
| 朝右 ▶ | `border-left` | top + bottom |
| 朝左 ◀ | `border-right` | top + bottom |

> 💡 记忆技巧：**有颜色的边框在三角形对面的方向**。朝下的三角形 = `border-top` 有颜色。

---

### 实际应用：气泡提示箭头

```css
.tooltip {
    position: relative;
    background-color: #333;
    color: white;
    padding: 10px;
    border-radius: 5px;
}

.tooltip::after {
    content: '';
    position: absolute;
    bottom: -10px;
    left: 20px;
    width: 0;
    height: 0;
    border-top: 10px solid #333;     /* 与背景同色 */
    border-left: 10px solid transparent;
    border-right: 10px solid transparent;
}
```

## 小结

```
圆角三角形速记：
radius 圆角四角调，50% 正方变圆形
顺时针序同 padding，左上右上右下左
单角设置也可行，top-left 到 bottom-left

三角形靠 border 造，宽高为零是关键
有颜色边在对向，透明三边来配合
朝下用 top 有颜色，朝上 bottom 来着色
朝右 left 朝左 right，配合透明就成型
