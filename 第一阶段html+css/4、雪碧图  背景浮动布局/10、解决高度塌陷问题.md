# 10、解决高度塌陷问题

## 什么是高度塌陷？

当子元素设置浮动后，脱离了文档流，父元素无法通过内容撑开高度，导致**父元素高度变为 0**。

```html
<div class="outer">       <!-- 父元素高度塌陷为 0 -->
    <div class="inner1"></div>  <!-- 左浮动 -->
    <div class="inner2"></div>  <!-- 右浮动 -->
</div>
```

```css
.outer {
    background-color: red;
    /* 没有设置固定高度，高度 = 0 */
}

.inner1 {
    float: left;
    height: 100px;
    width: 100px;
    background-color: royalblue;
}

.inner2 {
    float: right;
    height: 100px;
    width: 100px;
    background-color: gold;
}
```

---

## 解决方法

### 方法一：给父元素设置固定高度

```css
.outer {
    height: 100px;  /* 固定高度 */
}
```

**缺点**：不够灵活，无法自适应内容高度。❌ 不推荐

---

### 方法二：添加空元素清除浮动

```html
<div class="outer">
    <div class="inner1"></div>
    <div class="inner2"></div>
    <div style="clear: both;"></div>  <!-- 空元素清除浮动 -->
</div>
```

**缺点**：添加无意义的 HTML 元素，不语义化。❌ 不推荐

---

### 方法三：让父元素也浮动

```css
.outer {
    float: left;  /* 父元素也浮动 */
}
```

**缺点**：父元素浮动后也会影响其兄弟元素，治标不治本。❌ 不推荐

---

### 方法四：开启 BFC

BFC（Block Formatting Context，块级格式化上下文）可以让父元素包含浮动子元素。

```css
.outer {
    overflow: hidden;  /* 开启 BFC */
}
```

**原理**：`overflow: hidden` 触发 BFC，BFC 区域不会与浮动元素重叠。

> ⚠️ `overflow: hidden` 可能会裁剪溢出内容，有副作用。

---

### 方法五：伪元素清除浮动（✅ 推荐）

```css
.clearfix::after {
    content: "";        /* 内容为空 */
    display: block;     /* 设置为块元素 */
    clear: both;        /* 清除左右浮动 */
}
```

```html
<div class="outer clearfix">
    <div class="inner1"></div>
    <div class="inner2"></div>
</div>
```

**优点**：
- ✅ 没有副作用
- ✅ 不需要添加额外 HTML 元素
- ✅ 可复用（给任何父元素加 `.clearfix` 类即可）

---

## 伪元素清除浮动的原理

1. `::after` 伪元素在父元素内容**最后面**生成一个虚拟元素
2. `display: block` 让这个虚拟元素成为块元素
3. `clear: both` 让这个块元素清除浮动，排列在浮动元素下方
4. 父元素需要包含这个块元素，因此高度被撑开

```
没有伪元素：              有伪元素：
┌──────────────┐         ┌──────────────┐
│┌────┐  ┌────┐│         │┌────┐  ┌────┐│
││左浮│  │右浮││         ││左浮│  │右浮││
││动  │  │动  ││         ││动  │  │动  ││
│└────┘  └────┘│         │└────┘  └────┘│
│（高度=0）     │         │┌────────────┐│
└──────────────┘         ││::after 块  ││ ← 清除浮动
                         │└────────────┘│
                         └──────────────┘
                         父元素高度被撑开
```

---

## 五种方法对比

| 方法 | 代码 | 推荐度 | 缺点 |
|------|------|--------|------|
| 固定高度 | `height: 100px` | ❌ | 不自适应 |
| 空元素 | `<div clear>` | ❌ | 不语义化 |
| 父元素浮动 | `float: left` | ❌ | 影响兄弟 |
| overflow | `overflow: hidden` | ⚠️ | 可能裁剪内容 |
| **伪元素** | `.clearfix::after` | ✅ | 无副作用 |

---

## 完整代码模板

```css
/* 清除浮动的通用类 */
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}

/* 也可以加上兼容性处理 */
.clearfix::before,
.clearfix::after {
    content: "";
    display: table;
}

.clearfix::after {
    clear: both;
}
```

```html
<!-- 使用时给父元素加 clearfix 类 -->
<div class="container clearfix">
    <div class="item" style="float: left;">左浮动</div>
    <div class="item" style="float: right;">右浮动</div>
</div>
```

## 小结

```
高度塌陷速记：
子元素浮动脱了流，父元素高度变成零
五种方法来解决：
一设高度不自适，二加空元素不语义
三让父浮治标本，四开 BFC 有副作用
五用伪元素最推荐，after 伪元加 clear
content 为空 display 块，clear both 三件套
clearfix 类随处用，清除浮动无烦恼
