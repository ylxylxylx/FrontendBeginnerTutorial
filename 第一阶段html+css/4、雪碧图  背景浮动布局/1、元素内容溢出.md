# 1、元素内容溢出

## 什么是内容溢出？

当元素的内容（文字、子元素等）超过了元素设定的宽高时，内容会**溢出**元素边界。

```css
.content {
    width: 100px;
    /* div 的高度尽量不设置，让它由内容撑开 */
    /* height: 100px; */
    background-color: cornflowerblue;
}
```

> 💡 实际开发中，块元素的高度一般**不设置**，让内容自动撑开高度，实现自适应。

---

## overflow 属性

`overflow` 控制内容溢出时的显示方式：

```css
.content {
    width: 100px;
    height: 100px;
    overflow: visible; /* 默认值，溢出内容可见 */
}
```

| 值 | 效果 | 说明 |
|------|------|------|
| `visible` | 溢出内容可见 | 默认值，内容超出边界照常显示 |
| `hidden` | 溢出部分隐藏 | 超出部分被裁剪，不可见 |
| `scroll` | 显示滚动条 | 无论是否溢出，始终显示滚动条 |
| `auto` | 自动 | 内容溢出时显示滚动条，不溢出则不显示 |

---

## overflow-x / overflow-y

可以分别控制水平和垂直方向的溢出：

```css
.content {
    overflow-x: hidden; /* 水平方向溢出隐藏 */
    overflow-y: auto;   /* 垂直方向自动滚动条 */
}
```

---

## 单行文本溢出省略号

```css
.content {
    width: 200px;
    overflow: hidden;         /* 溢出隐藏 */
    text-overflow: ellipsis;  /* 溢出部分显示省略号 */
    white-space: nowrap;      /* 文本不换行 */
}
```

**三件套缺一不可**：
1. `white-space: nowrap` — 强制文本不换行
2. `overflow: hidden` — 隐藏溢出内容
3. `text-overflow: ellipsis` — 溢出部分显示 `...`

---

## 多行文本溢出省略号

```css
.content {
    display: -webkit-box;           /* 弹性伸缩盒模型 */
    -webkit-box-orient: vertical;   /* 垂直方向排列 */
    -webkit-line-clamp: 3;          /* 显示 3 行 */
    overflow: hidden;               /* 溢出隐藏 */
}
```

> ⚠️ 多行省略号使用了 WebKit 私有属性，主要在 Chrome/Safari 等浏览器生效。

## overflow 各值对比

```
┌─────────────────────┐
│  visible（默认）     │  内容超出边界照常显示
│  ┌──────┐           │
│  │ 元素 │ 溢出文字...│
│  └──────┘           │
└─────────────────────┘

┌─────────────────────┐
│  hidden             │  超出部分被裁剪
│  ┌──────┐           │
│  │ 元素 │           │  溢出部分不可见
│  └──────┘           │
└─────────────────────┘

┌─────────────────────┐
│  scroll             │  始终显示滚动条
│  ┌──────┐ ║         │
│  │ 元素 │ ║         │  可滚动查看
│  └──────┘ ║         │
└─────────────────────┘

┌─────────────────────┐
│  auto               │  溢出时才显示滚动条
│  ┌──────┐           │  不溢出则无滚动条
│  │ 元素 │           │
│  └──────┘           │
└─────────────────────┘
```
