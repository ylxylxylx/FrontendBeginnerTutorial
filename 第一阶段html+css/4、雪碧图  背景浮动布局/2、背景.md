# 2、背景

## 背景颜色

```css
div {
    background-color: hotpink; /* 设置背景颜色 */
}
```

- 背景颜色填充区域：**内容区 + 内边距区 + 边框区**

---

## 背景图片

```css
div {
    background-image: url(./image.jpg); /* 设置背景图片 */
}
```

- `url()` 内填写图片路径（默认相对路径）
- **大图片**：默认显示图片的**左上角**
- **小图片**：默认**平铺**整个元素

### 图片格式对比

| 格式 | 特点 | 适用场景 |
|------|------|----------|
| JPEG | 色彩丰富，不支持透明 | 照片、复杂图像 |
| PNG | 支持透明 | 图标、需要透明背景的图片 |
| GIF | 支持动图 | 动画、简单图标 |

> ⚠️ 背景图片会**覆盖**背景颜色（图片区域不可见背景色）。

---

## background-repeat 背景平铺

```css
div {
    background-repeat: repeat;     /* 默认，水平和垂直都平铺 */
    background-repeat: no-repeat;  /* 不平铺 */
    background-repeat: repeat-x;   /* 水平方向平铺 */
    background-repeat: repeat-y;   /* 垂直方向平铺 */
}
```

| 值 | 效果 |
|------|------|
| `repeat` | 默认，两个方向都平铺 |
| `no-repeat` | 不平铺，只显示一张 |
| `repeat-x` | 水平方向平铺 |
| `repeat-y` | 垂直方向平铺 |

---

## background-position 背景定位

```css
div {
    /* 关键字定位 */
    background-position: left top;      /* 左上 */
    background-position: right bottom;  /* 右下 */
    background-position: center center; /* 居中 */

    /* 百分比定位 */
    background-position: 100% 0%;  /* 右上角 */
    background-position: 50% 50%;  /* 居中 */

    /* 像素定位 */
    background-position: 10px 20px; /* x偏移10px, y偏移20px */
}
```

- 第一个值：**x 轴**（水平方向）
- 第二个值：**y 轴**（垂直方向）

---

## background-size 背景尺寸

```css
div {
    background-size: 300px;          /* 只设宽度，高度等比缩放 */
    background-size: 300px 200px;    /* 宽度 高度 */
    background-size: 50% 50%;        /* 相对于元素尺寸 */

    /* 关键字 */
    background-size: contain;  /* 完整显示图片 */
    background-size: cover;    /* 完全覆盖元素 */
}
```

| 值 | 效果 | 说明 |
|------|------|------|
| `contain` | 图片完整显示 | 较长边延伸至边框，较短边自适应，**图片完整**但可能留白 |
| `cover` | 完全覆盖元素 | 较短边延伸至边框，较长边自适应，**不留白**但图片可能裁剪 |

```
contain:          cover:
┌──────────┐     ┌──────────┐
│  ┌────┐  │     │ ┌────────┤
│  │图片│  │     │ │ 图片(裁)│
│  │    │  │     │ │        │
│  └────┘  │     │ └────────┤
│  (留白)  │     └──────────┘
└──────────┘     无留白，图片可能不完整
图片完整，可能留白
```

## background-attachment 背景附着

```css
body {
    background-attachment: scroll; /* 默认，跟随页面滚动 */
    background-attachment: fixed;  /* 固定不动 */
}
```

| 值 | 效果 |
|------|------|
| `scroll` | 背景随页面滚动（默认） |
| `fixed` | 背景固定在视口，不随页面滚动 |

> 💡 `fixed` 常用于实现**视差滚动**效果。

---

## background-origin 背景原点

```css
div {
    background-origin: content-box;  /* 从内容区开始 */
    background-origin: padding-box;  /* 从内边距区开始（默认） */
    background-origin: border-box;   /* 从边框外部开始 */
}
```

| 值 | 起始位置 |
|------|----------|
| `padding-box` | 内边距区边缘（默认） |
| `content-box` | 内容区边缘 |
| `border-box` | 边框外边缘 |

---

## background-clip 背景裁剪

```css
div {
    background-clip: content-box;  /* 背景只在内容区显示 */
    background-clip: padding-box;  /* 背景在内边距区内显示 */
    background-clip: border-box;   /* 背景到边框外边缘（默认） */
}
```

| 值 | 裁剪区域 |
|------|----------|
| `border-box` | 到边框外边缘（默认） |
| `padding-box` | 到内边距区边缘 |
| `content-box` | 只在内容区 |

> 💡 `background-origin` 控制背景**从哪开始**，`background-clip` 控制背景**到哪结束**。

---

## background 简写

```css
div {
    /* 顺序：color image repeat position/size attachment */
    background: hotpink url(./bg.jpg) no-repeat center/cover fixed;
}
```

> ⚠️ `position` 和 `size` 用 `/` 分隔，如 `center/cover`。

---

## 属性总览

| 属性 | 作用 | 常用值 |
|------|------|--------|
| `background-color` | 背景颜色 | `red`、`#f00` |
| `background-image` | 背景图片 | `url(路径)` |
| `background-repeat` | 平铺方式 | `no-repeat`、`repeat-x` |
| `background-position` | 背景定位 | `center`、`50% 50%` |
| `background-size` | 背景尺寸 | `cover`、`contain` |
| `background-attachment` | 背景附着 | `fixed`、`scroll` |
| `background-origin` | 背景原点 | `content-box` |
| `background-clip` | 背景裁剪 | `content-box` |
