# 3、雪碧图（精灵图）

## 什么是雪碧图？

雪碧图（CSS Sprite）也叫精灵图，是将**多个小图标整合到一张大图**上的技术。

**优点**：减少请求服务器的次数，加快页面加载速度。

```
传统方式：每个图标单独请求
图标1 → 请求1
图标2 → 请求2
图标3 → 请求3
...（多次请求）

雪碧图方式：一张图包含所有图标
icons.jpg → 请求1（一次请求）
```

---

## 雪碧图原理

通过 `background-image` 引入大图，再用 `background-position` 和 `background-size` 定位到具体的小图标。

```css
.box {
    width: 50px;
    height: 50px;
    background-image: url(./icons.jpg);

    /* 背景图片尺寸设为元素的倍数 */
    background-size: 700% 700%;

    /* 通过位移定位到具体图标 */
    background-position: -500% -200%;
}
```

---

## 实现步骤

### 1. 设置元素尺寸

元素尺寸 = 单个图标的显示尺寸：

```css
.icon {
    width: 50px;
    height: 50px;
}
```

### 2. 引入雪碧图

```css
.icon {
    background-image: url(./icons.jpg);
}
```

### 3. 设置背景尺寸

将背景图片缩放到合适大小，使单个图标恰好填满元素：

```css
.icon {
    /* 如果雪碧图是 7×7 的图标网格 */
    background-size: 700% 700%;
    /* x 和 y 都设为 700%，即图片宽高 = 元素宽高 × 7 */
}
```

> 💡 `background-size` 的百分比是**相对于元素尺寸**的。`700%` 表示图片宽度 = 元素宽度 × 7。

### 4. 定位到具体图标

```css
.icon-1 {
    background-position: 0% 0%;       /* 第1行第1列 */
    background-position: -200% 0%;    /* 第1行第3列 */
    background-position: -500% -200%; /* 第3行第6列 */
}
```

- 负值表示向左/向上移动背景图片
- 通过调整 x 和 y 的百分比定位到不同的图标

---

## 使用 CSS 类管理图标

```css
/* icons.css - 统一管理雪碧图 */
.icon {
    display: inline-block;
    background-image: url(./icons.jpg);
    background-size: 700% 700%;
    background-repeat: no-repeat;
}

/* 每个图标单独定义位置 */
.icon-clock {
    width: 50px;
    height: 50px;
    background-position: -500% -200%;
}

.icon-search {
    width: 50px;
    height: 50px;
    background-position: -300% 0%;
}
```

```html
<!-- HTML 中使用 -->
<div class="icon icon-clock"></div>
<div class="icon icon-search"></div>
```

## 雪碧图 vs 现代方案

| 对比项 | 雪碧图 | 图标字体 | SVG 图标 |
|--------|--------|----------|----------|
| 原理 | 背景定位 | 字体渲染 | 矢量图形 |
| 缩放 | 模糊 | 清晰 | 清晰 |
| 颜色 | 需重新制作 | CSS 控制 | CSS 控制 |
| 维护 | 合图麻烦 | 更新字体 | 单个文件 |
| 兼容性 | 极好 | 好 | 好 |

> 💡 现代开发中，**图标字体（如 Font Awesome）**和 **SVG 图标**更为常用，但雪碧图原理仍需掌握。
