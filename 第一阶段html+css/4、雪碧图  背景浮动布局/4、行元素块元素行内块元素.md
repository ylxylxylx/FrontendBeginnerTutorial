# 4、行元素、块元素、行内块元素

## HTML 元素的布局分类

HTML 元素按照布局方式分为三大类：

| 类型 | 英文名 | 特点 |
|------|--------|------|
| 块元素 | block | 独占一行，可设宽高 |
| 行元素 | inline | 不独占一行，不可设宽高 |
| 行内块元素 | inline-block | 不独占一行，可设宽高 |

---

## 一、块元素（Block）

### 特点

1. **独占一行**，从上到下排列
2. 默认宽度 = **父元素宽度**（100%）
3. 默认高度 = **内容撑开**（无内容则为 0）
4. **可以设置宽度和高度**
5. 可以包含行元素和行内块元素

### 常见块元素

```
div、h1~h6、p、hr、ul、li、table、form
```

```html
<div class="box"></div>  <!-- 独占一行，可设宽高 -->
```

```css
.box {
    height: 100px;
    border: 1px solid #000;
    background-color: lawngreen;
}
```

---

## 二、行元素（Inline）

### 特点

1. **不独占一行**，从左到右排列，自动换行
2. 宽度和高度**不能设置**，由内容撑开
3. 只能包含文本和其他行元素

### 常见行元素

```
a、span、i、b、u、s、q、em、strong
```

```html
<a href="#">超链接1</a>
<a href="#">超链接2</a>
<a href="#">超链接3</a>
<!-- 三个链接在同一行排列 -->
```

```css
a {
    height: 100px; /* ❌ 对行元素无效 */
}
```

> ⚠️ 行元素设置 `width` 和 `height` **无效**，上下 `margin` 也无效。

---

## 三、行内块元素（Inline-Block）

### 特点

1. **不独占一行**，从左到右排列，自动换行
2. **可以设置宽度和高度**
3. 只设置一个方向，另一个方向会**等比自适应**

### 常见行内块元素

```
input、button、img、select、textarea
```

```html
<input type="text">  <!-- 可设宽高，不独占一行 -->
<img src="./logo.png" alt="">  <!-- 图片可设宽高 -->
```

---

## 三种元素对比

| 特性 | 块元素 | 行元素 | 行内块元素 |
|------|--------|--------|------------|
| 独占一行 | ✅ 是 | ❌ 否 | ❌ 否 |
| 设置宽高 | ✅ 可以 | ❌ 不可以 | ✅ 可以 |
| 默认宽度 | 父元素 100% | 内容撑开 | 内容撑开 |
| 默认高度 | 内容撑开 | 内容撑开 | 内容撑开 |
| 排列方向 | 从上到下 | 从左到右 | 从左到右 |
| 包含关系 | 可含行/行内块 | 只含文本/行 | - |

---

## display 属性转换元素类型

```css
div {
    display: inline;        /* 块元素 → 行元素 */
}

a {
    display: block;         /* 行元素 → 块元素 */
}

span {
    display: inline-block;  /* 行元素 → 行内块元素 */
}
```

| display 值 | 转换为 | 说明 |
|------------|--------|------|
| `block` | 块元素 | 可设宽高，独占一行 |
| `inline` | 行元素 | 不可设宽高，同行排列 |
| `inline-block` | 行内块元素 | 可设宽高，同行排列 |
| `none` | 隐藏元素 | 元素不显示，不占空间 |

> 💡 `div` 之所以是块元素，是因为它的 `display` 默认值是 `block`。同理，`a` 的默认值是 `inline`。

---

## 浏览器默认外边距

```css
* {
    margin: 0;
    padding: 0;
}
```

- 浏览器会默认给 `body` 元素添加约 **8px 的外边距**
- 实际开发中通常使用通配符选择器清除默认边距
