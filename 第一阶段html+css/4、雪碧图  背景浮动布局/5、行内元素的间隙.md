# 5、行内元素的间隙

## 问题：行内元素之间的空隙

当行内元素（如 `<a>`）在 HTML 中换行书写时，元素之间会出现**不可见的空隙**：

```html
<div>
    <a href="#">智游</a>
    <a href="#">智游</a>
    <a href="#">智游</a>
</div>
<!-- 三个 <a> 之间会有间隙 -->
```

**原因**：HTML 中的换行符、空格、制表符会被浏览器渲染为**空白字符**（约 4px 宽度）。

---

## 解决方法

### 方法一：父元素 font-size: 0

```css
div {
    font-size: 0;  /* 消除空白字符的宽度 */
}

a {
    font-size: 16px;  /* 子元素恢复字体大小 */
}
```

**原理**：空白字符也是字符，`font-size: 0` 使其宽度为 0。

---

### 方法二：元素写在一行

```html
<a href="#">智游</a><a href="#">智游</a><a href="#">智游</a>
```

**缺点**：代码可读性差，不符合书写习惯。

---

### 方法三：word-spacing 负值

```css
div {
    word-spacing: -50px;  /* 词间距设为负值 */
}
```

**原理**：空白字符属于"词间距"，设为负值可消除间隙。

---

### 方法四：负外边距

```css
a {
    margin-left: -2px;  /* 用负 margin 抵消间隙 */
}
```

**缺点**：间隙大小不固定，需要调试具体数值。

---

### 方法五：浮动布局（推荐）

```css
a {
    float: left;  /* 浮动后元素紧密排列，无间隙 */
}
```

**原理**：浮动元素脱离文档流，不再受空白字符影响。

---

## 五种方法对比

| 方法 | 代码 | 优点 | 缺点 |
|------|------|------|------|
| font-size: 0 | 父元素设 0，子元素恢复 | 简单 | 需要子元素重新设置字体 |
| 写在一行 | HTML 不换行 | 无需 CSS | 可读性差 |
| word-spacing | 负值 | 简单 | 可能影响其他文本 |
| 负 margin | margin: -2px | 灵活 | 数值不精确 |
| **浮动** | float: left | ✅ 最常用 | 需要清除浮动 |

> 💡 **推荐方法**：使用浮动布局，既解决间隙问题，又是实际开发中的常用布局方式。

---

## 小结

```
