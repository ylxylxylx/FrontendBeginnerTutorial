# 6、文档流

## 什么是文档流？

文档流（Normal Flow）是浏览器默认的元素排列方式：

- **块元素**：从**上到下**排列，独占一行
- **行元素**：从**左到右**排列，自动换行

每个元素都有自己相应的位置，这种布局方式称为**流式布局**。

```
文档流示意：

┌───────────────────────┐
│    块元素1（div）       │  ← 独占一行
├───────────────────────┤
│    块元素2（p）         │  ← 独占一行
├───────────────────────┤
│ 行元素1 行元素2 行元素3 │  ← 左到右排列
├───────────────────────┤
│    块元素3（h1）        │  ← 独占一行
└───────────────────────┘
```

---

## 布局方式可以改变

通过 `display` 属性可以改变元素的布局方式：

```css
div {
    display: block;         /* 块元素（默认） */
    display: inline;        /* 行元素 */
    display: inline-block;  /* 行内块元素 */
    display: none;          /* 隐藏，脱离文档流 */
}
```

### display 值与布局

| display 值 | 帀局方式 | 焩占一行 | 可设宽高 |
|------------|---------|---------|---------|
| `block` | 块元素 | ✅ 是 | ✅ 可以 |
| `inline` | 行元素 | ❌ 否 | ❌ 不可以 |
| `inline-block` | 行内块 | ❌ 否 | ✅ 可以 |
| `none` | 隐藏 | - | - |

> 💡 元素的布局方式不是固定的，`div` 默认 `block` 是因为浏览器设置了 `display: block`。

---

## 脱离文档流

以下方式会让元素脱离文档流：

| 方式 | 说明 |
|------|------|
| `float: left/right` | 浮动脱离文档流 |
| `position: absolute` | 绝对定位脱离文档流 |
| `position: fixed` | 固定定位脱离文档流 |
| `display: none` | 隠除元素，不占空间 |

> ⚠️ 元素脱离文档流后，不再参与流式布局，可能影响其他元素的位置。

---

## 嵌套规则

### 块元素可以包含行元素

```html
<div>
    <a href="#">链接</a>  ✅ 正确
</div>
```

### 行元素不能包含块元素

```html
<a href="#">
    <p>段落</p>  ❌ 不规范
</a>
```

> ⚠️ 行元素（如 `<a>`）不应包含块元素（如 `<p>`、`<div>`），虽然浏览器可能会容错渲染，但不符合规范。
