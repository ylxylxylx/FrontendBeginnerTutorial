# 7、浮动布局

## 为什么使用浮动？

传统文档流中，块元素**独占一行**，无法实现左右并排布局。浮动可以让块元素**不再独占一行**，实现多列布局。

> CSS 布局三大核心：**浮动 + 定位 + div**

---

## float 属性

```css
div {
    float: left;   /* 左浮动 */
    float: right;  /* 右浮动 */
    float: none;   /* 不浮动（默认） */
}
```

---

## 浮动的特点

### 1. 脱离文档流

设置浮动后，元素**不再参与流式布局**，块元素不再独占一行。

```css
.box {
    float: left;
    height: 100px;
    width: 100px;
    background-color: red;
}
/* 多个 .box 会在同一行从左到右排列 */
```

### 2. 宽高由内容撑开

浮动后，块元素的默认宽高**由内容撑开**（不再是父元素 100% 宽度）。

### 3. 层级上调

浮动元素的层级会**上调**，可能覆盖未浮动的元素。

### 4. 不会超过上面的兄弟元素

浮动元素**不会超过**它上面的兄弟元素，最多与上面的元素**一边齐**。

```
┌──────────┐
│ 未浮动元素 │
└──────────┘
┌────┐┌────┐┌────┐
│浮动││浮动││浮动│  ← 不会超过上面的元素
└────┘└────┘└────┘
```

### 5. 不会覆盖文字

浮动元素**不会覆盖文字内容**，文字会环绕浮动元素排列，实现**文字环绕效果**。

```html
<div class="outer">
    <div class="inner"></div>
    这是一段文字，会环绕浮动的元素显示...
</div>
```

```
┌──────────────────┐
│┌────┐这是一段文字 │
││浮动│环绕浮动元素 │
││元素│显示的文字内 │
│└────┘容会自动排列 │
└──────────────────┘
```

---

## 浮动对父元素的影响：高度塌陷

### 什么是高度塌陷？

父元素在文档流中的高度是由内容撑开的。子元素一旦浮动脱离文档流，文档流中就没有该元素的位置，**父元素高度变为 0**。

```html
<div class="main">       <!-- 父元素高度塌陷为 0 -->
    <div class="content"></div>  <!-- 子元素浮动 -->
</div>
```

```css
.main {
    background-color: yellow;
    /* 没有设置高度，由内容撑开 */
    /* 但子元素浮动后，高度塌陷为 0 */
}

.content {
    float: right;
    height: 100px;
    width: 100px;
    background-color: hotpink;
}
```

```
正常：                   塌陷：
┌──────────────┐        ───────────────
│┌────┐        │        ┌────┐（脱离文档流）
││子元│        │        │子元│
││素  │        │        │素  │
│└────┘        │        └────┘
└──────────────┘
父元素有高度              父元素高度为 0
```

---

## 浮动属性总览

| 属性值 | 效果 |
|--------|------|
| `float: left` | 左浮动，元素向左排列 |
| `float: right` | 右浮动，元素向右排列 |
| `float: none` | 不浮动（默认） |

---

## 浮动特点总结

| 特点 | 说明 |
|------|------|
| 脱离文档流 | 不再参与流式布局 |
| 不独占一行 | 块元素可左右并排 |
| 宽高由内容撑开 | 默认不再占满父元素宽度 |
| 层级上调 | 可能覆盖未浮动元素 |
| 不超过上方兄弟 | 最多与上方元素一边齐 |
| 不覆盖文字 | 文字会环绕浮动元素 |
| 引起高度塌陷 | 父元素高度可能变为 0 |
