# 8、内联元素设置浮动

## 核心规则：浮动让行元素变成块元素

行元素（如 `<a>`）设置浮动后，会**自动变成块元素**，可以设置宽度和高度。

```css
a {
    float: left;           /* 设置浮动 */
    height: 100px;         /* ✅ 现在可以设置高度了！ */
    width: 100px;          /* ✅ 现在可以设置宽度了！ */
    background-color: yellow;
}
```

```html
<a href="#">超链接</a>
<!-- 浮动后，<a> 变成块元素，可设宽高 -->
```

---

## 浮动前 vs 浮动后

| 特性 | 浮动前（行元素） | 浮动后 |
|------|-----------------|--------|
| 独占一行 | ❌ 否 | ❌ 否（但可并排） |
| 设置宽高 | ❌ 不可以 | ✅ 可以 |
| 默认宽度 | 内容撑开 | 内容撑开 |
| 排列方式 | 从左到右 | 从左到右（浮动方向） |

---

## 为什么行元素浮动后能设宽高？

浮动让元素脱离文档流，行元素脱离文档流后**自动具有块元素的特性**，因此可以设置宽度和高度。

这相当于同时执行了：
```css
a {
    float: left;   /* 浮动 */
    /* 隐含效果：display 变为 block */
}
```

---

## 实际应用：导航栏

```html
<nav>
    <a href="#">首页</a>
    <a href="#">新闻</a>
    <a href="#">关于</a>
</nav>
```

```css
nav a {
    float: left;           /* 左浮动，横向排列 */
    width: 100px;          /* 可设宽度 */
    height: 40px;          /* 可设高度 */
    line-height: 40px;     /* 文字垂直居中 */
    text-align: center;    /* 文字水平居中 */
    text-decoration: none; /* 去除下划线 */
    background-color: #333;
    color: white;
}
```

> 💡 这是制作**水平导航栏**的经典方法：行元素 + 浮动 = 可设宽高的横向排列元素。
