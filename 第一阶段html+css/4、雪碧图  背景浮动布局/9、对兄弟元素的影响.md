# 9、浮动对兄弟元素的影响

## 问题：浮动元素影响后面的兄弟

当一个元素浮动后，后面的**未浮动兄弟元素**会占据浮动元素原来的文档流位置，导致布局错乱。

```
正常布局：              红色浮动后：
┌────┐┌────┐┌────┐     ┌────┐┌────┐
│ 红 ││ 蓝 ││ 绿 │     │ 红 ││ 蓝 │  ← 蓝色占据红色原来的位置
└────┘└────┘└────┘     └────┘└────┘
                              ┌────┐
                              │ 绿 │
                              └────┘
```

---

## clear 属性：清除浮动

`clear` 属性可以清除浮动对兄弟元素的影响，让元素回到正确的位置。

```css
.green {
    clear: left;   /* 清除左浮动的影响 */
    clear: right;  /* 清除右浮动的影响 */
    clear: both;   /* 清除左右浮动的影响 */
    clear: none;   /* 不清除（默认） */
}
```

| 值 | 效果 |
|------|------|
| `left` | 清除左浮动，元素不会排列在左浮动元素旁边 |
| `right` | 清除右浮动，元素不会排列在右浮动元素旁边 |
| `both` | 清除左右浮动，元素不会排列在浮动元素旁边 |
| `none` | 不清除（默认） |

---

## 示例

### 不清除浮动

```css
.red {
    width: 100px;
    height: 100px;
    background-color: red;
    float: left;  /* 左浮动 */
}

.blue {
    width: 100px;
    height: 100px;
    background-color: blue;
    float: right; /* 右浮动 */
    /* 蓝色会占据红色原来的文档流位置 */
}

.green {
    width: 200px;
    height: 200px;
    background-color: green;
    /* 绿色会被浮动元素影响，位置错乱 */
}
```

### 清除浮动

```css
.blue {
    float: right;
    clear: left;  /* 清除左浮动的影响 */
}

.green {
    clear: both;  /* 同时清除左浮动和右浮动 */
    /* 绿色回到正确的位置 */
}
```

---

## clear 的工作原理

`clear` 并不是真的"清除"了浮动，而是让元素**移动到浮动元素的下方**，不再与浮动元素并排。

```
clear 前：              clear 后：
┌────┐                 ┌────┐
│浮动│┌────┐            │浮动│
│元素││兄弟│            │元素│
└────┘│元素│            └────┘
      └────┘            ┌────┐
                        │兄弟│
                        │元素│
                        └────┘
```

---

## clear 的局限性

- `clear` 只能清除**前面**浮动元素的影响
- `clear` 不能解决**父元素高度塌陷**问题
- `clear` 需要在每个受影响的元素上单独设置

> 💡 解决高度塌陷问题，需要使用伪元素清除浮动（详见下一节）。
