# 简单布局

> 本节学习使用浮动（float）完成经典的页面三栏布局，这是 CSS 布局入门的重要实践。

## 经典页面结构

一个典型的网页由以下区域组成：

| 区域 | 说明 | 常见宽度 |
|------|------|----------|
| header | 页面顶部（导航栏、Logo） | 与容器同宽 |
| main | 主体内容区 | 与容器同宽 |
| ├ left | 左侧栏（侧边导航） | 较窄，约 100px |
| ├ center | 中间内容 | 最宽，约 500px |
| └ right | 右侧栏（广告、推荐） | 较窄，约 100px |
| footer | 页面底部（版权信息） | 与容器同宽 |

## 布局实现

### 外层容器

```css
.box {
    width: 1000px;
    margin: 0 auto;    /* 水平居中 */
    padding: 50px;
}
```

### 头部和底部

```css
.header {
    width: 800px;
    height: 50px;
}

.footer {
    width: 800px;
    height: 100px;
}
```

### 主体三栏布局

```css
.main {
    width: 800px;
    height: 400px;
    padding: 20px;
}

.left {
    float: left;       /* 左浮动 */
    width: 100px;
}

.center {
    float: left;       /* 左浮动，紧跟左侧栏 */
    width: 500px;
    margin-left: 30px; /* 与左侧栏保持间距 */
}

.right {
    float: right;      /* 右浮动 */
    width: 100px;
}
```

## 布局要点

1. **容器居中**：外层 `margin: 0 auto` 实现整体居中
2. **三栏浮动**：左栏和中间用 `float: left`，右栏用 `float: right`
3. **间距控制**：用 `margin-left` 在栏之间添加间距
4. **清除浮动**：父元素需清除浮动，防止高度塌陷

> ⚠️ 使用浮动布局后，别忘了在父元素上清除浮动（clearfix），否则会出现高度塌陷问题。

## 速记口诀

> 外层居中 auto 定，头部底部定宽高；
> 三栏左右浮起来，中间左浮跟旁边；
> 间距全靠 margin 排，清除浮动别忘了。
