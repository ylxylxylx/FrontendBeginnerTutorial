# 伪类和伪元素

> 本节学习 CSS 伪类（元素特殊状态）和伪元素（元素特殊位置），以及 visibility 与 display:none 的区别。

## 伪类 — 元素的特殊状态

伪类用**单冒号** `:` 表示，用于选择元素的某种状态。

### 链接伪类

| 伪类 | 说明 | 触发时机 |
|------|------|---------|
| `a:link` | 未访问的链接 | 页面加载后未点击 |
| `a:visited` | 已访问的链接 | 点击过该链接 |
| `a:hover` | 鼠标悬浮 | 鼠标移到元素上 |
| `a:active` | 激活状态 | 鼠标按下未松开 |

> ⚠️ 链接伪类的书写顺序：**L-V-H-A**（link → visited → hover → active），否则可能失效！

```css
a:link    { color: blue; }     /* 未访问 - 蓝色 */
a:visited { color: purple; }   /* 已访问 - 紫色 */
a:hover   { color: red; }      /* 悬浮 - 红色 */
a:active  { color: orange; }   /* 点击 - 橙色 */
```

### 表单伪类

| 伪类 | 说明 | 适用元素 |
|------|------|---------|
| `:focus` | 获取焦点 | input、textarea |

```css
input:focus {
    border-color: blue;   /* 输入框获得焦点时边框变蓝 */
    outline: none;        /* 去掉默认轮廓线 */
}
```

### 鼠标指针 — cursor

| 值 | 效果 |
|----|------|
| `default` | 默认箭头 |
| `pointer` | 小手（可点击） |
| `text` | 文本选择光标 |
| `move` | 移动光标 |
| `not-allowed` | 禁止 |

```css
.clickable {
    cursor: pointer;  /* 鼠标悬浮显示小手 */
}
```

## 伪元素 — 元素的特殊位置

伪元素用**双冒号** `::` 表示，用于选择元素的某个虚拟部分。

| 伪元素 | 说明 | 必须属性 |
|--------|------|---------|
| `::before` | 元素内容**之前**插入 | `content: ""` |
| `::after` | 元素内容**之后**插入 | `content: ""` |
| `::first-line` | 元素**第一行** | — |
| `::first-letter` | 元素**第一个字母/汉字** | — |

### ::before 和 ::after

```css
/* 必须设置 content 属性，否则不显示 */
.quote::before {
    content: "「";
}

.quote::after {
    content: "」";
}
```

> ⚠️ `::before` 和 `::after` 必须设置 `content` 属性，否则伪元素不会显示！

### ::first-line 和 ::first-letter

```css
p::first-line {
    font-weight: bold;     /* 首行加粗 */
}

p::first-letter {
    font-size: 2em;        /* 首字母放大 */
    color: red;
}
```

## visibility vs display:none

两种隐藏元素的方式有本质区别：

| 属性 | 隐藏效果 | 文档流位置 | 事件响应 |
|------|---------|-----------|---------|
| `visibility: hidden` | 元素不可见 | **保留**（占位） | 不响应 |
| `visibility: visible` | 元素可见（默认） | — | — |
| `display: none` | 元素不可见 | **消失**（不占位） | 不响应 |

```css
/* 隐藏但保留位置 — 适合 tooltip 提示框 */
.hint {
    visibility: hidden;
}

.hint:hover {
    visibility: visible;   /* 悬浮时显示 */
}

/* 隐藏且不占位置 — 适合下拉菜单 */
.menu {
    display: none;
}

.menu:hover {
    display: block;        /* 悬浮时显示 */
}
```

> 💡 **选择建议**：需要保留占位空间用 `visibility`，不需要占位用 `display:none`

## 速记口诀

> 伪类单冒选状态，L-V-H-A 顺序排；
> 伪元素双冒选位置，before after 加 content；
> first-line 选首行，first-letter 选首字；
> hidden 占位看不见，display none 彻底没。
