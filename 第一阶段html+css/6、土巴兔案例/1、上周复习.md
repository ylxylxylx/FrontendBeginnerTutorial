## CSS 三大特性

| 特性 | 说明 | 示例 |
|------|------|------|
| 层叠性 | 同一属性后写覆盖先写 | 后面的 `color` 覆盖前面的 |
| 优先级 | 权重高的优先 | `!important` > 行内 > id > class > 标签 |
| 继承性 | 子元素继承父元素某些属性 | `color`、`font-size` 可继承 |

## 常用选择器

| 选择器 | 写法 | 权重 |
|--------|------|------|
| 标签选择器 | `div { }` | 0,0,0,1 |
| class 选择器 | `.box { }` | 0,0,1,0 |
| id 选择器 | `#main { }` | 0,1,0,0 |
| 通配符选择器 | `* { }` | 0,0,0,0 |
| 行内样式 | `style=""` | 1,0,0,0 |
| !important | `color: red !important;` | 最高 |

## 知识脉络

```
CSS 样式
├── 文本样式：font-size / font-weight / font-family / text-align / text-decoration
├── 盒模型：content + padding + border + margin
├── 背景知识：background-color / background-image / background-position / background-size
└── 布局
    ├── 文档流（默认流式布局）
    │   └── 问题：块元素独占一行 → display 转行内块
    ├── 浮动布局（float）
    │   └── 问题：元素位置还需调整 → position 定位
    └── 定位布局（position）
        └── div + float + position 完成页面布局
```

## 行内元素间隙问题

行内元素（如 img）之间会出现间隙，解决方案：

```css
/* 方案：父元素设置 font-size: 0 */
div {
    font-size: 0;  /* 消除行内元素间隙 */
}

img {
    /* 图片恢复正常大小需单独设置 font-size */
}
```

## 布局总结

| 布局方式 | 特点 | 适用场景 |
|---------|------|---------|
| 文档流 | 默认，块元素独占一行 | 简单上下排列 |
| display: inline-block | 行内块，可设宽高 | 导航条、按钮组 |
| float | 脱离文档流，横向排列 | 多栏布局 |
| position | 精确定位 | 覆盖层、固定元素 |

## 速记口诀

> CSS 三性叠优继，选择器权重要牢记；
> 文本盒模加背景，文档流是默认局；
> 块独占行转行内块，浮动横向来排列；
> 位置不对用定位，div + float + position 三件套。
