# 土巴兔案例

> 本案例是一个综合实战项目，模拟土巴兔装修网站页面，综合运用浮动、定位、雪碧图、伪类等知识。

## 页面结构

```
页面
├── banner        顶部横幅广告（背景图居中）
├── nav_bck       导航条背景区
│   └── nav       导航条（左浮动 + 右浮动）
│       ├── nav_left    左侧：城市选择
│       └── nav_right   右侧：登录/注册/商家中心
├── header        第二导航条
│   ├── Logo（雪碧图）
│   ├── 导航链接（浮动 li）
│   ├── 搜索框
│   └── 下拉菜单（定位 + display:none）
├── main          主体内容区
│   ├── main_left   左侧内容（float:left）
│   └── main_right  右侧推荐（float:right）
└── fixed         右下角固定栏（position:fixed）
```

## 涉及知识点

| 知识点 | 应用位置 |
|--------|---------|
| 浮动布局 | nav_left/nav_right、header li、main_left/main_right |
| 清除浮动 | clearfix 伪元素法 |
| 雪碧图 | Logo、搜索图标、二维码图标 |
| 定位 | 下拉菜单（absolute）、固定栏（fixed） |
| :hover 伪类 | 导航悬浮效果、下拉菜单显示 |
| display:none | 下拉菜单隐藏/显示 |
| 行高垂直居中 | line-height = height |
| 背景图居中 | background-position: center |

## 核心实现

### 1. 清除浮动（clearfix）

```css
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}
```

### 2. 导航条浮动布局

```css
.nav_left {
    float: left;    /* 左浮动 */
}

.nav_right {
    float: right;   /* 右浮动 */
}

.nav ul li {
    float: left;           /* li 横向排列 */
    margin-left: 30px;     /* 项间距 */
    padding: 10px;
}
```

### 3. 雪碧图使用

```css
/* Logo — 从雪碧图中截取 */
#header_bckimg {
    width: 145px;
    height: 50px;
    background-image: url(./imgs/sprite.png);
    background-position: 2px 165px;  /* 偏移到Logo位置 */
}

/* 搜索图标 */
.header i {
    display: inline-block;
    width: 20px;
    height: 20px;
    background-image: url(./imgs/sprite.png);
    background-position: -205px 95px;
}
```

### 4. 下拉菜单（定位 + display）

```css
/* 商家中心下拉 */
.shoopcenter {
    position: relative;   /* 父元素相对定位 */
}

.shoopcenter_item {
    position: absolute;   /* 子元素绝对定位 */
    display: none;        /* 默认隐藏 */
}

.shoopcenter:hover .shoopcenter_item {
    display: block;       /* 悬浮时显示 */
    background-color: white;
    z-index: 5;           /* 提高层级 */
}
```

### 5. 固定栏

```css
.fixed {
    width: 70px;
    background-color: white;
    position: fixed;       /* 固定定位 */
    right: 0;              /* 右侧 */
    bottom: 100px;         /* 底部上方100px */
}
```

### 6. 行高垂直居中

```css
.header li {
    float: left;
    line-height: 50px;   /* 行高等于高度，文字垂直居中 */
}
```

## 页面布局要点

1. **整体居中**：`margin: 0 auto` + 固定宽度
2. **导航条**：左浮动 + 右浮动，clearfix 清除
3. **下拉菜单**：子绝父相 + display:none/block
4. **雪碧图**：一张图多个图标，用 background-position 截取
5. **固定元素**：position:fixed 固定在视口

> ⚠️ 综合案例中，布局顺序：先整体结构 → 再局部细节 → 最后交互效果。
