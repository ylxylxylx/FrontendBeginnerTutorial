# 浮动的影响

> 本节通过实例演示浮动元素对父容器和兄弟元素的影响，理解浮动布局中的常见问题。

## 浮动元素的特点

当一个元素设置 `float` 后：

1. **脱离文档流**：不再占据原来的空间
2. **宽度由内容决定**：不再撑满父容器
3. **可以向左或向右排列**：直到碰到容器边缘或另一个浮动元素

## 实例分析

### 浮动子元素对父容器的影响

```css
.outer {
    width: 1000px;
    height: 500px;
    background-color: red;
}

.inner {
    height: 300px;
    background-color: blue;
    float: right;     /* 右浮动 */
}
```

**现象**：
- `.inner` 设置 `float: right` 后，向右浮动
- `.inner` 的宽度**不再撑满**父容器，而是由内容决定
- 如果 `.inner` 没有设置宽度，宽度会收缩到内容宽度

### hover 改变宽度

```css
.inner:hover {
    width: 300px;
    height: 300px;
}
```

**现象**：
- 鼠标悬浮时，浮动元素变为 300×300
- 再次移开鼠标，宽度恢复为内容宽度

## 浮动带来的问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 父容器高度塌陷 | 浮动子元素不占高度 | 清除浮动（clearfix） |
| 兄弟元素位置异常 | 浮动元素脱离文档流 | clear: both |
| 浮动元素宽度收缩 | 脱离文档流后宽度由内容决定 | 显式设置 width |

> ⚠️ 浮动元素一定要设置明确的宽度，否则宽度会收缩到内容宽度，导致布局不可控。

## 速记口诀

> 浮动一设离文档，宽度收缩看内容；
> 父容器高会塌陷，兄弟位置也混乱；
> 宽高明确要写好，清除浮动别忘了。
