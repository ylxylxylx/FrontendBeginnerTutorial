# 浮动清除的方法

> 本节系统总结 8 种清除浮动的方法，分析各自的优缺点和适用场景。

## 为什么需要清除浮动？

浮动元素脱离文档流，导致父容器**无法自动获取高度**（高度塌陷），影响后续布局。

## 8 种清除浮动方法

### 方法一：父级 div 定义 height

```css
.parent {
    height: 200px;  /* 手动指定高度 */
}
```

| 项目 | 说明 |
|------|------|
| 原理 | 手动定义高度，解决父级无法自动获取高度的问题 |
| 优点 | 简单、代码少、容易掌握 |
| 缺点 | 只适合高度固定的布局，需给出精确高度 |
| 建议 | ⚠️ 不推荐，仅限高度固定的布局 |

### 方法二：结尾处加空 div 标签 clear:both

```html
<div class="parent">
    <div class="child" style="float:left;"></div>
    <div style="clear:both;"></div>  <!-- 空div清除浮动 -->
</div>
```

| 项目 | 说明 |
|------|------|
| 原理 | 添加空 div，利用 clear:both 清除浮动 |
| 优点 | 简单、代码少、浏览器支持好 |
| 缺点 | 页面浮动多时需增加很多空 div |
| 建议 | ⚠️ 不推荐，但这是以前主要使用的方法 |

### 方法三：父级 div 定义伪类 :after 和 zoom（推荐）

```css
.clearfix::after {
    content: "";
    display: block;
    clear: both;
    visibility: hidden;
    height: 0;
}
.clearfix {
    zoom: 1;  /* 兼容 IE6/7 */
}
```

| 项目 | 说明 |
|------|------|
| 原理 | 伪元素生成清除浮动的块级元素，zoom 兼容旧 IE |
| 优点 | 浏览器支持好，大型网站都在使用（腾讯、网易、新浪） |
| 缺点 | 代码多，需两句代码结合使用 |
| 建议 | ✅ **推荐使用**，建议定义公共类减少代码量 |

### 方法四：父级 div 定义 overflow:hidden

```css
.parent {
    overflow: hidden;  /* 触发 BFC */
    width: 100%;       /* 或 zoom:1 */
}
```

| 项目 | 说明 |
|------|------|
| 原理 | overflow:hidden 触发 BFC，浏览器自动检查浮动区域高度 |
| 优点 | 简单、代码少、浏览器支持好 |
| 缺点 | 不能和 position 配合使用，超出部分被隐藏 |
| 建议 | ⚠️ 仅限未使用 position 的场景 |

### 方法五：父级 div 定义 overflow:auto

```css
.parent {
    overflow: auto;
    width: 100%;
}
```

| 项目 | 说明 |
|------|------|
| 原理 | 同方法四，但超出时出现滚动条 |
| 优点 | 简单、代码少 |
| 缺点 | 内容超出时出现滚动条 |
| 建议 | ⚠️ 不推荐 |

### 方法六：父级 div 也一起浮动

```css
.parent {
    float: left;  /* 父元素也浮动 */
}
```

| 项目 | 说明 |
|------|------|
| 原理 | 所有元素一起浮动变成整体 |
| 优点 | 无 |
| 缺点 | 产生新的浮动问题 |
| 建议 | ❌ 不推荐，仅作了解 |

### 方法七：父级 div 定义 display:table

```css
.parent {
    display: table;
}
```

| 项目 | 说明 |
|------|------|
| 原理 | 将 div 属性变成表格 |
| 优点 | 无 |
| 缺点 | 产生新的未知问题 |
| 建议 | ❌ 不推荐，仅作了解 |

### 方法八：结尾处加 br 标签 clear:both

```html
<br style="clear:both;">
```

| 项目 | 说明 |
|------|------|
| 原理 | 用 br 标签替代空 div |
| 建议 | ❌ 不推荐，仅作了解 |

## 方法对比总结

| 方法 | 推荐度 | 代码量 | 兼容性 | 副作用 |
|------|--------|--------|--------|--------|
| 定义 height | ★☆☆ | 少 | 好 | 高度固定 |
| 空div + clear | ★★☆ | 中 | 好 | 多空标签 |
| **:after + zoom** | **★★★** | 中 | 好 | 无 |
| overflow:hidden | ★★☆ | 少 | 好 | 超出隐藏 |
| overflow:auto | ★☆☆ | 少 | 好 | 出滚动条 |
| 父级也浮动 | ☆☆☆ | 少 | 好 | 新问题 |
| display:table | ☆☆☆ | 少 | 好 | 未知问题 |
| br + clear | ☆☆☆ | 少 | 好 | 语义差 |

## 速记口诀

> 清除浮动八种法，伪元素清除最推荐；
> clearfix after 加 zoom，大站都在用它干；
> overflow:hidden 也能清，但怕定位超出边；
> 其他方法了解好，实际项目选最优。
