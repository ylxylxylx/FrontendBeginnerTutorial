# document 的特殊用法

> 本节学习 document 对象的特殊属性和方法，以及如何遍历页面元素。

## document 常用属性

### document.all

获取 document 文档中所有的元素：

```javascript
var all = document.all;
for (var i = 0; i < all.length; i++) {
    var ele = all[i];
    var tag = ele.tagName;
    if (tag == 'HTML' || tag == 'SCRIPT') {
        continue;
    }
    // 实现类似于 *{ box-sizing: 'border-box' } 的效果
    ele.style.boxSizing = 'border-box';
}
```

### 其他常用属性

| 属性 | 说明 |
|------|------|
| `document.all` | 获取页面所有元素 |
| `document.forms` | 查找页面上所有 form 标签 |
| `document.images` | 获取页面上所有的 img 标签 |
| `document.links` | 获取页面所有具有 href 属性的 a 和 area 标签 |
| `document.scripts` | 获取页面上的脚本程序 |
| `document.styleSheets` | 返回页面上可用的样式表 |
| `document.documentURI` | 返回文档的 URI |
| `document.scrollingElement` | 返回当前页面正在滚动的元素 |

### scrollingElement 说明

```javascript
// 返回滚动文档的 Element 对象的引用
// 在标准模式下，这是文档的根元素 document.documentElement
// 在怪异模式下，scrollingElement 属性返回 HTML body 元素
console.dir(document.scrollingElement);
```

## 实际应用

### 批量设置样式

利用 `document.all` 遍历所有元素，批量设置样式：

```javascript
var all = document.all;
for (var i = 0; i < all.length; i++) {
    var ele = all[i];
    var tag = ele.tagName;
    if (tag == 'HTML' || tag == 'SCRIPT') {
        continue;
    }
    ele.style.boxSizing = 'border-box';
}
```

### 获取特定类型元素

```javascript
// 获取所有表单
console.dir(document.forms);

// 获取所有图片
console.log(document.images);

// 获取所有链接
console.log(document.links);

// 获取所有脚本
console.log(document.scripts);

// 获取所有样式表
console.log(document.styleSheets);
