# 2D 图形变换

> 本节学习 CSS 2D 图形变换：平移（translate）、缩放（scale）、旋转（rotate）以及变换原点（transform-origin）。

## 2D 图形变换概述

2D 图形变换：在二维平面上对图形进行平移、缩放、旋转等操作。

## translate — 平移

将元素沿 x 轴和 y 轴移动：

```css
/* 两个值分别对应 x轴 和 y轴 */
/* x轴正方向水平向右；y轴正方向垂直向下 */
/* 正值：往正方向移动；负值：往负方向移动 */
transform: translate(30px, 50px);

/* 一个值对应 x轴，y轴默认为 0 */
transform: translate(30px);

/* 单独设置某个轴 */
transform: translateX(30px);
transform: translateY(-20px);
```

## scale — 缩放

对元素进行缩放：

```css
/* 两个值分别对应 x轴和y轴 */
transform: scale(2, 0.5);

/* 一个值同时对应 x轴和y轴 */
transform: scale(2);   /* 放大2倍 */
transform: scale(0.5); /* 缩小到0.5倍 */
```

## rotate — 旋转

对元素进行旋转：

```css
/* 单位：deg（度） */
/* 正值顺时针旋转；负值逆时针旋转 */
transform: rotate(30deg);
transform: rotate(-45deg);
```

## transform-origin — 变换原点

设置变换的原点，默认值是 `50% 50%`（即 center center）：

```css
/* 取值可以是：长度值px、百分比、top/bottom/left/right/center */
transform-origin: right top;
transform-origin: 0 0;
transform-origin: center bottom;
```

**取值规则：**
- 两个值分别作用于 x 轴和 y 轴
- 一个值：如果是固定值和百分比则作用于 x 轴，y 轴默认 center
- 如果是 top/bottom/left/right/center，浏览器会自动判断作用于哪个轴

## 组合变换

可以同时写多个变换，**顺序不同效果可能不同**：

```css
/* 先平移再缩放 */
transform: translate(30px) scale(0.5);

/* 先缩放再平移（效果不同） */
transform: scale(0.5) translate(30px);
```

## 完整示例

```css
.d1:active {
    /* 按下鼠标：平移 + 缩放 */
    transform: translate(30px) scale(0.5);
}

.d2:hover {
    /* 鼠标悬停：放大2倍 */
    transform: scale(2);
}

.d3:hover {
    /* 鼠标悬停：顺时针旋转30度 */
    transform: rotate(30deg);
    /* 变换原点设在右上角 */
    transform-origin: right top;
}
```

## 变换属性总结

| 属性 | 说明 | 示例 |
|------|------|------|
| `translate(x, y)` | 平移 | `translate(30px, 50px)` |
| `translateX(x)` | 水平平移 | `translateX(30px)` |
| `translateY(y)` | 垂直平移 | `translateY(-20px)` |
| `scale(x, y)` | 缩放 | `scale(2)` |
| `rotate(deg)` | 旋转 | `rotate(30deg)` |
| `transform-origin` | 变换原点 | `right top` |
