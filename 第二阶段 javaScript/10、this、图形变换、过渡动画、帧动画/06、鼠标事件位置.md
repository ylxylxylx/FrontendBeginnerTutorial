# 鼠标事件位置

> 本节学习鼠标事件中各种坐标属性的应用，以及拖拽功能的实现细节。

## 鼠标坐标属性回顾

| 属性 | 参照物 | 说明 |
|------|--------|------|
| `pageX / pageY` | 文档 | 相对于整个文档，包含滚动距离 |
| `clientX / clientY` | 可视窗口 | 相对于可视页面，不包含滚动距离 |
| `offsetX / offsetY` | 点击元素 | 相对于触发事件的元素 |
| `screenX / screenY` | 屏幕 | 相对于整个电脑屏幕 |

**关系：** `pageY = clientY + scrollTop`

## 拖拽实现详解

### 核心思路

1. **mousedown**：记录鼠标相对于元素的偏移量
2. **mousemove**：用 pageX/Y 减去偏移量，得到元素的新位置
3. **mouseup**：取消移动事件

### 代码实现

```javascript
var inner = document.querySelector('.inner');

inner.onmousedown = function(dv) {
    // 每次按下鼠标时，相对于点击的div有一个固定偏移量
    // 移动的过程中这个偏移量不变
    var offsetX = dv.offsetX;
    var offsetY = dv.offsetY;

    document.onmousemove = function(mv) {
        // 让div停留在被点击的任意位置
        inner.style.left = mv.pageX - offsetX + 'px';
        inner.style.top = mv.pageY - offsetY + 'px';
    };
};

inner.onmouseup = function() {
    document.onmousemove = null;
};
```

### 为什么要在 document 上绑定 mousemove？

如果在元素上绑定 `mousemove`，当鼠标移动过快时会脱离元素，导致拖拽中断。在 `document` 上绑定可以确保鼠标在整个页面范围内移动时都能被捕获。

### 偏移量的作用

如果不减去偏移量，元素会跳到鼠标位置（左上角对齐鼠标位置）。减去偏移量后，元素会保持在鼠标点击的位置，实现更自然的拖拽效果。
