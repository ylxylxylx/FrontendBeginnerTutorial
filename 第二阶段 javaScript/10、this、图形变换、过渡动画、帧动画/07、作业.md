# 作业

> 本节包含 this、图形变换、过渡动画、帧动画相关的练习题。

##  作业一

### 1. 控制 div 属性

通过按钮控制 div 的宽、高、颜色、显示/隐藏等属性。

**提示：**
- 使用数组存储属性名和属性值
- 使用 `div.style[attrs[index]]` 动态设置属性
- 使用 `this.index` 获取当前按钮的索引

### 2. 网页换肤

通过切换 CSS 文件实现网页主题换肤功能。

**提示：**
- 使用 `link.href` 切换 CSS 文件
- 利用 `id` 向 JS 传值
- 使用 `classList.add/remove` 切换选中状态

### 3. 循环将三个 DIV 变成红色

使用 for 循环遍历 div，点击按钮将所有 div 背景色改为红色。

**提示：**
- 使用 `classList.add('red')` 添加类名

### 4. 通过循环添加监听事件

给多个 div 添加点击事件，点击后分别变成不同颜色。

**提示：**
- 在 for 循环中使用 `div.index = i` 记录索引
- 在事件中使用 `this.index` 获取索引
- 使用 `this` 指向当前点击的元素

##  作业二

### 1. 千图网首页过渡动画

实现千图网风格的过渡动画效果：鼠标悬停时显示遮罩层和按钮。

**提示：**
- 使用 `transition` 实现平滑过渡
- 使用 `:hover` 触发过渡效果
- 使用 `opacity` 控制遮罩层显示

### 2. 设置一个按钮：开始和暂停动画

实现一个按钮控制动画的播放和暂停，同时修改按钮文字。

**提示：**
- 使用 `animationPlayState` 控制动画状态
- 使用 `isPlaying` 变量记录当前状态
- 使用 `!isPlaying` 切换状态

### 3. 千图网首页关键帧动画

使用 `@keyframes` 实现千图网风格的图片滚动动画。

**提示：**
- 使用 `@keyframes` 定义关键帧
- 使用 `animation` 综合属性设置动画

### 4. 电子时钟

使用 Date 对象和 setInterval 实现动态电子时钟。

### 5. 带有遮罩层的弹出框

实现可拖拽的弹出框，带有遮罩层效果。

**提示：**
- 使用 `classList.add/remove` 控制遮罩层显示
- 使用 mousedown/mousemove/mouseup 实现拖拽
- 遮罩层使用绝对定位覆盖整个页面

### 6. 改变图片的透明度

鼠标悬停改变图片透明度。

### 7. 简易的选项卡

实现选项卡切换功能。

### 8. 简易的日历

实现简易日历效果。

### 9. 提示框的效果

实现鼠标悬停显示提示框的效果。

### 10. 鼠标经过修改图片路径

鼠标经过时修改图片的 src 属性。
