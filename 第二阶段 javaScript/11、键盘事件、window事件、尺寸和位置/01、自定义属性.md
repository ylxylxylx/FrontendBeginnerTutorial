# 自定义属性

## 从页面向 JS 传值的三种方式

在开发中，经常需要将 HTML 中的数据传递给 JS，主要有以下三种方式：

### 1. 自定义属性 `data-*`

`data-*` 自定义属性一般用来存储标签的数据，向 JS 传值。

```html
<button data-box="collapse" data-index="1" title="点击">按钮</button>
```

**获取 `data-*` 属性值：**

```javascript
var btn = document.querySelector('button');

// 方法一：使用 dataset（推荐）
console.log(btn.dataset.box);   // "collapse"
console.log(btn.dataset.index); // "1"

// 方法二：使用 getAttribute
console.log(btn.getAttribute('data-box')); // "collapse"
```

**注意：** `btn.data-box` 是错误写法，JS 会把 `-` 当成减号。

**添加 `data-*` 属性：**

```javascript
btn.dataset.color = 'red';

// 多个单词用 - 连接，对应 dataset 的驼峰命名
btn.dataset.borderColor = 'red';  // 对应 data-border-color="red"
console.log(btn.dataset.borderColor); // "red"
```

### 2. 在 onclick 中直接传参

```html
<li onclick="btnClick(0)">w1</li>
<li onclick="btnClick(1)">w2</li>
<li onclick="btnClick(2)">w3</li>
```

```javascript
function btnClick(ev) {
    console.log(ev); // 直接获取传入的参数 0、1、2
}
```

### 3. 使用自定义 index 属性

在 for 循环中使用自定义 `index` 属性记录索引值，在事件中用 `this.index` 获取。

```javascript
var lis = document.querySelectorAll('body>ul>li');
var uls = document.querySelectorAll('.box ul');

for (var i = 0; i < lis.length; i++) {
    lis[i].index = i;  // 记录索引
    lis[i].onclick = function () {
        console.log(this.index);          // 获取索引
        console.log(uls[this.index]);     // 通过索引获取对应元素
    }
}
```

## dataset 与 getAttribute 对比

| 方式 | 语法 | 说明 |
|------|------|------|
| `dataset` | `el.dataset.box` | 只能获取 `data-*` 属性，驼峰命名 |
| `getAttribute` | `el.getAttribute('data-box')` | 可获取任何属性，需要完整属性名 |

## 自定义属性传值方式对比

| 方式 | 优点 | 缺点 |
|------|------|------|
| `data-*` + `dataset` | 语义清晰，HTML5 标准 | 只能存字符串 |
| `onclick` 传参 | 简单直接 | HTML 与 JS 耦合 |
| `index` 属性 | 灵活，可存任意值 | 非标准属性 |
