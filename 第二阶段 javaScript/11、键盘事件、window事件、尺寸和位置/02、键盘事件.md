# 键盘事件

## 键盘事件类型

| 事件 | 触发时机 | 说明 |
|------|----------|------|
| `onkeydown` | 键盘按键被按下 | 识别所有按键，`keyCode` 不区分大小写 |
| `onkeypress` | 键盘按键被按下并松开 | 区分字母大小写，无法识别箭头和系统功能键 |
| `onkeyup` | 键盘按键被松开 | 按键松开时触发 |

## keydown 与 keypress 的区别

1. **keyCode 区分：** `keydown` 获取的 `keyCode` 不区分字母大小写（A 和 a 都是 65），`keypress` 区分大小写
2. **按键识别：** `keypress` 无法识别箭头键、系统功能键（Shift、Alt 等）

```javascript
window.onkeydown = function (ev) {
    console.log(ev.key);     // 获取按键的字符，如 "a"、"Enter"
    console.log(ev.keyCode); // 获取按键的数字编码，不分大小写
};

window.onkeypress = function (ev) {
    console.log(ev.keyCode); // 区分大小写：A=65, a=97
};

window.onkeyup = function (ev) {
    console.log(ev);         // 按键松开时触发
};
```

## 事件对象的常用属性

### 按键信息

| 属性 | 说明 |
|------|------|
| `ev.key` | 按键的字符值（如 "a"、"Enter"） |
| `ev.keyCode` | 按键的数字编码（已废弃，推荐使用 `ev.key`） |

### 组合键判断

| 属性 | 说明 |
|------|------|
| `ev.altKey` | ALT 键是否被按下 |
| `ev.ctrlKey` | CTRL 键是否被按下 |
| `ev.metaKey` | Meta 键（Mac 的 Command 键）是否被按下 |
| `ev.shiftKey` | SHIFT 键是否被按下 |

## 实际应用示例

### 禁止 Ctrl+C 复制

```javascript
window.onkeydown = function (ev) {
    if (ev.ctrlKey && ev.keyCode == 67) {
        ev.preventDefault(); // 阻止默认行为，禁止复制
        alert('付费操作，请充值');
    }
};
```

### 禁止 F5 刷新

```javascript
window.onkeydown = function (ev) {
    if (ev.keyCode == 116) {
        ev.preventDefault(); // 按下 F5 禁止刷新页面
    }
};
```
