# 获取浏览器窗口的尺寸和位置

## 一、屏幕相关

### 浏览器相对于屏幕的位置

```javascript
console.log(window.screenLeft, window.screenTop); // 浏览器左上角相对于屏幕的位置
console.log(window.screenX, window.screenY);       // 同上（另一种写法）
```

### 屏幕宽高

```javascript
console.log(window.screen.width, window.screen.height);       // 屏幕分辨率
console.log(window.screen.availWidth, window.screen.availHeight); // 屏幕可用工作区域（排除任务栏）
```

## 二、页面的尺寸

### 1. 浏览器可视页面尺寸

```javascript
// 包含滚动条的大小
console.log(window.innerWidth, window.innerHeight);

// 不包含滚动条的大小（推荐）
console.log(document.documentElement.clientWidth, document.documentElement.clientHeight);
```

### 2. 页面的完整尺寸

包含滚动区域的大小：`scrollHeight = clientHeight + scrollTop`

```javascript
console.log(document.documentElement.scrollWidth, document.documentElement.scrollHeight);
```

### 3. 页面被卷去的大小（滚动距离）

```javascript
window.onscroll = function () {
    // 以下三种写法等价（推荐第三种）
    // console.log(document.body.scrollTop);
    // console.log(document.documentElement.scrollTop);
    console.log(document.scrollingElement.scrollTop);
};
```

## 尺寸属性总结

| 属性 | 说明 | 是否包含滚动条 |
|------|------|---------------|
| `window.innerWidth` | 浏览器可视宽度 | 是 |
| `window.innerHeight` | 浏览器可视高度 | 是 |
| `document.documentElement.clientWidth` | 可视宽度 | 否 |
| `document.documentElement.clientHeight` | 可视高度 | 否 |
| `document.documentElement.scrollWidth` | 页面完整宽度 | - |
| `document.documentElement.scrollHeight` | 页面完整高度 | - |
| `document.scrollingElement.scrollTop` | 垂直滚动距离 | - |

## 屏幕属性总结

| 属性 | 说明 |
|------|------|
| `window.screen.width` | 屏幕宽度 |
| `window.screen.height` | 屏幕高度 |
| `window.screen.availWidth` | 屏幕可用宽度 |
| `window.screen.availHeight` | 屏幕可用高度 |
| `window.screenLeft` | 浏览器距屏幕左边距离 |
| `window.screenTop` | 浏览器距屏幕顶部距离 |
