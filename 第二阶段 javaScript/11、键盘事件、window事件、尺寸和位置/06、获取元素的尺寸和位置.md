# 获取元素的尺寸和位置

## 一、元素的尺寸

### 1. clientWidth / clientHeight

包含 **内容 + 内边距**，不包含边框和滚动条。

```javascript
console.log(inner.clientWidth, inner.clientHeight);
```

### 2. offsetWidth / offsetHeight

包含 **内容 + 内边距 + 边框**。

```javascript
console.log(inner.offsetWidth, inner.offsetHeight);
```

### 3. scrollWidth / scrollHeight

元素的完整宽高，如果出现滚动，加上滚动的距离，**不包含边框**。

```javascript
console.log(inner.scrollWidth, inner.scrollHeight);
```

## 二、元素的位置（偏移量）

### offsetLeft / offsetTop

获取元素的偏移量，以有定位方式的父级元素为参考（`relative`/`absolute`/`fixed`），如果父级都没有定位方式，最终以 `body` 为参考。

```javascript
console.log(inner.offsetLeft, inner.offsetTop);
```

**注意：** `offsetLeft`/`offsetTop` 和定位的父级或页面顶部相关，和滚动无关。

## 三、getBoundingClientRect()

获取元素相对于视口的尺寸和位置信息对象。

```javascript
var rect = inner.getBoundingClientRect();
console.log(rect);
```

### 返回值属性

| 属性 | 说明 |
|------|------|
| `rect.width` | 元素宽度（包含边框） |
| `rect.height` | 元素高度（包含边框） |
| `rect.top` | 元素上边到视窗上边的距离 |
| `rect.right` | 元素右边到视窗左边的距离 |
| `rect.bottom` | 元素下边到视窗上边的距离 |
| `rect.left` | 元素左边到视窗左边的距离 |

**注意：** `getBoundingClientRect()` 返回的 `top` 和 `left` 是相对于可视窗口的，会随滚动变化。每次滚动后需要重新调用获取最新值。

```javascript
document.onclick = function () {
    // offsetLeft/offsetTop：和滚动无关
    console.log(inner.offsetLeft, inner.offsetTop);

    // getBoundingClientRect：和滚动有关，到可视窗口的距离
    console.log(inner.getBoundingClientRect().left, inner.getBoundingClientRect().top);
};
```

## 四、元素的滚动

### scrollTop / scrollLeft

元素内部被卷去的大小。

```javascript
inner.onscroll = function () {
    console.log(inner.scrollTop); // 元素内部垂直滚动距离
};
```

## 尺寸属性对比总结

| 属性 | 包含内容 | 包含内边距 | 包含边框 | 包含滚动区域 |
|------|----------|-----------|---------|-------------|
| `clientWidth` | ✅ | ✅ | ❌ | ❌ |
| `offsetWidth` | ✅ | ✅ | ✅ | ❌ |
| `scrollWidth` | ✅ | ✅ | ❌ | ✅ |

## 位置属性对比总结

| 属性 | 参考点 | 是否受滚动影响 |
|------|--------|---------------|
| `offsetLeft`/`offsetTop` | 定位父级或 body | 否 |
| `getBoundingClientRect().left`/`.top` | 视口 | 是 |
