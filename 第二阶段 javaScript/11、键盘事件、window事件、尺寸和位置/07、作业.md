# 作业

> 本节包含键盘事件、window 事件、尺寸和位置相关的练习题。

##  作业一

### 1. 千图网过渡动画

实现千图网风格的过渡动画效果：鼠标悬停时显示遮罩层和按钮。

**提示：**
- 使用 `transition` 实现平滑过渡
- 使用 `:hover` 触发过渡效果
- 使用 `opacity` 控制遮罩层显示
- 使用 `transform: translateY()` 实现按钮滑入效果

### 2. 选项卡

实现选项卡切换功能：鼠标悬停在标签上时，显示对应的内容区域。

**提示：**
- 在 for 循环中使用 `span[i].index = i` 记录索引
- 在事件中使用 `this.index` 获取当前索引
- 使用 `classList.add/remove` 切换 `active` 和 `current` 类名
- 先清除所有标签和内容的激活状态，再给当前项添加

### 3. 千图网首页关键帧动画

使用 `@keyframes` 实现千图网风格的图片滚动动画。

**提示：**
- 使用 `@keyframes` 定义关键帧（从 `top: -8%` 到 `top: -130%`）
- 使用 `animation: move 10s linear infinite alternate` 设置动画
- 使用 `transform: rotate()` 倾斜图片区域
- 使用 `overflow: hidden` 隐藏溢出部分

### 4. 设置一个按钮：开始和暂停动画

实现一个按钮控制动画的播放和暂停，同时修改按钮文字。

**提示：**
- 使用 `animationPlayState` 控制动画状态（`running`/`paused`）
- 使用 `isPlaying` 变量记录当前状态
- 使用 `isPlaying = !isPlaying` 切换状态

```javascript
var isPlaying = true;
btn.onclick = function () {
    if (isPlaying) {
        btn.value = '播放';
        box.style.animationPlayState = 'paused';
    } else {
        btn.value = '暂停';
        box.style.animationPlayState = 'running';
    }
    isPlaying = !isPlaying;
};
```

使用 for 循环遍历 div，点击按钮将所有 div 背景色改为红色。

**提示：**
- 使用 `classList.add('red')` 添加类名

### 6. 带有遮罩层的弹出框

实现可拖拽的弹出框，带有遮罩层效果。

**提示：**
- 使用 `classList.add/remove` 控制遮罩层显示
- 使用 mousedown/mousemove/mouseup 实现拖拽
- 遮罩层使用绝对定位覆盖整个页面
- 弹出框使用 `position: absolute` + `calc(50% - 宽度/2)` 居中

```javascript
// 拖拽核心逻辑
box.onmousedown = function (ev) {
    var offsetX = ev.offsetX;
    var offsetY = ev.offsetY;
    document.onmousemove = function (mv) {
        box.style.left = mv.pageX - offsetX + 'px';
        box.style.top = mv.pageY - offsetY + 'px';
    };
};
box.onmouseup = function () {
    document.onmousemove = null;
};
```

### 7. 动态固定位置

滚动页面时，当导航栏滚动到页面顶部时，将其固定在顶部。

**提示：**
- 使用 `window.onscroll` 监听滚动事件
- 使用 `document.scrollingElement.scrollTop` 获取滚动距离
- 当 `scrollTop >= 100` 时，设置 `position: fixed`
- 否则恢复 `position: static`
