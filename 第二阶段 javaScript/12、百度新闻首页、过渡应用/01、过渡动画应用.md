# 过渡动画应用

## 一、滚动触发的过渡动画

将 CSS 中 `:hover` 触发的过渡效果改为由 JavaScript 事件触发，实现更灵活的动画控制。

### 示例：滚动显示侧边栏

当页面向下滚动超过 300px 时，侧边栏内容滑入显示；小于 300px 时隐藏。

```css
.content {
    width: 200px;
    height: 60px;
    background-color: red;
    position: absolute;
    top: 0;
    left: 100%;          /* 初始位置在右侧隐藏 */
    transition: all 0.2s linear;
}
```

```javascript
var content = document.querySelector('.content');

window.onscroll = function () {
    var scrollTop = document.scrollingElement.scrollTop;
    if (scrollTop >= 300) {
        content.style.left = 0;        // 滑入显示
    } else {
        content.style.left = '100%';   // 滑出隐藏
    }
};
```

### 关键点

- CSS 中 `left` 设置百分比时，参照的是有定位的父级元素
- `transform: translate(100%)` 的百分比参照的是自身宽度
- 过渡动画的触发条件可以从 `:hover` 改为 JS 事件

## 二、旋转过渡动画

利用 `transform: rotate()` 和 `transform-origin` 实现元素的翻转效果。

### 示例：侧边栏图标翻转

鼠标悬停时，图标从旋转 90° 恢复到 0°，实现翻转显示效果。

```css
.box {
    width: 48px;
    height: 92px;
    overflow: hidden;
    border-radius: 5px;
}
.content {
    width: 100%;
    height: 100%;
    background-color: red;
    border-radius: 5px;
    transition: all 0.3s linear;
    transform-origin: -100% 50%;   /* 旋转中心在左侧外部 */
    transform: rotate(90deg);       /* 初始旋转 90° */
}
.box:hover .content {
    transform: rotate(0);           /* 悬停时恢复 */
}
```

### 关键点

- `transform-origin` 设置旋转中心点，`-100% 50%` 表示左侧外部中点
- 初始状态旋转 90°，悬停时旋转回 0°，配合 `transition` 产生翻转效果
- `overflow: hidden` 隐藏旋转时超出容器的部分

## 三、提示框效果

鼠标悬停时显示放大的提示图片，移出时隐藏。

### 实现思路

1. 每个 `<li>` 中包含一个隐藏的 `<img>` 提示图片
2. 鼠标移入时，显示对应索引的图片
3. 鼠标移出时，隐藏所有图片

```css
li {
    width: 100px;
    height: 100px;
    float: left;
    position: relative;
    transition: all 0.5s linear;
}
.img {
    width: 100px;
    height: 100px;
    position: absolute;
    top: 0;
    left: 0;
    display: none;           /* 默认隐藏 */
    transform: scale(1.5);   /* 放大 1.5 倍 */
    z-index: 2;
}
.active {
    display: block;          /* 激活时显示 */
}
```

```javascript
var li = document.querySelectorAll('li');
var img = document.querySelectorAll('img');

for (var i = 0; i < li.length; i++) {
    li[i].d = i;  // 自定义属性记录索引
    li[i].onmouseenter = function () {
        // 先清除所有
        for (var j = 0; j < li.length; j++) {
            img[j].classList.remove('active');
        }
        // 显示当前索引的图片
        img[this.d].classList.add('active');
    };
    li[i].onmouseleave = function () {
        for (var j = 0; j < li.length; j++) {
            img[j].classList.remove('active');
        }
    };
}
```

### 关键点

- 使用自定义属性 `li[i].d = i` 记录索引，在事件中用 `this.d` 获取
- `transform: scale(1.5)` 让提示图片放大显示
- `z-index: 2` 确保提示图片在最上层

## 过渡动画应用总结

| 应用场景 | 触发方式 | 核心属性 |
|----------|----------|----------|
| 滚动显示 | `window.onscroll` | `left` + `transition` |
| 图标翻转 | `:hover` | `rotate` + `transform-origin` + `transition` |
| 提示框 | `mouseenter/mouseleave` | `display` + `scale` + `transition` |
