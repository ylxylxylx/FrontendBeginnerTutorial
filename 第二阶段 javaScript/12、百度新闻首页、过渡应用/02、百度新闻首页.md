## 一、导航菜单滑动背景

鼠标悬停导航项时，红色背景平滑滑动到对应位置。

### CSS 实现

```css
.nav-list .bg {
    height: 100%;
    width: 72px;
    background-color: #c00;
    position: absolute;
    top: 0;
    left: 0;
    z-index: 0;
    transition: all 0.2s linear;  /* 过渡动画 */
}
```

### JS 控制

```javascript
var navLis = document.querySelectorAll('.nav li');
var navBg = document.querySelector('.nav .bg');

for (var i = 0; i < navLis.length; i++) {
    navLis[i].onmouseenter = function () {
        // bg 滑动到当前 li 的位置
        navBg.style.left = this.offsetLeft + 'px';
        navBg.style.width = this.offsetWidth + 'px';
    };
    navLis[i].onmouseleave = function () {
        // 鼠标移出时恢复到首页位置
        navBg.style.left = 0;
        navBg.style.width = navLis[0].offsetWidth + 'px';
    };
}
```

### 关键点

- 背景元素 `.bg` 使用绝对定位，`z-index: 0` 在文字下方
- 导航项 `<li>` 使用 `z-index: 2` 确保文字在背景上方
- `offsetLeft` 获取元素偏移量，`offsetWidth` 获取元素宽度
- `transition: all 0.2s linear` 实现平滑滑动效果

## 二、动态固定导航栏

滚动页面时，当导航栏到达页面顶部，将其固定。

```javascript
var nav = document.querySelector('.nav');
var offsetTop = nav.offsetTop;  // 记录导航栏初始偏移量

window.onscroll = function () {
    var scrollTop = document.scrollingElement.scrollTop;
    if (scrollTop >= offsetTop) {
        nav.style.position = 'fixed';
    } else {
        nav.style.position = 'static';
    }
};
```

### 关键点

- `nav.offsetTop` 获取导航栏到页面顶部的距离
- 固定导航需要设置 `z-index` 确保不被其他元素遮挡
- `position: fixed` 后导航栏脱离文档流，下方内容可能上移，需注意布局

## 三、右侧固定侧边栏

### CSS 样式

```css
.right-nav {
    width: 48px;
    position: fixed;
    bottom: 20px;
    left: calc(50% + 492px + 10px);  /* 定位在内容区右侧 */
    overflow: hidden;
}
.right-nav-box {
    transform: translateY(53px);     /* 初始向下偏移隐藏 */
    transition: all 0.2s linear;
}
```

### 图标翻转效果

侧边栏图标初始旋转 90°，悬停时恢复 0°，显示文字。

```css
.right-nav-box li a {
    transform: rotate(90deg);
    transform-origin: -50% 50%;      /* 旋转中心在左侧外部 */
    transition: all 0.2s linear;
}
.right-nav-box li:hover a {
    transform: rotate(0);            /* 悬停恢复 */
}
```

### JS 控制：滚动显示侧边栏

```javascript
var rightNav = document.querySelector('.right-nav-box');

window.onscroll = function () {
    var scrollTop = document.scrollingElement.scrollTop;
    if (scrollTop >= 300) {
        rightNav.style.transform = 'translateY(0)';    // 显示
    } else {
        rightNav.style.transform = 'translateY(53px)'; // 隐藏
    }
};
```

## 四、回到顶部

点击按钮，页面滚动回顶部。

```javascript
var goTop = document.querySelector('.go-top');
goTop.onclick = function () {
    window.scroll(0, 0);  // 设置滚动位置为顶部
    // 以下写法等价：
    // document.scrollingElement.scrollTop = 0;
    // document.documentElement.scrollTop = 0;
};
```

## 综合知识点总结

| 功能 | 技术点 |
|------|--------|
| 导航滑动背景 | `offsetLeft`/`offsetWidth` + `transition` |
| 固定导航栏 | `offsetTop` + `scrollTop` + `position: fixed` |
| 侧边栏滚动显示 | `transform: translateY()` + `transition` + `onscroll` |
| 图标翻转 | `rotate` + `transform-origin` + `transition` |
| 回到顶部 | `window.scroll(0, 0)` |
| 清除浮动 | `clearfix::after` 伪元素 |
