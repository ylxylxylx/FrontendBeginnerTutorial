# 倒计时与时间差

三个与时间相关的 JS 小示例：倒计时器、计算时间差、朋友圈发布时间格式化。

---

## 一、倒计时器

用户输入秒数，点击开始后倒计时，支持暂停和继续。

### 核心代码

```javascript
var time = prompt("请输入倒计时秒数");
var spans = document.getElementsByTagName("span");
var begin = false;
var timer;

function btnClick() {
    if (begin) {
        // 暂倒计时
        clearInterval(timer);
        input.value = "开始";
        begin = false;
    } else {
        // 开启倒计时
        timer = setInterval(timeChange, 1000);
        input.value = "暂停";
        begin = true;
    }
}

function timeChange() {
    time--;
    // 更新UI
    var minute = parseInt(time / 60) < 10 ? '0' + parseInt(time / 60) : parseInt(time / 60);
    var second = time % 60 < 10 ? '0' + time % 60 : time % 60;
    spans[0].innerText = minute;
    spans[1].innerText = second;
    // 倒计时结束
    if (time == 0) {
        clearInterval(timer);
        alert("计时结束");
    }
}
```

### 关键点

- **状态变量** `begin` 掇制开始/暂停切换
- **时间格式化**：个位数补零（`'0' + parseInt(time/60)`）
- **分钟计算**：`parseInt(time / 60)`，**秒数计算**：`time % 60`
- **clearInterval** 清除定时器停止倒计时

## 二、计算时间差

计算当前时间到目标时间的天、小时、分钟、秒差。

### 核心代码

```javascript
var targetTime = new Date("2021-02-12 00:00:00");

setInterval(function () {
    var nowTime = new Date();
    // 计算时间差（秒）
    var offsetTime = targetTime.getTime() - nowTime.getTime();
    offsetTime = parseInt(offsetTime / 1000);

    // 总天数 = 总秒数 / 一天的秒数
    var days = parseInt(offsetTime / (24 * 60 * 60));

    // 不足一天的小时数
    var hours = parseInt(offsetTime % (24 * 60 * 60) / (60 * 60));

    // 不足一小时的分钟数
    var minutes = parseInt(offsetTime % (60 * 60) / 60);

    // 不足一分钟的秒数
    var seconds = offsetTime % 60;

    h1.innerText = "距离2021年春节还有" + days + "天" + hours + "小时" + minutes + "分钟" + seconds + "秒";
}, 1000);
```

### 时间差计算公式

| 单位 | 公式 | 说明 |
|------|------|------|
| 天 | `offsetTime / (24×60×60)` | 总秒数 ÷ 一天秒数 |
| 小时 | `offsetTime % (24×60×60) / (60×60)` | 余一天秒数 ÷ 一小时秒数 |
| 分钟 | `offsetTime % (60×60) / 60` | 余一小时秒数 ÷ 一分钟秒数 |
| 秒 | `offsetTime % 60` | 余一分钟秒数 |

### 关键点

- **getTime()** 返回毫秒，需除以 1000 转为秒
- **取整** 与 **取余** 配合使用：先取余得到不足大单位的部分，再除以小单位
- 使用 `setInterval` 每秒更新显示

## 三、朋友圈发布时间

根据发布时间与当前时间的差值，显示不同格式的时间描述。

### 核心代码

```javascript
var nowTime = new Date();
var targetTime = new Date('2019-12-28 00:02:00');

var offsetTime = (nowTime.getTime() - targetTime.getTime()) / 1000;

var SEC = 1;
var MIN = 60;
var HOUR = MIN * 60;
var DAY = HOUR * 24;

var days = Math.floor(offsetTime / DAY);
var hours = Math.floor(offsetTime % DAY / HOUR);
var minutes = Math.floor(offsetTime % HOUR / MIN);

if (offsetTime < MIN) {
    p.innerHTML = '刚刚发布';       // 一分钟以内
} else if (offsetTime < HOUR) {
    p.innerHTML = minutes + '分钟前'; // 一小时以内
} else if (offsetTime < DAY) {
    p.innerHTML = hours + '小时前';   // 一天以内
} else {
    p.innerHTML = days + '天前';      // 超过一天
}
```

### 时间显示规则

| 时间差 | 显示格式 | 示例 |
|--------|----------|------|
| < 1分钟 | 刚刚发布 | 刚刚发布 |
| < 1小时 | N分钟前 | 5分钟前 |
| < 1天 | N小时前 | 3小时前 |
| ≥ 1天 | N天前 | 2天前 |

### 关键点

- 使用 **时间常量**（SEC/MIN/HOUR/DAY）提高代码可读性
- **Math.floor** 取整（向下取整）
- 通过 **if-else 分支** 判断时间差范围，选择对应格式
- 注释中保留了"昨天"判断的逻辑（比较日期是否为昨天）
