# 全选与反选

实现复选框的全选、全不选、反选功能，以及子选项与全选框的状态联动。

---

## 功能说明

```
┌─────────────────────────┐
│  ☑ 全选    反选          │
├─────────────────────────┤
│  ☑ 选项1                │
│  ☑ 选项2                │
│  ☑ 选项3                │
│  ☐ 选项4                │
│  ...                    │
└─────────────────────────┘
```

- **全选**：点击全选框，所有子选项同步选中/取消
- **反选**：点击反选链接，所有子选项状态取反
- **联动**：子选项全部选中时，全选框自动勾选；否则自动取消

---

## 核心代码

```javascript
var allInput = document.getElementById("all");
var inverse = document.getElementsByClassName("inverse")[0];
var inputs = document.querySelectorAll(".items input");
var label = document.querySelector(".check-all label");

// 1. 点击全选，更改所有子选项状态
allInput.onclick = function () {
    for (var i = 0; i < inputs.length; i++) {
        inputs[i].checked = allInput.checked;
    }
    isCheckAll();
};

// 2. 点击反选，所有子选项状态取反
inverse.onclick = function () {
    for (var i = 0; i < inputs.length; i++) {
        inputs[i].checked = !inputs[i].checked;
    }
    isCheckAll();
};

// 3. 点击子选项，判断全选状态
for (var i = 0; i < inputs.length; i++) {
    inputs[i].onclick = function () {
        isCheckAll();
    };
}

// 4. 全选状态判断的封装
function isCheckAll() {
    var checkAll = true;
    for (var j = 0; j < inputs.length; j++) {
        if (!inputs[j].checked) {
            checkAll = false;
            break;
        }
    }
    // 更新全选框状态
    allInput.checked = checkAll;
    // 更新标签文字
    label.innerHTML = checkAll ? "全不选" : "全选";
}
```

## 关键点

### checkbox 属性

| 属性 | 说明 | 值 |
|------|------|-----|
| `checked` | 选中状态 | `true`/`false` |
| `id` + `label[for]` | 点击文字触发复选框 | id 关联 |

### 逻辑要点

1. **全选 → 子选项**：遍历所有子选项，设置 `checked = allInput.checked`
2. **反选**：遍历所有子选项，`checked = !checked` 取反
3. **子选项 → 全选**：遍历所有子选项，只要有一个未选中则全选框为 `false`
4. **break 优化**：判断全选状态时，发现一个未选中即可 `break` 跳出循环
5. **标签文字联动**：全选时显示"全不选"，未全选时显示"全选"

### `href="javascript:;"` 的作用

反选链接使用 `javascript:;` 阻止默认跳转行为，仅执行点击事件。
