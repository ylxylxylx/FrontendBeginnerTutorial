# 下拉菜单

导航栏下拉菜单：鼠标悬停显示子菜单，自动判断子菜单左对齐或右对齐。

---

## 功能说明

```
┌──────────────────────────────────────────────┐
│ 站长之家 │ 行业资讯 │ 站长在线 │ 网站运营 │ ... │
│          └──┬──────────────────────────┘      │
│             │ 业界动态│收购融资│门户动态│... │   ← 子菜单
│             ▲                                  │
│             └─ 小箭头                          │
└──────────────────────────────────────────────┘
```

- 鼠标移入导航项，显示对应子菜单
- 子菜单位置自适应：空间足够则左对齐，不够则右对齐
- 鼠标移出导航区域，延迟隐藏子菜单

---

## 核心代码

```javascript
var nav = document.querySelector('#nav');
var lis = document.querySelectorAll('#nav ul li');
var subnavs = document.querySelectorAll('#nav ul li .subnav');
var arrows = document.querySelectorAll('.arrow');
var lastindex = 0;  // 记录上一次显示的子菜单索引

// 鼠标移入大标题，显示对应子列表
for (var i = 1; i < lis.length; i++) {
    lis[i].index = i;
    lis[i].onmouseover = function () {
        // 上一个列表隐藏
        subnavs[lastindex].style.display = "none";
        // 当前子列表显示
        subnavs[this.index - 1].style.display = "block";
        // 记录当前索引
        lastindex = this.index - 1;

        // 判断子菜单对齐方式
        if (nav.offsetWidth - this.offsetLeft > subnavs[this.index - 1].offsetWidth) {
            // 剩余空间 > 子菜单宽度 → 左对齐
            subnavs[this.index - 1].style.left = "0px";
            arrows[this.index - 1].style.left = "50px";
        } else {
            // 剩余空间 < 子菜单宽度 → 右对齐
            subnavs[this.index - 1].style.right = "0px";
            arrows[this.index - 1].style.right = "50px";
        }
    };
}

// 鼠标移出隐藏
nav.onmouseleave = function () {
    setTimeout(() => {
        subnavs[lastindex].style.display = "none";
    }, 300);
};
```

---

## 关键点

### 子菜单位置判断

```javascript
// 大列表宽度 - 当前li横坐标 > 子列表宽度 → 左对齐
// 大列表宽度 - 当前li横坐标 < 子列表宽度 → 右对齐
nav.offsetWidth - this.offsetLeft > subnav.offsetWidth
```

- `nav.offsetWidth`：导航栏总宽度
- `this.offsetLeft`：当前 `<li>` 的左偏移量
- 两者之差即为当前 `<li>` 右侧的剩余空间

### 其他要点

1. **lastindex 记录**：避免每次都遍历隐藏所有子菜单，只隐藏上一个
2. **setTimeout 延迟隐藏**：鼠标移出后延迟 300ms 隐藏，防止鼠标移向子菜单时闪烁
3. **雪碧图（Sprite）**：所有背景图使用同一张 `nav_bg.png`，通过 `background-position` 定位
4. **自定义属性 index**：`lis[i].index = i` 为每个元素存储索引，在事件回调中通过 `this.index` 获取
5. **i 从 1 开始**：第一个 `<li>`（站长之家）没有子菜单，跳过
