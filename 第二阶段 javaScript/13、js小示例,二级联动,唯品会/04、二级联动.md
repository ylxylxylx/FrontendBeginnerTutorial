# 二级联动

省份-城市二级联动下拉菜单：选择省份后，城市列表自动更新。

---

## 功能说明

```
┌───────────┐  ┌───────────┐
│ 河南   ▼  │  │ 郑州   ▼  │
└───────────┘  └───────────┘
选择省份        域市自动更新
```

---

## 数据结构

```javascript
var data = [
    {
        province: "河南",
        city: ["郑州", "开封", "新乡", "焦作", "南阳", "信阳"]
    },
    {
        province: "河北",
        city: ["石家庄", "保定", "秦皇岛", "唐山"]
    },
    {
        province: "山西",
        city: ["太原", "大同", "阳泉"]
    }
];
```

每个对象包含 `province`（省份名）和 `city`（城市数组）。

---

## 核心代码

```javascript
var provinceSelect = document.getElementById("province");
var citySelect = document.getElementById("city");

// 1. 将省份显示到第一个下拉列表
data.forEach(function (item, index) {
    var option = document.createElement("option");
    option.innerText = item.province;
    provinceSelect.appendChild(option);
});

// 2. 默认显示第一个省份的城市
var citys = data[0].city;
citys.forEach(function (item) {
    var option = document.createElement("option");
    option.innerText = item;
    citySelect.appendChild(option);
});

// 3. 二级联动：切换省份时刷新城市列表
provinceSelect.onchange = function () {
    // selectedIndex 指下拉列表当前选中的索引
    var obj = data[provinceSelect.selectedIndex];

    // 先清空城市下拉列表
    citySelect.innerHTML = "";

    // 重新填充城市列表
    obj.city.forEach(function (item) {
        var option = document.createElement("option");
        option.innerText = item;
        citySelect.appendChild(option);
    });
};
```

---

## 关键点

### select 相关属性

| 属性/方法 | 说明 |
|-----------|------|
| `selectedIndex` | 当前选中项的索引（只读） |
| `value` | 当前选中项的值 |
| `onchange` | 选中项改变时触发 |
| `innerHTML = ""` | 清空所有选项 |

### 动态创建 option

```javascript
var option = document.createElement("option");
option.innerText = "文本";
select.appendChild(option);
```

### 联动逻辑流程

```
1. 页面加载 → 霰充省份列表 → 默认显示第一个省份的城市
2. 用户切换省份 → onchange 触发
3. 通过 selectedIndex 获取当前选中索引
4. 从数据源 data[index] 取出对应省份对象
5. 清空城市列表 (innerHTML = "")
6. 霰充新的城市列表
```

### 扩展：三级联动

本目录下的 `三级联动数据/` 供供了省市区数据：
- `provinces.js` — 省份列表
- `cities.js` — 做市列表
- `areas.js` — 区县列表

三级联动原理相同，只需增加区县下拉列表，在 city 的 onchange 中更新区县。
