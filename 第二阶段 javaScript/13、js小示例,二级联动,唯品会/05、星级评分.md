# 星级评分

星级评分系统：鼠标悬停预览评分，点击确认评分，移出恢复已选评分。

---

## 功能说明

```
  点击星星就能打分
  ★ ★ ★ ★ ★        ← 5颗星（雪碧图）
  3分满意              ← 悬停评语
  质量不错，与卖家描述的基本一致，还是挺满意的
```

- **悬停**：鼠标移入星星，点亮对应星级并显示评语
- **点击**：确认评分，显示评分结果
- **移出**：恢复到已确认的评分状态

---

## 核心代码

```javascript
var stars = box.querySelectorAll("#box a");
var starBox = box.querySelector(".star-box");
var result = box.querySelector(".result");
var tips = box.querySelector(".tips");

var msg = [
    "很不满意|差得太离谱，与卖家描述的严重不符，非常不满",
    "不满意|部分有破损，与卖家描述的不符，不满意",
    "一般|质量一般，没有卖家描述的那么好",
    "满意|质量不错，与卖家描述的基本一致，还是挺满意的",
    "非常满意|质量非常好，与卖家描述的完全一致，非常满意"
];

var score = 0;  // 记录当前分数

for (var i = 0; i < stars.length; i++) {
    stars[i].index = i;

    // 鼠标移入：点亮星星 + 显示评语
    stars[i].onmouseover = function () {
        for (var j = 0; j < stars.length; j++) {
            if (j <= this.index) {
                stars[j].classList.add("on");
            } else {
                stars[j].classList.remove("on");
            }
        }
        // 显示评语
        var arr = msg[this.index].split("|");
        tips.innerHTML = "<strong>" + (this.index + 1) + "分" + arr[0] + "</strong><br>" + arr[1];
        tips.style.left = this.offsetLeft + "px";
    };

    // 点击：确认评分
    stars[i].onclick = function () {
        score = this.index + 1;
        tips.innerHTML = "";
        var arr = msg[this.index].split("|");
        result.innerHTML = "<strong>" + (this.index + 1) + "分" + arr[0] + "</strong>" + arr[1];
    };
}

// 鼠标移出：恢复已确认的评分
starBox.onmouseout = function () {
    for (var j = 0; j < stars.length; j++) {
        if (j < score) {
            stars[j].classList.add("on");
        } else {
            stars[j].classList.remove("on");
        }
    }
    tips.innerHTML = "";
};
```

## 关键点

### 雪碧图实现星星

```css
.star-box a {
    float: left;
    width: 24px;
    height: 24px;
    background: url(star.png) 0 0 / 100% auto;  /* 灰色星星 */
}
.star-box a.on {
    background-position: 0 -35px;  /* 金色星星 */
}
```

- 默认显示灰色星星（`background-position: 0 0`）
- 添加 `.on` 类后切换到金色星星（`background-position: 0 -35px`）

### 评语数据结构

```javascript
"评分等级|详细描述"
// 用 split("|") 拆分
var arr = msg[this.index].split("|");
// arr[0] = "满意"，arr[1] = "质量不错..."
```

### 交互逻辑

| 事件 | 行为 |
|------|------|
| `onmouseover` | 点亮当前及之前的星星，显示评语 |
| `onclick` | 记录 score，隐藏评语，显示结果 |
| `onmouseout` | 根据 score 恢复星星状态，隐藏评语 |

### on 与 addEventListener 的区别

| 特性 | on 绑定 | addEventListener |
|------|---------|-----------------|
| 可否取消 | 不可取消 | 可用 removeEventListener 取消 |
| 重复绑定 | 同一事件只能绑定一个函数 | 可绑定多个函数，触发时依次执行 |
