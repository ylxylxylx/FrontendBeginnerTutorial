# 鼠标修改图片路径

鼠标悬停缩略图，上方大图切换为对应图片。

---

## 功能说明

```
┌─────────────────────┐
│                     │
│     大图预览区       │  ← 鼠标悬停缩略图时切换
│     (340×280)       │
│                     │
├──┬──┬──┬──┬──┬──────┤
│1 │2 │3 │4 │5 │6 │...│  ← 缩略图列表
└──┴──┴──┴──┴──┴──────┘
```

---

## 核心代码

```javascript
var img = document.querySelectorAll("img");

for (var i = 0; i < img.length; i++) {
    img[i].index = i;
    img[i].onmouseenter = function () {
        // 将大图的 src 设为当前缩略图对应的图片
        img[0].src = './' + this.index + '.jpg';
    };
}
```

---

## 关键点

### 实现思路

1. 大图使用空的 `<img>` 标签（`src=""`）
2. 缩略图按数字命名（`1.jpg`, `2.jpg`, ...）
3. 鼠标移入缩略图时，通过 `this.index` 获取索引
4. 将大图 `img[0].src` 设为 `'./' + index + '.jpg'`

### 自定义属性 index

```javascript
img[i].index = i;  // 为每个元素存储索引
```

- 在事件回调中通过 `this.index` 获取当前元素的索引
- 这是闭包问题的经典解决方案之一

### this 指向

- `onmouseenter` 回调中，`this` 指向触发事件的元素（当前 `<img>`）
- `this.index` 获取当前悬停图片的索引
- `img[0]` 始终指向大图元素
