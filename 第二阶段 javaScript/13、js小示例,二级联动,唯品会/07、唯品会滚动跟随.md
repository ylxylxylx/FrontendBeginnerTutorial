# 唯品会滚动跟随

综合案例：唯品会首页滚动效果，包含固定导航栏、左侧导航跟随、左右联动。

---

## 页面结构

```
┌──────────────────────────────────────┐
│              头部 (130px)             │
├──────────────────────────────────────┤
│  全部分类 │ 首页 │ 唯品快抢 │ 女装 │...│  ← 顶部导航（滚动固定）
├──────────────────────────────────────┤
│              横幅 Banner              │
├──────────────────────────────────────┤
```

## 一、顶部导航栏滚动固定

```javascript
var topNav = document.querySelector("nav");
var navTop = topNav.offsetTop;  // 记录导航栏初始位置

window.onscroll = function () {
    if (document.scrollingElement.scrollTop >= navTop) {
        topNav.style.position = "fixed";
        topNav.style.top = "0";
    } else {
        topNav.style.position = "static";
        topNav.style.top = "-50px";
    }
};
```

### 关键点

- `offsetTop` 记录导航栏初始位置（只需获取一次）
- 滚动距离 ≥ `offsetTop` 时切换为 `position: fixed`
- 滚动回去时恢复 `position: static`
- CSS 中 `top: -50px` + `transition: all 0.3s linear` 实现滑入效果

## 二、左侧导航滚动固定

```javascript
var navLeft = document.getElementsByClassName("nav-left")[0];
var items = document.getElementsByClassName("item");
var itemTops = [];  // 记录每个分类区域的 offsetTop

for (var i = 0; i < items.length; i++) {
    itemTops.push(items[i].offsetTop);
}

window.onscroll = function () {
    // 滚动到分类区域时，左侧导航固定
    if (document.scrollingElement.scrollTop >= itemTops[0] - 100) {
        navLeft.style.position = "fixed";
        navLeft.style.top = "100px";
    } else {
        navLeft.style.position = "absolute";
        navLeft.style.top = "1300px";
    }
};
```

### 关键点

- `itemTops` 数组记录各分类区域的 `offsetTop`
- 滚动超过第一个分类区域时固定左侧导航
- 未滚动到时使用 `position: absolute` 恢复原位

## 三、滚动时高亮当前分类

```javascript
var leftLis = document.querySelectorAll(".nav-left li");
var num = 0;  // 记录当前选中分类索引

window.onscroll = function () {
    leftLis[num].className = "";  // 清除上一个高亮

    // 判断当前滚动到哪个分类区域
    for (var i = 0; i < items.length; i++) {
        if (document.scrollingElement.scrollTop >= itemTops[i] - 300) {
            num = i;
        }
    }

    leftLis[num].className = "active";  // 设置当前高亮
};
```

### 关键点

- `scrollTop >= itemTops[i] - 300`：提前 300px 切换高亮
- 先清除上一个高亮，再设置当前高亮
- `num` 变量记录当前选中索引

## 四、左右联动（点击导航滚动到对应区域）

```javascript
for (var i = 0; i < leftLis.length; i++) {
    leftLis[i].index = i;
    leftLis[i].onclick = function () {
        // 设置样式
        leftLis[num].className = "";   // 清除上一个
        this.className = "active";     // 设置当前
        num = this.index;              // 更新索引

        // 滚动到对应分类区域
        document.scrollingElement.scrollTop = items[this.index].offsetTop - 100;
    };
}
```

### 关键点

- 点击左侧导航，页面滚动到对应分类区域
- `scrollTop = offsetTop - 100`：留出 100px 偏移，避免被固定导航遮挡
- 点击时同步更新 `num` 和高亮样式

## 五、CSS 过渡效果说明

```css
nav {
    transition: all 0.3s linear;
}
```

### 有过渡效果的 CSS 属性

- `transform`、`width`、`opacity`、`color`、`top`、`left` 等 — 有中间值

### 无过渡效果的 CSS 属性

- `display`、`position` 等 — 无中间值，瞬间切换

> 注：`position` 的切换（`static` ↔ `fixed`）本身无过渡效果，但配合 `top` 属性的变化可以实现视觉上的滑入效果。

## 综合知识点总结

| 功能 | 技术点 |
|------|--------|
| 固定导航栏 | `offsetTop` + `scrollTop` + `position: fixed/static` |
| 左侧导航固定 | `offsetTop` 数组 + `position: fixed/absolute` |
| 滚动高亮 | `scrollTop` 与 `itemTops` 比较 + `className` 切换 |
| 左右联动 | `onclick` + `scrollTop` 赋值 + `offsetTop` |
| 过渡效果 | `transition` + 有中间值的属性 |
