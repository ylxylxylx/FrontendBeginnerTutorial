# 表单事件

表单相关的事件：输入、焦点、修改、选择、重置、提交。

---

## 表单事件一览

| 事件 | 绑定对象 | 触发时机 |
|------|----------|----------|
| `oninput` | input 元素 | 输入框内容变化时（实时） |
| `onfocus` | input 元素 | 输入框获取焦点时 |
| `onblur` | input 元素 | 输入框失去焦点时 |
| `onchange` | input/select | 值发生变化时（失焦后触发） |
| `onselect` | input 元素 | 鼠标拖拽选中内容时 |
| `onreset` | form 元素 | 表单重置时 |
| `onsubmit` | form 元素 | 表单提交时 |

---

## 一、input 输入事件

```javascript
userInput.oninput = function () {
    console.log(this.value);  // 实时获取输入内容
};
```

- 每次输入（包括删除、粘贴）都会触发
- 比 `onchange` 更实时，`onchange` 需要失焦后才触发

---

## 二、focus 与 blur 焦点事件

```javascript
// 获取焦点
userInput.onfocus = function () {
    console.log("获取焦点");
};

// 失去焦点
userInput.onblur = function () {
    console.log("失去焦点");
};
```

- **focus**：点击输入框或 Tab 键切换到输入框时触发
- **blur**：点击输入框外部或 Tab 键离开时触发
- 常用于输入框获焦时显示提示、失焦时验证输入

---

## 三、change 修改事件

```javascript
userInput.onchange = function () {
    console.log("数据更新");
};
```

- **文本输入框**：内容变化 + 失焦后触发
- **单选/多选/下拉列表/滑动条/日期/时间/颜色/文件**：选择变化时立即触发
- 适用于不需要实时监听的场景

---

## 四、select 选择事件

```javascript
userInput.onselect = function (e) {
    console.log("select", e);  // e 为事件信息对象
};
```

- 鼠标拖拽选中输入框内容时触发

---

## 五、reset 与 submit 表单事件

```javascript
// 重置事件（绑定在 form 上）
form.onreset = function () {
    console.log("表单重置");
};

// 提交事件（绑定在 form 上）
form.onsubmit = function (e) {
    // 阻止表单的默认提交行为
    e.preventDefault();
    console.log("表单提交");
};
```

### 关键点

- `onreset` 和 `onsubmit` 必须绑定在 `<form>` 标签上
- **e.preventDefault()**：阻止表单默认提交，防止页面刷新
- form 中的 input 监听到 Enter 键会触发提交

## 六、input type 类型

| type | 说明 | type | 说明 |
|------|------|------|------|
| `text` | 文本 | `radio` | 单选框 |
| `password` | 密码 | `checkbox` | 多选框 |
| `number` | 数字 | `email` | 邮箱 |
| `date` | 日期 | `file` | 选择文件 |
| `time` | 时间 | `color` | 调色板 |
| `range` | 滑动条 | `image` | 图像提交按钮 |
| `button` | 按钮 | `reset` | 重置 |
| `submit` | 提交 | `select` | 下拉列表 |
