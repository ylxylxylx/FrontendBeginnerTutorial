# 错误监测

Error 对象、try...catch 错误捕获、throw 抛出错误。

---

## 一、Error 对象

```javascript
// JS 中错误是一个对象，代码出错时会自动生成
// 也可以手动创建
var error = new Error("这是一个自定义错误对象");

// 错误对象打印看不到，需要 throw 抛出
throw(error);
```

- 错误一旦抛出，代码会**立即终止执行**
- `new Error("消息")` 创建自定义错误对象

---

## 二、try...catch 错误捕获

```javascript
try {
    alert(a + b);  // a 未定义，会报错
} catch (error) {
    console.log("捕捉到错误" + error);
    // catch 捕获错误后，控制台不会报错，代码不会终止

    // 可以手动抛出错误，终止进程
    // throw(error);
}
```

### 执行流程

```
try {
    可能出错的代码
} catch (error) {
    出错后执行的代码（error 为错误对象）
}
```

1. 执行 `try` 中的代码
2. 如果出错，立即跳转到 `catch`，捕获错误对象
3. `catch` 中可以处理错误（记录日志、显示提示等）
4. 如果 `try` 中没有出错，`catch` 不执行

### 关键点

- **catch 捕获错误后不会抛出**，控制台不报错，代码不终止
- 可以在 `catch` 中手动 `throw(error)` 终止进程
- **防止程序因不明错误导致终止**

---

## 三、throw 抛出错误

```javascript
throw(new Error("自定义错误信息"));
```

- `throw` 会立即终止代码执行
- 常在 `catch` 中使用，决定是否将错误继续抛出
- 也可在业务逻辑中主动抛出（如参数校验失败）

---

## 四、onerror vs try...catch

| 特性 | window.onerror | try...catch |
|------|---------------|-------------|
| 作用范围 | 全局错误监听 | 指定代码块 |
| 是否终止进程 | 返回 true 时不终止 | catch 中不终止 |
| 兼容性 | 老版本语法，可能被废除 | 标准语法，广泛支持 |
| 推荐度 | 不推荐 | 推荐 |

> 实际开发中推荐使用 `try...catch` 代替 `window.onerror`
