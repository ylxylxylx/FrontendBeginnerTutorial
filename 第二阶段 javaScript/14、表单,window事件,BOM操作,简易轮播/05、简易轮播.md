# 简易轮播

使用 opacity 过渡实现的简易图片轮播，包含自动轮播和指示器联动。

---

## 效果说明

```
┌──────────────────────────────┐
│                              │
│         当前图片              │  ← opacity: 1
│     （其他图片隐藏）          │  ← opacity: 0
│                              │
│     ● ○ ○ ○                  │  ← 指示器
└──────────────────────────────┘
```

- 图片使用 `opacity` 控制显示/隐藏，配合 `transition` 实现淡入淡出
- 指示器与图片联动，当前图片对应指示器高亮
- `setInterval` 定时自动切换

---

## CSS 实现

```css
main {
    width: 400px;
    height: 400px;
    position: relative;
}
img {
    width: 100%;
    height: 100%;
    position: absolute;
    opacity: 0;             /* 默认隐藏 */
    transition: all 0.3s;   /* 淡入淡出过渡 */
}
img.active {
    opacity: 1;             /* 当前显示 */
}
li {
    width: 20px;
    height: 20px;
    border-radius: 50%;
    background-color: white;
    display: inline-block;
    transition: all 0.5s;
}
li.active {
    background-color: aqua; /* 当前指示器高亮 */
}
```

## 核心代码

```javascript
var imgs = document.querySelectorAll("main img");
var lis = document.querySelectorAll("ul li");
var index = 0;  // 记录当前展示的图片索引

// 切换图片（轮播）的函数
function change() {
    // 1. 还原上一张图和指示器
    imgs[index].className = "";
    lis[index].className = "";

    // 2. 更新索引
    index++;

    // 3. 判断边界（循环）
    if (index > 3) {
        index = 0;
    }

    // 4. 显示下一张图和指示器
    imgs[index].className = "active";
    lis[index].className = "active";
}

// 自动轮播
setInterval(change, 2000);
```

---

## 轮播四步法

```
1. 还原视图   →  移除上一张的 active 类
2. 更新索引   →  index++
3. 判断边界   →  index > 3 时重置为 0
4. 更新视图   →  给下一张添加 active 类
```

这是循环操作数据的常规步骤，适用于所有轮播、Tab 切换等场景。

---

## 关键点

### opacity 方案 vs display 方案

| 特性 | opacity | display |
|------|---------|---------|
| 过渡效果 | 支持 transition | 不支持 transition |
| 元素占位 | 始终占位 | 隐藏时不占位 |
| 事件响应 | 隐藏时仍可响应 | 隐藏时不响应 |
| 适用场景 | 淡入淡出轮播 | 直接切换 |

### CSS 选择器区别

```css
li.active { }    /* class 为 active 的 li 标签 */
li .active { }   /* li 的子标签中 class 为 active 的标签 */
```

- `li.active`：选择本身有 `active` 类的 `<li>`
- `li .active`：选择 `<li>` 后代中有 `active` 类的元素

## 扩展：手动轮播

作业：添加左右箭头，点击箭头向左或向右轮播。

```javascript
// 向右轮播（同自动轮播逻辑）
nextBtn.onclick = function () {
    change();
};

// 向左轮播
prevBtn.onclick = function () {
    imgs[index].className = "";
    lis[index].className = "";
    index--;
    if (index < 0) {
        index = 3;  // 跳转到最后一张
    }
    imgs[index].className = "active";
    lis[index].className = "active";
};
```
