# 作业

## 1. 表单验证

利用表单事件知识，实现一个表单验证功能：
- 用户名：非空验证，失焦时检查
- 密码：长度验证（6-16位）
- 邮箱：格式验证

**提示**：使用 `onblur` + `oninput` 事件配合

## 2. 轮播图完善

为简易轮播添加手动轮播功能：
- 在轮播图左右添加箭头按钮
- 点击左箭头向左轮播
- 点击右箭头向右轮播
- 鼠标悬停暂停自动轮播，移出恢复

**提示**：
- 左箭头：`index--`，`index < 0` 时跳转到最后一张
- 暂停：`clearInterval(timer)`，恢复：`timer = setInterval(change, 2000)`

## 3. 唯品会完善

完善唯品会滚动跟随案例：
- 添加回到顶部按钮
- 滚动超过一屏时显示，否则隐藏
- 点击回到顶部

**提示**：`window.scroll(0, 0)` 或 `scrollTop = 0`
