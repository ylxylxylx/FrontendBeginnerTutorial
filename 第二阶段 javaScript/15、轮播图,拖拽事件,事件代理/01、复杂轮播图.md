# 复杂轮播图

> 在简易轮播（opacity淡入淡出）基础上，增加**左右箭头手动翻页**和**指示器点击切换**功能

## 一、整体结构

```
┌──────────────────────────────────────┐
│  <                              >    │
│  左箭头      轮播图片区       右箭头   │
│                                      │
│           ● ○ ○ ○                    │
│           指示器                      │
└──────────────────────────────────────┘
```

- 图片：`position: absolute` + `opacity: 0/1` + `transition` 实现淡入淡出
- 指示器：`<ul><li>` 圆点，`.active` 变色
- 左右箭头：`<span>` 默认隐藏，`main:hover` 时显示

## 二、change() 函数升级（支持双向切换）

简易轮播的 `change()` 只能正向轮播，复杂轮播通过**参数 offset** 实现正反双向：

```javascript
function change(offset) {
    // 1. 还原视图
    imgs[index].className = '';
    lis[index].className = '';
    // 2. 更新索引
    index += offset;   // offset=1 下一张, offset=-1 上一张
    // 3. 判断边界（双向）
    if (index > 3) { index = 0; }        // 超过末尾 → 回到开头
    if (index < 0) { index = imgs.length - 1; }  // 超过开头 → 回到末尾
    // 4. 更新视图
    imgs[index].className = 'active';
    lis[index].className = 'active';
}
```

### offset 参数的作用

| 调用方式 | offset值 | 效果 |
|---------|----------|------|
| `change(1)` | +1 | 下一张（正向） |
| `change(-1)` | -1 | 上一张（反向） |

### 边界判断对比

```
简易轮播（单向）:          复杂轮播（双向）:
if (index > 3)            if (index > 3)
    index = 0;                index = 0;
                           if (index < 0)
                               index = imgs.length - 1;
```

## 三、三大功能实现

### 功能1：自动轮播 + 鼠标暂停

```javascript
// 自动轮播
timer = setInterval("change(1)", 2000);

// 鼠标移入暂停
main.onmouseover = function () {
    clearInterval(timer);
}

// 鼠标移出继续
main.onmouseout = function () {
    timer = setInterval("change(1)", 2000);
}
```

> **setInterval 传参写法**：`setInterval("change(1)", 2000)` 字符串形式可传参；`setInterval(change, 2000)` 不传参形式无法传参

### 功能2：手动轮播（左右箭头）

```javascript
// 右箭头 → 下一张
right.onmousedown = function () {
    change(1);
}

// 左箭头 → 上一张
left.onmousedown = function () {
    change(-1);
}
```

### 功能3：指示器切换

```javascript
for (var i = 0; i < lis.length; i++) {
    lis[i].count = i;  // 给每个li存储索引（自定义属性）
    lis[i].onmouseover = function () {
        // 1. 还原
        imgs[index].className = '';
        lis[index].className = '';
        // 2. 更新索引
        index = this.count;
        // 3. 更新界面（无需判断边界，索引由li决定）
        imgs[index].className = 'active';
        lis[index].className = 'active';
    }
}
```

> **为什么用 `lis[i].count = i`？** for循环中 `var i` 是函数作用域，闭包内 `i` 始终为最终值。通过自定义属性 `count` 将索引绑定到每个 `li` 元素上，事件内用 `this.count` 获取正确索引

## 四、CSS关键样式

### 左右箭头显示控制

```css
.img-click span {
    display: none;  /* 默认隐藏 */
}
main:hover span {
    display: block; /* 鼠标移入轮播区显示 */
}
```

### 箭头定位

```css
.img-click .left {
    top: 180px;
    left: 0px;
}
.img-click .right {
    top: 180px;
    right: 0px;
}
```

## 五、知识总结

| 功能 | 核心技术 | 关键点 |
|------|---------|--------|
| 自动轮播 | setInterval + change(1) | 鼠标移入暂停、移出恢复 |
| 手动翻页 | change(offset) | offset=1下一张、offset=-1上一张 |
| 指示器切换 | 自定义属性存索引 | this.count 获取当前li索引 |
| 双向边界 | index > 3 / index < 0 | 超过末尾回0、超过开头回末尾 |
| 箭头显隐 | main:hover span | CSS :hover 控制显示 |
