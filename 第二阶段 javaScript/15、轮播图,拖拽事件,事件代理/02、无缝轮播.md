# 无缝轮播

> 与opacity淡入淡出轮播不同，无缝轮播使用**left坐标平移**实现滑动效果，图片到达边界后**瞬移到对面**形成无限循环

## 一、核心原理

### opacity轮播 vs 无缝轮播

```
opacity轮播（简易/复杂）:          无缝轮播:
┌───┐ ┌───┐ ┌───┐ ┌───┐         ┌───┬───┬───┬───┐
│img0│ │img1│ │img2│ │img3│         │img0│img1│img2│img3│  ← 四张图左右排列
└───┘ └───┘ └───┘ └───┘         └───┴───┴───┴───┘
  ↑ 全部重叠在同一位置               ↑ 通过left坐标排列
  opacity: 0/1 控制显隐              transition: left 1s 滑动切换
```

### 无缝循环的关键

```
正常排列:    [img0] [img1] [img2] [img3]
left坐标:     0      400    800    1200

滑动切换时:
  ← 左滑: 所有图片left -= 400
  → 右滑: 所有图片left += 400

边界处理:
  img超出左边界(left < -400) → 瞬移到右侧(left = 800)
  img超出右边界(left > 800)  → 瞬移到左侧(left = -400)
```

## 二、初始布局

```javascript
var width = main.offsetWidth;  // 获取容器宽度(400px)

// 设置四张图片的left坐标，使其左右排列
for (var i = 0; i < imgs.length; i++) {
    imgs[i].style.left = i * width + 'px';
}
// 最后一张图放到左侧（实现循环衔接）
imgs[imgs.length - 1].style.left = -width + 'px';
```

### 初始位置示意

```
         -400    0     400    800
          ↑      ↑      ↑      ↑
        [img3] [img0] [img1] [img2]
                ↑
            当前显示(img0)
```

## 三、move() 滑动函数

```javascript
function move(offset) {
    // (一) 所有图片坐标偏移
    for (var i = 0; i < imgs.length; i++) {
        var left = imgs[i].offsetLeft;     // 获取当前坐标
        left -= width * offset;            // 偏移：offset=1左滑, offset=-1右滑

        // 判断左边界
        if (left < -width) {
            left = width * 2;              // 瞬移到右侧
            imgs[i].style.zIndex = 0;     // 降低层级（从下方穿过）
            imgs[i].ontransitionend = function () {
                this.style.zIndex = 10;   // 过渡结束后恢复层级
                moving = false;            // 更新过渡状态
            }
        }

        // 判断右边界
        if (left > width * 2) {
            left = -width;                 // 瞬移到左侧
            imgs[i].style.zIndex = 0;
            imgs[i].ontransitionend = function () {
                this.style.zIndex = 10;
                moving = false;
            }
        }

        imgs[i].style.left = left + 'px'; // 更新坐标
        moving = true;                     // 标记过渡中
    }

    // (二) 更新指示器（四步法）
    lis[index].className = "";             // 1.还原
    index += offset;                       // 2.更新索引
    if (index > 3) { index = 0; }         // 3.判断边界
    if (index < 0) { index = 3; }
    lis[index].className = "active";       // 4.更新视图
}
```

### zIndex 层级处理

```
正常状态:  所有图片 zIndex = 10
边界穿越:  边界图片 zIndex = 0（从下方穿过，避免遮挡）

   img2(10)    img0(10)
   ─────────────────────
   img3(0)  ← 从下方穿过，不遮挡其他图片
```

## 四、transitionend 过渡结束事件

```javascript
imgs[i].ontransitionend = function () {
    this.style.zIndex = 10;   // 恢复层级
    moving = false;            // 标记过渡结束
}
```

| 事件 | 触发时机 | 用途 |
|------|---------|------|
| `transitionend` | CSS过渡动画执行完毕 | 恢复层级、更新过渡状态 |

> **注意**：`transitionend` 是CSS过渡特有事件，不是JS定时器回调

## 五、防止快速连续点击（moving锁）

```javascript
var moving = false;  // 定义过渡状态变量

// move()函数中：
//   开始过渡时: moving = true
//   过渡结束时: moving = false (在ontransitionend中)

// 手动轮播中判断：
left.onclick = function () {
    if (moving) return;  // 过渡中 → 忽略点击
    move(-1);
}
right.onclick = function () {
    if (moving) return;  // 过渡中 → 忽略点击
    move(1);
}
```

### 实现步骤

```
1. 定义变量:  var moving = false;
2. 过渡开始:  moving = true;           (move函数内，更新坐标后)
3. 过渡结束:  moving = false;          (ontransitionend回调中)
4. 限制操作:  if(moving) return;       (手动轮播点击事件中)
```

## 六、自动轮播 + 手动轮播

```javascript
// 自动轮播
timer = setInterval("move(1)", 2000);

// 鼠标移入暂停
main.onmouseenter = function () {
    clearInterval(timer);
}

// 鼠标移出继续
main.onmouseleave = function () {
    timer = setInterval("move(1)", 2000);
}

// 手动轮播（带防抖）
left.onclick = function () {
    if (moving) return;
    move(-1);
}
right.onclick = function () {
    if (moving) return;
    move(1);
}
```

## 七、CSS关键样式

```css
main div img {
    position: absolute;
    transition: left 1s linear;  /* left属性过渡，1秒匀速 */
    z-index: 10;
}

/* 左右箭头：hover时滑入 */
body div span {
    opacity: 0;
    transition: all 0.3s;
}
#left { left: -30px; }
#right { right: -30px; }
main:hover #left { left: 0; opacity: 1; }
main:hover #right { right: 0; opacity: 1; }
```

## 八、复杂轮播 vs 无缝轮播对比

| 对比项 | 复杂轮播 | 无缝轮播 |
|--------|---------|---------|
| 切换方式 | opacity淡入淡出 | left坐标滑动 |
| 图片布局 | 全部重叠同一位置 | 左右排列不同位置 |
| 过渡属性 | `transition: all 0.5s` | `transition: left 1s linear` |
| 边界处理 | index归0/归末尾 | 图片坐标瞬移到对面 |
| 层级问题 | 无需处理 | 需zIndex控制穿越 |
| 防抖 | 不需要 | 需要（moving锁） |
| 过渡事件 | 不需要 | transitionend恢复层级 |
| 视觉效果 | 渐变切换 | 滑动切换 |
