# 拖拽事件

> HTML5 拖拽API（Drag and Drop）实现元素的拖拽操作和文件拖拽上传

## 一、draggable 属性

HTML标签的 `draggable` 属性控制标签能否被拖动：

```html
<a draggable="false" href="...">链接</a>      <!-- 禁拖 -->
<img draggable="false" src="...">              <!-- 禁拖 -->
<div draggable="true" id="div1">可拖拽div</div> <!-- 可拖 -->
<div id="div2">拖入区域</div>                   <!-- 默认false -->
```

| 标签类型 | draggable默认值 | 说明 |
|---------|----------------|------|
| `<a>` | true | 超链接默认可拖 |
| `<img>` | true | 图片默认可拖 |
| 其他标签 | false | 手动设置为true |

> **前提**：拖拽事件触发的前提是标签的 `draggable` 属性值为 `true`

## 二、拖拽源事件（绑定到被拖拽的元素）

```javascript
var div1 = document.getElementById("div1");

// 1. dragstart — 开始拖拽
div1.ondragstart = function () {
    console.log("开始拖拽");
}

// 2. drag — 正在拖拽（连续触发）
div1.ondrag = function () {
    console.log("正在拖拽");
}

// 3. dragend — 拖拽结束（松开鼠标触发）
div1.ondragend = function () {
    console.log("拖拽结束");
}

// 4. dragexit — 拖拽取消（离开窗口区域触发）
div1.ondragexit = function () {
    console.log("拖拽取消");
}
```

### 事件触发顺序

```
dragstart → drag(连续) → dragend
                        ↗ dragexit(离开窗口)
```

## 三、拖拽目标事件（绑定到拖入区域）

```javascript
var div2 = document.getElementById("div2");

// 1. dragenter — 拖入事件
div2.ondragenter = function () {
    console.log("有东西被拖拽进入这个标签");
}

// 2. dragleave — 拖出事件
div2.ondragleave = function () {
    console.log("有什么东西被拖出这个标签");
}

// 3. dragover — 拖动事件（连续触发）
div2.ondragover = function (e) {
    e.preventDefault();  // 必须阻止默认行为！
}

// 4. drop — 丢入事件（拖入并松开鼠标）
div2.ondrop = function (e) {
    e.preventDefault();  // 阻止默认行为（如图片全屏展示）
    // 处理拖入内容...
}
```

### 关键：阻止 dragover 默认行为

```
浏览器对 dragover 有默认行为 → 会阻止 drop 事件触发

解决：在 dragover 中调用 e.preventDefault()
```

> **必须**在目标标签（或window）的 dragover 事件中阻止默认行为，否则 drop 事件不会触发

## 四、七种拖拽事件总结

| 事件 | 绑绑对象 | 触发时机 | 连续触发 |
|------|---------|---------|---------|
| dragstart | 拖拽源 | 开始拖拽 | 否 |
| drag | 拖拽源 | 正在拖拽 | 是 |
| dragend | 拖拽源 | 松开鼠标 | 否 |
| dragexit | 拖拽源 | 离开窗口 | 否 |
| dragenter | 拖拽目标 | 拖入区域 | 否 |
| dragleave | 拖拽目标 | 拖出区域 | 否 |
| dragover | 拖拽目标 | 在区域内拖动 | 是 |
| drop | 拖拽目标 | 拖入并松开鼠标 | 否 |

## 五、文件拖拽上传

```javascript
div2.ondrop = function (e) {
    e.preventDefault();

    // e.dataTransfer.files — 拖入的文件列表
    var file = e.dataTransfer.files[0];  // 取第一个文件

    if (!file) {
        // 拖入的不是文件（如标签元素）
        div2.appendChild(div1);
        return;
    }

    if (file.type.startsWith("image")) {
        // 是图片 → 颐览显示
        var url = URL.createObjectURL(file);
        div2.innerHTML = "<img src=" + url + ">";
    } else {
        // 不是图片 → 显示文件名
        div2.innerText = file.name;
    }
}
```

### dataTransfer 对象

| 属性/方法 | 说明 |
|----------|------|
| `e.dataTransfer.files` | 拖入的文件列表（FileList） |
| `e.dataTransfer.files[0]` | 第一个文件对象（File） |

### URL.createObjectURL()

```javascript
URL.createObjectURL(file)
```

- 功能：获取文件的本地缓存地址（blob URL）
- 参数：File对象
- 返回值：类似 `blob:http://localhost:xxx/xxx` 的临时URL
- 用途：将拖入的文件在页面中预览显示

## 六、file 对象属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `file.name` | 文件名 | `"photo.jpg"` |
| `file.type` | MIME类型 | `"image/jpeg"` |
| `file.size` | 文件大小(字节) | `1024` |

> **判断图片类型**：`file.type.startsWith("image")` 可匹配所有图片MIME类型（image/jpeg、image/png、image/gif等）
