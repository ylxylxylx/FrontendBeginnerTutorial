# 点击加号选择图片

> 事件代理 + 文件选择综合应用：点击加号图片触发文件选择，选中图片后预览显示，支持动态添加和删除

## 一、效果说明

```
初始状态:
  ┌──────┐ ┌──────┐ ┌──────┐
  │  +   │ │  +   │ │  +   │    [添加] [删除]
  │add.png│ │add.png│ │add.png│
  └──────┘ └──────┘ └──────┘

点击图片后:
  ┌──────┐ ┌──────┐ ┌──────┐
  │  X   │ │  X   │ │  +   │    [添加] [删除]
  │photo │ │photo │ │add.png│
  └──────┘ └──────┘ └──────┘

删除模式:
  点击[删除] → 所有图片显示X按钮 → 点击X删除对应div
  点击[完成] → 隐藏所有X按钮
```

## 二、HTML 结构

```html
<main>
    <div>
        <i>X</i>                          <!-- 删除按钮 -->
        <img src="add.png" alt="">        <!-- 加号图片/预览图片 -->
        <input type="file" accept="image/*">  <!-- 文件选择(隐藏) -->
    </div>
    <!-- 可动态添加更多div -->
</main>
<button onclick="add()">添加</button>
<button onclick="myremove(event)">删除</button>
```

### 关键CSS

```css
input { display: none; }          /* 隐藏文件选择框 */
main i { display: none; }         /* 默认隐藏删除按钮 */
```

## 三、事件代理：点击图片触发文件选择

```javascript
var main = document.querySelector("main");

main.onclick = function (e) {
    if (e.target.nodeName == "IMG") {
        // 点击图片 → 触发input的点击事件
        var input = e.target.nextElementSibling;
        input.click();  // 触发文件选择
    }
    else if (e.target.nodeName == "I") {
        // 点击X → 删除父标签div
        var div = e.target.parentElement;
        div.remove();
    }
}
```

### 核心思路

```
点击img → e.target.nodeName == "IMG"
  → 找到相邻的input: e.target.nextElementSibling
  → 触发input点击: input.click()

点击i → e.target.nodeName == "I"
  → 找到父标签div: e.target.parentElement
  → 删除div: div.remove()
```

## 四、事件代理：文件选择后预览

```javascript
main.onchange = function (e) {
    if (e.target.nodeName == "INPUT") {
        // 获取选中的文件
        var file = e.target.files[0];
        // 找到相邻的img
        var img = e.target.previousElementSibling;
        // 生成本地URL并预览
        img.src = URL.createObjectURL(file);
    }
}
```

### 文件选择流程

```
用户点击图片 → input.click() → 文件选择对话框
  → 用户选择文件 → input触发change事件
  → e.target.files[0] → File对象
  → URL.createObjectURL(file) → blob URL
  → img.src = blobURL → 图片预览
```

## 五、动态添加图片选择框

```javascript
function add() {
    var div = document.createElement("div");
    main.appendChild(div);

    var i = document.createElement("i");
    i.innerText = "X";
    div.appendChild(i);
    // 如果当前是删除状态，显示X按钮
    if (document.getElementsByTagName("button")[1].innerText == "完成") {
        i.style.display = "inline";
    }

    var img = document.createElement("img");
    img.src = "./add.png";
    div.appendChild(img);

    var input = document.createElement("input");
    input.type = "file";
    input.style.accept = "image/*";
    div.appendChild(input);
}
```

## 六、删除模式切换

```javascript
// 动态获取i标签（变化时自动更新）
var iBtn = document.getElementsByTagName("i");
// 注意：querySelectorAll只获取一次，不会更新！

function myremove(e) {
    if (e.target.innerText == "删除") {
        e.target.innerText = "完成";
        // 显示所有X按钮
        for (var i = 0; i < iBtn.length; i++) {
            iBtn[i].style.display = "inline";
        }
    } else {
        e.target.innerText = "删除";
        // 隐藏所有X按钮
        for (var i = 0; i < iBtn.length; i++) {
            iBtn[i].style.display = "none";
        }
    }
}
```

### getElementsByTagName vs querySelectorAll

```javascript
// 动态获取：i标签变化时，iBtn自动更新
var iBtn = document.getElementsByTagName("i");

// 静态获取：只获取一次，后续i标签变化不会更新
var iBtn = document.querySelectorAll("i");
```

> **重要**：动态添加元素时，用 `getElementsByTagName` 获取的列表是**动态的**，会自动包含新添加的元素

## 七、核心知识点总结

| 知识点 | 用法 | 说明 |
|--------|------|------|
| 事件代理 | `main.onclick` + `e.target.nodeName` | 父元素代理子元素事件 |
| `input.click()` | 手动触发文件选择 | 点击图片触发隐藏input |
| `e.target.files[0]` | 获取选中的文件 | File对象 |
| `URL.createObjectURL()` | 生成本地预览URL | blob URL |
| `nextElementSibling` | 获取下一个兄弟元素 | img → input |
| `previousElementSibling` | 获取上一个兄弟元素 | input → img |
| `parentElement` | 获取父元素 | i → div |
| `element.remove()` | 删除元素 | 删除div |
| `getElementsByTagName` | 动态获取元素列表 | 新增元素自动包含 |
