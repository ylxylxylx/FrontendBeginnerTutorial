# 在浏览器端保存数据

> 浏览器端保存数据的四种方式：全局变量、Cookie、sessionStorage、localStorage

## 一、四种方式概览

| 方式 | 保存时长 | 说明 |
|------|---------|------|
| 全局变量 | 短暂 | 页面跳转或刷新后数据消失 |
| Cookie | 可短可长 | 会话Cookie窗口关闭消失；持久化Cookie可指定存活时间 |
| sessionStorage | 会话级 | 关闭浏览器即消失 |
| localStorage | 长期 | 除非手动清除，否则一直存在 |

## 二、保存时长详解

### 全局变量
- 只能短时间保存数据
- 页面跳转或刷新后数据会消失

### Cookie（按保存时间分两种）

| 类型 | 说明 |
|------|------|
| 会话Cookie | 窗口关闭即消失 |
| 持久化Cookie | 程序员可指定存活时间（expires），关闭窗口也不会消失 |

### sessionStorage
- 在会话中保存数据，称为**会话存储**
- 关闭浏览器即消失

### localStorage
- 长期保存数据，称为**本地存储**
- 除非手动清除，否则一直存在

## 三、数据类型限制

| 方式 | 数据类型 |
|------|---------|
| 全局变量 | 任意类型（数字、字符串、对象、数组等） |
| Cookie | 原生API只能保存字符串 |
| sessionStorage | 原生API只能保存字符串 |
| localStorage | 原生API只能保存字符串 |

> **注意**：webStorage 原生API只能保存字符串，如需保存对象/数组，需用 `JSON.stringify()` 转换，读取时用 `JSON.parse()` 还原

## 四、作用域与可访问范围

| 方式 | 作用范围 |
|------|---------|
| 全局变量 | 当前页面的window对象内部；有嵌入或弹出关系的页面可通过 `window.parent` / `window.top` 相互访问 |
| Cookie | 可跨越多个页面、多个窗口；同域名下的页面都能操作本网站的Cookie |
| sessionStorage | 域内（同一个域名之内） |
| localStorage | 域内（同一个域名之内） |

### Cookie 的特殊行为

- 浏览器端保存的Cookie会放入请求头（Cookie头）中被发送到服务器
- 即每次HTTP请求都会自动携带Cookie

## 五、容量大小

| 方式 | 容量 |
|------|------|
| 全局变量 | 可多可少，与用户设备的内存有关 |
| Cookie | 只能保存几十个数据，总量不能超过4KB（整个网站） |
| sessionStorage | 约5MB |
| localStorage | 约5MB |

## 六、综合对比表

| 对比项 | 全局变量 | Cookie | sessionStorage | localStorage |
|--------|---------|--------|---------------|-------------|
| 保存时长 | 页面刷新消失 | 会话/可指定 | 关闭浏览器消失 | 永久（手动清除） |
| 数据类型 | 任意 | 字符串 | 字符串 | 字符串 |
| 作用范围 | 当前页面 | 同域名 | 同域+同窗口 | 同域名 |
| 容量 | 取决于内存 | ≤4KB | ≈5MB | ≈5MB |
| 随请求发送 | 否 | 是 | 否 | 否 |
| API | 直接赋值 | 字符串拼接 | setItem/getItem | setItem/getItem |
| 典型用途 | 临时计算 | 登录状态 | 表单临时数据 | 用户偏好设置 |
