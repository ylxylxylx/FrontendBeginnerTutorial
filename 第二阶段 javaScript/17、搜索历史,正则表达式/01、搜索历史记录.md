# 搜索历史记录

> 使用 localStorage 实现搜索历史记录功能：搜索时保存关键字，获取焦点时展示历史，支持去重和数量限制

## 一、效果说明

```
┌─────────────────────────┐
│  [搜索关键字]  [搜索]    │
├─────────────────────────┤
│  最新搜索关键字          │  ← onfocus 时展示
│  较早搜索关键字          │
│  更早搜索关键字          │
│  ...                    │
└─────────────────────────┘

点击搜索 → 关键字存入localStorage → 下次获取焦点时展示
```

## 二、数据存储方案

```javascript
// 使用数组记录搜索关键字
var keywordArray;

// 从本地读取搜索历史（字符串格式）
var historyString = localStorage.getItem("history");

if (historyString) {
    // 有历史记录 → 字符串转数组
    keywordArray = historyString.split("*");
} else {
    // 无历史记录 → 初始化空数组
    keywordArray = [];
}
```

### 存储格式

```
localStorage中存储格式: "关键字1*关键字2*关键字3"

存入时: keywordArray.join("*")  → 数组转字符串
读取时: historyString.split("*") → 字符串转数组
```

> **分隔符选择**：使用 `*` 作为分隔符，需确保搜索关键字中不包含 `*`

## 三、展示历史记录（onfocus）

```javascript
input.onfocus = function () {
    // 清空历史区域
    historyDiv.innerHTML = "";
    // 遍历数组，创建p标签展示
    keywordArray.forEach(function (item) {
        var p = document.createElement("p");
        p.innerText = item;
        historyDiv.appendChild(p);
    });
}
```

## 四、隐藏历史记录（onblur）

```javascript
input.onblur = function () {
    historyDiv.innerHTML = "";
}
```

## 五、搜索并保存关键字

```javascript
function search() {
    // 1. 输入合法性验证
    if (input.value.includes("*") || input.value.trim().length == 0) {
        alert("搜索信息不合法");
        return;
    }

    // 2. 去重：如果已存在，先删除旧的
    var index = keywordArray.indexOf(input.value);
    if (index >= 0) {
        keywordArray.splice(index, 1);
    }

    // 3. 添加到数组开头（最新的在前）
    keywordArray.unshift(input.value);

    // 4. 限制数组长度（只保留最近5条）
    if (keywordArray.length > 5) {
        keywordArray.pop();
    }

    // 5. 清空输入框
    input.value = "";

    // 6. 更新本地存储
    localStorage.setItem("history", keywordArray.join("*"));
}
```

## 六、核心逻辑流程

```
页面加载:
  localStorage.getItem("history") → 字符串 → split("*") → 数组

获取焦点(onfocus):
  遍历数组 → 创建p标签 → 展示历史记录

点击搜索:
  1. 验证合法性（不含*、不为空）
  2. 去重（indexOf + splice）
  3. 添加到开头（unshift）
  4. 限制长度（pop）
  5. 存入本地（join("*") + setItem）

失去焦点(onblur):
  清空历史区域
```

## 七、关键数组方法

| 方法 | 用法 | 说明 |
|------|------|------|
| `indexOf()` | `arr.indexOf(value)` | 查找元素索引，不存在返回-1 |
| `splice()` | `arr.splice(index, 1)` | 从index位置删除1个元素 |
| `unshift()` | `arr.unshift(value)` | 在数组开头添加元素 |
| `pop()` | `arr.pop()` | 删除数组最后一个元素 |
| `join()` | `arr.join("*")` | 数组转字符串，用*连接 |
| `split()` | `str.split("*")` | 字符串转数组，按*分割 |

## 八、实现步骤总结

1. 网页打开或刷新时，从本地读取历史记录，放入数组
2. 输入框获取焦点时，用历史记录数组展示记录
3. 点击搜索按钮时，更新历史记录数组，并把数组存入本地
4. 输入框失去焦点，隐藏历史

## 九、扩展思路

- 点击历史记录项可直接搜索（给p标签添加onclick）
- 添加清空历史按钮（`localStorage.removeItem("history")`）
- 使用JSON存储替代join/split（`JSON.stringify` / `JSON.parse`）
- 搜索关键字高亮显示
