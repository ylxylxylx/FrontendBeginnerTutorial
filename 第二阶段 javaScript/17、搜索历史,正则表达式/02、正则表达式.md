# 正则表达式

> 正则表达式（Regular Expression）是用于匹配字符串中字符组合的模式，在表单验证、字符串检索替换中广泛使用

## 一、什么是正则表达式

```
普通字符串查找:  只能找固定的文字
正则表达式查找:  可以按规则匹配一类字符串

示例:
  "手机号" → 不是固定文字，但有规则：1开头 + 9位数字
  正则: /^1[3-9]\d{9}$/
```

## 二、创建正则表达式

### 1. 字面量方式（推荐）

```javascript
var reg1 = /\d/;           // 匹配一位数字
var reg2 = /\d/g;          // 全局匹配（global）
var reg3 = /\d/i;          // 忽略大小写（ignoreCase）
var reg4 = /\d/gi;         // 全局 + 忽略大小写
```

### 2. RegExp构造函数

```javascript
var reg5 = new RegExp(/\d/, "g");
var reg6 = new RegExp(/^\d.*好$/, "gi");
```

### 3. 两种方式对比

| 方式 | 语法 | 适用场景 |
|------|------|----------|
| 字面量 | `/pattern/flags` | 模式固定，简洁直观 |
| 构造函数 | `new RegExp(pattern, flags)` | 模式需要动态拼接 |

## 三、正则语法规则

### 1. 边界符

| 符号 | 含义 | 示例 |
|------|------|------|
| `^` | 匹配开头 | `/^abc/` 匹配以abc开头 |
| `$` | 匹配结尾 | `/abc$/` 匹配以abc结尾 |
| `^...$` | 精确匹配 | `/^abc$/` 只匹配"abc" |

### 2. 量词

| 符号 | 含义 | 示例 |
|------|------|------|
| `*` | 0次或多次 | `/a*/` 匹配0个或多个a |
| `+` | 1次或多次 | `/a+/` 匹配1个或多个a |
| `?` | 0次或1次 | `/a?/` 匹配0个或1个a |
| `{n}` | 恰好n次 | `/\d{3}/` 匹配3位数字 |
| `{n,}` | 至少n次 | `/\d{3,}/` 匹配3位及以上数字 |
| `{n,m}` | n到m次 | `/\d{3,5}/` 匹配3~5位数字 |

### 3. 字符类

| 符号 | 含义 | 等价写法 |
|------|------|----------|
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 字母数字下划线 | `[a-zA-Z0-9_]` |
| `\W` | 非字母数字下划线 | `[^a-zA-Z0-9_]` |
| `.` | 任意字符（除换行符） | - |

### 4. 字符集合

| 写法 | 含义 | 示例 |
|------|------|------|
| `[abc]` | 匹配a或b或c | `/[abc]/` |
| `[a-z]` | 匹配a到z任意小写字母 | `/[a-z]/` |
| `[0-9]` | 匹配0到9任意数字 | `/[0-9]/` |
| `[^abc]` | 匹配除a、b、c外的字符 | `/[^abc]/` |

### 5. 或运算

| 写法 | 含义 | 示例 |
|------|------|------|
| `a\|b` | 匹配a或b | `/a\|b/` |
| `[abc]` | 等价于 `a\|b\|c` | - |

### 6. 转义

| 写法 | 含义 |
|------|------|
| `\\.` | 匹配真正的点号（.） |
| `\\*` | 匹配真正的星号（*） |
| `\\/` | 匹配真正的斜杠（/） |

> **注意**：在正则中 `.` `*` `+` `?` `^` `$` `|` `\` `(` `)` `[` `]` `{` `}` 是特殊字符，匹配本身需转义

## 四、正则标志（flags）

| 标志 | 含义 | 说明 |
|------|------|------|
| `g` | global | 全局匹配，找到所有匹配项 |
| `i` | ignoreCase | 忽略大小写 |
| `gi` | 两者组合 | 全局匹配 + 忽略大小写 |

## 五、正则相关API

### 1. match — 字符串调用，返回匹配数组

```javascript
var str = "abc123def456";

// 不加g → 只返回第一个匹配
str.match(/\d/);      // ["1"]

// 加g → 返回所有匹配
str.match(/\d/g);     // ["1","2","3","4","5","6"]

// 无匹配 → 返回null
str.match(/xyz/);     // null
```

### 2. exec — 正则调用，只返回第一个匹配

```javascript
var str = "abc123def456";
var reg = /\d/g;

reg.exec(str);  // ["1"]  — 每次调用返回下一个匹配
reg.exec(str);  // ["2"]
reg.exec(str);  // ["3"]
// ... 直到返回null
```

### 3. test — 正则调用，返回布尔值

```javascript
var str = "abc123";

/\d/.test(str);    // true  — 包含数字
/^\d/.test(str);   // false — 不以数字开头
/^\d+$/.test(str); // false — 不全是数字
/^\d+$/.test("123"); // true
```

### 4. replace — 字符串调用，替换匹配内容

```javascript
var str = "abc123def456";

// 简单替换
str.replace(/\d/g, "X");  // "abcXXXdefXXX"

// 回调函数替换（可获取匹配内容）
str.replace(/\d+/g, function(match) {
    return "*".repeat(match.length);  // 等长*号替换
});
// "abc***def***"
```

### 5. split — 字符串调用，参数可以是正则

```javascript
var str = "abc,123;def:456";

// 用正则分割（多种分隔符）
str.split(/[,;:]/);  // ["abc", "123", "def", "456"]
```

### API对比总结

| 方法 | 调用者 | 参数 | 返回值 | 加g效果 |
|------|--------|------|--------|---------|
| `match` | 字符串 | 正则 | 数组/null | 返回所有匹配 |
| `exec` | 正则 | 字符串 | 数组/null | 逐次返回下一个 |
| `test` | 正则 | 字符串 | boolean | 无影响 |
| `replace` | 字符串 | 正则+替换值 | 新字符串 | 替换所有 |
| `split` | 字符串 | 正则 | 数组 | 已是全部分割 |

## 六、实战：表单验证

### 1. 手机号验证

```javascript
// 规则：1开头 + 第2位3~9 + 后面9位数字，共11位
var phoneReg = /^1[3|4|5|6|7|8|9][0-9]{9}$/;

phoneReg.test("13812345678");  // true
phoneReg.test("23812345678");  // false — 不以1开头
phoneReg.test("1381234567");   // false — 只有10位
```

### 2. 邮箱验证

```javascript
// 规则：字母数字下划线@字母数字.域名
var emailReg = /^\w+@[0-9a-zA-Z]+\.[com|cn|net]$/;

emailReg.test("user123@qq.com");   // true
emailReg.test("user@163.cn");      // true
emailReg.test("user@.com");        // false — @后缺域名
emailReg.test("user@qq");          // false — 缺.域名
```

### 3. 密码验证

```javascript
// 规则：大写字母开头 + 6~16位字母数字
var pwdReg = /^[A-Z][0-9a-zA-Z]{5,15}$/;

pwdReg.test("Abc123");     // false — 不以大写开头
pwdReg.test("A12345");     // true  — 大写开头 + 5位 = 6位
pwdReg.test("A123456789012345"); // false — 超过16位
```

### 4. 敏感词过滤

```javascript
var text = "这是一段包含敏感词1和敏感词2的文字";

// 简单替换 — 固定长度星号
text.replace(/敏感词1/g, "***");

// 回调函数 — 等长星号替换（更合理）
text.replace(/敏感词\d/g, function(match) {
    var stars = "";
    for (var i = 0; i < match.length; i++) {
        stars += "*";
    }
    return stars;
});
// "这是一段包含****和****的文字"
```

## 七、正则编写思路

```
1. 分析规则 → 拆解为若干条件
2. 逐条件编写 → 每个条件对应正则片段
3. 组合拼接 → 用^$包裹，确保精确匹配
4. 测试验证 → 用test方法测试多种情况

示例：6位数字验证码
  规则分析: 6位 + 纯数字
  编写: /^\d{6}$/
  测试: "123456" → true, "abc123" → false, "12345" → false
```

## 八、常见正则模式速查

| 场景 | 正则表达式 |
|------|-----------|
| 手机号 | `/^1[3-9]\d{9}$/` |
| 邮箱 | `/^\w+@\w+\.\w+$/` |
| 身份证 | `/^\d{17}[\dX]$/` |
| 邮编 | `/^\d{6}$/` |
| 中文字符 | `/^[\u4e00-\u9fa5]+$/` |
| 网址 | `/^https?:\/\/\w+\.\w+/` |
