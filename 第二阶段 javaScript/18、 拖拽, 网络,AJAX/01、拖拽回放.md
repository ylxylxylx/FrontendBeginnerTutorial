# 拖拽回放

> 在拖拽移动过程中记录每一步坐标，点击回放按钮时按记录逆序还原轨迹

## 一、效果说明

```
┌──────────────────────────────────┐
│  ┌────── 拖拽回放窗口 ──────┐    │
│  │  section (拖拽区域)  [回放] │    │
│  │───────────────────────────│    │
│  │  isDrag: false            │    │
│  │  offsetLeft: 100          │    │
│  │  offsetTop: 200           │    │
│  └───────────────────────────┘    │
│                                   │
│  拖拽 → 记录坐标 → 点击回放 → 逆序还原  │
└──────────────────────────────────┘
```

## 二、核心变量

```javascript
var isDrag = false;       // 标记拖拽状态
var mousedownX, mousedownY; // 鼠标按下时的坐标
var divX, divY;           // 鼠标按下时box的坐标
var posArray = [];        // 记录box移动过程中的历史坐标
// posArray = [{x:100, y:200}, {x:102, y:198}, ...]
```

## 三、拖拽实现

### 1. 鼠标按下 — 开始拖拽

```javascript
section.onmousedown = function(e) {
    isDrag = true;
    // 记录鼠标坐标
    mousedownX = e.pageX;
    mousedownY = e.pageY;
    // 记录box坐标
    divX = box.offsetLeft;
    divY = box.offsetTop;
    
    // 把按下时的初始坐标存入数组
    posArray.push({ x: divX, y: divY });
}
```

### 2. 鼠标移动 — box跟随

```javascript
window.onmousemove = function(e) {
    if (!isDrag) return;  // 未拖拽则不计算
    
    // 计算鼠标坐标差
    var offsetX = e.pageX - mousedownX;
    var offsetY = e.pageY - mousedownY;
    
    // 计算box新坐标 = 按下时box坐标 + 坐标差
    var left = divX + offsetX;
    var top = divY + offsetY;
    
    // 边界判断
    var maxX = window.innerWidth - box.offsetWidth;
    var maxY = window.innerHeight - box.offsetHeight;
    if (left > maxX) left = maxX;
    if (top > maxY)  top = maxY;
    if (left < 0)    left = 0;
    if (top < 0)     top = 0;
    
    // 更新坐标
    box.style.left = left + "px";
    box.style.top = top + "px";
    
    // 记录最新坐标到数组
    posArray.push({ x: left, y: top });
}
```

### 3. 鼠标抬起 — 结束拖拽

```javascript
window.onmouseup = function() {
    isDrag = false;
}
```

## 四、回放实现

```javascript
function back(e) {
    // 阻止冒泡，防止触发section的mousedown
    e.stopPropagation();
    
    var timer = setInterval(function() {
        // 从数组末尾取出坐标（pop逆序）
        var pos = posArray.pop();
        
        // 更新box坐标
        box.style.left = pos.x + "px";
        box.style.top = pos.y + "px";
        
        // 数组清空时结束
        if (posArray.length <= 0) {
            clearInterval(timer);
        }
    }, 20);  // 每20ms还原一步
}
```

## 五、拖拽原理图解

```
鼠标按下时记录:
  mousedownX = 鼠标X坐标
  divX = box的left值

鼠标移动时计算:
  offsetX = 当前鼠标X - mousedownX    (鼠标移动了多少)
  left = divX + offsetX               (box也移动相同距离)

  ┌─────────── 鼠标移动offsetX ───────────┐
  │                                        │
  ↓ mousedownX                        当前鼠标X
  ●────────────────────────────────────●
  
  ┌─────────── box移动offsetX ────────────┐
  │                                        │
  ↓ divX                              新left
  ■────────────────────────────────────■
```

## 六、边界判断

```
窗口范围:
  ┌─────────────────────────────────────┐
  │ (0,0)                         maxX  │
  │   ┌─────┐                    ┌─────┐│
  │   │ box │                    │ box ││
  │   └─────┘                    └─────┘│
  │ (0,0)                      (maxX,maxY)
  └─────────────────────────────────────┘
  
  maxX = window.innerWidth - box.offsetWidth
  maxY = window.innerHeight - box.offsetHeight
  
  left < 0      → left = 0      (左边界)
  left > maxX   → left = maxX   (右边界)
  top < 0       → top = 0       (上边界)
  top > maxY    → top = maxY    (下边界)
```

## 七、UI实时更新

```javascript
function updateUI() {
    spans[0].innerText = isDrag;          // 拖拽状态
    spans[1].innerText = box.offsetLeft;  // X坐标
    spans[2].innerText = box.offsetTop;   // Y坐标
}
```

## 八、关键知识点

| 知识点 | 说明 |
|--------|------|
| `e.pageX/pageY` | 鼠标在页面上的坐标 |
| `offsetLeft/offsetTop` | 元素相对定位父级的偏移 |
| `offsetWidth/offsetHeight` | 元素自身宽高（含边框） |
| `innerWidth/innerHeight` | 浏览器窗口宽高 |
| `e.stopPropagation()` | 阻止事件冒泡 |
| `posArray.push()` | 记录坐标（从末尾添加） |
| `posArray.pop()` | 回放坐标（从末尾取出，逆序） |
| `setInterval(fn, 20)` | 定时器实现动画效果 |

## 九、实现步骤总结

1. 定义变量：拖拽状态、鼠标坐标、box坐标、坐标数组
2. 鼠标按下：记录初始坐标，存入数组，开始拖拽
3. 鼠标移动：计算坐标差，更新box位置，边界判断，存入坐标
4. 鼠标抬起：结束拖拽
5. 点击回放：setInterval + pop逆序取出坐标，还原轨迹
6. UI更新：实时显示拖拽状态和坐标值
