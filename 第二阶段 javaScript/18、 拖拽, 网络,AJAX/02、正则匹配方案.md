# 正则匹配方案

> 使用正则表达式对数组中重复元素添加序号，实现数据去重标识

## 一、问题描述

```javascript
var arr = ["ab", "c", "ab", "d", "c", "ab", "ab", "c"];
// 期望结果: ["ab1", "c1", "ab2", "d", "c2", "ab3", "ab4", "c3"]
// 重复元素按出现顺序添加序号，不重复元素不变
```

## 二、解决思路

```
1. 数组拼成字符串 → 用特殊分隔符连接
2. 遍历数组每个元素 → 创建正则匹配
3. 统计匹配次数 → 次数>1说明重复
4. 用replace+回调函数 → 给重复项添加序号
5. 字符串拆回数组
```

## 三、完整代码

```javascript
var arr = ["ab", "c", "ab", "d", "c", "ab", "ab", "c"];

// 步骤1: 把数组拼成一个字符串
var str = arr.join("##");
// "ab##c##ab##d##c##ab##ab##c"

// 步骤2: 循环数组中的每一个数据，进行正则匹配
arr.forEach(function(item) {
    // 创建正则表达式，以数组中的数据为匹配规则
    var reg = new RegExp(item, "gi");
    
    // 全局匹配所有结果
    var list = str.match(reg);
    
    // 如果匹配失败，返回
    if (!list) return;
    
    // 获取数据匹配到的次数
    var count = list.length;
    
    // 步骤3: 如果次数大于1，说明这个数据在数组中出现多次，添加序号
    if (count > 1) {
        var index = 0;
        // 正则替换，替换所有匹配的结果
        // 因为替换的索引是累加的，所以第二个参数用函数实现
        str = str.replace(reg, function(v) {
            // 参数v指的是正则匹配出的每一个结果
            console.log(v);
            // 先加1，序号从1累加
            index++;
            // 判断如果这个数据后已经添加过序号了，则不再添加
            if (!str.includes(v + index)) {
                return v + index;
            } else {
                return v;
            }
        });
    }
});

console.log(str.split("##"));
// ["ab1", "c1", "ab2", "d", "c2", "ab3", "ab4", "c3"]
```

## 四、关键步骤详解

### 1. 数组转字符串

```
["ab", "c", "ab"] → "ab##c##ab"

原因: 正则只能匹配字符串，需要先把数组转为字符串
分隔符用##: 避免与数据内容冲突
```

### 2. 动态创建正则

```javascript
// 用 new RegExp() 动态创建，item是变量
var reg = new RegExp(item, "gi");

// 不能用字面量，因为字面量中item是固定字符串
// /item/gi  ← 错误！这匹配的是字母"item"，不是变量item的值
```

### 3. replace回调函数

```javascript
str.replace(reg, function(v) {
    // v: 当前匹配到的内容
    // 每匹配到一个，函数执行一次
    // 返回值: 替换后的内容
    index++;
    return v + index;  // "ab" → "ab1" → "ab2" → ...
});
```

### 4. 防止重复添加序号

```javascript
// 检查是否已添加过序号
if (!str.includes(v + index)) {
    return v + index;  // 未添加过，添加序号
} else {
    return v;          // 已添加过，保持不变
}
```

## 五、执行流程图

```
原始数组: ["ab", "c", "ab", "d", "c", "ab", "ab", "c"]
     ↓ join("##")
字符串: "ab##c##ab##d##c##ab##ab##c"
     ↓ 遍历 "ab"
匹配到4次 → replace添加序号
字符串: "ab1##c##ab2##d##c##ab3##ab4##c"
     ↓ 遍历 "c"
匹配到3次 → replace添加序号
字符串: "ab1##c1##ab2##d##c2##ab3##ab4##c3"
     ↓ 遍历 "d"
匹配到1次 → 不处理
     ↓ split("##")
结果: ["ab1", "c1", "ab2", "d", "c2", "ab3", "ab4", "c3"]
```

## 六、知识点总结

| 知识点 | 用法 | 说明 |
|--------|------|------|
| `arr.join("##")` | 数组→字符串 | 用分隔符连接 |
| `new RegExp(item, "gi")` | 动态正则 | 变量作为匹配模式 |
| `str.match(reg)` | 全局匹配 | 返回所有匹配项的数组 |
| `str.replace(reg, fn)` | 替换+回调 | 每次匹配执行回调函数 |
| `str.includes()` | 查找子串 | 判断是否包含指定字符串 |
| `str.split("##")` | 字符串→数组 | 按分隔符拆分 |
