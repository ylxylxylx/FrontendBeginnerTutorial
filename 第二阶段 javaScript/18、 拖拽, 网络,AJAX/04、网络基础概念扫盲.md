# 网络基础概念扫盲

> 前端开发必备的网络基础知识：IP地址、域名、DNS、端口号、URL、服务器

## 一、IP地址

### 什么是IP地址

```
IP地址: Internet Protocol Address，互联网协议地址
作用: 在互联网中唯一标识一台设备
格式: 4个0~255的数字，用.分隔

示例: 192.168.1.123
```

### IPv4 与 IPv6

| 版本 | 长度 | 地址数量 | 格式示例 |
|------|------|----------|----------|
| IPv4 | 4字节(32位) | 约43亿 | `192.168.1.1` |
| IPv6 | 16字节(128位) | 3.4×10³⁸ | `0:0:0:0:0:0:0:0` ~ `ffff:...:ffff` |

> IPv4地址已接近用完，IPv6是未来趋势

### 本机常用IP

```
127.0.0.1  →  本机地址（回环地址）
localhost  →  本地地址（域名的形式）
```

## 二、域名

### 什么是域名

```
域名: Domain Name，俗称网址
作用: 给IP地址起一个容易记忆的名字

示例:
  www.baidu.com    → 百度
  www.taobao.com   → 淘宝
  www.qq.com       → 腾讯
  www.jd.com       → 京东
```

### 域名结构

```
www.baidu.com
│   │    │
│   │    └── .com 国际域名（顶级域名）
│   └─────── baidu 域名主体（二级域名）
└─────────── www  主机名（三级域名）
```

### 常见域名分类

| 类型 | 示例 | 说明 |
|------|------|------|
| 国际域名 | .com | 工商企业 |
| 国际域名 | .net | 网络提供商 |
| 国际域名 | .org | 非盈利组织 |
| 国内域名 | .cn | 中国 |
| 国内域名 | .us | 美国 |
| 国内域名 | .jp | 日本 |

## 三、DNS

### 什么是DNS

```
DNS: Domain Name System，域名解析系统
作用: 将域名转换为对应的IP地址

流程:
  用户输入 www.baidu.com
       ↓
  向DNS服务器发送请求
       ↓
  DNS返回 IP地址: 111.13.100.91
       ↓
  浏览器访问该IP地址
```

### 域名与IP的关系

```
域名 ←→ IP地址  (一一对应)

DNS服务器就是"翻译官":
  域名是人用的（好记）
  IP地址是机器用的（好找）
```

## 四、端口号

### 什么是端口号

```
端口号: Port，0~65535范围内的数字
作用: 标识计算机中哪个程序（进程）接收数据

类比:
  IP地址  → 大楼的地址
  端口号  → 房间号
  数据    → 快递包裹
```

### 常见默认端口号

| 协议 | 默认端口 | 说明 |
|------|----------|------|
| HTTP | 80 | 网页访问（可省略） |
| HTTPS | 443 | 加密网页访问 |
| FTP | 21 | 文件传输 |
| MySQL | 3306 | 数据库 |

> 访问 `http://www.baidu.com` 实际是 `http://www.baidu.com:80`

## 五、URL

### 什么是URL

```
URL: Uniform Resource Locator，统一资源定位符
作用: 互联网上每个资源的唯一地址

示例: http://192.168.14.222:5000/register?username=3&password=4
```

### URL的5个组成部分

```
http://192.168.14.222:5000/register?username=3&password=4
  │       │            │     │          │
  │       │            │     │          └── 5.查询参数(?key=value&key=value)
  │       │            │     └──────────── 4.路径/接口(服务器中的功能)
  │       │            └────────────────── 3.端口号(:5000)
  │       └─────────────────────────────── 2.IP地址/域名
  └─────────────────────────────────────── 1.协议(http://)
```

### URL常见协议

| 协议 | 格式 | 说明 |
|------|------|------|
| HTTP | `http://` | 最常用的网络协议 |
| HTTPS | `https://` | 加密的HTTP协议 |
| File | `file://` | 访问本地文件 |
| FTP | `ftp://` | 文件传输协议 |

## 六、服务器

### 什么是服务器

```
服务器: 为客户端提供数据服务的计算机

硬件: 超强CPU、超大内存、超大硬盘、超快网络
软件: 运行服务器程序（如Node.js、IIS、Apache）
```

### 客户端与服务器

```
┌─────────┐    请求(request)    ┌─────────┐
│         │ ──────────────────→ │         │
│  客户端  │                    │  服务器  │
│ (浏览器) │ ←────────────────── │ (Node)  │
│         │    响应(response)   │         │
└─────────┘                     └─────────┘

客户端: 请求服务的一方（浏览器、App）
服务器: 提供服务的一方（存储数据、处理逻辑、返回结果）
```

### 服务器的作用

| 能力 | 说明 | 示例 |
|------|------|------|
| 存储 | 提供静态资源 | 网页、图片、视频 |
| 运算 | 生成动态资源 | 股票数据、推荐算法 |
| 网络 | 多用户连接 | 聊天、在线游戏 |

### 服务器分类

```
远程服务器: 外网服务器，正式上线使用
本地服务器: 内网服务器，开发测试使用

开发阶段: 在本机启动服务器（127.0.0.1:5000）
上线阶段: 部署到远程服务器（www.xxx.com）
```

## 七、网络请求流程总结

```
1. 用户在浏览器输入URL
2. DNS将域名解析为IP地址
3. 浏览器向服务器IP:端口发送请求
4. 服务器接收请求，处理逻辑
5. 服务器返回响应数据
6. 浏览器接收响应，渲染页面

完整流程:
  浏览器 → DNS → IP:端口 → 服务器 → 处理 → 响应 → 浏览器渲染
