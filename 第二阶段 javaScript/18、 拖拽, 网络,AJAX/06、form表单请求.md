# 使用form表单发起请求

> 传统的网络请求方式：通过form表单的submit事件，将数据发送到服务器

## 一、form表单提交原理

```html
<form action="http://192.168.14.222:5000/register">
    <label for="name">账号:</label>
    <input id="name" name="username" type="text">
    <br>
    <label for="pas">密码:</label>
    <input id="pas" name="password" type="password">
    <br>
    <input type="submit" value="提交">
</form>
```

### 提交流程

```
1. 用户填写表单数据
2. 点击提交按钮，触发submit事件
3. 浏览器自动将表单数据发送到action指定的地址
4. 页面跳转到服务器返回的结果页面（整个页面刷新）
```

## 二、form表单关键属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `action` | 请求的服务器地址 | `action="http://xxx:5000/register"` |
| `method` | 请求方式（默认GET） | `method="post"` |
| `name` | 输入框的名称（作为参数名） | `name="username"` |

## 三、数据提交格式

```
提交后浏览器地址变为:
http://192.168.14.222:5000/register?username=3&password=4

数据格式: key=value&key=value
  username=3    → name属性值=输入的值
  password=4    → name属性值=输入的值
  &             → 多个参数用&分隔
```

> **注意**：input必须有name属性，否则数据不会被提交

## 四、URL地址解析

```
http://192.168.14.222:5000/register?username=3&password=4
│       │                │     │          │
│       │                │     │          └── 查询参数
│       │                │     └───────────── 服务器接口/路径
│       │                └─────────────────── 端口号
│       └──────────────────────────────────── IP地址
└───────────────────────────────────────────── 协议
```

### URL的5个部分

| 部分 | 示例 | 说明 |
|------|------|------|
| 协议 | `http://` | 超文本传输协议 |
| IP地址 | `192.168.14.222` | 服务器地址 |
| 端口号 | `:5000` | 服务器程序端口 |
| 路径 | `/register` | 服务器接口（不同功能） |
| 参数 | `?username=3&password=4` | 表单提交的数据 |

## 五、form表单请求的缺陷

```
1. 页面刷新: 提交后整个页面会被服务器返回的结果替换
2. 同步等待: 提交后必须等服务器响应才能继续操作
3. 用户体验差: 页面白屏等待，无法局部更新
4. 无法获取响应数据: JS无法直接处理服务器返回的结果

这些缺陷正是AJAX出现的原因！
```

## 六、GET vs POST

| 对比项 | GET | POST |
|--------|-----|------|
| 数据位置 | URL参数中 | 请求体中 |
| 可见性 | 地址栏可见 | 不可见 |
| 数据量 | URL长度限制 | 无限制 |
| 安全性 | 较低 | 较高 |
| 缓存 | 会被缓存 | 不会缓存 |
| 幂等性 | 幂等（多次请求结果相同） | 非幂等 |
