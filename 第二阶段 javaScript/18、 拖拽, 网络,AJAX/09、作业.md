## 作业2详细说明：获取新闻数据

### 步骤

```
1. 启动本地服务器
   - 在服务器目录下打开命令行
   - 执行 npm i 安装依赖
   - 执行 node index 启动服务器
   - 访问 http://127.0.0.1:5000

2. 使用AJAX请求news接口
   - 创建XMLHttpRequest对象
   - open("get", "http://127.0.0.1:5000/news")
   - send()发送请求
   - onreadystatechange监听响应

3. 解析JSON数据
   - JSON.parse(xhr.responseText)
   - 从stories数组中提取新闻标题和图片

4. 渲染到页面
   - 创建DOM元素
   - 设置内容（标题、图片）
   - 添加到页面
```

### 参考代码框架

```javascript
var xhr = new XMLHttpRequest();
xhr.open("get", "http://127.0.0.1:5000/news");
xhr.send();
xhr.onreadystatechange = function() {
    if (xhr.readyState == 4) {
        var data = JSON.parse(xhr.responseText);
        // 遍历stories数组
        data.stories.forEach(function(story) {
            // 创建元素，展示story.title和story.images[0]
        });
    }
}
```

## 服务器启动说明

```
1. 在服务器目录下，按住shift，右键选择"在此处打开powershell"
2. 输入指令 npm i 回车（安装依赖）
3. 输入指令 node index 回车（启动服务器）
4. 浏览器访问 http://127.0.0.1:5000 测试本地服务器
```

## 注意事项

- 服务器需要先启动才能发起AJAX请求
- news接口返回的是知乎日报的新闻数据
- 注意JSON.parse解析响应数据
- 页面渲染时注意处理images数组（可能为空）
