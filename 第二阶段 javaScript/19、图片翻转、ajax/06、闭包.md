# 闭包

> 闭包是JavaScript的重要概念：让局部变量拥有全局变量的功能

## 一、什么是闭包

```
闭包: 在函数A内部有另一个函数B，在函数A外部调用函数B，就是闭包

作用: 让局部变量拥有全局变量的功能
  → 不被重置
  → 不被外部直接修改
```

## 二、闭包的形成

### 1. 普通的函数嵌套（无法在外部调用内部函数）

```javascript
function A() {
    var count = 0;
    function B() {
        count++;
        console.log(count);
    }
}

// B();  // 报错！B是局部函数，只能在A()内部调用
```

### 2. 闭包的写法（把内部函数作为返回值返回）

```javascript
function A() {
    var count = 0;
    return function () {   // 把内部函数B作为返回值
        count++;
        console.log(count);
    }
}

var B = A();  // 调用A()之后得到一个函数B
B();          // 在外部成功调用B，输出 1
```

### 闭包的形成条件

```
在一个函数内部返回另一个函数，并在外部调用

三要素:
  1. 函数嵌套（函数A内部有函数B）
  2. 内部函数引用外部函数的局部变量
  3. 内部函数被返回并在外部调用
```

## 三、闭包的作用

### 作用一：让局部变量不被重置（实现累加）

```javascript
function AA() {
    var count = 0;
    return function () {
        count++;
        console.log(count);
    }
}

var BB = AA();
BB(); BB(); BB(); BB(); BB(); BB(); BB();
// 依次输出: 1、2、3、4、5、6、7
// count没有被重置，实现了累加功能
```

```
对比: 普通局部变量 vs 闭包中的局部变量

普通局部变量:
  每次调用函数，count都重新初始化为0 → 永远输出1

闭包中的局部变量:
  count被闭包"锁定"，不会被重置 → 实现累加
```

### 作用二：锁定变量值（经典按钮点击问题）

**需求**：给6个button绑定点击事件，点击时提示"点击了第N个按钮"

**一般写法（使用自定义属性）**：

```javascript
var btns = document.querySelectorAll("button");
for (var i = 1; i <= btns.length; i++) {
    btns[i - 1].index = i;   // 把i存到按钮的自定义属性上
    btns[i - 1].onclick = function () {
        alert("点击了第" + this.index + "个按钮");
    }
}
```

**闭包写法**：

```javascript
function AAA(index) {
    return function () {
        alert("点击了第" + index + "个按钮");
    }
}

var btns = document.querySelectorAll("button");
for (var i = 1; i <= btns.length; i++) {
    btns[i - 1].onclick = AAA(i);
}
```

**闭包写法原理**：

```
for循环的变量i被传入闭包函数中，作为局部变量index

每次循环:
  i=1 → AAA(1) → 返回函数，index锁定为1
  i=2 → AAA(2) → 返回函数，index锁定为2
  i=3 → AAA(3) → 返回函数，index锁定为3
  ...

因为闭包可以保证局部变量不被重置和修改
所以每一个点击事件都对应了各自的索引index
这些索引被闭包锁定，互不干扰
```

## 四、闭包的应用：封装插件

```
第三方插件的基本要求:
  插件中的变量名不能和我们自己写的代码变量名冲突
  否则会导致插件失效

所以:
  1. 插件中的变量必须是局部变量（避免冲突）
  2. 插件的API需要在全局作用域中使用

闭包正好满足这个需求:
  → 内部变量是局部的（不污染全局）
  → 通过返回值暴露API到全局

例如: jQuery在使用闭包封装之后
  只有一个全局变量 $() 这个函数
  相当于上边闭包结构中的 A()、AA()、AAA()
```

```javascript
console.log($);  // jQuery只暴露这一个全局变量
// jQuery内部成百上千的变量、函数都是局部的，不会与用户代码冲突
```

## 五、补充：垃圾回收机制

### 什么是垃圾回收机制

```
电脑或手机会定期清理没用的缓存，释放内存

在网页上:
  浏览器会定期清理没有用的变量、数组、对象等数据

对于函数:
  当一个函数执行结束，会被认为函数中所有的局部变量都没有用了
  → 会被垃圾回收机制清理掉，释放内存

全局变量:
  在网页关闭时才清理
```

### 为什么局部变量会被重置？

```
局部变量使用之后会被垃圾回收机制回收、释放
下次再用，需要重新初始化
所以每次都会重置
```

### 闭包为什么能防止局部变量被重置？

```
闭包结构可以阻止垃圾回收机制清理对应的局部变量

原因: 内部函数还在引用这个变量
  → 浏览器认为这个变量还有用
  → 不会清理它
  → 变量值得以保留

这就是闭包让局部变量"拥有全局变量功能"的底层原理
```

## 六、闭包完整示例代码

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>闭包</title>
</head>
<body>
    <button>1</button>
    <button>2</button>
    <button>3</button>
    <button>4</button>
    <button>5</button>
    <button>6</button>
</body>
<script src="./jquery.min.js"></script>
<script>
    // 1. 闭包的形成
    function A() {
        var count = 0;
        return function () {
            count++;
            console.log(count);
        }
    }
    var B = A();
    B();

    // 2. 闭包的作用一：局部变量累加
    function AA() {
        var count = 0;
        return function () {
            count++;
            console.log(count);
        }
    }
    var BB = AA();
    BB(); BB(); BB();

    // 3. 闭包的作用二：锁定变量值
    function AAA(index) {
        return function () {
            alert("点击了第" + index + "个按钮");
        }
    }
    var btns = document.querySelectorAll("button");
    for (var i = 1; i <= btns.length; i++) {
        btns[i - 1].onclick = AAA(i);
    }
</script>
</html>
```

## 七、总结

| 要点 | 说明 |
|------|------|
| 定义 | 函数A内部有函数B，在A外部调用B |
| 形成条件 | 函数嵌套 + 返回内部函数 + 外部调用 |
| 作用一 | 让局部变量不被重置（累加器） |
| 作用二 | 锁定变量值（按钮点击索引） |
| 应用 | 封装插件，避免全局变量冲突 |
| 底层原理 | 闭包阻止垃圾回收机制清理局部变量 |
| 典型案例 | jQuery只暴露一个全局变量 `$` |
