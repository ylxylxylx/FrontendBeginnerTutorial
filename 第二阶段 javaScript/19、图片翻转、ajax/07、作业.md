## 作业2详细说明：加载更多功能

### 需求

```
页面底部有一个"加载更多"按钮
点击按钮时，向服务器请求下一页的数据
请求参数: page（页码），如 page=3 表示请求第3页数据
请求方式: GET
接口地址: /loadMore
```

### 实现步骤

```
1. 准备页面结构
   - 一个列表容器（展示数据）
   - 一个"加载更多"按钮

2. 定义页码变量
   - var page = 1;  // 从第1页开始

3. 点击按钮时发起AJAX请求
   - 使用 $.get() 或原生AJAX
   - 传递参数 page
   - 请求成功后将数据追加到列表中

4. 页码自增
   - page++  // 下次点击请求下一页
```

### 参考代码框架

```javascript
var page = 1;

document.querySelector("button").onclick = function () {
    // 使用jQuery的$.get()发起请求
    $.get("http://192.168.14.222:5000/loadMore", {
        page: page
    }, function (data) {
        // 请求成功，data是响应数据（jQuery已自动解码JSON）
        console.log(data);

        // 遍历数据，创建元素追加到页面列表中
        // data.forEach(function (item) {
        //     var li = document.createElement("li");
        //     li.innerText = item.title;
        //     document.querySelector("ul").appendChild(li);
        // });

        // 页码自增，下次点击加载下一页
        page++;
    });
}
```

### 原生AJAX写法参考

```javascript
var page = 1;
var btn = document.querySelector("button");

btn.onclick = function () {
    var xhr = new XMLHttpRequest();
    // GET请求，数据拼接在URL中
    xhr.open("get", "http://192.168.14.222:5000/loadMore?page=" + page);
    xhr.send();
    xhr.onreadystatechange = function () {
        if (xhr.readyState == 4) {
            var data = JSON.parse(xhr.responseText);
            console.log(data);
            // 渲染数据到页面...
            page++;
        }
    }
}
```

## 注意事项

- 服务器需要先启动才能发起AJAX请求
- GET请求的数据拼接在URL中：`?page=3`
- 使用jQuery时响应数据已自动解码JSON，无需手动JSON.parse
- 使用原生AJAX时需要手动JSON.parse解码
- 每次请求成功后记得 page++，否则永远请求同一页
