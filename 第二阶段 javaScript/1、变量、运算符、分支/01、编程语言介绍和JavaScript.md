# 编程语言介绍和 JavaScript

> 本节了解编程语言的发展历程、分类方式，以及 JavaScript 的定位与历史。

## 编程语言的三个历史阶段

### 1. 机器语言

- 直接使用 **0 和 1** 组成的二进制指令控制计算机
- 计算机直接执行，**运算效率最高**
- 极难阅读和维护，不同计算机指令系统不同，**不可移植**

### 2. 汇编语言

- 用单词缩写替代二进制指令，如 `ADD`（加法）、`MOV`（数据传递）
- 需要汇编程序翻译成机器语言才能执行
- 仍然依赖硬件，**移植性不好**，但效率高

### 3. 高级语言

- 使用接近人类语言的语法，**所有机器通用**
- 需要编译程序翻译为机器语言才能执行
- 编程复杂度和学习难度大幅降低

| 阶段 | 特点 | 可读性 | 可移植性 | 效率 |
|------|------|--------|---------|------|
| 机器语言 | 0和1二进制 | 极低 | 不可移植 | 最高 |
| 汇编语言 | 英文缩写 | 中等 | 差 | 高 |
| 高级语言 | 接近人类语言 | 高 | 通用 | 较低 |

## 高级语言的分类

### 按运行原理

| 类型 | 说明 | 代表语言 |
|------|------|---------|
| 编译型 | 先编译全部代码为可执行文件，再执行 | C、C++、Java |
| 解释型 | 一边编译一边执行（编译一行，执行一行） | JavaScript、Python、PHP |

> 理论上，编译型语言比解释型语言执行效率高。

### 按数据类型

| 类型 | 说明 | 代表语言 |
|------|------|---------|
| 强类型 | 变量必须指明类型，不同类型不能互相赋值 | C、Java、C++ |
| 弱类型 | 变量不需要指定类型，类型不固定 | JavaScript、VB |

### 按编程范式

| 类型 | 说明 | 代表语言 |
|------|------|---------|
| 面向过程 | 函数为基本单元，着重流程开发 | C、JavaScript |
| 面向对象 | 类和对象为基本单元，着重对象开发 | C++、Java |

**类比 — 把大象装进冰箱：**

- **面向过程**：1.打开冰箱门 → 2.把大象装进去 → 3.关上冰箱门（自己操作所有步骤）
- **面向对象**：冰箱有打开、装入、关闭三个功能，告诉冰箱执行即可（对象自动完成）

## JavaScript 简介

JavaScript 是一种**弱类型的脚本语言**，支持多范式开发（面向过程为主，也可实现面向对象）。

### JS 的运行环境

- **浏览器**：JS 没有独立运行环境，只能依附于浏览器运行
- **Node.js**：使 JS 有了独立的运行环境，可以调用操作系统功能

### JS 与 Java 的关系

> JavaScript 和 Java 是**两种不同的语言**，关系就好比"雷锋"和"雷峰塔"的关系。

1995年，网景公司的布兰登·艾奇开发了 JavaScript，起名时借了 Java 的名气来推广，但两者除了语法有点像，基本没有关系。

### HTML、CSS、JS 的关系

| 技术 | 职责 | 比喻 |
|------|------|------|
| HTML | 决定页面**内容**（结构） | 骨架 |
| CSS | 决定页面**样式**（美化） | 皮肤 |
| JS | 决定页面**逻辑**（交互） | 肌肉 |

> JS 能够修改 HTML 和 CSS。

### ECMAScript 与 JavaScript

ECMAScript 是 JavaScript 的**规格标准**，JavaScript 是 ECMAScript 的一种**实现**。

| 版本 | 时间 | 说明 |
|------|------|------|
| ES 1.0 | 1997 | 首版 |
| ES 3.0 | 1999 | 巨大成功，奠定基本语法 |
| ES 5.0 | 2009 | 使用最广泛的版本 |
| ES 6 | 2015 | 重大更新，添加大量新特性 |
| ES 7+ | 2016+ | 每年发布一个新版本 |
