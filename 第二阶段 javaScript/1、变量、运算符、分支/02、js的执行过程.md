# JS 的执行过程

> 本节学习 JavaScript 在页面中的引入方式和执行顺序。

## JS 代码的引入方式

### 方式一：页面内嵌

在 HTML 页面中添加 `<script>` 标签，直接在标签内写 JS 代码：

```html
<script>
    console.log('Hello JavaScript');
</script>
```

### 方式二：外部引入

通过 `<script>` 标签的 `src` 属性引入外部 JS 文件：

```html
<script src="a.js"></script>
<script src="b.js"></script>
```

> ⚠️ 引入外部文件的 `<script>` 标签内不要再写 JS 代码，不会执行。

## JS 的执行顺序

### 从上到下执行

程序在页面中的执行顺序是**从上而下**执行的。

### 渲染与 JS 的关系

1. 浏览器会**优先渲染** HTML 和文字信息
2. 图片、视频和外部资源放在**后面**加载
3. JS 执行时，浏览器会**暂停** HTML 和 CSS 的渲染
4. JS 执行完毕后，**继续** HTML 和 CSS 的渲染

### 多个 script 标签

一个页面上有多个 `<script>` 标签时，按照**从上往下**的顺序执行。最终会把所有 script 标签中的代码**拼接在一起**执行。

```html
<script>
    var a = 2;
    var b = 3;
    console.log(a + b);  // 5
</script>

<script src="a.js"></script>  <!-- 外部文件 -->

<script>
    console.log('xxx');  // 继续执行
</script>
```

## 执行流程图

```
页面加载
  ↓
从上到下解析 HTML
  ↓
遇到 <script> → 暂停渲染 → 执行 JS → 继续渲染
  ↓
遇到 <script src> → 暂停渲染 → 加载并执行 JS → 继续渲染
  ↓
页面渲染完成
```

## 速记口诀

> script 两种写法，内嵌外引都可以；
> 从上到下顺序走，JS 执行停渲染；
> 多个 script 拼一起，外部文件别忘引。
