## 变量

变量是程序执行过程中**值可以变化的量**，用来保存值、传值、修改值。

### 声明变量

使用 `var` 关键字声明变量（variable 的缩写）：

```javascript
var age;        // 声明变量
age = 18;       // 赋值：把 18 赋给变量 age
console.log(age); // 输出：18
```

### 声明并赋值

```javascript
var height = 180;  // 声明的同时赋值
```

### 同时声明多个变量

```javascript
var age1, age2;              // 同时声明
var h1 = 100, h2 = 200;     // 同时声明并赋值
```

> 💡 `=` 是**赋值运算符**，不是"等于"的意思。

### 命名规范

| 规则 | 说明 |
|------|------|
| 组成 | 字母、数字、下划线 `_` |
| 开头 | 以字母或下划线开头，不能以数字开头 |
| 关键字 | 不能使用 JS 保留字（如 `var`、`if`、`for`） |
| 命名法 | **小驼峰**命名法：`myName`、`isLogin` |
| 语义 | 命名要有意义，见名知意 |

**大驼峰 vs 小驼峰**：

| 命名法 | 示例 | 说明 |
|--------|------|------|
| 大驼峰 | `MyName` | 每个单词首字母大写 |
| 小驼峰 | `myName` | 首字母小写，其后每个单词首字母大写 |

### 分号

- 每一行结尾的 `;` 可以不写，但**建议写上**
- 每个分号表示一句代码的结束
- 不加分号时必须使用回车换行

## 基本数据类型

### 1. number — 数字类型

整数、小数、负数都是 number 类型：

```javascript
var score = 95;     // 整数
score = 92.6;       // 小数
score = -10;        // 负数
console.log(typeof score);  // "number"
```

### 2. string — 字符串类型

写在 `""` 双引号或 `''` 单引号中的内容：

```javascript
var myName = '金西振';
var myHome = "河南";
console.log(myName, myHome, typeof myName);  // 金西振 河南 string
```

### 3. boolean — 布尔类型

只有两个值：`true`（真）和 `false`（假）：

```javascript
var isLogin = true;   // 是否登录
console.log(isLogin, typeof isLogin);  // true "boolean"
```

> 💡 布尔值变量名一般用 `is` 或 `has` 开头，如 `isLogin`、`hasPermission`。

## typeof — 检测类型

`typeof` 运算符用于获取变量的数据类型：

```javascript
typeof score      // "number"
typeof myName     // "string"
typeof isLogin    // "boolean"
typeof(isLogin)   // 也可以用括号
```

## 扩展：ES5 的 6 种数据类型

| 类别 | 类型 | 说明 |
|------|------|------|
| 基本类型 | number | 数字 |
| 基本类型 | string | 字符串 |
| 基本类型 | boolean | 布尔 |
| 基本类型 | null | 空值，此处应该有值 |
| 基本类型 | undefined | 未定义，声明未赋值 |
| 引用类型 | object | 对象 |

```javascript
var num;               // 声明未赋值
console.log(typeof num);   // "undefined"

var o = null;          // 空值
console.log(typeof o);     // "object"（历史遗留bug）

var p = {};            // 空对象
console.log(typeof p);     // "object"
```

> ⚠️ `typeof null` 返回 `"object"`，这是 JS 的历史遗留 bug，null 不是对象。

## 速记口诀

> var 声明变量，小驼峰来命名；
> number 数字 string 串，boolean 真 false 假；
> typeof 查类型，undefined 未赋值；
> null 空值 typeof object，六个类型要记牢。
