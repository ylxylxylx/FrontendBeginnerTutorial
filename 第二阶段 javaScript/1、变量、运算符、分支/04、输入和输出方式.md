# JS 输入和输出方式

> 本节学习 JavaScript 中常用的输入输出方法，用于与用户交互和调试。

## 输出方式

### 1. console.log() — 控制台输出

最常用的调试输出方式，输出到浏览器开发者工具的控制台：

```javascript
console.log(100);           // 输出数值：100
console.log(100 + 200);     // 输出表达式结果：300
console.log("hello");       // 输出字符串：hello
var name = "张三";
console.log(name);          // 输出变量值：张三
console.log("姓名", name);  // 多参数逗号分隔：姓名 张三
```

> 💡 `console.log()` 不会阻塞程序执行，是最推荐的调试方式。

### 2. alert() — 弹窗输出

弹出对话框，显示内容，**会阻塞程序执行**：

```javascript
alert("欢迎光临！");
alert(100 + 200);   // 弹出 300
```

> ⚠️ `alert()` 会暂停代码执行，用户点击"确定"后才继续。开发调试时少用，影响体验。

### 3. document.write() — 页面输出

向 HTML 页面中写入内容：

```javascript
document.write("Hello World");     // 页面显示：Hello World
document.write("<h1>标题</h1>");    // 可写 HTML 标签
```

### 4. document.writeln() — 页面输出（带换行）

输出内容后自动加一个回车：

```javascript
document.writeln("第一行");
document.writeln("第二行");
```

> ⚠️ `writeln` 的换行在 HTML 中表现为空格，需配合 `<pre>` 标签才能看到换行效果。

### `<pre>` 标签保留格式

`<pre>` 标签内的内容会**保留空格和换行**：

```html
<pre>
    document.writeln("第一行");
    document.writeln("第二行");
</pre>
<!-- 输出会真正换行显示 -->
```

## 输入方式

### 1. prompt() — 输入弹窗

弹出带输入框的对话框，返回用户输入的内容：

```javascript
var name = prompt("请输入你的姓名：");
console.log(name);   // 输出用户输入的内容
```

**返回值情况**：

| 用户操作 | 返回值 |
|----------|--------|
| 输入内容后点确定 | 输入的字符串 |
| 不输入直接点确定 | 空字符串 `""` |
| 点取消 | `null` |

> ⚠️ `prompt()` 返回值始终是**字符串类型**，即使用户输入的是数字。

### 2. confirm() — 确认弹窗

弹出确认对话框，返回布尔值：

```javascript
var result = confirm("确定要删除吗？");
console.log(result);   // 点确定返回 true，点取消返回 false
```

## 输入输出方式对比

| 方法 | 类型 | 阻塞执行 | 返回值 | 用途 |
|------|------|----------|--------|------|
| `console.log()` | 输出 | 否 | 无 | 调试输出 |
| `alert()` | 输出 | **是** | 无 | 提示用户 |
| `document.write()` | 输出 | 否 | 无 | 向页面写入 |
| `prompt()` | 输入 | **是** | 字符串/null | 获取用户输入 |
| `confirm()` | 输入 | **是** | 布尔值 | 确认操作 |

## 速记口诀

> console.log 控制台，调试输出最常用；
> alert 弹窗会阻塞，开发调试要少用；
> prompt 输入返回串，取消得 null 记心中；
> confirm 确认返回布尔，write 向页面写内容。
