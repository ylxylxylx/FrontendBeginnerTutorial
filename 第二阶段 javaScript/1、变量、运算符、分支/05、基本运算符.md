# 基本运算符

> 本节学习 JavaScript 中的赋值运算符、算术运算符、字符串拼接和自增自减运算。

## 赋值运算符

| 运算符 | 示例 | 等价写法 | 说明 |
|--------|------|----------|------|
| `=` | `x = 5` | — | 赋值 |
| `+=` | `x += 3` | `x = x + 3` | 加后赋值 |
| `-=` | `x -= 3` | `x = x - 3` | 减后赋值 |
| `*=` | `x *= 3` | `x = x * 3` | 乘后赋值 |
| `/=` | `x /= 3` | `x = x / 3` | 除后赋值 |

```javascript
var sum = 0;
sum += 10;   // sum = sum + 10 = 10
sum += 20;   // sum = sum + 20 = 30
console.log(sum);  // 30
```

> 💡 `sum += n` 是累加的常用写法，等价于 `sum = sum + n`。

## 算术运算符

| 运算符 | 说明 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `3 + 2` | `5` |
| `-` | 减法 | `3 - 2` | `1` |
| `*` | 乘法 | `3 * 2` | `6` |
| `/` | 除法 | `6 / 2` | `3` |
| `%` | 取余（求模） | `5 % 2` | `1` |

```javascript
console.log(10 / 3);    // 3.3333...（JS 除法得小数）
console.log(5 % 2);     // 1（5除以2余1）
console.log(10 % 2);    // 0（10除以2余0，说明10是偶数）
```

> 💡 `%` 取余常用于判断奇偶：`n % 2 === 0` 为偶数，`n % 2 !== 0` 为奇数。

## Math.floor() — 向下取整

```javascript
console.log(Math.floor(3.9));   // 3
console.log(Math.floor(3.1));   // 3
console.log(Math.floor(-3.1));  // -4（向下取整，负数更小）
```

## 字符串拼接

`+` 遇到字符串时会执行**拼接**操作，结果为字符串：

```javascript
console.log("hello" + " world");  // "hello world"
console.log("年龄：" + 18);        // "年龄：18"
```

### 拼接顺序（重要！）

从左到右依次计算，`+` 遇到字符串就拼接：

```javascript
console.log('2' + 2 + 6);   // "226" → '2'+2='22', '22'+6='226'
console.log(2 + '2' + 6);   // "226" → 2+'2'='22', '22'+6='226'
console.log(2 + 2 + '6');   // "46"  → 2+2=4, 4+'6'='46'
```

> ⚠️ 拼接顺序从左到右！先算数字加法，再拼接字符串。

### 其他运算符遇到字符串

`-`、`*`、`/` 遇到字符串数字会**尝试转换为数字**再运算：

```javascript
console.log('6' - 2);     // 4（'6'转成6，6-2=4）
console.log('6' * 2);     // 12
console.log('6' / 2);     // 3
console.log('a' - 2);     // NaN（'a'无法转数字）
```

> ⚠️ 转换失败得到 `NaN`（Not a Number），表示不是一个数字。

## 自增和自减

| 运算符 | 示例 | 等价写法 | 说明 |
|--------|------|----------|------|
| `++` | `count++` | `count = count + 1` | 自增1 |
| `--` | `count--` | `count = count - 1` | 自减1 |

```javascript
var count = 0;
count++;       // count = 1
count++;       // count = 2
count--;       // count = 1
console.log(count);  // 1
```

### 前置与后置的区别

```javascript
var a = 5;
console.log(a++);   // 5（先输出，后自增）
console.log(a);     // 6

var b = 5;
console.log(++b);   // 6（先自增，后输出）
console.log(b);     // 6
```

| 写法 | 名称 | 执行顺序 | 示例（a=5） |
|------|------|----------|-------------|
| `a++` | 后置自增 | 先用后加 | 返回5，a变6 |
| `++a` | 前置自增 | 先加后用 | 返回6，a变6 |
| `a--` | 后置自减 | 先用后减 | 返回5，a变4 |
| `--a` | 前置自减 | 先减后用 | 返回4，a变4 |

> 💡 单独使用时 `a++` 和 `++a` 效果一样，只有在表达式中才有区别。

## 运算优先级

`()` 括号可以改变运算优先级：

```javascript
console.log(2 + 3 * 4);     // 14（先乘后加）
console.log((2 + 3) * 4);   // 20（括号优先）
```

**优先级从高到低**：`() → * / % → + - → 赋值`

## 速记口诀

> 赋值算术要分清，+= 累加最常用；
> 加遇字符串拼接，从左到右顺序算；
> 减乘除遇串转数，转不了得 NaN；
> ++ 自增 -- 自减，单独用时不分前后。
