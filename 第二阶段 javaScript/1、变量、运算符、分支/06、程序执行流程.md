# 程序执行流程

> 本节了解程序的三种基本执行结构：顺序、分支和循环。

## 三种程序结构

| 结构 | 说明 | 关键字 |
|------|------|--------|
| 顺序结构 | 从上到下逐行执行 | — |
| 分支结构 | 根据条件选择执行 | if / if-else / if-else if / switch |
| 循环结构 | 重复执行某段代码 | for / while / do-while |

## 1. 顺序结构

程序默认的执行方式，**从上到下逐行执行**：

```javascript
var a = 10;
var b = 20;
var c = a + b;
console.log(c);   // 30
```

> 💡 顺序结构是最基本的结构，所有程序都从上到下执行。

## 2. 分支结构

根据条件判断，**选择性地执行**不同的代码块：

```javascript
// 单分支
var age = 18;
if (age >= 18) {
    console.log("已成年");
}

// 双分支
var score = 75;
if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}

// 多分支
var level = "A";
if (level === "A") {
    console.log("优秀");
} else if (level === "B") {
    console.log("良好");
} else {
    console.log("一般");
}
```

## 3. 循环结构

**重复执行**某段代码，直到条件不满足：

```javascript
// for 循环
for (var i = 1; i <= 5; i++) {
    console.log(i);   // 输出 1 2 3 4 5
}

// while 循环
var j = 1;
while (j <= 5) {
    console.log(j);
    j++;
}

// do-while 循环（至少执行一次）
var k = 1;
do {
    console.log(k);
    k++;
} while (k <= 5);
```

## 三种循环对比

| 循环 | 特点 | 适用场景 |
|------|------|----------|
| `for` | 已知循环次数 | 遍历、计数 |
| `while` | 先判断后执行，可能不执行 | 不确定次数 |
| `do-while` | 先执行后判断，至少执行一次 | 至少执行一次 |

## 速记口诀

> 顺序结构最基本，从上到下逐行跑；
> 分支结构做选择，if else 来判断；
> 循环结构重复做，for while do-while；
> 三种结构组合用，程序逻辑就清晰。
