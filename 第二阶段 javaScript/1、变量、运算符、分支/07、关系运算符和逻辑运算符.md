# 关系运算符和逻辑运算符

> 本节学习关系运算符（比较）和逻辑运算符（与、或、非），它们是分支判断的基础。

## 关系运算符

关系运算符用于**比较两个值**，返回布尔值 `true` 或 `false`：

| 运算符 | 说明 | 示例 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | `true` |
| `>=` | 大于等于 | `5 >= 5` | `true` |
| `<` | 小于 | `3 < 5` | `true` |
| `<=` | 小于等于 | `3 <= 3` | `true` |
| `!=` | 不等于（值） | `5 != 3` | `true` |
| `==` | 等于（值） | `5 == 5` | `true` |
| `===` | 全等（值+类型） | `5 === 5` | `true` |

## == 和 === 的区别（重点！）

| 比较 | `==` 结果 | `===` 结果 | 说明 |
|------|-----------|------------|------|
| `5 == 5` | `true` | `true` | 值和类型都相同 |
| `5 == "5"` | `true` | `false` | `==` 只比较值，会类型转换 |
| `5 === "5"` | `false` | `false` | `===` 比较值和类型 |
| `0 == false` | `true` | `false` | `==` 会隐式转换 |
| `null == undefined` | `true` | `false` | `==` 认为相等 |

```javascript
console.log(2 == '2');    // true（值相等）
console.log(2 === '2');   // false（类型不同：number vs string）
console.log(0 == false);  // true（隐式转换）
console.log(0 === false); // false（类型不同）
```

> ⚠️ **推荐始终使用 `===`**，避免 `==` 的隐式类型转换带来的意外结果。

## 逻辑运算符

逻辑运算符用于**组合多个条件**：

### 1. && — 逻辑与（且）

**两边都为真，结果才为真**：

| 条件A | 条件B | A && B |
|-------|-------|--------|
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

```javascript
var age = 20;
var hasTicket = true;
if (age >= 18 && hasTicket) {
    console.log("可以进入");   // 两个条件都满足才执行
}
```

> 💡 记忆：**一假即假**（有一个 false 结果就是 false）

### 2. || — 逻辑或

**有一个为真，结果就为真**：

| 条件A | 条件B | A \|\| B |
|-------|-------|----------|
| true | true | true |
| true | false | true |
| false | true | true |
| false | false | false |

```javascript
var isVip = false;
var hasCoupon = true;
if (isVip || hasCoupon) {
    console.log("享受折扣");   // 满足任一条件即可
}
```

> 💡 记忆：**一真即真**（有一个 true 结果就是 true）

### 3. ! — 逻辑非（取反）

**将布尔值取反**，也常用于将任意值转为布尔值：

| 值 | !值 | !!值 |
|----|-----|------|
| true | false | true |
| false | true | false |

```javascript
var isLogin = false;
if (!isLogin) {
    console.log("请先登录");   // isLogin为false时执行
}

// !! 双重取反，将任意值转为布尔值
console.log(!!1);      // true
console.log(!!0);      // false
console.log(!!"hello"); // true
console.log(!!"");      // false
```

## 条件的写法

分支语句的条件可以是：

1. **关系表达式**：`age >= 18`
2. **逻辑表达式**：`age >= 18 && hasTicket`
3. **变量**：`isLogin`（布尔变量直接作为条件）
4. **取反**：`!isLogin`

```javascript
// 以下写法等价
if (isLogin === true) { ... }
if (isLogin) { ... }           // 推荐：布尔变量直接用

// 以下写法等价
if (isLogin === false) { ... }
if (!isLogin) { ... }          // 推荐：取反
```

## 速记口诀

> == 比值 === 比全，推荐用 === 更安全；
> && 与运算一假假，|| 或运算一真真；
> ! 取反得布尔，!! 双取反转布尔；
> 条件写法要简洁，布尔变量直接用。
