# 分支语句

> 本节学习 JavaScript 中的分支语句：单分支 if、双分支 if-else。

## 单分支 if

**条件成立时执行**，不成立则跳过：

```javascript
if (条件) {
    // 条件为 true 时执行的代码
}
```

```javascript
var age = 20;
if (age >= 18) {
    console.log("已成年，可以进入");
}
// 如果 age < 18，则跳过，什么都不执行
```

### 条件的写法

条件可以是**任何能产生布尔值的表达式**：

```javascript
// 关系运算符
if (score >= 60) { ... }

// 逻辑运算符
if (age >= 18 && hasTicket) { ... }

// 布尔变量
if (isLogin) { ... }

// 取反
if (!isLogin) { ... }
```

> ⚠️ 条件中的 `=` 是赋值，`==` 是比较值，`===` 是比较值和类型。判断相等**必须用 `==` 或 `===`**。

## 双分支 if-else

**条件成立执行一个分支，不成立执行另一个分支**，两个分支**有且只有一个**会执行：

```javascript
if (条件) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

```javascript
var score = 75;
if (score >= 60) {
    console.log("及格了！");
} else {
    console.log("不及格，继续努力！");
}
```

### 多分支 if-else if

当有多个条件需要依次判断时：

```javascript
if (条件1) {
    // 条件1为 true 时执行
} else if (条件2) {
    // 条件2为 true 时执行
} else if (条件3) {
    // 条件3为 true 时执行
} else {
    // 以上条件都不满足时执行
}
```

```javascript
var score = 85;
if (score >= 90) {
    console.log("优秀");
} else if (score >= 80) {
    console.log("良好");    // 输出这个
} else if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}
```

> 💡 多分支从上到下依次判断，**一旦某个条件满足，后面的都不再判断**。

### switch 语句

当条件是**固定值匹配**时，可以用 switch：

```javascript
var day = 3;
switch (day) {
    case 1: console.log("周一"); break;
    case 2: console.log("周二"); break;
    case 3: console.log("周三"); break;  // 匹配这个
    case 4: console.log("周四"); break;
    case 5: console.log("周五"); break;
    default: console.log("周末"); break;
}
```

> ⚠️ 每个 case 后必须加 `break`，否则会**穿透**执行后续所有 case。

### if-else if vs switch

| 对比 | if-else if | switch |
|------|------------|--------|
| 条件类型 | 范围判断（>=、<=） | 固定值匹配（===） |
| 灵活性 | 高，可写复杂条件 | 低，只能匹配具体值 |
| 可读性 | 条件多时较乱 | 值匹配时更清晰 |

## 嵌套分支

分支语句可以嵌套使用：

```javascript
var age = 25;
var gender = "男";

if (age >= 18) {
    if (gender === "男") {
        console.log("成年男性");
    } else {
        console.log("成年女性");
    }
} else {
    console.log("未成年");
}
```

> 💡 嵌套层数不宜过深（一般不超过3层），否则代码可读性差。

## 常见错误

### 1. 条件中用 = 代替 ==

```javascript
// ❌ 错误：= 是赋值，不是比较
if (score = 60) { ... }   // 永远为 true

// ✅ 正确
if (score === 60) { ... }
```

### 2. 省略大括号

```javascript
// ❌ 不推荐：省略大括号容易出错
if (age >= 18)
    console.log("成年");

// ✅ 推荐：始终写大括号
if (age >= 18) {
    console.log("成年");
}
```

## 速记口诀

> if 单分支看条件，成立执行不成立跳；
> if-else 双分支，二选一必走一个；
> else if 多分支，从上到下依次判；
> switch 匹配固定值，break 别忘防穿透；
> 条件比较用 ===，赋值 = 莫混淆。
