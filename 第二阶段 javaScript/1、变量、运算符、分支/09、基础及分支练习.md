## 基础练习

### 练习1：成绩求和

从键盘输入小明的语数外成绩，输出小明的总分：

```javascript
var yuwen = prompt('请输入语文成绩');
var shuxue = prompt('请输入数学成绩');
var yingyu = prompt('请输入英语成绩');
// prompt 返回字符串，需要转为数字
var sum = yuwen * 1 + shuxue * 1 + yingyu * 1;
alert('小明的总分是：' + sum);
```

> 💡 `prompt()` 返回字符串，用 `*1` 或 `Number()` 转换为数字。

### 练习2：圆的面积

定义变量 PI=3.1415926，从键盘输入半径 r，输出圆的面积（保留2位小数）：

```javascript
var PI = 3.1415926;
var r = prompt('请输入半径');
var area = PI * r * r;
console.log('圆的面积：' + area.toFixed(2));
```

### 练习3：圆柱体积

从键盘获取圆的半径 r 和圆柱高 h，求圆柱体积（保留三位小数）：

```javascript
var PI = 3.1415926;
var r = prompt('请输入半径');
var h = prompt('请输入高');
var volume = PI * r * r * h;
console.log('圆柱体积：' + volume.toFixed(3));
```

### 练习4：四位数拆分

从键盘输入一个四位正整数，输出个、十、百、千位上的数字：

```javascript
var num = prompt('请输入一个四位正整数');
// 千位：除以1000取整
var qian = Math.floor(num / 1000);
// 百位：除以100取整，再对10取余
var bai = Math.floor(num / 100) % 10;
// 十位：除以10取整，再对10取余
var shi = Math.floor(num / 10) % 10;
// 个位：对10取余
var ge = num % 10;
console.log('千位：' + qian + ' 百位：' + bai + ' 十位：' + shi + ' 个位：' + ge);
```

> 💡 拆分数字的通用方法：`Math.floor(num / 位权) % 10`

## 双分支练习

### 练习1：奖惩

张三的阶段测试成绩大于90分，奖励苹果；否则惩罚默写笔记：

```javascript
var score = prompt('请输入成绩');
if (score > 90) {
    alert('奖励一个苹果！');
} else {
    alert('惩罚默写笔记！');
}
```

### 练习2：及格判断

60分为及格，判断是否及格：

```javascript
var score = prompt('请输入分数');
if (score >= 60) {
    alert('你及格了！');
} else {
    alert('学渣！');
}
```

### 练习3：登录验证

用户名为"admin"且密码为"123"则登录成功，否则提示错误：

```javascript
var username = prompt('请输入用户名');
var password = prompt('请输入密码');
if (username === 'admin' && password === '123') {
    alert('登录成功！');
} else {
    alert('用户名或密码错误！');
}
```

### 练习4：复合条件奖励

数学>90且体育>80，或数学=100且体育>70，可获得奖励：

```javascript
var math = prompt('请输入数学成绩');
var pe = prompt('请输入体育成绩');
if ((math > 90 && pe > 80) || (math == 100 && pe > 70)) {
    alert('获得奖励！');
```

## 嵌套练习

### 练习1：相亲条件

输入性别、身高、收入，判断是否合适：

```javascript
var gender = prompt('请输入性别');
var height = prompt('请输入身高(cm)');
var income = prompt('请输入收入');
if (gender === '男') {
    if (height > 180 || income > 10000) {
        alert('I do!');
    } else {
        alert('你是个好人');
    }
} else {
    alert('我们性别不合适');
}
```

### 练习2：周末外出

如果是周六或周日，气温30度以上去游泳，否则去爬山：

```javascript
var day = prompt('今天是周几？（输入6或7表示周末）');
var temp = prompt('请输入气温');
if (day == 6 || day == 7) {
    if (temp > 30) {
        alert('去游泳');
    } else {
        alert('去爬山');
    }
}
```

### 练习4：三数排序

输入三个不同的数字，找出最大、最小、中间数：

```javascript
var a = prompt('请输入第一个数') * 1;
var b = prompt('请输入第二个数') * 1;
var c = prompt('请输入第三个数') * 1;
var max, mid, min;
if (a > b && a > c) {
    max = a;
    if (b > c) { mid = b; min = c; }
    else { mid = c; min = b; }
} else if (b > a && b > c) {
    max = b;
    if (a > c) { mid = a; min = c; }
    else { mid = c; min = a; }
} else {
    max = c;
    if (a > b) { mid = a; min = b; }
    else { mid = b; min = a; }
}
alert('最大：' + max + ' 中间：' + mid + ' 最小：' + min);
```

### 练习2：闰年判断

闰年规则：**四年一闰，百年不闰，四百年再闰**

```javascript
var year = prompt('请输入年份');
if (year % 400 === 0) {
    alert(year + '年是闰年');       // 能被400整除
} else if (year % 100 === 0) {
    alert(year + '年是平年');       // 能被100整除但不能被400整除
} else if (year % 4 === 0) {
    alert(year + '年是闰年');       // 能被4整除但不能被100整除
} else {
    alert(year + '年是平年');
}
```

> 💡 也可以简化为：`(year % 4 === 0 && year % 100 !== 0) || year % 400 === 0`
