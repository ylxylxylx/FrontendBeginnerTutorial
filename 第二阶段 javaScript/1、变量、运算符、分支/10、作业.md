## 作业1：++ -- 位置不同的结果

理解前置和后置自增自减的区别：

```javascript
var count = 5;

// 前置自增：先加1，再使用
console.log(++count);  // 6（count先变成6，再输出）
console.log(count);    // 6

// 后置自增：先使用，再加1
count = 5;
console.log(count++);  // 5（先输出5，count再变成6）
console.log(count);    // 6

// 前置自减：先减1，再使用
count = 5;
console.log(--count);  // 4（count先变成4，再输出）

// 后置自减：先使用，再减1
count = 5;
console.log(count--);  // 5（先输出5，count再变成4）
```

### 练习题

写出以下代码的输出结果：

```javascript
var a = 10;
console.log(a++);   // ?
console.log(++a);   // ?
console.log(a--);   // ?
console.log(--a);   // ?
```

<details>
<summary>参考答案</summary>

```
10  (先输出10，a变为11)
12  (a先变为12，再输出12)
12  (先输出12，a变为11)
10  (a先变为10，再输出10)
```

</details>

## 作业2：运算符的优先级

掌握运算符的优先级顺序：

### 优先级从高到低

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高） | `()` | 括号 |
| 2 | `++` `--` `!` | 自增自减、逻辑非 |
| 3 | `*` `/` `%` | 乘除取余 |
| 4 | `+` `-` | 加减 |
| 5 | `>` `>=` `<` `<=` | 关系运算符 |
| 6 | `==` `!=` `===` `!==` | 相等运算符 |
| 7 | `&&` | 逻辑与 |
| 8 | `\|\|` | 逻辑或 |
| 9（最低） | `=` `+=` `-=` | 赋值运算符 |

### 练习题

写出以下表达式的结果：

```javascript
console.log(2 + 3 * 4);         // ?
console.log((2 + 3) * 4);       // ?
console.log(10 > 5 && 3 < 1);   // ?
console.log(10 > 5 || 3 < 1);   // ?
console.log(!true);             // ?
console.log(!(10 > 5));         // ?
```

<details>
<summary>参考答案</summary>

```
14   (3*4=12, 2+12=14)
20   (2+3=5, 5*4=20)
false (true && false = false)
true  (true || false = true)
false (!true = false)
false (10>5为true, !true为false)
```

</details>

## 速记口诀

> 前置先用后置后，单独使用没区别；
> 括号最高赋值低，乘除优先于加减；
> 关系高于逻辑与，逻辑与高于逻辑或。
