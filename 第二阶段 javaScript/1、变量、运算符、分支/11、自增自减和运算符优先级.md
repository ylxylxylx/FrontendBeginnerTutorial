# 自增自减和运算符优先级

> 本节学习自增（++）和自减（--）运算符的前置后置区别，以及运算符的优先级顺序。

## 自增运算符 ++

自增运算符让变量的值**加1**，分为前置和后置两种写法。

### 前置自增 ++count

**先加1，再使用**：

```javascript
var count = 5;
console.log(++count);  // 6（count先变成6，再输出）
console.log(count);    // 6
```

### 后置自增 count++

**先使用，再加1**：

```javascript
var count = 5;
console.log(count++);  // 5（先输出5，count再变成6）
console.log(count);    // 6
```

### 单独使用没区别

```javascript
var a = 5;
a++;    // a变为6
var b = 5;
++b;    // b也变为6
// 单独使用时，前置和后置效果相同
```

> 💡 只有在**表达式中参与其他运算**时，前置和后置才有区别。

### 表达式中的区别

```javascript
// 示例1：++count + count++
var count = 5;
var sum = ++count + count++;
// 第一步：++count → count先加1变为6，使用6
// 第二步：count++ → 先使用count的值6，count再加1变为7
// sum = 6 + 6 = 12，count = 7
console.log(sum, count);  // 12 7

// 示例2：count++ + ++count
var count = 5;
var sum = count++ + ++count;
// 第一步：count++ → 先使用count的值5，count加1变为6
// 第二步：++count → count先加1变为7，使用7
// sum = 5 + 7 = 12，count = 7
console.log(sum, count);  // 12 7
```

## 自减运算符 --

自减运算符让变量的值**减1**，同样分前置和后置。

### 前置自减 --count

**先减1，再使用**：

```javascript
var count = 5;
console.log(--count);  // 4（count先变成4，再输出）
console.log(count);    // 4
```

### 后置自减 count--

**先使用，再减1**：

```javascript
var count = 5;
console.log(count--);  // 5（先输出5，count再变成4）
console.log(count);    // 4
```

## 短路运算与自增

逻辑运算符 `&&` 和 `||` 具有**短路特性**，会影响自增运算的执行。

### 短路与 &&

**前面为 false，后面不再执行**：

```javascript
var count = 5;
var num1 = 5 < 2 && count++;
// 5 < 2 为 false，短路，count++ 不执行
console.log(num1, count);  // false 5
```

### 短路或 ||

**前面为 true，后面不再执行**：

```javascript
var count = 5;
var num2 = 5 > 2 || count++ > 5;
// 5 > 2 为 true，短路，count++ 不执行
console.log(num2, count);  // true 5
```

### 非短路情况

```javascript
// || 前面为 falsy 值（0、""、null、undefined、false），后面会执行
var count = 5;
var num3 = 0 || count++;
// 0 为 falsy，继续执行 count++，先使用5，count变为6
console.log(num3, count);  // 5 6
```

> ⚠️ 短路运算中，`&&` 前面为 false 或 `||` 前面为 true 时，**后面的表达式不会执行**，自增/自减也不会生效。

## 运算符优先级

从高到低排列：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高） | `()` | 括号 |
| 2 | `++` `--` `!` | 自增、自减、逻辑非 |
| 3 | `*` `/` `%` | 乘、除、取余 |
| 4 | `+` `-` | 加、减 |
| 5 | `>` `>=` `<` `<=` | 关系运算符 |
| 6 | `==` `!=` `===` `!==` | 相等运算符 |
| 7 | `&&` | 逻辑与 |
| 8 | `||` | 逻辑或 |
| 9（最低） | `=` `+=` `-=` 等 | 赋值运算符 |

### 优先级示例

```javascript
// 1. 括号最高
console.log(2 + 3 * 4);     // 14（先乘后加）
console.log((2 + 3) * 4);   // 20（括号优先）

// 2. 自增高于算术
var a = 5;
console.log(++a * 2);       // 12（++a先执行，a=6，6*2=12）

// 3. 关系运算高于逻辑
console.log(5 > 3 && 2 < 1);  // false（先算关系，再算逻辑）
// 等价于 (5 > 3) && (2 < 1) → true && false → false

// 4. 逻辑与高于逻辑或
console.log(true || false && false);  // true
// 等价于 true || (false && false) → true || false → true

// 5. 赋值最低
var a = 5 > 3;  // 先算 5 > 3 得 true，再赋值给 a
console.log(a);  // true
```

### 练习题

写出以下代码的输出结果：

```javascript
var a = 10;
console.log(a++);   // 10（先使用10，a变为11）
console.log(++a);   // 12（a先变为12，再输出12）
console.log(a--);   // 12（先使用12，a变为11）
console.log(--a);   // 10（a先变为10，再输出10）
```

```javascript
console.log(2 + 3 * 4);         // 14
console.log((2 + 3) * 4);       // 20
console.log(10 > 5 && 3 < 1);   // false
console.log(10 > 5 || 3 < 1);   // true
console.log(!true);             // false
console.log(!(10 > 5));         // false
```

## 速记口诀

> 前置先用后置后，单独使用没区别；
> 括号最高赋值低，乘除优先于加减；
> 自增自减排第二，关系高于逻辑与；
> 逻辑与高于逻辑或，短路特性要牢记；
