# 三目运算符

> 本节学习三目运算符（三元运算符），掌握简洁的条件表达式写法。

## 语法

```javascript
结果 = 条件 ? 结果1 : 结果2;
```

### 执行流程

1. 判断**条件**是否为 true
2. 如果为 true，得到**结果1**
3. 如果为 false，得到**结果2**

> 三目运算符是 if-else 的简写形式，适合简单的二选一场景。

## 基础示例

### 示例1：成绩判断

```javascript
// if-else 写法
var score = prompt('请输入分数');
if (score < 60) {
    alert('不及格');
} else {
    alert('好厉害');
}

// 三目运算符写法
var score = prompt('请输入分数');
var res = score < 60 ? '不及格' : '好厉害';
alert(res);
```

### 示例2：奇偶判断

```javascript
var num = 7;
var result = num % 2 === 0 ? '偶数' : '奇数';
console.log(result);  // 奇数
```

### 示例3：求最大值

```javascript
var a = 10, b = 20;
var max = a > b ? a : b;
console.log('最大值：' + max);  // 20
```

### 示例4：判断成年

```javascript
var age = 20;
var status = age >= 18 ? '成年' : '未成年';
console.log(status);  // 成年
```

## 三目运算符 vs if-else

| 对比项 | 三目运算符 | if-else |
|--------|-----------|---------|
| 语法 | `条件 ? 结果1 : 结果2` | `if-else { ... }` |
| 返回值 | 有返回值 | 无返回值 |
| 代码量 | 一行 | 多行 |
| 适用场景 | 简单的二选一 | 复杂逻辑或多条语句 |
| 可读性 | 简洁但不宜嵌套 | 清晰明了 |

> 💡 三目运算符适合**简单的赋值或输出**，复杂逻辑还是用 if-else 更清晰。

## 三目运算符嵌套

当有多个条件时，可以嵌套使用：

```javascript
var score = 75;
var level = score >= 90 ? '优秀' : (score >= 60 ? '及格' : '不及格');
console.log(level);  // 及格
```

### 嵌套的执行流程

```
score >= 90 ?
  是 → '优秀'
  否 → score >= 60 ?
         是 → '及格'
         否 → '不及格'
```

### 嵌套示例：判断年龄阶段

```javascript
var age = 25;
var stage = age < 18 ? '未成年' : (age < 60 ? '成年' : '老年');
console.log(stage);  // 成年
```

> ⚠️ 三目嵌套层数不宜超过2层，否则代码可读性很差，应改用 if-else if。

## 条件和结果的类型

### 条件

条件可以是任何能产生布尔值的表达式：

```javascript
// 关系表达式
var a = 5 > 3 ? 'yes' : 'no';

// 逻辑表达式
var b = (x > 0 && y > 0) ? '正' : '非正';

// 布尔变量
var isLogin = true;
var c = isLogin ? '已登录' : '未登录';
```

### 结果

结果1和结果2可以是具体值，也可以是表达式：

```javascript
// 具体值
var a = x > 0 ? 1 : -1;

// 字符串
var b = score >= 60 ? '及格' : '不及格';

// 表达式
var c = x > 0 ? x * 2 : x + 1;
```

## 常见错误

### 1. 忘记赋值

```javascript
// ❌ 三目运算符的结果没有使用
score < 60 ? '不及格' : '好厉害';

// ✅ 需要赋值或输出
var res = score < 60 ? '不及格' : '好厉害';
```

### 2. 嵌套过深

```javascript
// ❌ 嵌套太深，难以阅读
var level = score >= 90 ? 'A' : (score >= 80 ? 'B' : (score >= 70 ? 'C' : (score >= 60 ? 'D' : 'F')));

// ✅ 改用 if-else if
var level;
if (score >= 90) level = 'A';
else if (score >= 80) level = 'B';
else if (score >= 70) level = 'C';
else if (score >= 60) level = 'D';
else level = 'F';
```

### 3. 在三目中写多条语句

```javascript
// ❌ 三目运算符不适合多条语句
score < 60 ? (alert('不及格'), console.log('需努力')) : (alert('好厉害'), console.log('继续保持'));

// ✅ 改用 if-else
if (score < 60) {
    alert('不及格');
    console.log('需努力');
} else {
    alert('好厉害');
    console.log('继续保持');
}
```

## 速记口诀

> 三目运算问号连，条件真假两结果；
> 条件为真取结果1，条件为假取结果2；
> 简单二选一用它，复杂逻辑用 if-else；
> 嵌套不要超两层，代码可读最重要；
