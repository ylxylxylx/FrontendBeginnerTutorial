# 字符串比较

> 本节学习 JavaScript 中字符串比较大小的规则，以及不同类型值比较时的隐式转换。

## 数字与数字比较

数字比较最直观，按**数学大小**比较：

```javascript
console.log(5 > 3);    // true
console.log(10 < 2);   // false
console.log(3 === 3);  // true
```

## 数字与数字字符串比较

当数字和**数字字符串**比较时，数字字符串会**隐式转换为数字**再比较：

```javascript
console.log(5 > '3');    // true（'3'隐式转为数字3）
console.log('5' > 3);    // true（'5'隐式转为数字5）
console.log(10 > '6');   // true（'6'隐式转为数字6）
```

> 💡 数字字符串就是内容全是数字的字符串，如 `'123'`、`'3.14'`。

## 字符串与字符串比较

两个**纯字符串**比较时，按**字符的 ASCII 码**逐位比较：

```javascript
console.log('1256' > '312');  // false
```

### 比较过程

```
'1256' vs '312'
第1位：'1' vs '3' → ASCII码 49 vs 51 → 49 < 51
→ '1' 比 '3' 小，后面的不用再比了
→ '1256' < '312'，结果为 false
```

> ⚠️ 字符串比较是**逐位比较**，第一位就能分出大小则不再比较后续位。

### ASCII 码常用值

| 字符 | ASCII 码 |
|------|----------|
| '0'-'9' | 48-57 |
| 'A'-'Z' | 65-90 |
| 'a'-'z' | 97-122 |

```javascript
console.log('a' > 'A');    // true（97 > 65）
console.log('A' > '0');    // true（65 > 48）
console.log('b' > 'a');    // true（98 > 97）
```

### 为什么 '10' < '6'？

```javascript
console.log('10' > '6');   // false
```

```
'10' vs '6'
第1位：'1' vs '6' → ASCII码 49 vs 54 → 49 < 54
→ '1' 比 '6' 小，结果为 false
```

> ⚠️ 字符串比较不是按数值大小，而是按字符的 ASCII 码逐位比较！`'10'` 和 `'6'` 比较时，先比第一位 `'1'` 和 `'6'`，`'1'` 的 ASCII 码更小，所以 `'10' < '6'`。

## 数字与非数字字符串比较

当数字和**非数字字符串**比较时，结果**总是 false**：

```javascript
console.log(999 > 'a');      // false
console.log(999 > '你好');   // false
console.log(999 < 'a');      // false
console.log(999 === 'a');    // false
```

> ⚠️ 非数字字符串无法转为数字（得到 NaN），任何与 NaN 的比较都返回 false。

## 三条规则总结

| 场景 | 比较方式 | 示例 | 结果 |
|------|----------|------|------|
| 纯字符串 vs 纯字符串 | 按 ASCII 码逐位比较 | `'1256' > '312'` | `false` |
| 纯数字 vs 数字字符串 | 数字字符串隐式转为数字 | `5 > '3'` | `true` |
| 纯数字 vs 非数字字符串 | 总是返回 false | `999 > 'a'` | `false` |

### 判断流程图

```
两个值比较
  ├── 都是字符串？→ 逐位比较 ASCII 码
  ├── 一个数字一个字符串？
  │     ├── 字符串是数字字符串？→ 隐式转数字再比较
  │     └── 字符串是非数字字符串？→ 返回 false
  └── 都是数字？→ 直接比较数值
```

## prompt 输入的比较陷阱

`prompt()` 返回的是**字符串**，直接比较可能出现意外结果：

```javascript
var a = prompt('数字1');  // 输入 10
var b = prompt('数字2');  // 输入 6
alert(a > b);  // false！因为 '10' 和 '6' 按字符串比较
```

### 解决方法：转为数字再比较

```javascript
var a = prompt('数字1') * 1;  // 转为数字
var b = prompt('数字2') * 1;  // 转为数字
alert(a > b);  // true，10 > 6
```

> 💡 使用 `*1`、`Number()` 或 `parseInt()` 将字符串转为数字后再比较。

## 常见错误

### 1. 忘记 prompt 返回字符串

```javascript
// ❌ 字符串比较，'10' < '6'
var age = prompt('请输入年龄');
if (age >= 18) { ... }  // 输入10也会通过！

// ✅ 转为数字再比较
var age = prompt('请输入年龄') * 1;
if (age >= 18) { ... }
```

### 2. 字符串比较误解为数值比较

```javascript
// '10' > '6' 是 false，不是 true
// 因为字符串逐位比较：'1' < '6'
console.log('10' > '6');   // false
console.log(10 > 6);       // true（数字比较）
```

### 3. 中文字符串比较

```javascript
// 中文字符串比较的是 Unicode 编码
console.log('你好' > '我好');  // false（'你' < '我'）
```

## 速记口诀

> 字符串比大小，ASCII码逐位查；
> 数字串遇数字比，隐式转换再比较；
> 非数字串遇数字，结果一律是 false；
> prompt 返回是字符串，比较之前先转数字；
