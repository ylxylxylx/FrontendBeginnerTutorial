# 数据类型转换

> 本节学习 JavaScript 中三种基本数据类型（Number、String、Boolean）之间的转换规则，包括强制转换和隐式转换。

## 概述

JavaScript 有三种基本数据类型：`Number`、`String`、`Boolean`。在运算过程中，JS 会根据运算符**自动**进行类型转换（隐式转换），也可以使用函数**手动**转换（强制转换）。

```
Number ←→ String ←→ Boolean
   ↕                   ↕
   └───── 隐式转换 ─────┘
```

---

## 一、转为 Number 类型

### 1. Number() 强制转换

| 输入值 | 转换结果 | 说明 |
|--------|----------|------|
| `'2'` | `2` | 数字字符串 → 对应数字 |
| `''` | `0` | 空字符串 → 0 |
| `' '` | `0` | 纯空格字符串 → 0 |
| `'x'` | `NaN` | 非数字字符串 → NaN |
| `null` | `0` | null → 0 |
| `undefined` | `NaN` | undefined → NaN |
| `true` | `1` | true → 1 |
| `false` | `0` | false → 0 |

```javascript
Number('2');      // 2
Number('');       // 0
Number(' ');      // 0
Number('x');      // NaN
Number(null);     // 0
Number(undefined); // NaN
Number(true);     // 1
Number(false);    // 0
```

### 2. 隐式转换（算术运算）

利用算术运算符自动将字符串转为数字：

```javascript
var num = '2' * 1;   // 2（乘法）
var num = '2' - 0;   // 2（减法）
var num = +'2';      // 2（一元加号）
```

> 💡 `+` 作为一元运算符时是转数字，但 `+` 作为二元运算符时如果有一方是字符串则做拼接。

### 3. NaN（Not a Number）

NaN 是 Number 类型的特殊值，表示"非数字"：

```javascript
var num = 0 / 0;       // NaN
var num = 2 + NaN;     // NaN（任何与NaN运算结果都是NaN）
```

**NaN 的两个特性：**

| 特性 | 说明 |
|------|------|
| 与任何值运算都是 NaN | `NaN + 1` → NaN |
| 不等于自身 | `NaN == NaN` → **false** |

```javascript
console.log(NaN == NaN);  // false（JS中唯一不等于自身的值）
```

### 4. isNaN() 判断

`isNaN()` 判断一个值是否为 NaN：

```javascript
isNaN(NaN);    // true
isNaN(2);      // false
isNaN('abc');  // true（'abc'先隐式转为NaN，再判断）
```

## 二、转为 String 类型

### 1. toString() 方法

```javascript
var num = 2;
var str = num.toString();  // '2'

var flag = true;
str = flag.toString();     // 'true'
```

**⚠️ toString() 的限制：** `null` 和 `undefined` 没有 `toString()` 方法，调用会报错：

```javascript
var n = null;
n.toString();          // ❌ TypeError: Cannot read property 'toString' of null

undefined.toString();  // ❌ TypeError: Cannot read property 'toString' of undefined
```

### 2. String() 函数

`String()` 可以转换任何值，包括 `null` 和 `undefined`：

```javascript
String(2);          // '2'
String(true);       // 'true'
String(null);       // 'null'
String(undefined);  // 'undefined'
```

### 3. toString() vs String() 对比

| 方法 | null | undefined | 其他值 | 推荐场景 |
|------|------|-----------|--------|----------|
| `toString()` | ❌ 报错 | ❌ 报错 | ✅ 正常 | 确定值不为null/undefined |
| `String()` | ✅ 'null' | ✅ 'undefined' | ✅ 正常 | 不确定值类型时 |

### 4. 隐式转换（字符串拼接）

```javascript
var str = 2 + '';       // '2'（数字 + 空字符串）
var str = true + '';    // 'true'
var str = null + '';    // 'null'
var str = undefined + ''; // 'undefined'
```

## 三、转为 Boolean 类型

### 1. Boolean() 强制转换

| 输入值 | 转换结果 | 说明 |
|--------|----------|------|
| `1` | `true` | 非零数字 → true |
| `0` | `false` | 零 → false |
| `'你好'` | `true` | 非空字符串 → true |
| `'0'` | `true` | ⚠️ '0' 是非空字符串 → true |
| `''` | `false` | 空字符串 → false |
| `' '` | `true` | 空格字符串 → true（不是空串） |
| `null` | `false` | null → false |
| `undefined` | `false` | undefined → false |
| `NaN` | `false` | NaN → false |

```javascript
Boolean(1);         // true
Boolean(0);         // false
Boolean('0');       // true（⚠️ 注意：'0' 不是空字符串）
Boolean('你好');    // true
Boolean('');        // false
Boolean(' ');       // true
Boolean(null);      // false
Boolean(undefined); // false
Boolean(NaN);       // false
```

### 2. 假值（Falsy）速记

JavaScript 中只有 **6 个假值**，其余全为真：

```
false、0、''（空字符串）、null、undefined、NaN
```

> 💡 记忆口诀：**"零空无"** — 0（零）、''（空串）、null/undefined/NaN（无）

### 3. 隐式转换（条件判断）

在 `if` 语句中，条件会自动转为 Boolean：

```javascript
var mx = null;
if (!mx) {
    console.log('mx 是假值');  // 会执行
}
```

## 四、隐式转换综合

JS 在运算过程中会努力计算出结果，**自动根据运算符进行类型转换**：

```javascript
var z = true + 1;      // 2（true转1，1+1=2）
var x = true + '1';    // 'true1'（true转'true'，字符串拼接）
var c = true + false;  // 1（true转1，false转0，1+0=1）

console.log(z, x, c);  // 2 "true1" 1
```

### 运算符优先级影响隐式转换

```javascript
var c = '1' + 1 / 1;
// / 优先级高于 +，先计算 1/1 = 1
// 再计算 '1' + 1 = '11'（字符串拼接）
console.log(c, typeof c);  // '11' string
```

### 隐式转换规则表

| 运算符 | 转换方向 | 示例 |
|--------|----------|------|
| `+`（有字符串） | 转字符串拼接 | `1 + '2'` → `'12'` |
| `+`（无字符串） | 转数字 | `true + 1` → `2` |
| `-` `*` `/` `%` | 转数字 | `'6' / '2'` → `3` |
| `>` `<` `>=` `<=` | 比较时按规则转换 | 见字符串比较章节 |
| `if()` `while()` | 转布尔值 | `if(1)` → true |

---

## 五、强制转换 vs 隐式转换

| 方式 | 方法 | 特点 |
|------|------|------|
| 强制转换 | `Number()` `String()` `Boolean()` | 代码意图明确，推荐使用 |
| 隐式转换 | 运算符自动触发 | 代码简洁，但可能产生意外结果 |

> 💡 建议：需要类型转换时优先使用强制转换，代码更清晰、意图更明确。

## 常见错误

### 1. '0' 转布尔值是 true

```javascript
// ❌ 误以为 '0' 是假值
if ('0') {
    console.log('会执行！');  // '0' 是非空字符串，Boolean('0') 为 true
}

// ✅ 如果要判断是否为数字0
if (Number('0') === 0) { ... }
```

### 2. toString() 对 null/undefined 报错

```javascript
// ❌ null 和 undefined 没有 toString 方法
var val = null;
val.toString();  // TypeError

// ✅ 使用 String() 代替
String(val);     // 'null'
```

### 3. + 号的歧义

```javascript
console.log(1 + '2');   // '12'（字符串拼接）
console.log(1 + +'2');  // 3（+'2'先转数字为2，1+2=3）
console.log('1' + 1);   // '11'（字符串拼接）
```

### 4. 忘记 prompt 返回字符串

```javascript
// ❌ 字符串拼接而非数字相加
var a = prompt('输入1');
var b = prompt('输入2');
alert(a + b);  // 输入1和2，显示'12'而非3

// ✅ 转为数字再运算
alert(a * 1 + b * 1);  // 显示3
```

## 速记口诀

> 转数字：Number()最规范，乘1减0也可行；
> 转字符串：String()最安全，toString怕空无；
> 转布尔：六个假值要记牢，零空无NaN全false；
> 隐式转换看运算，加号拼接要当心；
> NaN不等于自身，isNaN来判断它。
