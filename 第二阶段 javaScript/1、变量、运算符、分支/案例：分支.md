# 案例：分支 — 年龄与性别判断

> 通过案例练习 if 单分支和逻辑运算符 && 的使用。

## 案例1：年龄判断

从键盘输入年龄，如果大于等于18岁，提示已成年：

```javascript
var age = prompt('请输入年龄');
if (age >= 18) {
    alert('你已经成年了，你要对自己负责');
}
```

### 扩展：双分支版本

```javascript
var age = prompt('请输入年龄');
if (age < 18) {
    alert('你还是一个小朋友，回家长长个');
} else {
    alert('你是个大朋友');
}
```

## 案例2：年龄+性别判断

从键盘输入年龄和性别，如果年龄大于18且性别为女，输出提示：

```javascript
var age = prompt('请输入年龄');
var sex = prompt('请输入性别');
if (age > 18 && sex === '女') {
    alert('女大十八变，越变越好看^-^');
}
```

## 知识点回顾

| 知识点 | 说明 |
|--------|------|
| `if (条件)` | 条件为 true 时执行大括号内代码 |
| `>=` | 大于等于，关系运算符 |
| `&&` | 逻辑与，两个条件都满足才为 true |
| `===` | 全等，值和类型都相同才为 true |
| `prompt()` | 获取输入，返回字符串 |

## 条件组合对比

| 条件 | 含义 | 运算符 |
|------|------|--------|
| `age >= 18` | 年龄不小于18 | 关系运算符 |
| `age > 18 && sex === '女'` | 年龄大于18 **且** 性别为女 | 逻辑与 |
| `age > 18 \|\| sex === '女'` | 年龄大于18 **或** 性别为女 | 逻辑或 |

> 💡 `&&` 要求**所有条件都满足**，`||` 只要求**满足其中一个**。
