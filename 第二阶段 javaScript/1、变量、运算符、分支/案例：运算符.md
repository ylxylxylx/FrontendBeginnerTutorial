# 案例：运算符 — 成绩求和

> 通过案例练习变量声明、prompt 输入、类型转换和字符串拼接。

## 需求

从键盘输入小明的语文、数学、英语成绩，计算并输出总分。

## 代码实现

```javascript
// 1. 输入三科成绩
var yuwen = prompt('请输入语文成绩');
var shuxue = prompt('请输入数学成绩');
var yingyu = prompt('请输入英语成绩');

// 2. 计算总分（prompt 返回字符串，需转数字）
var sum = yuwen * 1 + shuxue * 1 + yingyu * 1;

// 3. 输出结果
alert('总分：' + sum);
```

## 知识点回顾

| 知识点 | 说明 |
|--------|------|
| `prompt()` | 弹窗获取用户输入，返回**字符串** |
| `* 1` | 字符串乘以1，隐式转为数字 |
| `+` | 数字相加；遇到字符串则拼接 |
| `alert()` | 弹窗输出结果 |

## 常见问题

**为什么不直接 `yuwen + shuxue + yingyu`？**

因为 `prompt()` 返回字符串，直接用 `+` 会拼接而非求和：

```javascript
// ❌ 字符串拼接
"80" + "90" + "70" = "809070"

// ✅ 转为数字后相加
80 + 90 + 70 = 240
```

**转数字的方式**：

```javascript
var num = prompt('输入数字');
// 方式1：乘以1
num * 1
// 方式2：Number()
Number(num)
// 方式3：parseInt()
parseInt(num)
