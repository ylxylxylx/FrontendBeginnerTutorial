# 触底加载更多

> 网页滚动到底部时自动请求下一页数据，是移动端最常见的交互之一

## 一、功能分析

```
触底加载更多 = 滚动监听 + 分页请求 + 节流控制

核心问题:
  1. 如何判断网页"触底"?      → 比较三个高度
  2. 触底后如何加载下一页?    → 页码 +1，发起请求
  3. 如何防止重复请求?        → 函数节流（loading 变量控制）
```

## 二、触底判断的三个高度

```
┌─────────────────────┐
│                     │ ← b: htmlHeight（网页总高度）
│   ┌─────────────┐   │
│   │             │   │
│   │  可视窗口   │   │ ← a: windowHeight（窗口高度）
│   │             │   │
│   └─────────────┘   │
│   已滚出视口的内容   │ ← c: scrollTop（滚动距离）
│                     │
└─────────────────────┘

触底条件:  b ≈ a + c   （总高度 ≈ 窗口高度 + 滚动距离）
```

```javascript
window.onscroll = function(){
    var windowHeight = window.innerHeight;                    // a: 浏览器窗口高度
    var htmlHeight   = document.documentElement.scrollHeight; // b: 网页总高度
    var scrollTop    = document.documentElement.scrollTop;    // c: 滚动距离

    // 判断触底：剩余距离小于10px即视为触底
    if(htmlHeight - windowHeight - scrollTop < 10){
        console.log("触底");
    }
}
```

> **为什么不用 `==` 判断相等？** 复杂网页中三个高度可能存在小数，精确相等很难触发。实际开发中一般判断"距离底部小于某个阈值"（如 10px、50px）即视为触底。

## 三、分页请求的实现

```javascript
var index = 1;        // 记录最新页码
var loading = false;  // 记录是否正在请求

// 获取某一页数据的函数
function getPage(){
    $.get("http://192.168.14.222:5000/loadMore", { page: index }, function(response){
        // 循环响应数据中的数组，创建标签展示
        response.data.forEach(function(item){
            var h1 = document.createElement("h1");
            h1.innerText = item;
            document.body.appendChild(h1);
        });
        // 本页请求完成，恢复可请求状态
        loading = false;
    });
}

// 默认先请求第一页
$.get("http://192.168.14.222:5000/loadMore", { page: 1 }, function(response){
    index++;
    getPage();
    response.data.forEach(function(item){
        var h1 = document.createElement("h1");
        h1.innerText = item;
        document.body.appendChild(h1);
    });
});
```

## 四、函数节流控制

**问题**：滚动到页面底部附近时，`onscroll` 事件会连续触发多次，导致同一页被重复请求。

**方案**：定义变量 `loading` 记录请求状态，请求未完成时不再发起新请求。

```javascript
window.onscroll = function(){
    var windowHeight = window.innerHeight;
    var htmlHeight   = document.documentElement.scrollHeight;
    var scrollTop    = document.documentElement.scrollTop;

    if(htmlHeight - windowHeight - scrollTop < 10){
        if(loading) return;  // ① 如果本次请求未结束，不再发起下次请求

        index++;             // ② 更新页码
        getPage();           // ③ 发起请求
        loading = true;      // ④ 记录请求状态
    }
}
```

### 节流四步法

| 步骤 | 代码 | 位置 |
|------|------|------|
| 1. 定义变量 | `var loading = false;` | 全局 |
| 2. 触发时置为 true | `loading = true;` | 发起请求后 |
| 3. 完成后置为 false | `loading = false;` | 请求回调中 |
| 4. 再次触发时判断 | `if(loading) return;` | 事件函数开头 |

```
时间轴:  ──────────────────────────────────────→

触发:    触底    触底    触底              触底
请求:    请求1 ──────────完成┐
状态:    true ──────────→ false            请求2 ───→
         ↑ 拦截  ↑ 拦截         ↑ 放行下一次
```

## 五、总结

| 要点 | 说明 |
|------|------|
| 触底判断 | `htmlHeight - windowHeight - scrollTop < 阈值` |
| 三个高度 | `innerHeight`（窗口）、`scrollHeight`（总高）、`scrollTop`（滚动） |
| 分页请求 | 页码 `index` 递增，作为参数传给接口 |
| 函数节流 | 上一次未执行完则不执行下一次，用变量控制 |
| 适用场景 | onscroll 滚动监听、触底加载、按钮点击、动画控制 |
