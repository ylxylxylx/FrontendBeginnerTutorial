# 函数防抖和节流

> 防抖和节流都是为了防止一个函数被连续多次调用，区别在于控制方式：节流用变量，防抖用计时器

## 一、为什么需要防抖和节流

```
某些事件会被高频触发:

  onscroll  → 滚动一页可触发上百次
  oninput   → 每输入一个字符触发一次
  onmousemove → 移动鼠标持续触发
  onresize  → 拖拽窗口边缘持续触发

如果每次触发都执行业务函数（发请求、操作DOM），会导致:
  ① 服务器压力巨大（大量无效请求）
  ② 页面卡顿（频繁重排重绘）
  ③ 用户体验差（结果闪烁、数据错乱）
```

## 二、函数节流（Throttle）

```
定义: 定义变量控制函数的执行，如果上一次函数功能未执行结束，
      则不再执行下一次；上次函数结束后，可执行下一次。

控制方式: 变量（开关）
常见场景: onscroll 滚动监听、触底加载、按钮点击、动画控制
```

### 节流四步法

```javascript
var loading = false;  // 1. 定义变量

function throttleFn(){
    if(loading) return;   // 4. 再次触发时判断，未完成则返回
    loading = true;       // 2. 触发时置为 true

    // ...执行业务逻辑（如发请求）...

    loading = false;      // 3. 完成后置为 false（通常在回调中）
}
```

### 节流示意图

```
触发:  ████████████████  (持续触发)
执行:  ■───────■───────■  (上一次完成，才执行下一次)
       执行1   执行2   执行3
       ↑       ↑       ↑
       loading  完成    loading
       =true   =false  =true

特点: 执行次数减少，但过程均匀，不会"憋着不执行"
```

## 三、函数防抖（Debounce）

```
定义: 事件触发时不立即调用函数，而是开启计时器，计时结束后才调用；
      如果计时时间内再次触发事件，则取消当前计时、重新计时（重新开始等），
      直到计时结束，才真正执行函数。

控制方式: 计时器（setTimeout / clearTimeout）
常见场景: 输入框 input 事件请求搜索建议、窗口 resize
```

### 防抖三步法

```javascript
var timer;  // 1. 定义计时器

function debounceFn(){
    clearTimeout(timer);              // 2. 先关掉上一个计时
    timer = setTimeout(function(){    // 3. 再开启下一次计时
        // ...执行业务逻辑（如发请求）...
    }, 1000);
}
```

### 防抖示意图

```
触发:  ████  ████████  ██████  (连续触发，间隔不断重置)
计时:  →取消 →取消    →取消   → 1秒到!
执行:                          ■  (只有停下来才执行)

特点: 连续触发期间一直"憋着"，停止触发后等够时间才执行一次
```

## 四、防抖 vs 节流 对比

| 对比项 | 函数节流 | 函数防抖 |
|--------|----------|----------|
| 控制方式 | 变量（开关） | 计时器 |
| 执行时机 | 上一次完成后可执行下一次 | 停止触发后延迟执行 |
| 执行次数 | 多次（但间隔被拉大） | 一次（最后一次触发后） |
| 典型场景 | 滚动触底、按钮防重复点击 | 输入搜索建议、resize |
| 形象比喻 | 水龙头滴水：滴一滴，等一会再滴 | 电梯关门：有人进就重新等，没人进才关门 |

```
节流:  触发→执行→(锁定)→完成→解锁→触发→执行→...
防抖:  触发→等1秒→(又触发)→重新等1秒→(没触发)→执行!
```

## 五、延伸：通用防抖/节流函数（闭包封装）

实际开发中，防抖和节流通常封装成通用函数，内部用**闭包**保存状态：

### 通用防抖函数

```javascript
function debounce(fn, delay){
    var timer;  // 闭包变量，保存计时器
    return function(){
        var that = this;        // 保存事件中的 this
        var args = arguments;   // 保存事件参数
        clearTimeout(timer);
        timer = setTimeout(function(){
            fn.apply(that, args);  // 计时结束后执行原函数
        }, delay);
    }
}

// 使用
input.oninput = debounce(update, 1000);
```

### 通用节流函数（定时器版）

```javascript
function throttle(fn, delay){
    var timer;  // 闭包变量，记录是否正在等待
    return function(){
        var that = this;
        var args = arguments;
        if(timer) return;  // 上一次还未完成，直接返回
        timer = setTimeout(function(){
            fn.apply(that, args);
            timer = null;  // 执行完毕，解锁
        }, delay);
    }
}

// 使用
window.onscroll = throttle(checkBottom, 500);
```

> **为什么用闭包？** `timer` 是闭包变量，每次调用 `debounce()` 返回的函数都共享同一个 `timer`，但不会污染全局。这正是上一课闭包知识的应用。

## 六、总结

| 要点 | 说明 |
|------|------|
| 共同目的 | 防止函数被高频连续调用 |
| 节流 | 变量控制，上一次完成才执行下一次，过程均匀 |
| 防抖 | 计时器控制，停止触发后延迟执行，只执行最后一次 |
| 节流步骤 | 定义变量 → 触发时锁定 → 完成后解锁 → 判断锁定状态 |
| 防抖步骤 | 定义计时器 → 清除旧计时 → 开新计时 → 计时结束执行 |
| 闭包封装 | 通用 debounce / throttle 函数，闭包保存 timer 状态 |
