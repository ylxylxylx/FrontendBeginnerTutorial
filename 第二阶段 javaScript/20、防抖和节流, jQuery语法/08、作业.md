## 一、理解记忆本课知识点

```
重点回顾:
  1. 函数节流: 变量控制，上一次未完成不执行下一次（触底加载）
  2. 函数防抖: 计时器控制，停止触发后延迟执行（搜索提示）
  3. jQuery 对象: $() 返回的类数组对象，与原生 DOM 的区别
  4. 链式调用原理: 每个方法返回 jQuery 对象
  5. DOM 增删改查: append/prepend/remove/empty/text/html/eq/each
  6. 属性样式操作: css()/attr()/addClass 系列
  7. 事件绑定: $(function(){})/click()/on()/one()/off()
```

## 二、使用 jQuery 语法重写无缝轮播练习

**目标**：将之前用原生 JS 实现的无缝轮播图，改用 jQuery 语法实现。

### 改写要点

| 原生 JS 写法 | jQuery 写法 |
|--------------|-------------|
| `document.querySelector()` | `$("选择器")` |
| `element.style.left = "..."` | `$(el).css("left", "...")` |
| `element.onclick = fn` | `$(el).click(fn)` |
| `document.createElement()` | `$("<div>")` |
| `element.appendChild()` | `$(parent).append(el)` |
| `element.classList.add()` | `$(el).addClass()` |
| `element.addEventListener()` | `$(el).on()` |

### 实现步骤提示

```
1. 页面加载事件:  $(function(){ ... })
2. 获取标签:      $(".carousel"), $("img"), $(".dot")
3. 自动轮播:      setInterval 中用 .css() 改变位移
4. 小圆点切换:    .click() 绑定，.eq(index) 定位，.addClass() 高亮
5. 左右箭头:      .click() 绑定，索引 +1 / -1 控制
6. 无缝衔接:      最后一张切换到第一张时，瞬间复位（无过渡）再滚动
```

## 三、使用 jQuery 语法重写全选与不全选练习

**目标**：将之前用原生 JS 实现的复选框全选/不全选功能，改用 jQuery 语法实现。

### 改写要点

```
1. 全选按钮:  $("#all").click(function(){ ... })
2. 子选项:    $(".item") 获取所有子复选框
3. 全选逻辑:  遍历子选项，同步全选按钮的状态
   - 原生:    items[i].checked = all.checked
   - jQuery:  $(".item").prop("checked", $(this).prop("checked"))

4. 反选逻辑:  每次点击子选项，检查是否全部选中
   - 全部选中 → 全选按钮勾上
   - 有未选中 → 全选按钮取消

5. 遍历判断:  $(".item").each(function(index, item){
                  // item 是原生 DOM，item.checked 可直接用
              })
```

> **提示**：复选框的 checked 是布尔属性，用 `prop()` 获取和设置比 `attr()` 更可靠。

## 四、唯品会综合练习

**目标**：综合运用本课知识，完善唯品会页面的交互功能。

### 涉及知识点

```
1. 触底加载更多   → 滚动监听 + 节流控制 + $.get 分页请求
2. 搜索框提示     → input 事件 + 防抖控制 + 动态创建标签
3. jQuery DOM操作 → 创建商品标签 .appendTo()，遍历数据 .each()
4. jQuery 样式操作 → .css() 设置商品卡片样式，.addClass() 高亮
5. jQuery 事件绑定 → .click() 绑定商品点击，.on() 绑定拖拽等
```

### 实现步骤提示

```
步骤1: 页面结构搭建（HTML + CSS）
步骤2: 默认请求第一页商品数据，$.get() + .appendTo() 渲染列表
步骤3: window.onscroll 监听触底，节流控制加载下一页
步骤4: 搜索框绑定 input 事件，防抖控制请求搜索建议
步骤5: 商品点击事件，跳转详情或弹出提示
```
