# 面向对象基础

> 从面向过程到面向对象，理解对象、构造函数与 new 关键字

## 一、需求引入

```
需求: 在 JS 中录入全班学生的基本信息（name, age, sex, phone）
```

### 方案一：面向过程写法

```javascript
var name1 = "张三"
var age1 = 10
var sex1 = true
var phone1 = "110"
var name2 = "李四"
var age2 = 20
var sex2 = true
var phone2 = "119"
// ........
// var nameArray = [name1, name2, ......]
// var ageArray = [age1, age2, ...]
// var sexArray = [sex1, sex2, ...]
// var phoneArray = [phone1, phone2, ...]
```

**缺点**：
1. 变量太多，内存消耗大
2. 每个人的信息之间关联性低

> 假设班里有 50 人，需要写 200 多行代码。

### 方案二：字面量创建对象

```javascript
var zhangsan = {
    name: "张三",
    age: 10,
    sex: true,
    phone: "110"
}
var lisi = {
    name: "李四",
    age: 20,
    sex: true,
    phone: "119"
}
// var studentArray = [zhangsan, lisi, ......]
```

**优点**：
1. 减少了变量个数，优化了内存
2. 加强了每个人信息之间的关联性

**缺点**：一个对象要写 6 行，50 个学生共需要 300 行，代码太多。

### 方案三：构造函数创建对象

```javascript
function Student(_name, _age, _sex, _phone){
    this.name = _name;
    this.age = _age;
    this.sex = _sex;
    this.phone = _phone;
}

var zhangsan = new Student("张三", 10, true, "110")
var lisi = new Student("李四", 20, true, "119")
// var studentArray = [zhangsan, lisi, ......]
```

**结果**：50 多行代码即可搞定 50 个学生的信息录入。

## 二、构造函数详解

```
构造函数 = 创建对象的模板（工厂）

  ┌───────────────────────────┐
  │   function Student(){}    │ ← 构造函数（模板/工厂）
  └────────────┬──────────────┘
               │ new Student("张三", 10, true, "110")
               ▼
  ┌───────────────────────────┐
  │  { name:"张三", age:10,   │ ← 自动产出的新对象
  │    sex:true, phone:"110" }│
  └───────────────────────────┘
```

### 构造函数的三个特点

```javascript
function Student(_name, _age, _sex, _phone){
    this.name = _name;
    this.age = _age;
    this.sex = _sex;
    this.phone = _phone;
}
```

| 特点 | 说明 |
|------|------|
| 函数名大写开头 | 为了和普通函数区分（如 `Student` 而非 `student`） |
| 一般有参数 | 参数赋值给对象的同名属性 |
| 调用时加 `new` | `new Student()` 会自动返回一个新对象 |

### this 与参数命名约定

```javascript
function Student(_name, _age){
    // _name 是参数，name 是属性
    // this.name 指向新对象的 name 属性
    this.name = _name;
    this.age = _age;
}
```

> **命名约定**：为了区分属性和参数，属性用 `this.` 调用，参数名前加下划线 `_`。

### new 的执行过程

```javascript
var zhangsan = new Student("张三", 10, true, "110")
```

```
new 关键字做了四件事:
  1. 创建一个空对象 {}
  2. 让 this 指向这个新对象
  3. 执行函数体（给 this 赋属性）
  4. 自动返回这个新对象

  结果: zhangsan = { name:"张三", age:10, sex:true, phone:"110" }
```

## 三、两种创建对象的方式对比

| 对比项 | 字面量创建 | 构造函数创建 |
|--------|-----------|-------------|
| 语法 | `{ name: "张三" }` | `new Student("张三")` |
| 代码量 | 每个对象都要写完整结构 | 定义一次模板，反复使用 |
| 适用场景 | 创建对象个数少 | 创建对象个数多 |
| 类型标识 | 无统一类型 | 有统一类型（都是 Student） |

```
选择原则:
  创建 1~2 个对象  → 用字面量 { }
  创建多个同类对象 → 用构造函数 new
```

## 四、面向过程 vs 面向对象

```
常见的编程语言大致分为两种:

  面向过程语言: 以变量和函数为操作单位，没有对象概念
    → C, Lua, 老版本 JS (ES5)

  面向对象语言: 以对象为操作单位，所有功能都要通过对象去实现
    → C#, Java, OC, TS

  JS 语言特殊: 既有面向过程的语法，又有面向对象的特征
    正在从面向过程向面向对象进化
```

| 对比项 | 面向过程 | 面向对象 |
|--------|---------|---------|
| 操作单位 | 变量、函数 | 对象 |
| 数据组织 | 散落的变量 | 封装在对象中的属性 |
| 关联性 | 低（变量之间无联系） | 高（同一对象的属性相关联） |
| 代码复用 | 函数复用 | 对象模板（类）复用 |
| 代表语言 | C、Lua | Java、C#、TS |

## 五、JS 中的内置构造函数

```javascript
// JS 中很多内置对象都是通过构造函数创建的
var date = new Date(2020, 9, 8, 17, 23, 40)   // 日期对象
var arr  = new Array(1, 2, 3)                   // 数组对象
var obj  = new Object()                         // 空对象 {}
var str  = new String("hello")                  // 字符串对象
```

> 之前用的 `new Date()` 就是在调用 JS 内置的日期构造函数，和我们自己写的 `new Student()` 道理相同。

## 六、完整代码

```javascript
// 需求: 录入全班学生信息

// 1. 定义构造函数（对象的模板）
function Student(_name, _age, _sex, _phone){
    this.name = _name;
    this.age = _age;
    this.sex = _sex;
    this.phone = _phone;
}

// 2. 用 new 创建对象
var zhangsan = new Student("张三", 10, true, "110")
var lisi = new Student("李四", 20, true, "119")

// 3. 存入数组统一管理
var studentArray = [zhangsan, lisi]
```

## 七、总结

| 要点 | 说明 |
|------|------|
| 面向过程 | 以变量和函数为单位，数据关联性低 |
| 面向对象 | 以对象为单位，数据封装关联性强 |
| 字面量创建 | `{ key: value }`，适合少量对象 |
| 构造函数 | 对象的模板/工厂，函数名大写开头 |
| new 关键字 | 创建空对象 → this 指向 → 执行赋值 → 自动返回 |
| 命名约定 | 属性用 `this.`，参数前加 `_` |
| JS 特性 | 既有面向过程又有面向对象特征 |
| 内置构造函数 | `new Date()`、`new Array()` 等都是同一原理 |
