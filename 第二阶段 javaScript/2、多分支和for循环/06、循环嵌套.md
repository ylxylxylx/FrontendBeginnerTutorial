# 循环嵌套

> 本节学习循环嵌套，掌握在一个循环内部使用另一个循环的结构和应用。

## 什么是循环嵌套

循环嵌套就是**一个循环的循环体中包含另一个循环**：

```javascript
for (var i = 1; i <= 3; i++) {       // 外层循环
    for (var j = 1; j <= 4; j++) {   // 内层循环
        console.log("i=" + i, "j=" + j);
    }
}
```

### 执行规律

- **外层循环执行一次，内层循环执行一遍**
- 如果外层循环 n 次，内层循环 m 次，则内层循环体总共执行 **n × m** 次

```
i=1 → j=1, j=2, j=3, j=4  (内层执行4次)
i=2 → j=1, j=2, j=3, j=4  (内层执行4次)
i=3 → j=1, j=2, j=3, j=4  (内层执行4次)
总共：3 × 4 = 12 次
```

## 经典示例：输出图形

### 示例1：输出矩形星号

```
*****
*****
*****
```

```javascript
// 3行5列的矩形
for (var i = 1; i <= 3; i++) {       // 外层控制行
    var row = "";
    for (var j = 1; j <= 5; j++) {   // 内层控制列
        row += "*";
    }
    console.log(row);
}
```

> 💡 外层循环控制**行数**，内层循环控制**每行的列数**。

### 示例2：输出直角三角形

```
*
**
***
****
*****
```

```javascript
for (var i = 1; i <= 5; i++) {       // 行数：1到5
    var row = "";
    for (var j = 1; j <= i; j++) {   // 每行i个星号
        row += "*";
    }
    console.log(row);
}
```

> 💡 关点：内层循环的次数依赖于外层变量 `i`，第 i 行输出 i 个星号。

### 示例3：输出倒直角三角形

```
*****
****
***
**
*
```

```javascript
for (var i = 5; i >= 1; i--) {       // 行数：5到1
    var row = "";
    for (var j = 1; j <= i; j++) {   // 每行i个星号
        row += "*";
    }
    console.log(row);
}
```

### 示例4：输出等腰三角形

```
    *
   ***
  *****
 *******
*********
```

```javascript
for (var i = 1; i <= 5; i++) {
    var row = "";
    // 空格：5-i 个
    for (var j = 1; j <= 5 - i; j++) {
        row += " ";
    }
    // 星号：2*i-1 个星号
    for (var k = 1; k <= 2 * i - 1; k++) {
        row += "*";
    }
    console.log(row);
}
```

> 💡 等腰三角形规律：第 i 行有 `5-i` 个空格和 `2*i-1` 个星号。

### 示例5：输出九九乘法表

```javascript
for (var i = 1; i <= 9; i++) {
    var row = "";
    for (var j = 1; j <= i; j++) {
        row += j + "×" + i + "=" + (i * j) + "  ";
    }
    console.log(row);
}
```

输出：
```
1×1=1
1×2=2  2×2=4
1×3=3  2×3=6  3×3=9
...
1×9=9  2×9=18  3×9=27  ...  9×9=81
```

## 循环嵌套的执行次数

| 外层次数 | 内层次数 | 总执行次数 |
|----------|----------|-----------|
| n | m（固定） | n × m |
| n | i（依赖外层） | 1+2+3+...+n = n(n+1)/2 |

```javascript
// 内层固定次数：3 × 4 = 12次
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= 4; j++) {
        console.log("执行");
    }
}

// 内层依赖外层：1+2+3 = 6次
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= i; j++) {
        console.log("执行");
    }
}
```

## 循环嵌套中的 break

### break 只跳出当前循环

```javascript
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= 3; j++) {
        if (j === 2) {
            break;  // 只跳出内层循环，外层继续
        }
        console.log("i=" + i, "j=" + j);
    }
}
// 输出：
// i=1 j=1
// i=2 j=1
// i=3 j=1
```

### 跳出所有循环的技巧

```javascript
// 方式1：使用标志变量
var flag = false;
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= 3; j++) {
        if (i === 2 && j === 2) {
            flag = true;
            break;
        }
        console.log("i=" + i, "j=" + j);
    }
    if (flag) break;  // 外层也跳出
}

// 方式2：使用标签（ES6推荐）
// 注：标签语法较为高级，初学者了解即可
outer:
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= 3; j++) {
        if (i === 2 && j === 2) {
            break outer;  // 跳出标签指定的循环
        }
        console.log("i=" + i, "j=" + j);
    }
}
```

## 常见错误

### 1. 内外层使用同一个变量

```javascript
// ❌ 内外层都用 i，导致逻辑混乱
for (var i = 1; i <= 3; i++) {
    for (var i = 1; i <= 4; i++) {  // 变量名冲突！
        console.log(i);
    }
}

// ✅ 外层用 i，内层用 j
for (var i = 1; i <= 3; i++) {
    for (var j = 1; j <= 4; j++) {
        console.log(i, j);
    }
}
```

### 2. 内层循环条件写错

```javascript
// ❌ 内层循环条件写反
for (var i = 1; i <= 5; i++) {
    var row = "";
    for (var j = 1; j <= 5 - i; j++) {  // 想输出三角形，但条件不对
        row += "*";
    }
    console.log(row);  // 输出的是倒三角形
}

// ✅ 直角三角形：每行 i 个星号
for (var i = 1; i <= 5; i++) {
    var row = "";
    for (var j = 1; j <= i; j++) {
        row += "*";
    }
    console.log(row);
}
```

## 图形输出解题思路

1. **确定行数** → 外层循环
2. **确定每行内容** → 内层循环
3. **找规律** → 每行的空格数、星号数与行号 i 的关系
4. **拼接字符串** → 用 `+=` 拼接后统一输出

| 图形 | 行数 | 第i行空格 | 第i行星号 |
|------|------|----------|----------|
| 直角三角形 | n | 0 | i |
| 倒直角三角形 | n | 0 | n-i+1 |
| 等腰三角形 | n | n-i | 2*i-1 |

## 速记口诀

> 外层循环控制行，内层循环控制列；
> 外层一次内层一遍，次数相乘是总执行；
> break 只跳当前层，想跳全部用标志；
> 图形输出找规律，空格星号与行号；
