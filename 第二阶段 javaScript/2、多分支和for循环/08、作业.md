## 作业1：switch 终生幸福指数

输入年龄，用 switch 输出对应的人生阶段：

| 年龄 | 阶段 |
|------|------|
| 0-6 | 确幸童年 |
| 7-17 | 努力学习 |
| 18-30 | 奋力拼搏 |
| 31-50 | 奢力稳重 |
| 51-70 | 安力晚年 |
| 71+ | 乐力长寿 |

> 提示：可以用 `Math.floor(age / 10)` 将年龄分段。

<details>
<summary>参考答案</summary>

```javascript
var age = prompt("请输入年龄") * 1;
switch (true) {
    case age >= 0 && age <= 6: alert("确幸童年"); break;
    case age >= 7 && age <= 17: alert("努力学习"); break;
    case age >= 18 && age <= 30: alert("奋力拼搏"); break;
    case age >= 31 && age <= 50: alert("奢力稳重"); break;
    case age >= 51 && age <= 70: alert("安力晚年"); break;
    case age > 70: alert("乐力长寿"); break;
    default: alert("输入有误");
}
```

</details>

## 作业2：求 1! + 2! + 3! + ... + 10!

求1到10每个数的阶乘之和：

<details>
<summary>参考答案</summary>

```javascript
var sum = 0;
for (var i = 1; i <= 10; i++) {
    var factorial = 1;
    for (var j = 1; j <= i; j++) {
        factorial *= j;
    }
    sum += factorial;
}
console.log("1!+2!+...+10! = " + sum);  // 4037913
```

</details>

## 作业3：输出100-200之间不能被3整除的数

<details>
<summary>参考答案</summary>

```javascript
// 方式1：用 continue
for (var i = 100; i <= 200; i++) {
    if (i % 3 === 0) {
        continue;
    }
    console.log(i);
}

// 方式2：不用 continue
for (var i = 100; i <= 200; i++) {
    if (i % 3 !== 0) {
        console.log(i);
    }
}
```

</details>

## 作业4：猴子吃桃

猴子每天吃桃子总数的一半多一个，第10天只剩1个桃子，问第1天有多少桃子？

> 提示：从第10天倒推，第n天的桃子 = (第n+1天的桃子 + 1) × 2

<details>
<summary>参考答案</summary>

```javascript
var peaches = 1;  // 第10天只剩1个
for (var i = 9; i >= 1; i--) {
    peaches = (peaches + 1) * 2;
}
console.log("第1天的桃子数：" + peaches);  // 1534
```

</details>

## 作业5：打印图形 — 空心矩形

输出5×10的空心矩形：

```
**********
*        *
*        *
*        *
**********
```

<details>
<summary>参考答案</summary>

```javascript
for (var i = 1; i <= 5; i++) {
    var row = "";
    for (var j = 1; j <= 10; j++) {
        if (i === 1 || i === 5 || j === 1 || j === 10) {
            row += "*";
        } else {
            row += " ";
        }
    }
    console.log(row);
}
```

</details>

## 作业6：百钱买百鸡

鸡翁5元一只，鸡母3元一只，鸡雏1元3只，100元买100只鸡，问每种鸡各多少？

> 提示：设公鸡x、母鸡y、小鸡z，则 5x+3y+z/3=100，x+y+z=100

<details>
<summary>参考答案</summary>

```javascript
for (var x = 0; x <= 20; x++) {       // 公鸡最多20只
    for (var y = 0; y <= 33; y++) {   // 母鸡最多33只
        var z = 100 - x - y;           // 小鸡数
        if (z % 3 === 0 && 5 * x + 3 * y + z / 3 === 100) {
            console.log("公鸡：" + x + " 母鸡：" + y + " 小鸡：" + z);
        }
    }
}
// 输出：
// 公鸡：0 母鸡：25 小鸡：75
// 公鸡：4 母鸡：18 小鸡：78
// 公鸡：8 母鸡：11 小鸡：81
// 公鸡：12 母鸡：4 小鸡：84
```

</details>

## 作业7：求Sn = a + aa + aaa + ... + a...a（n个a）

输入 a 和 n，求 Sn。例如 a=2, n=5：2+22+222+2222+22222

<details>
<summary>参考答案</summary>

```javascript
var a = prompt("请输入a") * 1;
var n = prompt("请输入n") * 1;
var sum = 0;
var item = 0;
for (var i = 1; i <= n; i++) {
    item = item * 10 + a;  // 2, 22, 222, 2222, 22222
    sum += item;
}
alert("Sn = " + sum);
// a=2, n=5: 2+22+222+2222+22222 = 24690
```

</details>

## 作业8：输入验证

要求用户输入一个1-10之间的整数，如果输入不在范围内，要求重新输入，直到输入有效为止：

<details>
<summary>参考答案</summary>

```javascript
var num;
do {
    num = prompt("请输入1-10之间的整数") * 1;
    if (num < 1 || num > 10 || num !== parseInt(num)) {
        alert("输入无效，请重新输入");
    }
} while (num < 1 || num > 10 || num !== parseInt(num));
alert("你输入了：" + num);
```

</details>

## 速记口诀

> switch 匹配固定值，穿透利用要牢记；
> while 先判后执行，do-while 至少做一次；
> for 三要素一行写，次数确定最方便；
> break 跳出 continue 跳过，嵌套循环行与列；
