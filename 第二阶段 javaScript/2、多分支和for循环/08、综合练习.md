## 练习1：1-100所有偶数之和（while实现）

**题目：** 计算 1-100 所有偶数之和，使用 while 循环实现。

<details>
<summary>参考答案</summary>

```javascript
var i = 1;
var sum = 0;
while (i <= 100) {
    if (i % 2 == 0) {
        sum += i;
    }
    i++;
}
console.log(sum);  // 2550
```

**思路：**
1. 循环变量 `i` 从 1 遍历到 100
2. 用 `i % 2 == 0` 判断偶数
3. 累加偶数到 `sum`

**优化写法：** 直接从 2 开始，步长为 2

```javascript
var i = 2;
var sum = 0;
while (i <= 100) {
    sum += i;
    i += 2;
}
console.log(sum);  // 2550
```

</details>

## 练习2：学习合格检查

**题目：** 老师每天检查张三的学习是否合格，如果不合格，则继续学习，否则提示"恭喜合格"。（是否合格从键盘输入，`y` 表示合格）

<details>
<summary>参考答案</summary>

```javascript
var result = prompt('学习是否合格？(y/n)');
while (result != 'y') {
    result = prompt('不合格，继续学习！学习是否合格？(y/n)');
}
alert('恭喜合格！');
```

**思路：**
1. 先输入一次判断结果
2. 不合格时循环提示重新输入
3. 合格时退出循环，弹出恭喜

**do-while 写法：** 更适合"先执行再判断"的场景

```javascript
var result;
do {
    result = prompt('学习是否合格？(y/n)');
} while (result != 'y');
alert('恭喜合格！');
```

</details>

## 练习3：培训人数增长

**题目：** 2006 年培养学员 8 万人，每年增长 25%，请问按此增长速度，到哪一年培训学员人数将达到 20 万人？

<details>
<summary>参考答案</summary>

```javascript
var year = 2006;
var people = 8;  // 万人
while (people < 20) {
    people = people * 1.25;  // 每年增长25%
    year++;
}
console.log('到' + year + '年，培训人数达到' + people.toFixed(2) + '万人');
// 到2011年，培训人数达到19.53万人 → 继续增长
// 到2012年，培训人数达到24.41万人 → 超过20万
```

**思路：**
1. 初始年份 2006，人数 8 万
2. 每年人数乘以 1.25（增长 25%）
3. 年份 +1
4. 当人数 ≥ 20 万时停止

**逐年变化：**

| 年份 | 人数（万） |
|------|-----------|
| 2006 | 8.00 |
| 2007 | 10.00 |
| 2008 | 12.50 |
| 2009 | 15.63 |
| 2010 | 19.53 |
| 2011 | 24.41 |

答案：**2011 年**培训人数将超过 20 万人。

</details>

## 练习4：闰年判断

**题目：** 输入一个年份，判断是否为闰年。

**闰年规则：** 四年一闰，百年不闰，四百年再闰。

- 能被 400 整除 → 闰年
- 能被 4 整除但不能被 100 整除 → 闰年
- 其他 → 平年

<details>
<summary>参考答案</summary>

```javascript
var year = prompt('请输入年份') * 1;

if (year % 400 == 0) {
    // 能被400整除 → 闰年
    alert(year + '是闰年');
} else {
    // 不能被400整除，判断是否能被4整除且不是整百年
    if (year % 4 == 0 && year % 100 != 0) {
        alert(year + '是闰年');
    } else {
        alert(year + '不是闰年');
    }
}
```

**简化写法（逻辑运算符）：**

```javascript
var year = prompt('请输入年份') * 1;

if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
    alert(year + '是闰年');
} else {
    alert(year + '不是闰年');
}
```

**验证：**

| 年份 | 结果 | 说明 |
|------|------|------|
| 2000 | 闰年 | 2000 % 400 == 0 |
| 1900 | 平年 | 1900 % 100 == 0 但 1900 % 400 != 0 |
| 2100 | 平年 | 2100 % 100 == 0 但 2100 % 400 != 0 |
| 2024 | 闰年 | 2024 % 4 == 0 且 2024 % 100 != 0 |
| 2023 | 平年 | 2023 % 4 != 0 |

</details>

## 练习5：个人所得税计算

**题目：** 根据工资计算个人所得税。

**计算步骤：**

1. **总工资** → 从键盘输入
2. **基准工资** → 总工资与 7662 取较小值（三险一金基数上限）
3. **三险一金** = 基准工资 × (8% + 2% + 0.5% + 10%)
4. **扣除三险一金后月收入** = 总工资 - 三险一金
5. **应纳税所得额** = 扣除三险一金后月收入 - 5000（起征点）
6. **查税率表** → 根据应纳税所得额确定税率和速算扣除数
7. **个税** = 应纳税所得额 × 税率 - 速算扣除数

**税率表（2018年10月起）：**

| 应纳税所得额 | 税率 | 速算扣除数 |
|-------------|------|-----------|
| ≤ 3000 | 3% | 0 |
| ≤ 12000 | 10% | 210 |
| ≤ 25000 | 20% | 1410 |
| ≤ 35000 | 25% | 2660 |
| ≤ 55000 | 30% | 4410 |
| ≤ 80000 | 35% | 7160 |
| > 80000 | 45% | 15160 |

<details>
<summary>参考答案</summary>

```javascript
// 1、总工资
var zongGongZi = prompt('请输入你的工资') * 1;

// 2、基准工资（三险一金基数上限7662）
var jiZhun = 0;
if (zongGongZi > 7662) {
    jiZhun = 7662;
} else {
    jiZhun = zongGongZi;
}

// 3、三险一金 = 基准工资 × (8%+2%+0.5%+10%)
var sanXian = jiZhun * (8 + 2 + 0.5 + 10) / 100;

// 4、扣除三险一金后月收入
var kouSanXianHou = zongGongZi - sanXian;

// 5、应纳税所得额 = 月收入 - 起征点5000
var suoDeE = kouSanXianHou - 5000;

if (suoDeE <= 0) {
    alert('回家涨涨工资再来吧');
} else {
    // 6、查税率表
    var shuLv = 0, suKou = 0;
    if (suoDeE <= 3000) {
        shuLv = 3 / 100;
        suKou = 0;
    } else if (suoDeE <= 12000) {
        shuLv = 10 / 100;
        suKou = 210;
    } else if (suoDeE <= 25000) {
        shuLv = 20 / 100;
        suKou = 1410;
    } else if (suoDeE <= 35000) {
        shuLv = 25 / 100;
        suKou = 2660;
    } else if (suoDeE <= 55000) {
        shuLv = 30 / 100;
        suKou = 4410;
    } else if (suoDeE <= 80000) {
        shuLv = 35 / 100;
        suKou = 7160;
    } else {
        shuLv = 45 / 100;
        suKou = 15160;
    }

    // 7、应纳个人所得税
    var geShui = suoDeE * shuLv - suKou;
    alert('这个月要缴税' + geShui.toFixed(2) + '，五险一金' + sanXian.toFixed(2));
}
```

**示例计算（工资 10000 元）：**

| 步骤 | 计算 | 结果 |
|------|------|------|
| 基准工资 | min(10000, 7662) | 7662 |
| 三险一金 | 7662 × 20.5% | 1570.71 |
| 扣除后月收入 | 10000 - 1570.71 | 8429.29 |
| 应纳税所得额 | 8429.29 - 5000 | 3429.29 |
| 税率/速扣 | 3429.29 在 3000-12000 档 | 10% / 210 |
| 个税 | 3429.29 × 10% - 210 | 132.93 |

</details>

## 知识点回顾

| 知识点 | 关键要点 |
|--------|----------|
| while 循环 | 先判断后执行，可能一次都不执行 |
| do-while 循环 | 先执行后判断，至少执行一次 |
| 条件判断 | if-else if-else 多分支、逻辑运算符 |
| toFixed(n) | 保留 n 位小数 |
