## 一、基础练习

### 练习1：成绩总分

**题目：** 从键盘输入小明的语文、数学、外语成绩，输出小明的总分。

<details>
<summary>参考答案</summary>

```javascript
var chinese = prompt('语文成绩') * 1;
var math = prompt('数学成绩') * 1;
var english = prompt('外语成绩') * 1;

var total = chinese + math + english;
alert('小明的总分是' + total);
```

**要点：** `prompt()` 返回字符串，用 `*1` 转为数字再运算。

</details>

---

### 练习2：圆的面积

**题目：** 定义变量 PI = 3.1415926，从键盘输入半径 r，输出圆的面积（保留2位小数）。

<details>
<summary>参考答案</summary>

```javascript
var r = prompt('请输入半径') * 1;
var pi = 3.1415926;
var s = pi * r * r;
var area = s.toFixed(2);  // 保留2位小数
alert('圆的面积：' + area);
```

**要点：** `toFixed(n)` 方法保留 n 位小数，返回的是**字符串**。

</details>

---

### 练习3：圆柱体积

**题目：** 从键盘获取圆的半径 r 和圆柱高 h，求圆柱的体积（保留三位小数）。

<details>
<summary>参考答案</summary>

```javascript
var r = prompt('请输入半径') * 1;
var h = prompt('请输入高') * 1;
var pi = 3.1415926;
var v = pi * r * r * h;
alert('圆柱的体积：' + v.toFixed(3));
```

**公式：** V = π × r² × h

</details>

### 练习4：提取四位数的各位数字

**题目：** 从键盘输入一个四位数的正整数，输出它的个、十、百、千位上的数字。

<details>
<summary>参考答案</summary>

```javascript
var num = prompt('请输入一个四位正整数') * 1;

var ge = num % 10;                        // 个位
var shi = Math.floor(num / 10) % 10;     // 十位
var bai = Math.floor(num / 100) % 10;    // 百位
var qian = Math.floor(num / 1000) % 10;  // 千位

alert('个位：' + ge + ' 十位：' + shi + ' 百位：' + bai + ' 千位：' + qian);
```

**提取规律：**

| 位数 | 方法 | 示例（8526） |
|------|------|-------------|
| 个位 | `num % 10` | 8526 % 10 = 6 |
| 十位 | `Math.floor(num / 10) % 10` | Math.floor(8526/10) % 10 = 852 % 10 = 2 |
| 百位 | `Math.floor(num / 100) % 10` | Math.floor(8526/100) % 10 = 85 % 10 = 5 |
| 千位 | `Math.floor(num / 1000) % 10` | Math.floor(8526/1000) % 10 = 8 % 10 = 8 |

> 💡 核心思路：先 `Math.floor(除以10的n次方)` 去掉低位，再 `% 10` 取个位。

</details>

## 二、双分支练习

### 练习5：成绩及格判断

**题目：** 从键盘获取分数，60 分为及格，判断是否及格。

<details>
<summary>参考答案</summary>

```javascript
var score = prompt('请输入分数') * 1;
if (score >= 60) {
    alert('恭喜你，及格了');
} else {
    alert('学渣');
}
```

</details>

### 练习6：登录验证

**题目：** 从键盘获取用户名和密码，如果用户名为 "admin" 且密码为 "123"，提示登录成功，否则提示用户名密码错误。

<details>
<summary>参考答案</summary>

```javascript
var username = prompt('请输入用户名');
var password = prompt('请输入密码');

if (username == 'admin' && password == '123') {
    alert('登录成功');
} else {
    alert('用户名或密码错误');
}
```

**要点：** 两个条件同时满足用 `&&`（逻辑与）。

</details>

---

### 练习7：奖励判断

**题目：** 张三数学成绩大于 90 分且体育成绩大于 80 分，或者数学等于 100 分且体育大于 70 分，可以获得奖励，否则惩罚。

<details>
<summary>参考答案</summary>

```javascript
var math = prompt('数学成绩') * 1;
var pe = prompt('体育成绩') * 1;

if ((math > 90 && pe > 80) || (math == 100 && pe > 70)) {
    alert('黄冈密卷一套');
} else {
    alert('小黑屋敲代码');
}
```

**要点：** 复合条件用 `()` 分组，`&&` 表示"并且"，`||` 表示"或者"。

</details>

## 三、嵌套练习

### 练习8：择偶条件

**题目：** 输入性别、身高、收入。如果是男性，判断身高大于 180 或收入大于 10000，输出 "I do!"，否则输出 "你是个好人"；如果是女性，输出 "我们性别不合适"。

<details>
<summary>参考答案</summary>

```javascript
var gender = prompt('请输入性别（男/女）');
var height = prompt('请输入身高(cm)') * 1;
var income = prompt('请输入收入') * 1;

if (gender == '男') {
    if (height > 180 || income > 10000) {
        alert('I do!');
    } else {
        alert('你是个好人');
    }
} else {
    alert('我们性别不合适');
}
```

</details>

### 练习9：周末活动安排

**题目：** 如果今天是周六或周日，打算外出。外出时如果气温在 30 度以上，去游泳；否则去爬山。

<details>
<summary>参考答案</summary>

```javascript
var week = prompt('今天是周几');
var temp = prompt('气温是多少度') * 1;

if (week == '周六' || week == '周日') {
    // 外出
    if (temp > 30) {
        alert('去游泳');
    } else {
        alert('去爬山');
    }
} else {
    alert('不外出');
}
```

**反向版本：** 如果不是周末就要工作，天气好去客户单位，否则在公司查资料。

```javascript
if (week != '周六' && week != '周日') {
    // 工作
    var weather = prompt('天气好吗？(好/不好)');
    if (weather == '好') {
        alert('去客户单位谈业务');
    } else {
        alert('在公司上网查资料');
    }
}
```

</details>

## 知识点回顾

| 知识点 | 关键要点 |
|--------|----------|
| prompt 输入 | 返回字符串，计算前用 `*1` 转数字 |
| toFixed(n) | 保留 n 位小数，返回字符串 |
| Math.floor() | 向下取整，用于提取数位 |
| 数位提取 | 先除后取余：`Math.floor(num/10^n) % 10` |
| 逻辑与 && | 两个条件都满足 |
| 逻辑或 \|\| | 任意一个条件满足 |
| 嵌套 if | 先判断外层，再判断内层 |
