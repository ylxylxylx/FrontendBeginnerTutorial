# 三数排序

> 本节学习如何对三个不同的数字找出最大值、最小值和中间值，掌握多种解法思路。

---

## 题目

从键盘输入三个不相同的数字，找出它们中的最大值、最小值和中间值，并输出。

---

## 方法一：if 嵌套法

**思路：** 先假设 a 最大，如果 a 确实最大，再比较 b 和 c；如果 a 不是最大，则最大值在 b 和 c 之间。

```javascript
var a = prompt('数字1') * 1;
var b = prompt('数字2') * 1;
var c = prompt('数字3') * 1;

var max, mid, min;

if (a > b && a > c) {
    max = a;  // a 最大
    if (b > c) {
        mid = b; min = c;
    } else {
        mid = c; min = b;
    }
} else {
    // a 不是最大，最大值在 b 和 c 之间
    if (b > c) {
        max = b;  // b 最大
        if (a > c) {
            mid = a; min = c;
        } else {
            mid = c; min = a;
        }
    } else {
        max = c;  // c 最大
        if (a > b) {
            mid = a; min = b;
        } else {
            mid = b; min = a;
        }
    }
}

alert('max=' + max + ' mid=' + mid + ' min=' + min);
```

**判断流程图：**

```
a > b && a > c ?
├── 是 → max = a
│   └── b > c ?
│       ├── 是 → mid = b, min = c
│       └──否 → mid = c, min = b
└──否 → a 不是最大
    └── b > c ?
        ├── 是 → max = b
        │   └── a > c ?
        │       ├── 是 → mid = a, min = c
        │       └──否 → mid = c, min = a
        └──否 → max = c
            └── a > b ?
                ├── 是 → mid = a, min = b
                └──否 → mid = b, min = a
```

> ⚠️ 嵌套 if 嵌套层次多，容易出错，但逻辑清晰直观。

## 方法二：三目运算符法

**思路：** 用三目运算符逐层比较，代码更简洁。

### 1. 先求最大值

```javascript
// 先比较 a 和 b，取较大值
var x = a > b ? a : b;
// 再让较大值和 c 比较，取最大值
var max = x > c ? x : c;
```

### 2. 再求最小值

```javascript
// 先比较 a 和 b，取较小值
var x = a < b ? a : b;
// 再让较小值和 c 比较，取最小值
var min = x < c ? x : c;
```

### 3. 求中间值

```javascript
var mid = a > b
    ? (b > c ? b : (a > c ? c : a))
    : (a > c ? a : (b > c ? c : b));
```

**中间值的逻辑拆解：**

``a > b`` 为 true 时（即 a > b）：
- b > c → 中间值是 b
- 否则：a > c → 中间值是 c；否则中间值是 a

``a > b`` 为 false 时（即 b > a）：
- a > c → 中间值是 a
- 否则：b > c → 中间值是 c；否则中间值是 b

### 完整代码

```javascript
var a = prompt('数字1') * 1;
var b = prompt('数字2') * 1;
var c = prompt('数字3') * 1;

var max = a > b ? (a > c ? a : c) : (b > c ? b : c);
var min = a < b ? (a < c ? a : c) : (b < c ? b : c);
var mid = a > b ? (b > c ? b : (a > c ? c : a)) : (a > c ? a : (b > c ? c : b));

alert('最大值：' + max + ' 中间值：' + mid + ' 最小值：' + min);
```

## 方法三：求和法（最简洁）

**思路：** 三个数的总和 = 最大值 + 最小值 + 中间值，所以中间值 = 总和 - 最大值 - 最小值。

```javascript
var a = prompt('数字1') * 1;
var b = prompt('数字2') * 1;
var c = prompt('数字3') * 1;

var max = a > b ? (a > c ? a : c) : (b > c ? b : c);
var min = a < b ? (a < c ? a : c) : (b < c ? b : c);
var mid = a + b + c - max - min;  // 巧求中间值！

alert('最大值：' + max + ' 中间值：' + mid + ' 最小值：' + min);
```

> 💡 这是最简洁的方法！先求出 max 和 min，中间值直接用 `a+b+c-max-min` 得出。

---

## 三种方法对比

| 方法 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| if 嵌套法 | 逻辑清晰，容易理解 | 代码较长，嵌套层次多 | ⭐⭐⭐ |
| 三目运算符法 | 代码简洁 | 三目嵌套可读性差 | ⭐⭐ |
| 求和法 | 代码最简洁，中间值计算巧妙 | 需要先求出 max 和 min | ⭐⭐⭐⭐ |

## 扩展：排序三个数

如果要求将三个数从小到大输出，可以用交换法：

```javascript
var a = prompt('数字1') * 1;
var b = prompt('数字2') * 1;
var c = prompt('数字3') * 1;

var temp;
// 确保 a 是最小的
if (a > b) { temp = a; a = b; b = temp; }
if (a > c) { temp = a; a = c; c = temp; }
// 确保 b 是中间的（此时 a 已是最小）
if (b > c) { temp = b; b = c; c = temp; }

alert('从小到大：' + a + ' < ' + b + ' < ' + c);
```

**思路：类似冒泡排序的思路**
1. 先让 a 和 b 比较，小的放 a
2. 再让 a 和 c 比较，小的放 a → 此时 a 是最小的
3. 最后让 b 和 c 比较，小的放 b → 排序完成

## 速记口诀

> 三数排序求大中小，if嵌套思路清；
> 三目运算虽简洁，嵌套多了读不懂；
> 求和法求中间值，总和大减两极端；
> 交换排序冒泡法，两两比较换位置。
