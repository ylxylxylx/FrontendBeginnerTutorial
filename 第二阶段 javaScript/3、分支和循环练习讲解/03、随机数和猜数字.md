# 随机数和猜数字游戏

> 本节学习 Math.random() 生成随机数，掌握指定范围随机整数的公式，并实现猜数字小游戏。

---

## 一、Math.random()

`Math.random()` 生成 **[0, 1)** 之间的随机小数（包含 0，不包含 1）。

```javascript
console.log(Math.random());  // 0.123456789
console.log(Math.random());  // 0.876543210
```

---

## 二、生成指定范围的随机整数

### 公式

```
[n, m] 之间的随机整数 = Math.floor(Math.random() * (m - n + 1)) + n
```

### 推导过程

以 **[3, 10]** 为例：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 1. 算差值 | 10 - 3 = 7 | 差值为 7 |
| 2. 乘 (差值+1) | Math.random() * 8 | [0, 8) 的随机小数 |
| 3. 向下取整 | Math.floor(上一步) | [0, 7] 的随机整数 |
| 4. 加最小值 | 上一步 + 3 | [3, 10] 的随机整数 |

### 示例

```javascript
// [0, 10] 之间的随机整数
var num = Math.floor(Math.random() * 11);

// [18, 76] 之间的随机整数
var num = Math.floor(Math.random() * (76 - 18 + 1)) + 18;

// [1, 100] 之间的随机整数
var num = Math.floor(Math.random() * 100) + 1;
```

### 通用公式记忆

```
Math.floor(Math.random() * (max - min + 1)) + min
```

> 💡 记忆技巧：`max - min + 1` 是范围宽度，乘以随机数后取整得到 [0, 宽度-1]，再加 min 偏移到目标范围。

## 三、猜数字游戏

### 基础版

**题目：** 系统随机生成 1~100 的整数，玩家输入数字猜测，猜大提示"猜大了"，猜小提示"猜小了"，猜对提示"猜对了"。

```javascript
// 生成 [1, 100] 的随机整数
var target = Math.floor(Math.random() * 100) + 1;
console.log('答案：' + target);  // 调试用

var num = prompt('请输入1-100之间的整数') * 1;

while (num != target) {
    if (num > target) {
        num = prompt('笨蛋，猜大了');
    } else {
        num = prompt('笨蛋，猜小了');
    }
}
alert('恭喜你猜对了！');
```

**流程：**
1. 系统生成随机数
2. 玩家输入猜测
3. 比较大小，给出提示
4. 猜对则退出循环

---

### 升级版：限制次数

**题目：** 最多 7 次机会，猜错显示剩余次数，猜对显示恭喜，次数用完游戏结束。

```javascript
// 生成 [1, 100] 的随机整数
var target = Math.floor(Math.random() * 100) + 1;
console.log('答案：' + target);

var num = prompt('请输入1-100之间的整数，最多7次机会') * 1;
var count = 1;  // 记录已猜次数

while (num != target && count <= 6) {
    // 猜错且还有机会
    if (num > target) {
        num = prompt('笨蛋，猜大了，还有' + (7 - count) + '次机会');
    } else {
        num = prompt('笨蛋，猜小了，还有' + (7 - count) + '次机会');
    }
    count++;
}

// 循环结束：猜对或次数用完
if (num == target) {
    alert('恭喜你猜对了！用了' + count + '次');
} else {
    alert('游戏结束！答案是' + target);
}
```

**关键点：**

| 要点 | 说明 |
|------|------|
| `count = 1` | 第1次猜在循环外，所以从1开始 |
| `count <= 6` | 循环内最多再猜6次，总共7次 |
| `7 - count` | 剩余次数 = 总次数 - 已猜次数 |
| `num != target && count <= 6` | 两个条件都满足才继续循环 |

---

### 为什么7次足够？

1~100 的数字，用**二分法**每次猜中间值，最多需要 ⌈log₂100⌉ = 7 次一定能猜对。

| 次数 | 剩余范围 |
|------|----------|
| 第1次 | 100 个数 → 猜50，剩50 |
| 第2次 | 50 个数 → 猜25或75，剩25 |
| 第3次 | 25 个数 → 剩12或13 |
| 第4次 | 12-13 个数 → 剩6 |
| 第5次 | 6 个数 → 剩3 |
| 第6次 | 3 个数 → 剩1或2 |
| 第7次 | 确定答案 |

## 常见错误

### 1. 忘记 +1

```javascript
// ❌ 生成 [0, 99]，不包含100
var num = Math.floor(Math.random() * 100);

// ✅ 生成 [1, 100]
var num = Math.floor(Math.random() * 100) + 1;
```

### 2. 用 Math.round 代替 Math.floor

```javascript
// ❌ Math.round 会导致两端概率偏低
var num = Math.round(Math.random() * 10);  // 0和10的概率是其他数的一半

// ✅ 用 Math.floor 保证均匀分布
var num = Math.floor(Math.random() * 11);  // 0-10 每个数概率相等
```

## 速记口诀

> 随机数零到一，Math.random()来帮忙；
> 要取范围 [n,m]，乘宽度加n再取整；
> 宽度就是 m-n+1，floor取整最均匀；
> 猜数字用while，二分法七次必中。
