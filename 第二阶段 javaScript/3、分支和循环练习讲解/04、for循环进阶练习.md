# for 循环进阶练习

> 本节通过练习巩固 for 循环和循环嵌套的进阶用法，包括阶乘、阶乘求和、班级成绩统计等。

---

## 练习1：1-100 的和与偶数和

### 1.1 计算 1-100 的和

```javascript
var sum = 0;
for (var i = 1; i <= 100; i++) {
    sum += i;
}
console.log(sum);  // 5050
```

**累加思路：** `sum = sum + i`，每次循环把 i 加到 sum 上。

### 1.2 计算 1-100 所有偶数之和

```javascript
var sum = 0;
for (var i = 1; i <= 100; i++) {
    if (i % 2 == 0) {
        sum += i;
    }
}
console.log(sum);  // 2550
```

**优化：** 直接从 2 开始，步长为 2

```javascript
var sum = 0;
for (var i = 2; i <= 100; i += 2) {
    sum += i;
}
console.log(sum);  // 2550
```

## 练习2：1-10 的积（阶乘）

**题目：** 计算 1×2×3×...×10

```javascript
var product = 1;  // 注意：累乘初始值是1，不是0
for (var i = 1; i <= 10; i++) {
    product *= i;
}
console.log(product);  // 3628800
```

**累加 vs 累乘：**

| 操作 | 初始值 | 累加 | 累乘 |
|------|--------|------|------|
| 求和 | `sum = 0` | `sum += i` | — |
| 求积 | `product = 1` | — | `product *= i` |

> ⚠️ 累乘的初始值必须是 1，如果是 0 则结果永远为 0。

## 练习3：n 的阶乘

**题目：** 从键盘输入 n，计算 n!（n 的阶乘）

```javascript
var n = prompt('请输入一个正整数') * 1;
var product = 1;
for (var i = 1; i <= n; i++) {
    product *= i;
}
alert(n + '! = ' + product);
```

**示例：**
- 5! = 1×2×3×4×5 = 120
- 6! = 1×2×3×4×5×6 = 720
- 0! = 1（规定）

## 练习4：1! + 2! + 3! + ... + 10!

**题目：** 计算阶乘的累加和

### 方法一：双重循环（容易理解但效率低）

```javascript
var sum = 0;
for (var i = 1; i <= 10; i++) {
    // 计算 i!
    var product = 1;
    for (var j = 1; j <= i; j++) {
        product *= j;
    }
    sum += product;
}
console.log(sum);  // 4037913
```

### 方法二：单循环（高效）

**思路：** 利用 `i! = (i-1)! × i`，不需要每次从头计算阶乘。

```javascript
var sum = 0;
var product = 1;  // 保存上一个阶乘的结果
for (var i = 1; i <= 10; i++) {
    product *= i;   // i! = (i-1)! * i
    sum += product;  // 累加 i!
}
console.log(sum);  // 4037913
```

**执行过程：**

| i | product (i!) | sum |
|---|-------------|-----|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 6 | 9 |
| 4 | 24 | 33 |
| 5 | 120 | 153 |
| ... | ... | ... |
| 10 | 3628800 | 4037913 |

> 💡 方法二只需一次循环，时间复杂度 O(n)；方法一需要双重循环，时间复杂度 O(n²)。

## 练习5：筛选数字

**题目：** 求 1-100 内能被 3 整除且不能被 5 整除的数字，每行打印 5 个。

```javascript
var count = 0;
for (var i = 1; i <= 100; i++) {
    if (i % 3 == 0 && i % 5 != 0) {
        document.write(i + ' ');
        count++;
        if (count % 5 == 0) {
            document.write('<br>');
        }
    }
}
```

**换行技巧：** 用计数器 `count`，每 5 个换一行：`count % 5 == 0` 时输出 `<br>`。

## 练习6：班级成绩统计

**题目：** 有 3 个班，每个班级 4 人，求各个班级总成绩（成绩从键盘输入）。

```javascript
for (var i = 0; i < 3; i++) {
    var banji = i + 1;  // 班级编号
    var sum = 0;
    for (var j = 0; j < 4; j++) {
        var num = j + 1;  // 学生编号
        var score = prompt('请输入' + banji + '班' + num + '号同学的成绩') * 1;
        sum += score;
    }
    alert(banji + '班总成绩：' + sum);
}
```

**执行流程：**

```
外层 i=0（1班）→ 内层 j=0,1,2,3（4个学生）→ 输出1班总成绩
外层 i=1（2班）→ 内层 j=0,1,2,3（4个学生）→ 输出2班总成绩
外层 i=2（3班）→ 内层 j=0,1,2,3（4个学生）→ 输出3班总成绩
```

**关键点：**

| 要点 | 说明 |
|------|------|
| `sum` 在外层循环内声明 | 每个班级的 sum 独立，重新从 0 开始 |
| 内层循环用 `prompt` | 每个学生成绩从键盘输入 |
| `banji = i + 1` | 显示时从 1 开始更自然 |

## 练习7：打印偶数（格式化输出）

**题目：** 打印 1-100 所有偶数，一行显示 6 个。

```javascript
var count = 0;
for (var i = 1; i <= 100; i++) {
    if (i % 2 == 0) {
        document.write(i + ' ');
        count++;
        if (count % 6 == 0) {
            document.write('<br>');
        }
    }
}
```

## 知识点回顾

| 知识点 | 关键要点 |
|--------|----------|
| 累加 | `sum = 0` 开始，`sum += i` |
| 累乘 | `product = 1` 开始，`product *= i` |
| 阶乘优化 | 利用 `i! = (i-1)! * i`，避免重复计算 |
| 格式化输出 | 用计数器控制换行 |
| 嵌套循环 | 外层控制行/组，内层控制列/个 |
| 嵌套循环变量 | `sum` 等累加变量要在外层循环内声明 |
