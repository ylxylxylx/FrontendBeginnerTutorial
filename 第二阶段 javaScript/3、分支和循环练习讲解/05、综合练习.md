## 练习1：水仙花数

**题目：** 打印所有"水仙花数"——三位数中，各位数字立方和等于该数本身的数。例如：153 = 1³ + 5³ + 3³

<details>
<summary>参考答案</summary>

```javascript
for (var i = 100; i < 1000; i++) {
    // 提取各位数字
    var ge = i % 10;
    var shi = Math.floor(i / 10) % 10;
    var bai = Math.floor(i / 100) % 10;

    // 计算立方和
    var res = Math.pow(ge, 3) + Math.pow(shi, 3) + Math.pow(bai, 3);

    if (res == i) {
        document.write('水仙花数：' + i + ' ');
    }
}
```

**要点：**
- 三位数范围：100-999
- 数位提取：个位 `%10`，十位 `Math.floor(n/10)%10`，百位 `Math.floor(n/100)%10`
- `Math.pow(x, 3)` 计算 x 的 3 次方，也可用 `x*x*x`

**结果：** 153、370、371、407

</details>

## 练习2：打印图形

### 2.1 矩形

**题目：** 打印 5 行 8 列的矩形

```javascript
for (var i = 0; i < 5; i++) {       // 行
    for (var j = 0; j < 8; j++) {   // 列
        document.write('*');
    }
    document.write('<br>');
}
```

### 2.2 直角三角形

**题目：** 打印高度为 5 的直角三角形

```javascript
for (var i = 0; i < 5; i++) {           // 行
    for (var j = 0; j < i + 1; j++) {   // 第i行有i+1个*
        document.write('* ');
    }
    document.write('<br>');
}
```

### 2.3 等腰三角形

**题目：** 打印高度为 8 的等腰三角形

```javascript
document.write('<pre>');
for (var i = 0; i < 8; i++) {
    // 空格：第i行有 (7-i) 个空格
    for (var j = 0; j < 7 - i; j++) {
        document.write(' ');
    }
    // 星号：第i行有 (2*i+1) 个星号
    for (var j = 0; j < 2 * i + 1; j++) {
        document.write('*');
    }
    document.write('<br>');
}
document.write('</pre>');
```

**规律：**

| 行号 i | 空格数 | 星号数 |
|--------|--------|--------|
| 0 | 7 | 1 |
| 1 | 6 | 3 |
| 2 | 5 | 5 |
| ... | ... | ... |
| i | 7-i | 2i+1 |

> 💡 `<pre>` 标签让空格不被浏览器合并，保持等腰三角形形状。

## 练习3：质数判断

### 3.1 判断单个数是否为质数

**题目：** 从键盘输入一个数，判断是否为质数。

<details>
<summary>参考答案</summary>

```javascript
var num = prompt('请输入一个整数') * 1;
var isPrime = true;  // 假设是质数

if (num < 2) {
    isPrime = false;  // 小于2的不是质数
} else {
    // 用 [2, num-1] 的数去试除
    for (var i = 2; i <= num - 1; i++) {
        if (num % i == 0) {
            isPrime = false;  // 能整除，不是质数
            break;             // 找到一个就够了，不用继续
        }
    }
}

if (isPrime) {
    alert(num + '是质数');
} else {
    alert(num + '不是质数');
}
```

**思路：**
1. 假设是质数（`isPrime = true`）
2. 用 2 到 num-1 的数逐个试除
3. 一旦能整除，标记为非质数并 break
4. 循环结束根据 `isPrime` 输出结果

</details>

### 3.2 打印 101-200 之间的质数

<details>
<summary>参考答案</summary>

```javascript
for (var i = 101; i < 200; i++) {
    var isPrime = true;  // 假设是质数
    for (var j = 2; j <= i - 1; j++) {
        if (i % j == 0) {
            isPrime = false;
            break;
        }
    }
    if (isPrime) {
        document.write(i + '是质数 ');
    }
}
```

> 💡 质数（素数）：只能被 1 和自身整除的大于 1 的自然数，如 2、3、5、7、11、13...

</details>

## 练习4：跳过特定数字

**题目：** 输出 1-100 的数字，8 个一行，遇到个位是 3 或 3 的倍数不输出。

<details>
<summary>参考答案</summary>

```javascript
var count = 0;
for (var i = 1; i <= 100; i++) {
    // 个位是3 或 是3的倍数 → 跳过
    if (i % 10 == 3 || i % 3 == 0) {
        continue;
    }
    document.write(i + ' ');
    count++;
    if (count % 8 == 0) {
        document.write('<br>');
    }
}
```

**要点：**
- `i % 10 == 3` 判断个位是否为 3（如 3、13、23、33...）
- `i % 3 == 0` 判断是否为 3 的倍数（如 3、6、9、12...）
- 用 `continue` 跳过不符合条件的数字

</details>

## 练习5：百鸡问题

**题目：** 一百块买一百只鸡，公鸡 5 块一只，母鸡 3 块一只，小鸡 1 块钱 3 只。每种至少买一只，有几种方案？

<details>
<summary>参考答案</summary>

**分析：**
- 公鸡 x：5 元/只，最多买 20 只（100/5=20）
- 母鸡 y：3 元/只，最多买 33 只（100/3≈33）
- 小鸡 z：1/3 元/只，最多买 100 只
- 条件：x + y + z = 100（只数），5x + 3y + z/3 = 100（金额）

```javascript
for (var x = 0; x <= 20; x++) {          // 公鸡
    for (var y = 0; y <= 33; y++) {      // 母鸡
        for (var z = 0; z <= 100; z++) { // 小鸡
            if ((x + y + z == 100) && (5 * x + 3 * y + z / 3 == 100)) {
                document.write('公鸡：' + x + ' 母鸡：' + y + ' 小鸡：' + z + '<br>');
            }
        }
    }
}
```

**优化：** 小鸡数量可以用 z = 100 - x - y 算出，减少一层循环：

```javascript
for (var x = 0; x <= 20; x++) {
    for (var y = 0; y <= 33; y++) {
        var z = 100 - x - y;
        if (z >= 0 && (5 * x + 3 * y + z / 3 == 100)) {
            document.write('公鸡：' + x + ' 母鸡：' + y + ' 小鸡：' + z + '<br>');
        }
    }
}
```

**结果：**
- 公鸡：0 母鸡：25 小鸡：75
- 公鸡：4 母鸡：18 小鸡：78
- 公鸡：8 母鸡：11 小鸡：81
- 公鸡：12 母鸡：4 小鸡：84

</details>

## 练习6：数字求和游戏

**题目：** 指定基数 base 和次数 count，求 base + basebase + basebasebase + ... 的值。如 base=2, count=3，求 2+22+222。游戏后提示是否继续。

<details>
<summary>参考答案</summary>

**核心算法：** 每一项 = 上一项 × 10 + base

```
i=0: temp = 0×10 + 2 = 2
i=1: temp = 2×10 + 2 = 22
i=2: temp = 22×10 + 2 = 222
```

```javascript
var isGo = false;
do {
    // 1、输入基数和次数
    var base = prompt('请输入基数（1-9）') * 1;
    var count = prompt('请输入次数') * 1;

    // 2、计算
    var sum = 0;
    var temp = 0;
    for (var i = 0; i < count; i++) {
        temp = temp * 10 + base;  // 生成每一项：2 → 22 → 222
        sum += temp;
    }

    alert('结果：' + sum);

    // 3、是否继续
    isGo = confirm('是否继续游戏？');
} while (isGo);
```

**执行过程（base=2, count=3）：**

| i | temp | sum |
|---|------|-----|
| 0 | 2 | 2 |
| 1 | 22 | 24 |
| 2 | 222 | 246 |

结果：2 + 22 + 222 = 246

</details>

## 练习7：登录系统（3次机会）

**题目：** 用户登录验证，最多 3 次机会。正确用户名 kate，密码 123456。

<details>
<summary>参考答案</summary>

```javascript
var count = 3;  // 剩余次数

do {
    var username = prompt('请输入账号');
    var password = prompt('请输入密码');

    if (username == 'kate' && password == '123456') {
        alert('登录成功');
        break;  // 登录成功，退出循环
    } else {
        count--;  // 次数减一
        if (count == 0) {
            alert('输入次数已达3次，账号已锁定');
            break;  // 次数用完，退出循环
        }
        alert('账号或密码错误，还有' + count + '次机会');
    }
} while (true);
```

**要点：**
- `do-while(true)` 实现无限循环，用 `break` 控制退出
- 两个退出条件：登录成功 或 次数用完
- `count` 从 3 递减，记录剩余机会

</details>

## 练习8：购物系统

**题目：** 循环输入商品编号和数量，自动计算金额，结账时打八折，输入实付金额并找零。商品：1.T恤￥245  2.网球鞋￥570  3.网球拍￥120

<details>
<summary>参考答案</summary>

```javascript
var isShopping = true;
var allPrice = 0;
var info = '';

do {
    // 1、输入商品编号和数量
    var num = prompt('请选择商品编号：\n1.T恤￥245\n2.网球鞋￥570\n3.网球拍￥120') * 1;
    var count = prompt('请输入购买数量') * 1;

    if (num && count) {
        // 2、根据编号获取价格和名称
        var price = 0;
        var sort = '';
        switch (num) {
            case 1: price = 245; sort = 'T恤'; break;
            case 2: price = 570; sort = '网球鞋'; break;
            case 3: price = 120; sort = '网球拍'; break;
        }

        // 3、计算商品价钱和总价
        var goodsPrice = price * count;
        allPrice += goodsPrice;
        info += sort + ' ￥' + price.toFixed(2) + ' 数量：' + count + ' 合计：￥' + goodsPrice.toFixed(2) + '\n';
        alert(info);

        isShopping = confirm('是否继续下单？');
    } else {
        isShopping = confirm('未选择商品，是否重新下单？');
        if (!isShopping) {
            alert('欢迎下次光临！');
            break;
        }
    }

    // 4、结束下单，开始结算
    if (!isShopping) {
        var isPay = confirm('购物清单：\n' + info + '总价：￥' + allPrice.toFixed(2) + '\n是否结算？');
        if (isPay) {
            var yingfu = allPrice * 0.8;  // 八折
            var shifu = prompt('特惠打八折，应付：￥' + yingfu.toFixed(2) + '\n请输入实付金额') * 1;
            while (shifu < yingfu) {
                shifu = prompt('金额不足，请重新输入') * 1;
            }
            alert('实付：￥' + shifu.toFixed(2));
            alert('找零：￥' + (shifu - yingfu).toFixed(2));
        } else {
            alert('欢迎下次光临！');
            break;
        }
    }
} while (isShopping);
```

**流程：**
1. 选择商品 → 输入数量 → 计算金额 → 是否继续
2. 结束购物 → 显示清单 → 是否结算
3. 结算 → 计算折扣 → 输入实付 → 找零

</details>
