# 函数的创建与使用

> 本节学习 JavaScript 中函数的两种创建方式（函数声明和函数表达式）、参数（形参和实参）以及返回值的使用。

---

## 一、什么是函数

函数（Function）是通过一系列操作实现某个功能的代码块。将重复使用的代码封装成函数，可以多次调用，减少代码冗余。

```
函数的作用：
1. 封装重复代码，提高复用性
2. 让代码结构更清晰
3. 便于维护和修改
```

---

## 二、函数的两种创建方式

### 1. 函数声明

```javascript
function 函数名() {
    函数体;  // 功能代码
}
```

- `function`：关键字，声明函数
- `函数名`：遵循变量命名规范，要有意义
- `()`：参数列表
- `{}`：函数体，实现功能的代码

```javascript
// 声明函数
function test() {
    console.log('test 函数');
}

// 调用函数 —— 函数体中的代码不会自动执行，调用后才执行
test();
```

### 2. 函数表达式

```javascript
var 函数名 = function() {
    函数体;
};
```

```javascript
var test1 = function() {
    console.log('test1 函数');
};
test1();
```

### 3. 两种方式的区别

| 对比项 | 函数声明 | 函数表达式 |
|--------|----------|------------|
| 语法 | `function 名(){}` | `var 名 = function(){}` |
| 提升 | **整体提升**（可以在声明前调用） | **变量提升**（赋值前调用报错） |
| 分号 | 不需要 | 赋值语句建议加分号 |

```javascript
console.log(typeof test, typeof test1);  // function function
```

## 三、函数的参数

### 形参和实参

```javascript
// a 和 b 是形参（形式参数）—— 定义时的占位符
function add(a, b) {
    console.log('a=' + a, 'b=' + b);
    var c = a + b;
    console.log('c=' + c);
}

// 2 和 3 是实参（实际参数）—— 调用时传入的值
add(2, 3);   // a=2 b=3, c=5
```

**要点：**
- 形参：函数定义时 `()` 中的参数，相当于变量声明
- 实参：函数调用时 `()` 中传入的值，给形参赋值
- 多个参数用逗号 `,` 隔开

### 不传参的情况

```javascript
function add(a, b) {
    console.log('a=' + a, 'b=' + b);
}

add();  // a=undefined b=undefined
```

> 💡 调用时不传实参，形参默认值为 `undefined`。

## 四、函数的返回值

### return 关键字

```javascript
function sum(a, b) {
    var c = a + b;
    return c;       // 返回 c 的值，并结束函数
    // return 之后的代码不会执行
    console.log('这行不会执行');
}

var res = sum(2, 3);  // 用变量接收返回值
console.log('res=' + res);  // res=5
```

**return 的两个作用：**
1. **返回值**：将结果返回给调用者
2. **结束函数**：执行到 return，函数立即结束

### 返回值类型

```javascript
// 返回值是什么类型，接收变量就是什么类型
function getNum() {
    return 100;       // 返回 number
}
function getStr() {
    return 'hello';   // 返回 string
}
function getBool() {
    return true;       // 返回 boolean
}
```

### 注意事项

```javascript
// ❌ 错误：return 和返回值之间不能换行
return
c;        // JS 自动加分号，变成 return; c; —— 返回 undefined

// ✅ 正确
return c;
```

## 五、typeof 检查函数类型

```javascript
function test() {}
var test1 = function() {};

console.log(typeof test);   // function
console.log(typeof test1);  // function
```

**数据类型回顾：**
- 基本类型：`number`、`string`、`boolean`、`null`、`undefined`
- 引用类型：`object`（包含 `function`、`array`）

```javascript
console.log(typeof NaN);        // number
console.log(typeof undefined);  // undefined
console.log(typeof null);       // object
```

## 知识点速记

| 知识点 | 要点 |
|--------|------|
| 函数声明 | `function 名(){}`，整体提升 |
| 函数表达式 | `var 名 = function(){}`，变量提升 |
| 形参 | 定义时的占位符，未传参默认 undefined |
| 实参 | 调用时传入的值 |
| return | 返回值 + 结束函数 |
| return 后不执行 | return 之后的代码是无效代码 |
| typeof 函数 | 返回 `"function"` |
