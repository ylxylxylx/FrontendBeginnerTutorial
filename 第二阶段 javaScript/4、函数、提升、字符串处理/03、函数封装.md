# 函数封装

> 本节学习函数封装的思想：将重复代码提取为函数，提高代码复用性，以及如何将封装的函数放到独立 js 文件中供多个页面使用。

---

## 一、为什么需要函数封装

### 问题：重复代码

计算组合数 C(n,m) = n! / ((n-m)! × m!)，需要计算 3 次阶乘：

```javascript
var n = 6, m = 4;
var up = 1, bottomLeft = 1, bottomRight = 1;

// n! — 重复的阶乘代码
for (var i = 1; i <= n; i++) {
    up *= i;
}
// (n-m)! — 又写了一遍
for (var i = 1; i <= n - m; i++) {
    bottomLeft *= i;
}
// m! — 再写一遍
for (var i = 1; i <= m; i++) {
    bottomRight *= i;
}

var res = up / (bottomLeft * bottomRight);
```

> 同样的阶乘代码写了 3 遍，如果要改逻辑需要改 3 处。

### 解决：封装成函数

```javascript
// 封装阶乘函数
function jieCheng(n) {
    var sum = 1;
    for (var i = 1; i <= n; i++) {
        sum *= i;
    }
    return sum;
}

// 使用：简洁清晰
var res = jieCheng(6) / (jieCheng(6 - 4) * jieCheng(4));
```

## 二、函数封装的步骤

```
1. 找出重复代码
2. 提取变化的部分作为参数
3. 用 function 包裹，返回结果
4. 用函数调用替换原来的重复代码
```

### 示例：封装组合函数

```javascript
// 第一步：封装阶乘
function jieCheng(n) {
    var sum = 1;
    for (var i = 1; i <= n; i++) {
        sum *= i;
    }
    return sum;
}

// 第二步：封装组合
function zuHe(n, m) {
    return jieCheng(n) / (jieCheng(n - m) * jieCheng(m));
}

// 第三步：直接调用
var res = zuHe(6, 4);   // C(6,4) = 15
console.log(res);
```

> 💡 函数可以调用其他函数，形成**函数组合**，让代码更模块化。

## 三、函数封装到独立 js 文件

在 `<script>` 标签中封装的函数，只能在当前 HTML 文档中使用。如果想让封装的代码在多个页面复用，需要将函数放到独立的 js 文件中。

### 1. 创建 js 文件

`zuhe.js`：

```javascript
// 封装阶乘函数
function jieCheng(n) {
    var sum = 1;
    for (var i = 1; i <= n; i++) {
        sum *= i;
    }
    return sum;
}

// 封装组合函数
function zuHe(n, m) {
    return jieCheng(n) / (jieCheng(n - m) * jieCheng(m));
}
```

### 2. 在 HTML 中引入

```html
<script src="zuhe.js"></script>
<script>
    // 引入后可以直接使用 zuhe.js 中封装的函数
    var res = zuHe(12, 8);
    alert('组合：' + res);
</script>
```

### 3. 引入顺序

多个 js 文件和 `<script>` 标签按引入顺序执行。如果后面文件依赖前面文件的变量或函数，**必须先引入依赖文件**。

```html
<!-- ✅ 正确：先引入 zuhe.js，再使用 -->
<script src="zuhe.js"></script>
<script>
    zuHe(6, 4);  // 可以使用
</script>

<!-- ❌ 错误：使用在引入之前 -->
<script>
    zuHe(6, 4);  // 报错：zuHe is not defined
</script>
<script src="zuhe.js"></script>
```

## 四、命名冲突

在同一 HTML 页面引入多个 js 文件时，如果不同文件中有同名变量或函数，**后引入的会覆盖先引入的**。

```javascript
// a.js
var out = 20;

// b.js
var out = 30;  // 覆盖 a.js 中的 out

// HTML 中
<script src="a.js"></script>
<script src="b.js"></script>
<script>
    console.log(out);  // 30（b.js 的值）
</script>
```

> ⚠️ 多个文件中不能起相同的变量名、函数名，否则会产生命名冲突。

## 五、函数封装的优势

| 优势 | 说明 |
|------|------|
| 减少重复 | 同一逻辑只写一次 |
| 易于维护 | 修改只需改一处 |
| 提高可读性 | 函数名即功能说明 |
| 可复用 | 放到 js 文件中，多页面共享 |
| 可组合 | 函数之间可以互相调用 |

## 知识点速记

| 知识点 | 要点 |
|--------|------|
| 封装目的 | 减少重复代码，提高复用性 |
| 封装步骤 | 找重复 → 提参数 → 包函数 → 替换调用 |
| 独立 js 文件 | 用 `<script src>` 引入，多页面复用 |
| 引入顺序 | 依赖文件必须先引入 |
| 命名冲突 | 同名变量/函数，后引入覆盖前引入 |
