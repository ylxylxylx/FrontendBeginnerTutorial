# 作用域

> 本节学习 JavaScript 中的作用域概念：全局作用域、局部作用域、作用域链，以及变量的访问规则。

---

## 一、什么是作用域

作用域（Scope）是变量可以使用的范围。每个变量只能在自己作用域内使用。

```
作用域分类：
├── 全局作用域 —— script 标签或 js 文件中直接定义的变量
└── 局部作用域 —— 函数内部（只有函数创建时才有独立作用域）
```

> ⚠️ `if(){}`、`for(){}`、`switch(){}` 的花括号**没有**独立作用域！

---

## 二、全局作用域

直接在 `<script>` 标签或 js 文件中定义的变量，属于全局作用域（window 作用域）。

```javascript
var out = 6;          // 全局变量
console.log(out);     // 6
console.log(window.out);  // 6（全局变量等价于 window 的属性）
```

**全局变量特点：**
- 在任何地方都可以访问
- `var out = 6` 等价于 `window.out = 6`
- 生命周期：页面打开到关闭

---

## 三、局部作用域

每一个函数都有一个独立的作用域——局部作用域。局部作用域中的变量是局部变量。

```javascript
function f1() {
    var inner = 100;  // 局部变量
    console.log('inner=' + inner);  // 100
}
f1();
console.log(inner);  // ❌ ReferenceError: inner is not defined
```

**局部变量特点：**
- 只能在函数内部访问
- 函数外部无法访问函数内部的变量
- 生命周期：函数调用到函数执行结束

---

## 四、作用域链

当函数嵌套函数时，形成作用域链：

```
全局作用域 → f1 函数作用域 → f2 函数作用域
```

### 访问规则

1. **就近查找**：需要某个变量时，先从自身作用域查找，找不到再去上层作用域，直到全局作用域
2. **同名覆盖**：本作用域变量名与上层同名时，覆盖上层变量

```javascript
var out = 6;  // 全局

function f1() {
    var inner = 100;  // f1 局部
    console.log('inner=' + inner);  // 100
    console.log('out=' + out);      // 6（访问全局）

    function f2() {
        var box = 200;  // f2 局部
        console.log('f2 inner=' + inner);  // 100（访问 f1）
        console.log('f2 out=' + out);      // 6（访问全局）
    }
    f2();

    // console.log(box);  // ❌ f1 不能访问 f2 的局部变量
}
f1();
```

### 同名变量覆盖

```javascript
var out = 6;  // 全局

function f1() {
    var out = 60;  // 局部变量覆盖全局变量
    console.log('out=' + out);  // 60（访问局部）
}
f1();
console.log('out=' + out);  // 6（全局不受影响）
```

---

## 五、函数内外访问规则

| 场景 | 能否访问 | 说明 |
|------|----------|------|
| 函数内访问函数外 | ✅ | 内层可以访问外层变量 |
| 函数外访问函数内 | ❌ | 外层不能访问内层局部变量 |
| 同名变量 | 就近原则 | 内层同名变量覆盖外层 |

### 访问被覆盖的全局变量

当局部变量与全局变量同名时，用 `window.变量名` 访问全局变量：

```javascript
var b = 'hello world';
function f1() {
    var b = 'hello world x';  // 局部 b 覆盖全局 b
    console.log(b);           // 'hello world x'（局部）
    console.log(window.b);    // 'hello world'（全局）
}
f1();
```

## 六、if / for 没有独立作用域

```javascript
// if 块没有独立作用域
if (true) {
    var xxx = 300;
}
console.log(xxx);  // 300（可以访问，var 壁坏到函数作用域）

// for 块没有独立作用域
for (var i = 0; i < 5; i++) {}
console.log(i);  // 5（i 壁坏到函数作用域）
```

> 💡 在 ES6 中，`let` 和 `const` 有块级作用域，`var` 没有。

---

## 七、多文件作用域

同一 HTML 文件引入多个 js 文件和 `<script>` 标签，**同属一个全局作用域**。

```html
<script src="a.js"></script>  <!-- var out = 20; -->
<script src="b.js"></script>  <!-- var out = 30; -->
<script>
    console.log('script');
    var out = 6;
    console.log(out);  // 6
</script>
```

**执行规则：**
1. 按引入顺序执行 js 代码
2. 后面文件中同名变量覆盖前面的
3. 浏览器将多个文件代码按顺序拼接后从上往下执行

---

## 知识点速记

| 知识点 | 要点 |
|--------|------|
| 全局作用域 | script 标签 / js 文件直接定义 |
| 局部作用域 | 只有函数 `{}` 有独立作用域 |
| 全局变量 | 任何地方可访问，等价 window 属性 |
| 局部变量 | 只能在函数内部访问 |
| 作用域链 | 自身 → 上层 → ... → 全局 |
| 同名覆盖 | 内层同名变量覆盖外层 |
| window.变量 | 访问被覆盖的全局变量 |
| if/for 无作用域 | var 壁坏到函数作用域 |
