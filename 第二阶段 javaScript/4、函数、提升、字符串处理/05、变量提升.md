# 变量提升

> 本节学习 JavaScript 中的变量提升机制：var 声明的变量会被提升到作用域顶部，赋值位置不变，以及相关面试题分析。

---

## 一、什么是变量提升

变量提升（Hoisting）：在一个作用域内，**变量的声明会被 JS 引擎提升到这个作用域的顶部**，但**赋值位置不变**。

```javascript
console.log(a);   // undefined（声明提升，但未赋值）
var a = 'hello world';
console.log(a);   // 'hello world'
```

JS 引擎实际执行顺序：

```javascript
var a;            // 声明提升到顶部
console.log(a);   // undefined
a = 'hello world'; // 赋值留在原位
console.log(a);   // 'hello world'
```

---

## 二、变量提升的规则

### 1. 全局作用域中的变量提升

```javascript
// 等价于：
// var a;  ← 声明提升到全局作用域顶部
console.log(a);   // undefined
var a = 'hello world';
console.log(a);   // 'hello world'
```

### 2. 函数作用域中的变量提升

```javascript
function f1() {
    // var b;  ← 声明提升到函数作用域顶部
    console.log(b);   // undefined
    var b = 'hello world';
    console.log(b);   // 'hello world'
}
f1();
```

### 3. 变量提升不会超过参数

```javascript
function f2(c) {
    // 变量提升：var c; → 但参数 c 已经存在
    // 实际执行：c = 20（参数赋值优先）
    console.log(c);   // 20
    var c = 30;
    console.log(c);   // 30
}
f2(20);
```

等价于：

```javascript
function f2(c) {
    // var c;     ← 变量提升，但 c 已通过参数赋值
    // c = 20;    ← 参数赋值
    console.log(c);   // 20
    c = 30;           ← 赋值
    console.log(c);   // 30
}
f2(20);
```

---

## 三、基础知识点回顾

| 规则 | 示例 | 结果 |
|------|------|------|
| 声明未赋值 | `var a; console.log(a)` | `undefined` |
| 全局变量等价 window 属性 | `var a = 66; console.log(window.a)` | `66` |
| 重复声明已赋值变量无意义 | `var a=100; var a; console.log(a)` | `100` |
| 函数参数未传值 | `function fn(a){console.log(a)}` | `undefined` |
| 函数参数传值 | `fn(2)` | `2`（相当于 `var a=2`） |

## 四、经典例题

### 例1：同名变量覆盖

```javascript
var b = 'hello world';
function f1() {
    // var b;  ← 变量提升到函数顶部
    console.log(b);      // undefined（局部 b 已声明但未赋值）
    b = 'hello world x'; // 给局部 b 赋值
    console.log(b);      // 'hello world x'
    console.log(window.b); // 'hello world'（访问全局 b）
}
f1();
```

> 💡 函数内有 `var b`，变量提升后局部 b 已存在但未赋值，所以第一个 `console.log(b)` 是 `undefined` 而不是全局的 `'hello world'`。

### 例2：嵌套作用域

```javascript
var e = 'hello';
function f3() {
    var e = 'f3 你好';
    function f4() {
        var e = 'f4 你好';
        console.log(e);  // 'f4 你好'（就近原则）
    }
    f4();
    console.log(e);      // 'f3 你好'
}
f3();
console.log(e);          // 'hello'（全局）
```

### 例3：window.f 与 var f

```javascript
var f = 10;
function f5() {
    var f;           // 变量提升
    window.f = 20;   // 修改全局 f
    console.log(f);  // undefined（局部 f 未赋值）
    console.log(window.f);  // 20（全局 f 被修改）
}
f5();
```

## 五、加 var 与不加 var 的区别

```javascript
function f6() {
    g = 100;  // 不加 var，变量成为全局变量
}
f6();
console.log(g);  // 100（全局可访问）
```

| 写法 | 作用域 | 说明 |
|------|--------|------|
| `var g = 100` | 局部变量 | 只在函数内可用 |
| `g = 100` | 全局变量 | 不加 var 等于引用/创建全局变量 |

> ⚠️ 不加 var 的变量会成为全局变量（挂在 window 上），容易造成命名冲突，**始终使用 var 声明变量**。

## 六、AO 对象（扩展）

JS 引擎处理函数执行时的内部机制：

```
1. 创建 AO（Activation Object）对象
2. 将形参和变量声明存入 AO，值为 undefined
   { c: undefined, d: undefined }
3. 实参和形参统一：给形参赋值
   { c: 20, d: undefined }
4. 函数声明存入 AO（函数提升）
```

```javascript
function f2(c) {
    var c = 30;
    var d = 40;
    console.log(c);  // 30
    console.log(d);  // 40
}
f2(20);
```

AO 对象变化过程：

| 步骤 | c | d |
|------|---|---|
| 1. 变量声明 | undefined | undefined |
| 2. 参数赋值 | 20 | undefined |
| 3. 代码执行 | 30 | 40 |

## 知识点速记

| 知识点 | 要点 |
|--------|------|
| 变量提升 | 声明提升到作用域顶部，赋值位置不变 |
| 提升结果 | 声明前访问为 undefined |
| 不会超过参数 | 参数赋值优先于变量提升 |
| 同名覆盖 | 局部变量提升后遮蔽全局变量 |
| window.变量 | 访问被覆盖的全局变量 |
| 不加 var | 成为全局变量，挂在 window 上 |
| AO 对象 | 函数执行时的内部机制 |
