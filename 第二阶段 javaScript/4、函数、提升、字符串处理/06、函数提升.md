# 函数提升

> 本节学习函数声明提升与函数表达式变量提升的区别，理解为什么函数声明可以在声明前调用。

---

## 一、函数声明提升

函数声明（`function 名(){}`）会被**整体提升**到作用域顶部——包括函数名和函数体。

```javascript
f1();  // ✅ 可以在声明前调用
function f1() {
    console.log('f1 函数');
}
```

等价于：

```javascript
// 函数声明整体提升到顶部
function f1() {
    console.log('f1 函数');
}
f1();  // 正常执行
```

> 💡 函数声明提升是 JS 的特性，让你可以在代码任何位置调用函数，不受声明顺序限制。

---

## 二、函数表达式的"提升"

函数表达式（`var 名 = function(){}`）只提升**变量声明**，不提升**赋值**。

```javascript
console.log(f2);   // undefined（变量提升，但未赋值）
f2();              // ❌ TypeError: f2 is not a function
var f2 = function() {
    console.log('f2 函数');
};
f2();              // ✅ 赋值之后才能调用
```

等价于：

```javascript
var f2;            // 变量声明提升
console.log(f2);   // undefined
f2();              // ❌ undefined 不是函数
f2 = function() {  // 赋值留在原位
    console.log('f2 函数');
};
f2();              // ✅ 现在可以调用
```

---

## 三、两种提升对比

| 对比项 | 函数声明 | 函数表达式 |
|--------|----------|------------|
| 语法 | `function f(){}` | `var f = function(){}` |
| 提升内容 | **整体提升**（名+体） | **变量提升**（仅声明） |
| 声明前调用 | ✅ 可以 | ❌ 报错 |
| 声明前访问 | 函数本身 | `undefined` |

```javascript
// 函数声明：整体提升
console.log(f1);  // ƒ f1(){...}
f1();             // ✅ 正常执行

function f1() {
    console.log('f1 函数');
}

// 函数表达式：变量提升
console.log(f2);  // undefined
// f2();          // ❌ TypeError

var f2 = function() {
    console.log('f2 函数');
};

f2();             // ✅ 赋值后可以调用
```

---

## 四、函数提升 vs 变量提升

当函数声明和变量声明同名时，**函数提升优先级更高**。

```javascript
console.log(fn);  // ƒ fn(){...}（函数提升优先）

function fn() {
    console.log('fn 函数');
}

var fn = 100;     // 变量赋值覆盖函数
console.log(fn);  // 100
```

> ⚠️ 避免函数名和变量名相同，容易造成混乱。

## 五、常见面试题

### 题1

```javascript
var a = 1;
function fn() {
    console.log(a);  // undefined（变量提升）
    var a = 2;
}
fn();
console.log(a);      // 1（全局 a 不受影响）
```

### 题2

```javascript
fn();               // 'fn 函数'（函数声明提升）
function fn() {
    console.log('fn 函数');
}
var fn = 100;       // 赋值覆盖
fn();               // ❌ TypeError: fn is not a function
```

### 题3

```javascript
console.log(a);     // ƒ a(){...}（函数提升优先）
var a = 1;
function a() {
    console.log('a 函数');
}
console.log(a);     // 1（赋值覆盖函数）
```

## 知识点速记

| 知识点 | 要点 |
|--------|------|
| 函数声明提升 | 整体提升（名+体），声明前可调用 |
| 函数表达式提升 | 变量提升（仅声明），赋值前为 undefined |
| 提升优先级 | 函数声明 > 变量声明 |
| 同名覆盖 | 后赋值覆盖先提升 |
| 避免同名 | 函数名和变量名不要相同 |
