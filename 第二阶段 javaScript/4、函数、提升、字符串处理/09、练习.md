## 一、函数练习

### 练习1：闰年判断函数

**题目：** 封装一个函数，判断某年是否为闰年。

<details>
<summary>参考答案</summary>

```javascript
function isLeapYear(year) {
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        return true;
    }
    return false;
}

// 测试
console.log(isLeapYear(2000));  // true
console.log(isLeapYear(1900));  // false
console.log(isLeapYear(2024));  // true
```

**闰年规则：** 四年一闰、百年不闰、四百年再闰

</details>

<details>
<summary>参考答案</summary>

```javascript
function isLeapYear(year) {
```

### 练习3：质数判断函数

**题目：** 封装一个函数，判断一个数是否为质数。

<details>
<summary>参考答案</summary>

```javascript
function isPrime(num) {
    if (num < 2) return false;
    for (var i = 2; i <= num - 1; i++) {
        if (num % i == 0) {
            return false;  // 能整除，不是质数
        }
    }
    return true;
}

// 测试
console.log(isPrime(7));   // true
console.log(isPrime(10));  // false
console.log(isPrime(1));   // false
```

</details>

## 二、字符串练习

### 练习5：统计字母出现次数

**题目：** 统计字符串 `'dfhjasdaaawwqqqfhfsdfffffadasdas'` 中字母 a 出现了多少次。

<details>
<summary>参考答案</summary>

```javascript
var str = 'dfhjasdaaawwqqqfhfsdfffffadasdas';
var count = 0;
for (var i = 0; i < str.length; i++) {
    if (str[i] === 'a') {
        count++;
    }
}
console.log('a 出现了 ' + count + ' 次');  // a 出现了 7 次
```

**方法二：用 indexOf**

```javascript
var str = 'dfhjasdaaawwqqqfhfsdfffffadasdas';
var count = 0;
var pos = 0;
while ((pos = str.indexOf('a', pos)) !== -1) {
    count++;
    pos++;
}
console.log('a 出现了 ' + count + ' 次');
```

</details>

### 练习6：字符串去重

**题目：** 对字符串 `'dfhjasdfhfsdfffffadasdas'` 去重，保留每个字符只出现一次。

<details>
<summary>参考答案</summary>

```javascript
var str = 'dfhjasdfhfsdfffffadasdas';
var result = '';
for (var i = 0; i < str.length; i++) {
    // 如果 result 中不包含当前字符，则添加
    if (result.indexOf(str[i]) === -1) {
        result += str[i];
    }
}
console.log(result);  // dfhjas
```

**思路：**
1. 遍历原字符串每个字符
2. 用 `indexOf` 检查结果字符串中是否已存在该字符
3. 不存在则添加，存在则跳过

</details>

### 练习7：去除所有空格

**题目：** 去除字符串 `'he l  lo   wor l d'` 中的所有空格。

<details>
<summary>参考答案</summary>

```javascript
var str = 'he l  lo   wor l d';
var result = '';
for (var i = 0; i < str.length; i++) {
    if (str[i] !== ' ') {
        result += str[i];
    }
}
console.log(result);  // helloworld
```

**方法二：用 split + join**

```javascript
var str = 'he l  lo   wor l d';
var result = str.split(' ').join('');
console.log(result);  // helloworld
```

**方法三：用 replace（只去第一个空格，需循环）**

```javascript
var str = 'he l  lo   wor l d';
while (str.indexOf(' ') !== -1) {
    str = str.replace(' ', '');
}
console.log(str);  // helloworld
```

> 💡 `trim()` 只能去两端空格，不能去中间空格。

</details>

### 练习8：统计出现次数最多的字母（加强题）

**题目：** 统计字符串 `'dfhjasdaaawwqqqfhfsdfffffadasdas'` 中出现次数最多的字母。

<details>
<summary>参考答案</summary>

```javascript
var str = 'dfhjasdaaawwqqqfhfsdfffffadasdas';

// 1、统计每个字符出现的次数
var obj = {};
for (var i = 0; i < str.length; i++) {
    var char = str[i];
    if (obj[char]) {
        obj[char]++;
    } else {
        obj[char] = 1;
    }
}
console.log(obj);
// {d: 4, f: 8, h: 2, j: 1, a: 7, s: 4, w: 2, q: 3}

// 2、找出次数最多的
var maxChar = '';
var maxCount = 0;
for (var key in obj) {
    if (obj[key] > maxCount) {
        maxCount = obj[key];
        maxChar = key;
    }
}
console.log('出现最多的字母是 ' + maxChar + '，出现了 ' + maxCount + ' 次');
// 出现最多的字母是 f，出现了 8 次
```

**思路：**
1. 用对象 `obj` 记录每个字符的出现次数（字符为 key，次数为 value）
2. 遍历字符串，字符已存在则 +1，不存在则初始化为 1
3. 遍历对象，找出 value 最大的 key

</details>

## 三、综合练习

### 练习9：银行取款系统

**题目：** 写一个银行系统，用户名 admin，密码 123456，默认存款 8888，取款密码 000000。登录错误 3 次锁定，取款密码错误 3 次退出。登录后可选取款、存款、查看余额。

<details>
<summary>参考答案</summary>

```javascript
var loginCount = 3;     // 登录剩余次数
var payCount = 3;       // 取款密码剩余次数
var money = 8888;       // 余额
var isLogin = false;    // 是否登录成功

// 1、登录验证
do {
    var username = prompt('请输入用户名');
    var password = prompt('请输入密码');

    if (username == 'admin' && password == '123456') {
        isLogin = true;
        break;
    } else {
        loginCount--;
        if (loginCount == 0) {
            alert('输入次数已达3次，程序退出');
            break;
        }
        alert('账号或密码错误，还有' + loginCount + '次机会');
    }
} while (true);

// 2、登录成功后的操作
if (isLogin) {
    var isContinue = true;
    while (isContinue) {
        var choice = prompt('1.取款\n2.存款\n3.查看余额\n4.退出');

        switch (choice * 1) {
            case 1: // 取款
                var payPwd = prompt('请输入取款密码');
                if (payPwd == '000000') {
                    var amount = prompt('请输入取款金额') * 1;
                    if (amount > money) {
                        alert('对不起，余额不足');
                    } else {
                        money -= amount;
                        alert('取款成功！余额：' + money);
                    }
                } else {
                    payCount--;
                    if (payCount == 0) {
                        alert('取款密码错误3次，系统退出');
                        isContinue = false;
                    } else {
                        alert('取款密码错误，还有' + payCount + '次机会');
                    }
                }
                break;
            case 2: // 存款
                var deposit = prompt('请输入存款金额') * 1;
                money += deposit;
                alert('存款成功！余额：' + money);
                break;
            case 3: // 查看余额
                alert('当前余额：' + money);
                break;
            case 4: // 退出
                alert('欢迎下次光临！');
                isContinue = false;
                break;
            default:
                alert('请输入1-4');
        }
    }
}
```

**流程：**
1. 登录验证（3 次机会）
2. 登录成功 → 菜单选择（取款/存款/余额/退出）
3. 取款需验证取款密码（3 次机会）
4. 取款金额不能超过余额

</details>
