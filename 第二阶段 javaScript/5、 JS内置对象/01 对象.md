# JS内置对象 - Object 对象

## 一、什么是对象

对象是 JavaScript 中最重要的数据类型之一，它是一个包含了**属性**和**方法**的集合。

- **属性**：描述对象的特征，是静态的（如：身高、肤色）
- **方法**：描述对象的行为，是动态的（如：睡觉、吃饭、学习）

```javascript
// 生活中的对象示例
// 张三：
//   特征（属性）：大眼睛、高、瘦、白  → height=188, skin='白'
//   行为（方法）：睡觉、吃饭、跑步、学习 → sleep(), eat(), study()
```

## 二、创建对象的三种方式

### 1. 通过 new 关键字

`new` 是关键字，一般用来创建新对象。`Object()` 是系统创建对象的函数——构造函数。

```javascript
var obj = new Object({
    name: 'xxx'
});
```

### 2. 省去 new

```javascript
obj = Object();
```

### 3. 字面量方式（最常用）

```javascript
obj = {
    name: 'xxxi'
};

console.log(obj, typeof obj); // {} "object"
```

## 三、对象的属性和方法

### 添加属性和方法

使用 **键值对（key: value）** 的形式：
- **键**：属性名 或 方法名
- **值**：具体数值 或者 一个方法

```javascript
var zhangsan = {
    // 给对象添加属性
    name: '张三',
    age: 18,
    // 给对象添加方法
    run: function() {
        console.log('张三今天监督黄元卜跑50圈');
    }
};
```

### 获取属性的值

```javascript
// 对象名.属性名
var name = zhangsan.name;
console.log(name); // 张三
```

### 修改属性的值

```javascript
zhangsan.age = 20;
console.log(zhangsan.age); // 20
```

### 调用对象的方法

```javascript
// 对象名.方法名()
zhangsan.run(); // 张三今天监督黄元卜跑50圈
```

### 动态添加属性和方法

```javascript
// 添加属性
zhangsan.skin = '水嫩白';

// 添加方法
zhangsan.study = function() {
    console.log('张三在107学习前端');
};
```

### 打印对象

```javascript
console.log(zhangsan);   // 直接打印对象
console.dir(zhangsan);   // 以目录形式打印对象（更详细）
```

## 四、属性可以是任意类型

对象的属性值可以是任意数据类型，包括对象、数组、布尔值等：

```javascript
var lisi = {
    name: '李四',
    friend: zhangsan,    // 属性值是另一个对象
    sex: true,           // 属性值是布尔值
    money: [100, 2000, 500],  // 属性值是数组
    gf: {                // 属性值是嵌套对象
        name: 'Lili'
    }
};

// 访问嵌套属性
console.log(lisi.friend.name);  // 张三
console.log(lisi.gf.name);      // Lili
```

## 五、内置对象都有属性和方法

字符串也是对象，拥有自己的属性和方法：

```javascript
var str = 'www';
str.length;           // 属性：获取字符串长度
str.indexOf('a');     // 方法：查找字符位置
```

## 总结

| 操作 | 语法 |
|------|------|
| 创建对象 | `{ key: value }` |
| 获取属性 | `对象名.属性名` |
| 修改属性 | `对象名.属性名 = 新值` |
| 添加属性 | `对象名.新属性 = 值` |
| 添加方法 | `对象名.新方法 = function(){}` |
| 调用方法 | `对象名.方法名()` |
