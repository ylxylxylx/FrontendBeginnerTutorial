# JS内置对象 - Array 数组

## 一、创建数组的三种方式

### 1. 通过 new

```javascript
var array = new Array(1, 2, 3, 6);
```

### 2. 省去 new

```javascript
array = Array();
```

### 3. 字面量（最常用）

```javascript
array = [];
console.log(array, typeof array); // [] "object"
```

> 注意：`typeof` 数组返回的是 `"object"`，因为数组本质上也是对象。

## 二、数组存储任意类型的数据

```javascript
var arr = [1, 2, true, null, undefined, {name: '张三'}, 'xxx'];
console.log(arr);
```

## 三、索引与访问

数组中的元素有索引值，从 **0** 开始：0, 1, 2, 3 ...

```javascript
var nums = ['a', 'b', 'c', 'd'];
console.dir(nums);

// 通过索引值获取数组元素的值
console.log(nums[1]); // 100（修改后的值）

// 如果索引值不存在，返回 undefined —— 数组越界
console.log(nums[10]); // undefined
```

## 四、修改数组元素

```javascript
// 根据数组的索引值改变元素的值
nums[1] = 100;
```

## 五、数组长度 length

```javascript
// 获取数组长度值：元素的个数
console.log(nums.length); // 4

// 获取数组最后一个元素的值
console.log(nums[nums.length - 1]); // d
```

> 索引值取值范围是 `[0, arr.length - 1]`

## 六、遍历数组

### 方式一：for 循环

```javascript
for (var i = 0; i < nums.length; i++) {
    var num = nums[i];
    console.log(num);
}
```

### 方式二：forEach

`forEach` 遍历数组，相当于 for 循环，让数组的每一个元素都调用一次遍历函数。

**参数说明：**
- `item`：数组中每一个元素
- `index`：元素对应的索引值
- `arr`：数组本身

```javascript
nums.forEach(function(item, index, arr) {
    console.log(item, index, arr);
});
```

## 七、for 循环的几种写法

```javascript
var arr = [1, 2, 3, 4];
// arr.length 是 4
// 索引值取值范围是 [0, arr.length - 1]

// 写法1：i <= arr.length - 1
for (var i = 0; i <= arr.length - 1; i++) { }

// 写法2：i < arr.length（推荐）
for (var i = 0; i < arr.length; i++) { }

// 写法3：固定次数
for (var i = 0; i < 3; i++) { }

// 写法4：从1开始计数
for (var i = 1; i <= 100; i++) { }

// 写法5：从0到100
for (var i = 0; i < 101; i++) { }
```

## 总结

| 操作 | 语法 | 说明 |
|------|------|------|
| 创建数组 | `[]` | 字面量方式，最常用 |
| 访问元素 | `arr[索引]` | 索引从0开始 |
| 修改元素 | `arr[索引] = 新值` | - |
| 越界访问 | `arr[超出索引]` | 返回 `undefined` |
| 数组长度 | `arr.length` | 元素个数 |
| 最后元素 | `arr[arr.length - 1]` | - |
| for遍历 | `for(var i=0; i<arr.length; i++)` | 推荐写法 |
| forEach遍历 | `arr.forEach(function(item,index,arr){})` | 更简洁 |
