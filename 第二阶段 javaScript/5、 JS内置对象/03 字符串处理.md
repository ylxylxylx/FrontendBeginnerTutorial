# JS内置对象 - String 字符串处理

```javascript
var str = 'Hello world';
```

## 一、索引与长度

### 索引值

从 0 开始，依次是 0, 1, 2, 3 ...（索引 = 位置）

```javascript
console.log(str[0);   // H
console.log(str[80]); // undefined（超过最大值返回 undefined）
```

### 长度

```javascript
console.log(str.length); // 11
```

> 最大索引值：`length - 1`

### 遍历字符串

```javascript
for (var i = 0; i < str.length; i++) {
    var s = str[i];
    // console.log(s);
}
```

## 二、获取字符串中的字符

### 方式一：通过索引访问 `str[索引]`

```javascript
console.log(str[2);  // l
console.log(str[20); // undefined（超过最大索引值）
```

### 方式二：charAt() 方法

```javascript
console.log(str.charAt(2);  // l
console.log(str.charAt(20); // ''（空字符串，不是 undefined）
```

> **区别**：索引越界时，`str[索引]` 返回 `undefined`，`charAt()` 返回空字符串 `''`。

## 三、大小写转换

```javascript
console.log(str.toLocaleLowerCase()); // 转为小写 → hello world
console.log(str.toLocaleUpperCase()); // 转为大写 → HELLO WORLD
```

## 四、split() 分割字符串

以某个字符分割字符串，分割之后得到一个**数组**。

```javascript
var arr = str.split('o');
console.log(arr); // ["Hell", " w", "rld"]
```

### 际际应用：从复合字符串中提取信息

```javascript
var names = ['Tom|hello Tom', 'Lily|hello Lily'];
var name = names[0]; // 'Tom|hello Tom'

// 用 | 分割，取第一部分
var nArr = name.split('|'); // ['Tom', 'hello Tom']
console.log(names[0].split('|')[0]); // Tom
```

## 五、查找字符位置

### indexOf() 第一次出现的索引

```javascript
console.log(str.indexOf('l');       // 2
```

### lastIndexOf() 最后一次出现的索引

```javascript
console.log(str.lastIndexOf('l'); // 9
```

> 如果字符不存在，返回 **-1**：
> ```javascript
> console.log(str.indexOf('x');   // -1
> console.log(str.lastIndexOf('a'); // -1
> ```

## 六、包含判断

### includes() 是否包含

```javascript
console.log(str.includes('wo'); // true
```

### startsWith() 是否以指定字符开头

```javascript
console.log(str.startsWith('He'); // true
```

### endsWith() 是否以指定字符结尾

```javascript
console.log(str.endsWith('ld'); // true
```

## 七、替换与重复

### replace() 换

```javascript
console.log(str.replace('w', 'XX'); // Hello XXorld
```

> 注意：`replace()` 只替换**第一个**匹配项。

### repeat() 重复

```javascript
console.log(str.repeat(3); // Hello worldHello worldHello world
```

## 八、去除空白

### trim() 去除两端空白

```javascript
console.log('-' + ' xx ' + '-');           // - xx -
console.log('-' + ' xx '.trim() + '-');    // -xx-
console.log('-' + ' x x  '.trim() + '-');  // -x x-（只去两端，中间空格保留）
```

## 九、常见错误：TypeError

### TypeError: Cannot read property 'xxx' of undefined

```javascript
var ch = str[20];       // undefined
var index = ch.indexOf('h'; // 报错！undefined 没有 indexOf 方法
```

**原因**：在 `undefined` 中没有 `indexOf` 属性。

**解决**：打印输出 `.` 前面的变量是否为 `undefined`。

### TypeError: Cannot read property 'xxx' of null

**原因**：在 `null` 中没有 `xxx` 属性。

**解决**：打印输出 `.` 前面的变量是否为 `null`。

## 总结

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `str[i]` | 通过索引获取字符 | 越界返回 `undefined` |
| `str.charAt(i)` | 通过索引获取字符 | 越界返回 `'' |
| `str.length` | 字符串长度 | 数字 |
| `str.toLocaleLowerCase()` | 转为小写 | 新字符串 |
| `str.toLocaleUpperCase()` | 转为大写 | 新字符串 |
| `str.split(分隔符)` | 分割字符串为数组 | 数组 |
| `str.indexOf(ch)` | 字符第一次出现的索引 | 不存在返回 `-1` |
| `str.lastIndexOf(ch)` | 字符最后一次出现的索引 | 不存在返回 `-1` |
| `str.includes(ch)` | 是否包含 | `true/false` |
| `str.startsWith(ch)` | 是否以ch开头 | `true/false` |
| `str.endsWith(ch)` | 是否以ch结尾 | `true/false` |
| `str.replace(old, new)` | 换第一个匹配 | 新字符串 |
| `str.repeat(n)` | 重复n次 | 新字符串 |
| `str.trim()` | 去除两端空白 | 新字符串 |
