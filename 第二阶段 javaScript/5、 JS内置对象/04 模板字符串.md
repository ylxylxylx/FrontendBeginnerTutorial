# JS内置对象 - 模板字符串

## 一、普通字符串的局限

不管是单引号还是双引号，字符串都**不能换行**，必须写在一行：

```javascript
var str = '123wwwwwwwwwwwwwwwwww';
```

## 二、模板字符串的基本用法

模板字符串使用**反引号** `` ` `` 包裹，可以**任意换行**：

```javascript
var str = `1231
    12321
    12321
    123`;
console.log(str);
```

## 三、变量插值 ${}

在模板字符串中可以使用 `${}` 添加任意变量或表达式：

```javascript
var num = 666;
var name = `张三`;

var str1 = `hel${num}lo wo${name}rld!${name}`;
console.log(str1); // hel666lo wo张三rld!张三
```

## 四、动态生成 HTML

模板字符串非常适合动态生成 HTML 内容：

```javascript
var htmlstr = `
    <div>头部</div>
    <div>底部</div>
`;
document.write(htmlstr);
```

## 总结

| 特性 | 普通字符串（'/"") | 模板字符串（``） |
|------|-------------------|-----------------|
| 换行 | 不支持 | 支持 |
| 变量插值 | 需要拼接 `+` | 使用 `${变量}` |
| 动态HTML | 拼接繁琐 | 直观清晰 |

> **推荐**：需要换行或嵌入变量时，优先使用模板字符串。
