# JS基础 - 循环嵌套

## 一、什么是循环嵌套

循环嵌套是指在一个循环体内部再包含一个循环语句。

**核心规则**：外层循环执行一次，内层循环要执行一个**完整**的循环。

```
外层循环第1次 → 内层循环完整执行一遍
外层循环第2次 → 内层循环重新开始，完整执行一遍
外层循环第3次 → 内层循环重新开始，完整执行一遍
...
```

## 二、简单示例

```javascript
for (var i = 0; i < 3; i++) {
    document.write(i);
    for (var j = 0; j < 3; j++) {
        document.write(' *');
    }
    document.write('<br>');
}
```

**执行过程分析**：

```
i=0 时：
    输出 0
    内层循环：j=0 输出 *，j=1 输出 *，j=2 输出 *
    输出换行
i=1 时：
    输出 1
    内层循环：j=0 输出 *，j=1 输出 *，j=2 输出 *
    输出换行
i=2 时：
    输出 2
    内层循环：j=0 输出 *，j=1 输出 *，j=2 输出 *
    输出换行
```

输出结果：
```
0 * * *
1 * * *
2 * * *
```

## 三、找规律：三角形图案

```javascript
for (var i = 0; i < 3; i++) {     // i 控制第几行
    for (var j = 0; j < i + 1; j++) { // j 控制一行有几个
        document.write(' *');
    }
    document.write('<br>');
}
```

**找规律**：
- i=0：内层循环 1 次 → j 最大为 1 = i+1
- i=1：内层循环 2 次 → j 最大为 2 = i+1
- i=2：内层循环 3 次 → j 最大为 3 = i+1

所以内层循环条件为 `j < i + 1`。

输出结果：
```
 *
 * *
 * * *
```

## 四、循环嵌套要点

1. **外层循环控制行数**，内层循环控制每行的内容
2. 内层循环的次数可以与外层循环变量相关（如 `j < i + 1`）
3. 找规律是关键：分析每行的输出与行号的关系

## 总结

| 概念 | 说明 |
|------|------|
| 外层循环 | 控制行数/轮次 |
| 内层循环 | 控制每行/每轮的内容 |
| 执行顺序 | 外层一次 → 内层完整一遍 |
| 找规律 | 分析每行输出与行号的关系 |
