# 数组的常用操作

> 本节学习数组的增删改查方法，包括 push/pop、unshift/shift、splice、slice、concat、join、indexOf、includes、reverse 等，以及扩展运算符和数组判断。

## 数组的添加和删除

### 末尾操作：push 和 pop

```javascript
var nums = [2, 4, 6, 8];

// push()：往数组末尾添加一个元素
nums.push('新增的');  // [2, 4, 6, 8, '新增的']

// pop()：删除数组最后一个元素
nums.pop();           // [2, 4, 6, 8]
```

### 开头操作：unshift 和 shift

```javascript
var nums = [2, 4, 6, 8];

// unshift()：往数组开头添加一个元素
nums.unshift('新增X');  // ['新增X', 2, 4, 6, 8]

// shift()：删除数组第一个元素
nums.shift();            // [2, 4, 6, 8]
```

## splice — 任意位置的删除和添加

`splice()` 是最灵活的数组方法，可以实现任意位置的删除、替换和插入。

### 两个参数：删除元素

```javascript
var nums = [2, 4, 6, 8];
// 参数1：开始位置  参数2：删除的个数
nums.splice(1, 2);  // [2, 8]  从索引1开始删除2个元素
```

### 三个参数：替换元素

```javascript
var nums = [2, 4, 6, 8];
// 参数1：开始位置  参数2：删除的个数  参数3：替换的内容
nums.splice(1, 2, 100);  // [2, 100, 8]  把100添加到索引1的位置
```

### 三个参数（删除0个）：插入元素

```javascript
var nums = [2, 4, 6, 8];
// 删除0个元素，把200添加到索引2的位置
nums.splice(2, 0, 200);  // [2, 4, 200, 6, 8]
```

### 用 splice 实现 push 的功能

```javascript
var nums = [2, 4, 6, 8];
// 在数组末尾（nums.length位置）插入600
nums.splice(nums.length, 0, 600);  // [2, 4, 6, 8, 600]
```

> 💡 `splice()` 会**修改原数组**。

## slice — 截取数组

`slice()` 从数组中截取一段，**不会修改原数组**，返回新数组。

```javascript
var nums = [2, 4, 6, 8, 10, 12];

// 一个参数：从指定位置一直到数组末尾
nums.slice(2);    // [6, 8, 10, 12]

// 两个参数：开始位置（包含）和结束位置（不包含）
nums.slice(2, 4); // [6, 8]
```

## concat 和扩展运算符 — 合并数组

```javascript
var nums = [2, 4, 6, 8];
var newarr = [100, 200];

// concat() 方法
var arr2 = nums.concat(newarr);  // [2, 4, 6, 8, 100, 200]

// 扩展运算符 ... （推荐）
arr2 = [...nums, ...newarr];     // [2, 4, 6, 8, 100, 200]
```

> 💡 扩展运算符 `...` 可以把数组"展开"为单个元素，更简洁直观。

## join 和 toString — 数组转字符串

```javascript
var arr2 = [2, 4, 6, 8, 100, 200];

// join()：用指定字符连接数组元素，转为字符串
arr2.join('');    // '2468100200'
arr2.join('|');   // '2|4|6|8|100|200'

// split()：字符串转数组（join 的逆操作）
arr2.join('|').split('|');  // ['2', '4', '6', '8', '100', '200']

// toString()：用逗号连接，转为字符串
arr2.toString();  // '2,4,6,8,100,200'
```

## indexOf、lastIndexOf 和 includes — 查找元素

```javascript
var arr2 = [2, 4, 6, 8, 100, 200];

// indexOf()：获取元素第一次出现的索引，找不到返回 -1
arr2.indexOf(6);     // 2

// lastIndexOf()：获取元素最后一次出现的索引，找不到返回 -1
arr2.lastIndexOf(6); // 2

// includes()：判断数组是否包含某个元素，返回 true/false
arr2.includes(300);  // false
```

### 用 indexOf 判断元素是否存在

```javascript
// 存在
arr2.indexOf(6) >= 0;   // true

// 不存在
arr2.indexOf(6) === -1; // false
```

## reverse — 颠倒数组

```javascript
var arr2 = [2, 4, 6, 8, 100, 200];

// reverse()：颠倒数组中元素的顺序（修改原数组）
arr2.reverse();  // [200, 100, 8, 6, 4, 2]
```

### 手动实现数组反转

```javascript
function getReverse(arr) {
    var rArr = [];
    for (var i = 0; i < arr.length; i++) {
        rArr.unshift(arr[i]);  // 每次往新数组开头添加
    }
    return rArr;
}

var newA = getReverse([2, 4, 6, 8, 100, 200]);
console.log(newA);  // [200, 100, 8, 6, 4, 2]
```

## Array.from 和 Array.isArray

```javascript
// Array.from()：把类数组对象转为真正的数组
// 例如：document.getElementsByClassName() 返回的就是类数组
// Array.from(divs);  // 转为数组

// Array.isArray()：判断一个值是否是数组
var a = [];
var b = {};

typeof a;            // 'object'
typeof b;            // 'object'  —— typeof 无法区分数组和对象

Array.isArray(a);    // true
Array.isArray(b);    // false
```

> 💡 `typeof` 对数组和对象都返回 `'object'`，需要用 `Array.isArray()` 来准确判断。

## 扩展：对象的合并

扩展运算符 `...` 也可以用于合并对象，后面的属性会覆盖前面的同名属性：

```javascript
var p1 = { name: 'x1', age: 12 };
var p2 = { height: 100, weight: 100, age: 10 };

var p = { ...p1, ...p2 };
console.log(p);  // {name: 'x1', age: 10, height: 100, weight: 100}
// age 属性被 p2 的值覆盖了
```

## 常用数组方法总结

| 方法 | 功能 | 是否修改原数组 |
|------|------|:------------:|
| `push()` | 末尾添加 | ✅ |
| `pop()` | 末尾删除 | ✅ |
| `unshift()` | 开头添加 | ✅ |
| `shift()` | 开头删除 | ✅ |
| `splice()` | 任意位置增删改 | ✅ |
| `slice()` | 截取子数组 | ❌ |
| `concat()` | 合并数组 | ❌ |
| `join()` | 数组转字符串 | ❌ |
| `toString()` | 数组转字符串 | ❌ |
| `indexOf()` | 查找元素索引 | ❌ |
| `includes()` | 判断是否包含 | ❌ |
| `reverse()` | 反转数组 | ✅ |
| `Array.from()` | 类数组转数组 | ❌ |
| `Array.isArray()` | 判断是否数组 | ❌ |
