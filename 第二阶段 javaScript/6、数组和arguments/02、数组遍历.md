# 数组遍历

> 本节学习数组的多种遍历方式，包括 for 循环、forEach、every、some、map、filter、find、findIndex 和 reduce。

## for 遍历

最基础的遍历方式，通过索引逐个访问数组元素：

```javascript
var nums = [2, 3, 4, 5, 6];

for (var i = 0; i < nums.length; i++) {
    console.log(nums[i]);
}
```

## forEach 遍历

`forEach()` 对数组的每个元素执行一次回调函数。

```javascript
var nums = [2, 3, 4, 5, 6];

// 参数：item 当前元素, index 当前索引, array 原始数组
nums.forEach(function(item, index, array) {
    console.log(item, index, array);
});
```

### forEach 的限制

- **不能使用 `break`**：无法中途跳出循环
- **使用 `return` 无效**：不会终止遍历，只是跳过当前回调

```javascript
nums.forEach(function(item, index, array) {
    if (index === 1) {
        return;   // 仅跳过本次回调，遍历不会停止
        // break;  // ❌ 报错，不能使用
    }
});
```

## every — 每一个都满足

`every()` 判断数组中**所有元素**是否都满足条件，全部满足返回 `true`，只要有一个不满足就返回 `false`。

```javascript
var nums = [2, 3, 4, 5, 6];

var res = nums.every(function(item, index, array) {
    return item > 4;
});
console.log(res);  // false（2、3、4 不大于4）
```

> 💡 `every` 只要遇到返回 `false` 的元素，就**立即停止**遍历，不再检查后续元素。

## some — 至少一个满足

`some()` 判断数组中是否**至少有一个**元素满足条件，有一个满足就返回 `true`，全部不满足才返回 `false`。

```javascript
var nums = [2, 3, 4, 5, 6];

var res = nums.some(function(item, index, array) {
    return item > 4;
});
console.log(res);  // true（5、6 大于4）
```

> 💡 `some` 只要遇到返回 `true` 的元素，就**立即停止**遍历。

### every vs some 对比

| 方法 | 返回 true 的条件 | 遇到什么就停止 |
|------|-----------------|--------------|
| `every` | 所有元素都满足 | 遇到 `false` |
| `some` | 至少一个元素满足 | 遇到 `true` |

## map — 映射变换

`map()` 对每个元素执行运算，将每次运算的结果组成一个**新数组**返回。

```javascript
var nums = [2, 3, 4, 5, 6];

// 求每个元素的平方
var res = nums.map(function(item, index, array) {
    return Math.pow(item, 2);
});
console.log(res);  // [4, 9, 16, 25, 36]
```

## filter — 过滤筛选

`filter()` 对每个元素进行判断，将符合条件的元素组成一个**新数组**返回。

```javascript
var nums = [2, 3, 4, 5, 6];

// 筛选大于4的元素
var res = nums.filter(function(item) {
    return item > 4;
});
console.log(res);  // [5, 6]
```

## find — 查找第一个符合条件的元素

`find()` 返回第一个满足条件的**元素值**，找不到返回 `undefined`。

```javascript
var nums = [2, 3, 4, 5, 6];

var res = nums.find(function(item) {
    return item > 4;
});
console.log(res);  // 5（第一个大于4的元素）
```

## findIndex — 查找第一个符合条件的索引

`findIndex()` 返回第一个满足条件的**索引值**，找不到返回 `-1`。

```javascript
var nums = [2, 3, 4, 5, 6];

var res = nums.findIndex(function(item) {
    return item > 4;
});
console.log(res);  // 3（5的索引值是3）
```

## reduce — 累计运算

`reduce()` 一般用于累计运算（求和、求积等），让每个元素参与运算，将结果存入回调函数的第一个参数中。

### 语法

```javascript
arr.reduce(callback, initValue);
// callback(prev, current, index, array)
// prev: 上一次运算的结果
// current: 当前元素的值
// index: 当前索引
// array: 原始数组
```

### 情况1：没有 initValue

第一次执行时，`prev` 等于数组第一个元素，`current` 等于数组第二个元素：

```javascript
var nums = [2, 3, 4, 5, 6];

var res = nums.reduce(function(prev, current, index) {
    console.log(prev, current);
    return current + 100;
});
// 第一次：prev=2, current=3
// 第二次：prev=103, current=4
// ...
```

### 情况2：有 initValue

第一次执行时，`prev` 等于 `initValue`，`current` 等于数组第一个元素：

```javascript
var nums = [2, 3, 4, 5, 6];

nums.reduce(function(prev, current, index) {
    console.log(prev, current);
    return current + 100;
}, 10);
// 第一次：prev=10, current=2
// 第二次：prev=102, current=3
// ...
```

### 实际应用：计算五险一金总费率

```javascript
var rates = [0.08, 0.02, 0.005, 0.1];  // 养老、医疗、失业、公积金

var total = rates.reduce(function(prev, current, index) {
    return prev + current;
});
console.log(total);  // 0.205（总费率20.5%）
```

## 遍历方法总结

| 方法 | 返回值 | 是否修改原数组 | 用途 |
|------|--------|:------------:|------|
| `forEach` | 无 | ❌ | 遍历每个元素 |
| `every` | boolean | ❌ | 判断是否全部满足 |
| `some` | boolean | ❌ | 判断是否至少一个满足 |
| `map` | 新数组 | ❌ | 映射变换每个元素 |
| `filter` | 新数组 | ❌ | 过滤符合条件的元素 |
| `find` | 元素值 | ❌ | 查找第一个满足的元素 |
| `findIndex` | 索引值 | ❌ | 查找第一个满足的索引 |
| `reduce` | 累计值 | ❌ | 累计运算 |
