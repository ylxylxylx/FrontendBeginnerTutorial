# 数组排序

> 本节学习冒泡排序的原理和实现，以及数组自带的 `sort()` 方法的使用。

## 变量交换

排序的核心操作是交换两个变量的值，需要借助第三个临时变量：

```javascript
var a = 2;
var b = 3;

// 交换 a 和 b 的值
var temp = a;  // temp 保存 a 的值，temp=2
a = b;         // a 保存 b 的值，a=3
b = temp;      // b 保存 temp 的值，b=2

// 结果：a=3, b=2
```

## 冒泡排序（Bubble Sort）

冒泡排序是一种简单的排序算法。它重复地遍历要排序的数列，一次比较两个相邻元素，如果顺序错误就交换它们。

### 算法描述

1. 比较相邻的元素，如果第一个比第二个大，就交换
2. 对每一对相邻元素做同样的工作，从开始到结尾，最后的元素就是最大值
3. 针对所有元素重复以上步骤，除了最后一个
4. 重复步骤 1~3，直到排序完成

> 名字由来：越小的元素会经由交换慢慢"浮"到数列的顶端，就像气泡一样。

### 图解过程

以 `[6, 3, 2, 5]` 从小到大排序为例：

```
第一轮（i=0）：确定最后一个位置的最大值
  j=0: 6>3，交换 → [3, 6, 2, 5]
  j=1: 6>2，交换 → [3, 2, 6, 5]
  j=2: 6>5，交换 → [3, 2, 5, 6]  ← 6 已到位

第二轮（i=1）：确定倒数第二个位置
  j=0: 3>2，交换 → [2, 3, 5, 6]
  j=1: 3<5，不换 → [2, 3, 5, 6]  ← 5 已到位

第三轮（i=2）：确定倒数第三个位置
  j=0: 2<3，不换 → [2, 3, 5, 6]  ← 3 已到位

排序完成：[2, 3, 5, 6]
```

### 代码实现

```javascript
var arr = [7, 5, 1, 2];

for (var i = 0; i < arr.length - 1; i++) {
    for (var j = 0; j < arr.length - 1 - i; j++) {
        if (arr[j] > arr[j + 1]) {
            var temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
console.log(arr);  // [1, 2, 5, 7]
```

### 循环要点

- **外层循环** `i`：控制比较轮数，共 `arr.length - 1` 轮
- **内层循环** `j`：每轮比较相邻元素，范围逐渐缩小（`arr.length - 1 - i`）
- **比较条件** `arr[j] > arr[j+1]`：从小到大排序；改为 `<` 则从大到小

## sort() — 数组自带排序

`sort()` 是数组内置的排序方法，内部原理就是冒泡排序。

### 基本用法

```javascript
var arr = [7, 5, 1, 2];

// 升序排列
arr.sort(function(x, y) {
    return x - y;
});
console.log(arr);  // [1, 2, 5, 7]

// 降序排列
arr.sort(function(x, y) {
    return y - x;
});
```

### 排序规则

`sort(function(x, y))` 的回调函数返回值决定了排序方式：

| 返回值 | 效果 |
|--------|------|
| 大于 0 | 交换 x 和 y 的位置 |
| 小于 0 | 不交换 |
| 等于 0 | 不交换 |

### 等价写法

```javascript
var arr = [7, 5, 1, 2];

arr.sort(function(x, y) {
    if (x > y) {
        return 1;   // 交换位置
    } else if (x < y) {
        return -1;  // 不交换
    } else {
        return 0;   // 不交换
    }
});
```

### 对象数组排序

`sort()` 也可以根据对象的某个属性进行排序：

```javascript
var arr = [
    { name: 'x1', age: 10, online: false },
    { name: 'x2', age: 6,  online: true },
    { name: 'x3', age: 8,  online: true },
    { name: 'x4', age: 8,  online: false }
];

// 按 online 状态排序：online 为 true 的排在前面
arr.sort(function(x, y) {
    if (x.online && y.online) {
        return 1;   // 都在线，不调整
    } else if (x.online && !y.online) {
        return -1;  // x 在线 y 不在线，x 排前面
    } else {
        return 0;   // 都不在线，不调整
    }
});

// 简写：利用布尔值转数字的特性
arr.sort(function(x, y) {
    return y.online - x.online;
});
```

## 冒泡排序 vs sort()

| 对比项 | 冒泡排序（手写） | sort() |
|--------|-----------------|--------|
| 代码量 | 较多 | 一行 |
| 灵活性 | 可自定义每一步 | 通过回调函数控制 |
| 可读性 | 直观展示排序过程 | 简洁但需理解规则 |
| 实际开发 | 理解原理为主 | **推荐使用** |

> 💡 实际开发中优先使用 `sort()`，手写冒泡排序主要用于理解排序原理和面试准备。
