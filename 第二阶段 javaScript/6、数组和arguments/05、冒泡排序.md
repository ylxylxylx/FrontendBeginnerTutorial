# 冒泡排序练习

> 本节通过一个利用 Math.max 和 splice 实现排序的练习，加深对数组操作的理解。

## 思路：每次找最大值，移到新数组

不同于传统的冒泡排序（相邻元素两两比较交换），这里采用一种更直观的方法：

1. 每次从原数组中找到**最大值**
2. 将最大值添加到新数组的**开头**（`unshift`）
3. 从原数组中**删除**该最大值
4. 重复以上步骤，直到原数组为空

### 代码实现

```javascript
function fun(arr) {
    var tempArr = [];

    // 注意：不能用 i++，因为 arr.length 每次都在变
    // 当 arr.length 变为 0 时循环自然结束
    for (var i = 0; i < arr.length; ) {
        var max = Math.max(...arr);     // 求数组中的最大值
        tempArr.unshift(max);            // 在 tempArr 的开头添加
        var maxIndex = arr.indexOf(max); // 找出最大元素的索引值
        arr.splice(maxIndex, 1);         // 删除最大值
    }

    return tempArr;
}

var arr = [12, 3, 11, 4, 5, 28, 7, 6];
console.log(fun(arr));  // [3, 4, 5, 6, 7, 11, 12, 28]
```

### 执行过程

以 `[12, 3, 11, 4, 5, 28, 7, 6]` 为例：

```
第一次循环：
  arr = [12, 3, 11, 4, 5, 28, 7, 6]
  max = 28
  tempArr = [28]
  删除28 -> arr = [12, 3, 11, 4, 5, 7, 6]

第二次循环：
  arr = [12, 3, 11, 4, 5, 7, 6]
  max = 12
  tempArr = [12, 28]
  删除12 -> arr = [3, 11, 4, 5, 7, 6]

第三次循环：
  arr = [3, 11, 4, 5, 7, 6]
  max = 11
  tempArr = [11, 12, 28]
  删除11 -> arr = [3, 4, 5, 7, 6]

...依此类推...

最后一次循环：
  arr = []
  tempArr = [3, 4, 5, 6, 7, 11, 12, 28]
```

## 关键点解析

### 1. Math.max 求数组最大值

```javascript
// Math.max 通常接收多个参数
Math.max(2, 5, 3, 8);  // 8

// 配合扩展运算符，求数组中的最大值
Math.max(...[2, 5, 3, 8]);  // 8
```

### 2. 为什么不用 i++

```javascript
for (var i = 0; i < arr.length; ) {
    // ...
    arr.splice(maxIndex, 1);  // 每次删除一个元素，arr.length 减1
}
```

每次循环都会从 `arr` 中删除一个元素，`arr.length` 逐渐减小。当 `arr` 为空时，`arr.length` 为 0，循环条件 `i < arr.length` 不满足，自然结束。

如果使用 `i++`，`i` 会不断增加而 `arr.length` 不断减少，可能导致循环提前结束或逻辑错误。

### 3. unshift 实现从大到小转从小到大

每次找到最大值并 `unshift`（添加到开头），最终结果就是从小到大的排列：

- 第1次找到最大值28 -> tempArr = [28]
- 第2次找到12 -> tempArr = [12, 28]
- 第3次找到11 -> tempArr = [11, 12, 28]
- ...
- 最终：tempArr = [3, 4, 5, 6, 7, 11, 12, 28]

## 与传统冒泡排序对比

| 对比项 | 本方法 | 传统冒泡排序 |
|--------|--------|------------|
| 思路 | 每次找最大值移到新数组 | 相邻元素两两比较交换 |
| 是否修改原数组 | 是，原数组被清空 | 是，原数组被排序 |
| 空间复杂度 | O(n)，需要新数组 | O(1)，原地交换 |
| 代码复杂度 | 较简单 | 嵌套循环较复杂 |
| 实际开发 | 不推荐，仅供理解 | 推荐，或使用 sort() |

> 实际开发中请使用 `arr.sort()`，本方法仅用于理解排序思路和练习数组操作。
