## 练习1：从数组中找最大值

封装一个函数，获取数组中的最大值。

### 代码实现

```javascript
function getArrMax(arr) {
    var max = arr[0];
    for (var i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

var re = getArrMax([10, 60, 5, 2]);
console.log(re);  // 60
```

### 思路

1. 假设第一个元素就是最大值
2. 从第二个元素开始，逐个与当前最大值比较
3. 如果比最大值大，就更新最大值
4. 遍历结束后返回最大值

> 函数的 `return` 让结果可以被后续使用，比 `console.log` 更灵活。

### 扩展：封装保留两位小数的函数

function getFloat(n) {
    var res = n.toFixed(2);
    return res;
}

var geshui = 333.245;
var gs = getFloat(geshui);
alert('要缴税：' + gs);  // 要缴税：333.25

## 练习2：统计字符串中出现次数最多的字母

给定一个字符串，统计每个字母出现的次数，找出出现次数最多的字母。

### 代码实现

```javascript
var str = 'hell';

// 第一步：用对象统计每个字符出现的次数
var obj = {};
for (var i = 0; i < str.length; i++) {
    var ch = str[i];  // ch = 'h', 'e', 'l', 'l'
    if (obj[ch]) {
        obj[ch]++;    // 已有该属性，次数+1
    } else {
        obj[ch] = 1;  // 没有该属性，初始化为1
    }
}
// obj = { h: 1, e: 1, l: 2 }

// 第二步：找出出现次数最多的字符
var max = 0;
var word = '';
for (var key in obj) {
    var num = obj[key];
    if (num > max) {
        max = num;   // 记录最大次数
        word = key;  // 记录对应字符
    }
}

console.log(word, max);  // 'l' 2
console.log(obj);        // { h: 1, e: 1, l: 2 }
```

### 思路

1. **用对象做计数器**：对象的属性名是字符，属性值是出现次数
2. **遍历字符串**：每个字符判断对象中是否已有该属性
   - 有：次数 +1
   - 没有：初始化为 1
3. **遍历对象**：找出属性值最大的那个属性名

### 关键知识点：对象的属性访问

```javascript
var zhangsan = {
    name: '张三',
    height: 188,
    skin: '水嫩白'
};

// 点语法访问（属性名固定）
console.log(zhangsan.height);      // 188

// 方括号语法访问（属性名可以是变量）
var key = 'height';
console.log(zhangsan[key]);        // 188

// 添加新属性
zhangsan['color'] = '蓝色';

// 遍历对象
for (var key in zhangsan) {
    console.log(key, zhangsan[key]);
    // key 是属性名，zhangsan[key] 是属性值
}
```

> 注意：`zhangsan.key` 访问的是名为 `key` 的属性（不存在则返回 `undefined`），而 `zhangsan[key]` 访问的是变量 `key` 的值对应的属性。

## 练习3：找出数组中所有的质数

质数（素数）是大于1的自然数中，除了1和它本身外不能被其他自然数整除的数。

### 代码实现

```javascript
// 判断某个数字是否是质数
function isPrime(n) {
    if (n < 2) {
        return false;
    } else {
        for (var i = 2; i < n; i++) {  // i的取值范围 [2, n-1]
            if (n % i === 0) {
                return false;  // 能被整除，不是质数
            }
        }
        return true;  // 不能被任何数整除，是质数
    }
}

var arr = [1, 2, 3, 4, 5, 6, 7, 8];
for (var i = 0; i < arr.length; i++) {
    if (isPrime(arr[i])) {
        console.log(arr[i]);  // 2, 3, 5, 7
    }
}
```

### 思路

1. **封装判断质数的函数** `isPrime(n)`
2. 小于2的数不是质数，直接返回 `false`
3. 从 2 到 n-1 依次试除，如果 n 能被其中任何一个数整除，就不是质数
4. 遍历数组，对每个元素调用 `isPrime` 进行判断

## 练习4：找出所有姓王的名字

从一个名字数组中，筛选出所有以"王"开头的名字。

### 代码实现

```javascript
var names = ['王二麻子', '张雪松', '王中王', '丁智勇', '王志强', '王鹏程'];

for (var i = 0; i < names.length; i++) {
    var aName = names[i];
    if (aName.startsWith('王')) {
        console.log(aName);
    }
}
// 输出：王二麻子、王中王、王志强、王鹏程
```

### 思路

1. 遍历名字数组
2. 用 `startsWith()` 方法判断字符串是否以指定字符开头
3. 符合条件的输出

### 相关字符串方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `startsWith()` | 判断是否以指定字符开头 | `'王二'.startsWith('王')` → `true` |
| `endsWith()` | 判断是否以指定字符结尾 | `'王二'.endsWith('二')` → `true` |
| `indexOf()` | 查找字符位置 | `'王二'.indexOf('王')` → `0` |
| `charAt()` | 获取指定位置的字符 | `'王二'.charAt(0)` → `'王'` |
