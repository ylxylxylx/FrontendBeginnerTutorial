# 匿名函数

> 本节学习匿名函数的概念、用法，包括函数作为参数传递、回调函数、自执行函数，以及匿名函数的作用域隔离。

## 什么是匿名函数

匿名函数就是**没有名字的函数**。

```javascript
// 有名函数
function add(a, b) {
    return a + b;
}

// 匿名函数
var add = function(a, b) {
    return a + b;
};
```

### 匿名函数的作用

1. **直接调用**（自执行函数）
2. **作为函数对象**，赋值给变量、参数、对象的属性

> ⚠️ 匿名函数直接声明会报错，必须赋值给变量或自执行。

## 函数作为参数传递

函数也是对象类型，可以把函数当做参数使用：

```javascript
var add = function(a, b) {
    return a + b;
};

function sum1(fn) {
    var c = fn(2, 3);
    return c;
}

// 把函数 add 当成参数，传递给 fn
var res = sum1(add);
console.log(res);  // 5
```

## 回调函数

将匿名函数作为参数传递给另一个函数，在适当的时候被调用，这就是**回调函数**。

```javascript
function sum(fn) {
    fn(2);
}

// 调用 sum，传递一个匿名函数作为参数
// 相当于 var fn = function(a) { console.log('sum 回调函数', a); }
sum(function(a) {
    console.log('sum 回调函数', a);  // sum 回调函数 2
});
```

### 模拟 forEach

```javascript
function each(fn) {
    var arr = [1, 2, 3];
    for (var i = 0; i < arr.length; i++) {
        fn(arr[i], i, arr);
    }
}

each(function(item, index, arr) {
    console.log(item, index, arr);
});
```

### 扩展数组方法

通过 `Array.prototype` 给所有数组添加自定义方法：

```javascript
Array.prototype.each = function(fn) {
    for (var i = 0; i < this.length; i++) {
        fn(this[i], i, this);
    }
};

var arr = [1, 2, 3];
arr.each(function(item, index, arr) {
    console.log(item, index, arr);
});
```

> 💡 `this` 在方法内部指向调用该方法的对象（即数组本身）。

## 自执行函数（IIFE）

匿名函数无法被外部调用，只能**自执行**。

### 语法

```javascript
// 写法1（推荐）
(function() {
    console.log('匿名函数1');
})();

// 写法2
(function() {
    console.log('匿名函数2');
}());
```

### 带参数的自执行函数

```javascript
(function(a, b) {
    console.log(a, b);  // 2 3
})(2, 3);
```

### 带返回值的自执行函数

```javascript
var res = (function(a, b) {
    return a + b;
})(2, 3);

console.log(res);  // 5
```

## 自执行函数的作用：隔离作用域

在多人协作开发中，不同 JS 文件可能定义了同名变量，导致冲突。自执行函数可以创建**独立作用域**，避免变量污染。

```javascript
// a.js
(function() {
    var a = 20;  // 只在自执行函数内部有效
})();

// b.js
(function() {
    var a = 30;  // 不会与 a.js 中的 a 冲突
})();
```

> 💡 自执行函数内部的变量不会影响全局，这是模块化开发的基础思想。

## 总结

| 概念 | 说明 | 示例 |
|------|------|------|
| 匿名函数 | 没有名字的函数 | `var fn = function() {}` |
| 回调函数 | 作为参数传递的函数 | `sum(function(){})` |
| 自执行函数 | 声明后立即执行的函数 | `(function(){})()` |
| 作用域隔离 | 自执行函数创建独立作用域 | 避免变量名冲突 |
