# 斐波那契数列

> 本节学习斐波那契数列的规律，以及用循环方式求第 n 项的值。

## 什么是斐波那契数列

斐波那契数列是一个经典的数列：**1、1、2、3、5、8、13、21、34、……**

规律：从第三项开始，**每一项等于前两项之和**。

```
第1项: 1
第2项: 1
第3项: 1 + 1 = 2
第4项: 1 + 2 = 3
第5项: 2 + 3 = 5
第6项: 3 + 5 = 8
...
第n项: 第(n-1)项 + 第(n-2)项
```

## 循环实现

用循环方式求第 n 项的值：

```javascript
function feibo(n) {
    if (n < 3) {
        return 1;  // 第1项和第2项都是1
    }

    var t1 = 1,   // 前一项的前一项
        t2 = 1,   // 前一项
        sum = 0;

    for (var i = 3; i <= n; i++) {
        sum = t1 + t2;  // 当前项 = 前两项之和
        t1 = t2;        // t1 后移：变成原来的 t2
        t2 = sum;       // t2 后移：变成当前的 sum
    }

    return sum;
}

console.log(feibo(6));  // 8
```

### 执行过程

以 `feibo(6)` 为例：

```
i=3: sum = 1 + 1 = 2,  t1 = 1, t2 = 2
i=4: sum = 1 + 2 = 3,  t1 = 2, t2 = 3
i=5: sum = 2 + 3 = 5,  t1 = 3, t2 = 5
i=6: sum = 3 + 5 = 8,  t1 = 5, t2 = 8

返回 sum = 8
```

### 关键点

- `t1` 和 `t2` 分别记录前两项的值
- 每次循环计算 `sum = t1 + t2`，然后让 `t1` 和 `t2` 整体后移
- `t1 = t2` 必须在 `t2 = sum` **之前**执行，否则 t2 的值会被覆盖

## 递归实现

斐波那契数列也可以用递归实现（下一节详解）：

```javascript
function feibo(n) {
    if (n < 3) {
        return 1;
    }
    return feibo(n - 1) + feibo(n - 2);
}

console.log(feibo(6));  // 8
```

## 循环 vs 递归

| 对比项 | 循环实现 | 递归实现 |
|--------|---------|---------|
| 代码量 | 稍多 | 简洁 |
| 性能 | 高，无重复计算 | 低，有大量重复计算 |
| 可读性 | 需理解变量后移 | 直接体现数学公式 |
| 实际开发 | **推荐** | 仅用于理解递归 |

> 💡 递归实现虽然简洁，但 `feibo(n-1) + feibo(n-2)` 会导致大量重复计算。例如 `feibo(5)` 会重复计算 `feibo(3)` 两次。实际开发中推荐循环实现。
