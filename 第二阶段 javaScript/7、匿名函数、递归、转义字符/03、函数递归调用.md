# 函数递归调用

> 本节学习函数递归的概念，包括递归的基本结构、结束条件，以及用递归求和、求斐波那契数列。

## 什么是递归

**递归**就是函数自己调用自己。递归必须有**结束条件**，否则会产生死循环。

### 死循环示例

```javascript
// ❌ 没有结束条件，会无限调用
function fn() {
    console.log('fn 函数');
    fn();  // 自己调用自己，没有结束条件
}
fn();
```

两个函数相互调用也会产生死循环：

```javascript
// ❌ 相互调用，没有结束条件
function f1() {
    console.log('f1 函数');
    f2();
}
function f2() {
    console.log('f2 函数');
    f1();
}
f2();
```

## 递归的基本结构

递归函数由两部分组成：

1. **结束条件**：当满足某个条件时，停止递归
2. **递归调用**：函数调用自身，参数向结束条件靠近

```javascript
function add(n) {
    if (n <= 0) {     // 结束条件
        return;
    }
    console.log('n=', n);
    add(n - 1);       // 递归调用，参数逐渐减小
}
add(6);
// 输出：n=6, n=5, n=4, n=3, n=2, n=1
```

## 用递归求 1~n 的和

```javascript
function sum(n) {
    if (n <= 0) {
        return 0;     // 结束条件：n<=0 时返回0
    }
    return n + sum(n - 1);  // 递归调用
}

console.log(sum(3));  // 6
```

### 执行过程

```
sum(3) = 3 + sum(2)
       = 3 + (2 + sum(1))
       = 3 + (2 + (1 + sum(0)))
       = 3 + (2 + (1 + 0))
       = 3 + 2 + 1 + 0
       = 6
```

逐层展开：

```
sum(0) = 0
sum(1) = 1 + sum(0) = 1 + 0 = 1
sum(2) = 2 + sum(1) = 2 + 1 = 3
sum(3) = 3 + sum(2) = 3 + 3 = 6
```

## 用递归求斐波那契数列

```javascript
function feibo(n) {
    if (n < 3) {
        return 1;     // 结束条件：第1项和第2项都是1
    }
    return feibo(n - 1) + feibo(n - 2);  // 递归调用
}

console.log(feibo(6));  // 8
```

### 执行过程

```
feibo(1) = 1
feibo(2) = 1
feibo(3) = feibo(2) + feibo(1) = 1 + 1 = 2
feibo(4) = feibo(3) + feibo(2) = 2 + 1 = 3
feibo(5) = feibo(4) + feibo(3) = 3 + 2 = 5
feibo(6) = feibo(5) + feibo(4) = 5 + 3 = 8
```

### 递归的重复计算问题

递归求斐波那契数列存在大量重复计算：

```
feibo(5)
├── feibo(4)
│   ├── feibo(3)     ← 计算了一次
│   │   ├── feibo(2)
│   │   └── feibo(1)
│   └── feibo(2)
└── feibo(3)         ← 又计算了一次
    ├── feibo(2)
    └── feibo(1)
```

> 💡 `feibo(3)` 被计算了两次。n 越大，重复计算越多，性能越差。实际开发中推荐循环实现。

## 递归的注意事项

| 注意点 | 说明 |
|--------|------|
| 必须有结束条件 | 否则会产生死循环（栈溢出） |
| 参数必须向结束条件靠近 | 每次递归调用，参数要越来越接近结束条件 |
| 注意性能 | 递归可能有重复计算，大数据量时慎用 |
| 递归深度有限制 | 浏览器对调用栈深度有限制，通常在万级别 |

## 总结

递归的本质是**把大问题拆成小问题**，直到问题小到可以直接解决：

- 求 1~n 的和：`sum(n) = n + sum(n-1)`，直到 `sum(0) = 0`
- 求斐波那契第 n 项：`feibo(n) = feibo(n-1) + feibo(n-2)`，直到 `feibo(1) = feibo(2) = 1`
