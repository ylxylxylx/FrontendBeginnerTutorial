# 转义字符

> 当字符串中需要包含特殊字符（如引号、换行、制表符等）时，需要使用反斜杠 `\` 进行转义，告诉解释器这些字符有特殊含义。

## 一、引号嵌套问题

单引号和双引号**不能嵌套自己**，但可以**相互嵌套**：

```js
// ✅ 相互嵌套——正确
str = '你好，我叫"rose"';
str = "你好，我叫'rose'";

// ❌ 嵌套自己——语法错误
// str = '你好，我叫'rose'';  // 报错！
```

使用模板字符串（反引号）可以避免引号冲突：

```js
var str = `你好，我叫'rose'  你好，我叫"rose"`;
```

## 二、常见转义字符

| 转义字符 | 含义 | 说明 |
|---------|------|------|
| `\n` | 换行 (LF) | 将当前位置移到下一行开头 |
| `\r` | 回车 (CR) | 将当前位置移到本行开头 |
| `\t` | 水平制表 (HT) | 跳到下一个 TAB 位置 |
| `\v` | 垂直制表 (VT) | 垂直方向跳到下一个制表位 |
| `\\` | 反斜线 | 代表一个反斜线字符 `\` |
| `\'` | 单引号 | 代表一个单引号字符 `'` |
| `\"` | 双引号 | 代表一个双引号字符 `"` |

### 代码示例

```js
console.log('你好，我叫\'rose\'');   // 你好，我叫'rose'
console.log("你好，我叫\"rose\"");   // 你好，我叫"rose"
console.log("你好，我叫\rose");      // 你好，我叫rose（\r 回车到行首，覆盖"你好"）
console.log("你好，我叫\nrose");     // 你好，我叫（换行）rose
console.log("你好，我叫\trose");     // 你好，我叫    rose（TAB 缩进）
console.log("你好，我叫\\rose");     // 你好，我叫\rose
console.log("你好，我叫\\\\rose");   // 你好，我叫\\rose
```

> **注意**：`\\` 表示一个 `\`，所以 `\\\\` 表示两个 `\`，转义字符本身也需要被转义。

## 三、Unicode 编码

### `\u` — 用十六进制表示字符

```js
console.log('\u4f60\u597d');  // 你好
```

- `\u4f60` → "你"
- `\u597d` → "好"

### `\x` — 用两位十六进制表示 ASCII 字符

```js
console.log('\x41\x46');  // AF
```

- `\x41` → "A"（十六进制 41 = 十进制 65）
- `\x46` → "F"（十六进制 46 = 十进制 70）

> **计算方法**：十六进制转十进制，如 `41 = 4×16¹ + 1×16⁰ = 65`

## 四、编码与字符互转

### charCodeAt() — 获取字符的 Unicode 十进制编码

```js
var str = 'hello';
console.log(str.charCodeAt(0));  // 104（'h' 的 Unicode 编码）
```

### String.fromCharCode() — 将编码转换为字符

```js
console.log(String.fromCharCode(104));  // 'h'
```

> 这两个方法互为逆操作：`charCodeAt` 从字符取编码，`fromCharCode` 从编码取字符。

## 五、键盘事件示例

利用 `charCodeAt` / `fromCharCode` 可以实现键盘按键的捕获与显示：

```js
window.onkeydown = function(ev) {
    // 获取按键的 Unicode 十进制编码
    console.log(ev.keyCode);
    // 将编码转换为对应字符并显示
    document.querySelector('.d').innerHTML = String.fromCharCode(ev.keyCode);
};
```

- `ev.keyCode`：获取按下键盘按键对应的数字编码
- `String.fromCharCode()`：将编码转换回可显示的字符

---

**小结**

| 方法/语法 | 作用 |
|----------|------|
| `\n` `\t` `\\` `\'` `\"` | 常见转义字符 |
| `\uXXXX` | Unicode 十六进制编码表示字符 |
| `\xXX` | 两位十六进制编码表示 ASCII 字符 |
| `str.charCodeAt(index)` | 获取指定位置字符的 Unicode 十进制编码 |
| `String.fromCharCode(code)` | 将十进制编码转换为对应字符 |
