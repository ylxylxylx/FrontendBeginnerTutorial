# 统计字符串

> 利用 `split()` 方法将字符串按指定字符分割成数组，数组长度减 1 就是该字符出现的次数——这是一种巧妙的字符统计技巧。

## 一、核心思路

**关键公式**：`str.split(ch).length - 1 = 字符 ch 在字符串中出现的次数`

### 压原理

```js
var str = 'asafdasf';
console.log(str.split('a').length - 1);  // 3
```

- `str.split('a')` → `["", "s", "fd", "sf"]`，数组长度为 4
- 出现次数 = 4 - 1 = **3**

> 用字符 `a` 去分割字符串，`a` 出现几次，数组就比原来多几项，所以**数组长度 - 1** 就是字符出现的次数。

## 二、找出出现次数最多的字符

```js
var str = "asaddadsadtdadsadcdb";

var ch = " ", max = 0;

for (var i = 0; i < str.length; i++) {
    // 用 str[i] 分割字符串
    var arr = str.split(str[i]);

    // 数组长度 - 1 = 字符出现的次数
    if (max < arr.length - 1) {
        max = arr.length - 1;  // 记录最大次数
        ch = str[i];           // 记录出现最多的字符
    }
}

document.write("出现最多的字符" + ch + ",总共出现的次数" + max);
// 输出：出现最多的字符a,总共出现的次数6
```

### 执行过程分析

以 `i = 0` 为例，`str[0] = 'a'`：

1. `str.split('a')` → 将字符串按 `'a'` 分割
2. `arr.length - 1` → 得到 `'a'` 出现的次数
3. 如果当前次数 > 已记录的最大值，则更新 `max` 和 `ch`

## 三、方法对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| `split().length - 1` | 代码简洁，思路巧妙 | 每次遍历都要分割，效率较低 |
| 对象计数 `{}` | 时间复杂度 O(n)，效率高 | 需要额外对象存储 |

### 对象计数法（补充）

```js
var str = "asaddadsadtdadsadcdb";
var obj = {};

for (var i = 0; i < str.length; i++) {
    if (obj[str[i]]) {
        obj[str[i]]++;
    } else {
        obj[str[i]] = 1;
    }
}

// 找出最大值
var ch = "", max = 0;
for (var key in obj) {
    if (obj[key] > max) {
        max = obj[key];
        ch = key;
    }
}
console.log("出现最多的字符" + ch + ",总共出现的次数" + max);
```

---

**小结**

- `split(字符).length - 1` 可以快速统计字符出现次数
- 遍历字符串的每个字符，用此方法统计并比较，即可找到出现最多的字符
- 对于大数据量，推荐使用对象计数法，效率更高
