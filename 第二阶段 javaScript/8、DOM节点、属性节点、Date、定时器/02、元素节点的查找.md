# 元素节点的查找

> 操作 DOM 元素的第一步是找到它们。JavaScript 提供了两类查找方法：传统方法（getElement 系列）和现代方法（querySelector 系列）。

## 一、传统查找方法

### 1. getElementById — 通过 ID 获取

```js
// 返回单个元素对象，找不到返回 null
var baidu = document.getElementById('baidu');
console.dir(baidu);
```

> ID 在页面中唯一，所以返回的是**单个元素**。

### 2. getElementsByClassName — 通过类名获取

```js
// 返回元素集合（HTMLCollection），类似数组的结构
var taobao = document.getElementsByClassName('taobao');
console.dir(taobao);

// 通过索引访问
var t01 = taobao[0];
console.log(t01);

// 遍历元素集合
for (var i = 0; i < taobao.length; i++) {
    var t = taobao[i];
}
```

### 3. getElementsByTagName — 通过标签名获取

```js
// 返回元素集合，标签名不分大小写
var ps = document.getElementsByTagName('p');
console.dir(ps);
```

### 4. getElementsByName — 通过 name 属性获取

```js
// 返回节点列表（NodeList），类似数组的结构
var names = document.getElementsByName('username');
console.dir(names);
console.log(names[0]);
```

> 主要用于表单元素，如 `<input name="username">`。

### 传统方法对比

| 方法 | 返回值 | 参数 | 适用场景 |
|------|--------|------|---------|
| `getElementById` | 单个元素 / null | id 名 | 精确查找唯一元素 |
| `getElementsByClassName` | HTMLCollection | 类名 | 按类名批量查找 |
| `getElementsByTagName` | HTMLCollection | 标签名 | 按标签批量查找 |
| `getElementsByName` | NodeList | name 值 | 表单元素查找 |

## 二、querySelector 查找方法

通过 **CSS 选择器** 获取元素，语法更灵活。

### 1. querySelector — 获取第一个符合条件的元素

```js
// 返回单个元素（第一个匹配的）
var p = document.querySelector('p');                    // 标签选择器
var div = document.querySelector('.taobao');            // 类名选择器
var input = document.querySelector('[name=username]');  // 属性选择器
console.log(div, input);
```

### 2. querySelectorAll — 获取所有符合条件的元素

```js
// 返回节点列表（NodeList），包含所有匹配的元素
var allP = document.querySelectorAll('p');
var ts = document.querySelectorAll('.taobao');
var inputs = document.querySelectorAll('[name=username]');
console.dir(allP);
```

### CSS 选择器语法

| 选择器 | 语法 | 示例 |
|--------|------|------|
| ID 选择器 | `#id` | `querySelector('#baidu')` |
| 类名选择器 | `.class` | `querySelector('.taobao')` |
| 标签选择器 | `tag` | `querySelector('p')` |
| 属性选择器 | `[attr=val]` | `querySelector('[name=username]')` |
| 后代选择器 | `parent child` | `querySelector('.box span')` |

## 三、两类方法对比

| 对比项 | getElement 系列 | querySelector 系列 |
|--------|----------------|-------------------|
| 返回类型 | HTMLCollection / 元素 | NodeList / 元素 |
| 实时性 | **实时更新**（动态集合） | **静态快照**（非动态） |
| 语法 | 固定方法名 | CSS 选择器，更灵活 |
| 性能 | 略快 | 略慢 |
| 推荐场景 | 简单查找 | 复杂选择器查找 |

> **实时性差异**：`getElement` 系列返回的是动态集合，DOM 变化后集合自动更新；`querySelector` 系列返回的是静态快照，DOM 变化后不会更新。

---

**小结**

- `getElementById` → 单个元素，通过 ID 查找
- `getElementsByClassName` / `getElementsByTagName` → 集合，通过类名/标签名查找
- `getElementsByName` → 节点列表，通过 name 属性查找
- `querySelector` → 单个元素，CSS 选择器查找
- `querySelectorAll` → 节点列表，CSS 选择器查找所有
