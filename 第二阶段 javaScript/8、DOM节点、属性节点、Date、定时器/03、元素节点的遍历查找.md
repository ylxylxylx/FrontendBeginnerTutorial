# 元素节点的遍历查找

> 找到元素后，还需要在节点树中上下左右移动——向上找父元素、向下找子元素、同级找兄弟元素，这就是 DOM 遍历。

## 一、元素遍历（常用）

元素遍历只关注**元素节点**，忽略文本节点和注释节点。

### 1. 向上遍历 — 获取父元素

```js
var ul = document.querySelector('ul');

// 获取父元素
console.dir(ul.parentElement);
// 继续向上
console.dir(ul.parentElement.parentElement);  // body → html
```

### 2. 向下遍历 — 获取子元素

```js
// 获取所有子元素（HTMLCollection）
console.dir(ul.children);

// 获取子元素数量
console.log(ul.childElementCount);     // 子元素数量
console.log(ul.children.length);       // 等价写法

// 获取第一个子元素
console.log(ul.children[0]);
console.log(ul.firstElementChild);     // 固定写法

// 获取最后一个子元素
console.log(ul.children[ul.children.length - 1]);
console.log(ul.lastElementChild);      // 固定写法
```

### 3. 同级遍历 — 获取兄弟元素

```js
var css = document.querySelector('li.css');

// 上一个相邻的兄弟元素
console.dir(css.previousElementSibling);  // <li class="html">html5</li>

// 下一个相邻的兄弟元素
console.dir(css.nextElementSibling);      // <li class="js">javascript</li>
```

### 4. 遍历子元素

```js
for (var i = 0; i < ul.children.length; i++) {
    var li = ul.children[i];
    li.style.color = 'red';  // 设置所有子元素的颜色
}
```

### 元素遍历属性一览

| 方向 | 属性 | 返回值 |
|------|------|--------|
| 向上 | `parentElement` | 父元素 |
| 向下 | `children` | 所有子元素集合 |
| 向下 | `childElementCount` | 子元素数量 |
| 向下 | `firstElementChild` | 第一个子元素 |
| 向下 | `lastElementChild` | 最后一个子元素 |
| 同级 | `previousElementSibling` | 上一个兄弟元素 |
| 同级 | `nextElementSibling` | 下一个兄弟元素 |

## 二、节点遍历（不常用）

节点遍历包含**所有类型的节点**：元素节点、文本节点、注释节点等。

### 1. 向上 — parentNode

```js
console.dir(ul.parentNode);
console.dir(ul.parentNode.parentNode);          // document
console.dir(ul.parentNode.parentNode.parentNode); // null
```

### 2. 向下 — childNodes

```js
// 获取所有节点：包含注释、文本、元素
console.dir(ul.childNodes);
console.dir(ul.firstChild);  // 第一个节点（可能是文本节点）
```

### 3. 同级 — previousSibling / nextSibling

```js
console.dir(css.previousSibling);  // 上一个兄弟节点（可能是文本节点）
```

### 4. 遍历所有节点

```js
for (var i = 0; i < ul.childNodes.length; i++) {
    var node = ul.childNodes[i];
    console.dir(node);
    console.log(node.nodeName);    // 节点名称
    console.log(node.nodeType);    // 节点类型（1=元素, 3=文本, 8=注释）
    console.log(node.nodeValue);   // 节点值
    console.log(node.textContent); // 文本内容
}
```

### 节点遍历属性一览

| 方向 | 属性 | 说明 |
|------|------|------|
| 向上 | `parentNode` | 父节点 |
| 向下 | `childNodes` | 所有子节点（含文本、注释） |
| 向下 | `firstChild` | 第一个子节点 |
| 同级 | `previousSibling` | 上一个兄弟节点 |
| 同级 | `nextSibling` | 下一个兄弟节点 |

## 三、元素遍历 vs 节点遍历

| 对比项 | 元素遍历 | 节点遍历 |
|--------|---------|---------|
| 关注范围 | 只看元素节点 | 包含所有节点类型 |
| 返回内容 | 纯元素 | 元素 + 文本 + 注释 |
| 常用程度 | ⭐⭐⭐ 常用 | ⭐ 不常用 |
| 属性命名 | 带 `Element` | 不带 `Element` |

> **推荐使用元素遍历**，除非确实需要处理文本节点或注释节点。

---

**小结**

- 元素遍历：`parentElement`、`children`、`firstElementChild`、`lastElementChild`、`previousElementSibling`、`nextElementSibling`
- 节点遍历：`parentNode`、`childNodes`、`firstChild`、`previousSibling`、`nextSibling`
- 实际开发中**优先使用元素遍历**，避免文本节点（空格、换行）的干扰
