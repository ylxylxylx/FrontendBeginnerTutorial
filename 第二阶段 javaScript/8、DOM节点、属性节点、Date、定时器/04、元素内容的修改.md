# 元素内容的修改

> 获取和修改元素内容是 DOM 操作中最常见的需求，主要通过 `innerHTML`、`innerText` 和 `textContent` 三个属性实现。

## 一、获取元素内容

```html
<div class="box">
    《八佰》
    <span>花好月圆</span>
</div>
```

```js
var box = document.querySelector('.box');

// innerHTML — 获取元素内的 HTML 内容（包含标签）
console.log(box.innerHTML);
// 输出: "\n    《八佰》\n    <span>花好月圆</span>\n"

// innerText — 获取元素内的纯文本（不含标签）
console.log(box.innerText);
// 输出: "《八佰》\n花好月圆"

// textContent — 获取元素内的纯文本（包含空格和换行）
console.log(box.textContent);
// 输出: "\n    《八佰》\n    花好月圆\n"
```

### 子元素查找方式

```js
// 三种等价写法
var span = document.querySelector('.box span');
var span = document.querySelector('.box').querySelector('span');
var span = box.querySelector('span');
```

## 二、设置元素内容

### innerHTML — 可以解析 HTML 标签

```js
box.innerHTML = '<p>电影：八佰</p>';
// 页面显示一个 p 元素，内容为"电影：八佰"
```

### innerText / textContent — 不解析标签

```js
box.innerText = '<p>电影：八佰</p>';
// 页面原样显示文本：<p>电影：八佰</p>

box.textContent = '<p>电影：八佰</p>';
// 同上，标签被当作普通文本
```

## 三、清空页面内容

```js
document.body.innerHTML = '';
```

> 将 `body` 的 `innerHTML` 设为空字符串，清空整个页面内容。

## 四、三者对比

| 属性 | 获取内容 | 设置时解析标签 | 包含隐藏元素文本 |
|------|---------|:------------:|:------------:|
| `innerHTML` | HTML + 文本 | ✅ 是 | ✅ |
| `innerText` | 纯文本 | ❌ 否 | ❌ 不包含 |
| `textContent` | 纯文本 | ❌ 否 | ✅ 包含 |

> **设置内容时**：需要插入 HTML 标签用 `innerHTML`，只设置纯文本用 `innerText` 或 `textContent`。

---

**小结**

- `innerHTML`：获取/设置 HTML 内容，**能解析标签**
- `innerText`：获取/设置纯文本，**不解析标签**，不包含隐藏元素
- `textContent`：获取/设置纯文本，**不解析标签**，包含所有文本
- 清空页面：`document.body.innerHTML = ''`
