# 元素节点的增删改

> DOM 提增了创建、插入、移除和替换元素节点的方法，实现对页面结构的动态操作。

## 一、创建元素

```js
// 创建一个新的元素，参数是标签名
var newLi = document.createElement('li');
newLi.innerHTML = 'java';
```

> `createElement` 只是在内存中创建元素，**不会自动添加到页面**，需要手动插入。

## 二、添加元素

### appendChild — 追加到末尾

```js
var ol = document.getElementsByTagName('ol')[0];
ol.appendChild(newLi);  // 在 ol 的最后位置添加 newLi
```

### insertBefore — 在指定子节点前插入

```js
// 参数1：新节点；参数2：在哪个子节点之前插入
ol.insertBefore(newLi, ol.children[1]);

// 参数2 为 null 或 undefined 时，效果等同于 appendChild
ol.insertBefore(newLi, null);
```

## 三、移除元素

```js
// 移除指定的子节点
ol.removeChild(newLi);
```

> 只能移除**自己的子节点**，不能直接移除其他节点的子节点。

## 四、替换元素

```js
// 用 newLi 替换 ol.children[1]
ol.replaceChild(newLi, ol.children[1]);
```

> `replaceChild(新节点, 被替换的旧节点)`，旧节点会被从页面中移除。

## 五、完整示例

```html
<ol>
    <li class="html">html5</li>
    <li class="css">css3</li>
    <li class="js">javascript</li>
</ol>
```

```js
var ol = document.getElementsByTagName('ol')[0];

// 1. 创建
var newLi = document.createElement('li');
newLi.innerHTML = 'java';

// 2. 插入到 children[1] 之前
ol.insertBefore(newLi, ol.children[1]);
// 结果: html5 → java → css3 → javascript

// 3. 移除
ol.removeChild(newLi);
// 结果: html5 → css3 → javascript

// 4. 替换：用 newLi 替换 children[1]（css3）
ol.replaceChild(newLi, ol.children[1]);
// 结果: html5 → java → javascript
```

## 六、方法总结

| 方法 | 作用 | 参数 |
|------|------|------|
| `createElement(tagName)` | 创建新元素 | 标名字符串 |
| `appendChild(newNode)` | 追加到末尾 | 新节点 |
| `insertBefore(newNode, refNode)` | 揲入到指定节点前 | 新节点, 参考节点 |
| `removeChild(child) | 移除子节点 | 要移除的子节点 |
| `replaceChild(newNode, oldNode) | 替换子节点 | 新节点, 旧节点 |

> **标签创建的一般步骤**：1. 创建 → 2. 添加 → 3. 美化

---

**小结**

- `createElement` 创建元素，需手动添加到页面
- `appendChild` 追加到末尾，`insertBefore` 插入到指定位置
- `removeChild` 移除子节点，`replaceChild` 替换子节点
- 所有增删改操作都在**父元素**上调用
