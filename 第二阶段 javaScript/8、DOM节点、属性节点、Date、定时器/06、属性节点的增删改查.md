# 属性节点的增删改查

> DOM 提供了多种操作元素属性的方法：点语法、attribute 方法和 classList 专用方法。

## 一、点语法方式

```html
<form action="/login.php" id="login" abc='x1' class="login">
```

```js
var form = document.getElementById('login');

// 获取属性值
console.log(form.action);  // "/login.php"
console.log(form.id);      // "login"

// 增加/修改属性
form.id = 'l1';
form.title = '登录';

// 移除属性（设为空字符串）
form.action = '';
form.id = '';
```

> **局限**：点语法只能操作**标准属性**，自定义属性（如 `abc`) 无法通过点语法获取。

## 二、attribute 方方式

### 获取属性值

```js
console.log(form.getAttribute('action'));  // "/login.php"
console.log(form.getAttribute('abc');      // "x1"（自定义属性也可以）
```

### 增加/修改属性

```js
form.setAttribute('id', 'l2');
form.setAttribute('title', '开始登录');
form.setAttribute('abc', 'x2');  // 自定义属性也可以
```

### 秵除属性

```js
form.removeAttribute('action');
```

### 判断属性

```js
// 判断是否具有某个属性
console.log(form.hasAttribute('action'));  // true

// 判断是否具有任何属性
console.log(form.hasAttributes();          // true
```

### 获取属性列表

```js
console.dir(form.attributes);  // NamedNodeMap

for (var i = 0; i < form.attributes.length; i++) {
    var attr = form.attributes[i];
    console.log(attr.name, attr.value);  // 属性名和属性值
}
```

### attribute 方法总结

| 方法 | 作用 |
|------|------|
| `getAttribute(name) | 获取属性值 |
| `setAttribute(name, value) | 设置/修改属性值 |
| `removeAttribute(name) | 秵除属性 |
| `hasAttribute(name) | 判断是否具有某个属性 |
| `hasAttributes() | 判断是否具有任何属性 |
| `attributes | 获取所有属性列表 |

> **操作自定义属性必须用 attribute 方方式**，点语法无法访问自定义属性。

## 三、class 的操作

### 方方式一：classList（推荐）

```js
// 1. 添加类名
form.classList.add('x1');

// 2. 秵除类名
form.classList.remove('x1');

// 3. 判断是否包含某个类名
console.log(form.classList.contains('x1');  // true / false

// 4. toggle 开关：包含则删除，不包含则添加
form.classList.toggle('x1');

// 5. 通过索引值获取类名
console.log(form.classList.item(0);  // "login"

// 6. 获取类名列表
console.dir(form.classList);
```

### toggle 详解

```js
// 如果元素有 'active' 类名 → 删除
// 如果元素没有 'active' 类名 → 添加
element.classList.toggle('active');
```

> `toggle` 常用于切换显示/隐藏、选中/未选中等状态。

### 方方式二：className

```js
// 1. 获取类名（完整字符串）
console.log(form.className);  // "login"

// 2. 设置类名（替换原来的所有类名）
form.className = 'x1 x2 login';

// 3. 清空类名
form.className = '';
```

> `className` 会**整体替换**所有类名，而 `classList` 可以**单独操作**某个类名。

### class 操作对比

| 操作 | classList | className |
|------|-----------|-----------|
| 添加 | `classList.add('x')` | 需要字符串拼接 |
| 删除 | `classList.remove('x')` | 需要字符串替换 |
| 判断 | `classList.contains('x')` | 需要字符串匹配 |
| 切换 | `classList.toggle('x')` | 无直接对应 |
| 清空 | 无直接对应 | `className = ''` |
| 推荐 | ✅ 推荐 | 简单场景可用 |

## 四、点语法 vs attribute 对比

| 对比项 | 点语法 | attribute 方法 |
|--------|--------|---------------|
| 标准属性 | ✅ 支持 | ✅ 支持 |
| 自定义属性 | ❌ 不支持 | ✅ 支持 |
| 语法 | 简洁 `el.id` | 略长 `el.getAttribute('id')` |
| 推荐 | 标准属性 | 自定义属性 |

---

**小结**

- 点语法：操作标准属性，简洁但不支持自定义属性
- attribute 方法：支持所有属性（含自定义），操作更通用
- classList：操作 class 的最佳方式，`add` / `remove` / `contains` / `toggle`
- className：整体替换类名字符串，适合简单场景
