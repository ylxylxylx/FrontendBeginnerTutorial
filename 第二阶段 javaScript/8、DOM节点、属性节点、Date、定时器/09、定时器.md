# 定时器

> JavaScript 提供了两种定时器：`setInterval`（间隔执行）和 `setTimeout`（延迟执行），配合 `clearInterval` 和 `clearTimeout` 可以清除定时器。

## 一、setInterval — 间隔执行

每隔一段时间（毫秒）重复执行一次函数。

```js
var count = 0;
var timer = setInterval(function() {
    count++;
    console.log('开始打印', count);
    if (count >= 10) {
        clearInterval(timer);  // 清除定时器，停止执行
    }
}, 1000);  // 每 1000 毫秒（1秒）执行一次
```

### 语法

```js
var timer = setInterval(回调函数, 间隔时间(毫秒));
clearInterval(timer);  // 清除定时器
```

### 实时显示时间

```js
var div = document.querySelector('.time');

// 方式1：匿名函数
setInterval(function() {
    div.innerHTML = new Date();
}, 1000);

// 方式2：先定义函数，再引用
function updateTime() {
    div.innerHTML = new Date();
}
updateTime();              // 先调用一次，避免等待1秒
setInterval(updateTime, 1000);  // 函数名引用，不加括号
```

> **注意**：`setInterval(updateTime, 1000)` 传的是函数名，不是 `updateTime()`。加括号会立即执行并传返回值。

## 二、setTimeout — 延迟执行

延迟一段时间后**只执行一次**函数。

```js
var timer2 = setTimeout(function() {
    console.log('等待11秒钟');
}, 11000);  // 11000 毫秒 = 11 秒
```

### 语法

```js
var timer = setTimeout(回调函数, 延迟时间(毫秒));
clearTimeout(timer);  // 清除延迟操作
```

## 三、clearInterval 与 clearTimeout

```js
// 清除间隔定时器
clearInterval(timer);

// 清除延迟定时器
clearTimeout(timer2);
```

> 定时器返回一个唯一 ID，用 `clearInterval(id)` 或 `clearTimeout(id)` 清除。

## 四、回调函数

定时器的第一个参数是**回调函数**——即作为参数传递给另一个函数的函数。

```js
function f1(x) {
    console.log('f1', 12);
}

// f3 接收一个函数作为参数
function f3(a) {
    console.log(a);    // 输出 f1 函数本身
    a(12);             // 调用传入的函数，相当于 f1(12)
}

// 把 f1 传递给 a
f3(f1);
```

### 回调函数的本质

```js
// 函数也是对象，可以像变量一样传递
setInterval(function() {    // 匿名函数作为回调
    console.log('每秒执行');
}, 1000);

// 等价于
function callback() {
    console.log('每秒执行');
}
setInterval(callback, 1000);  // 函数名作为回调
```

## 五、setInterval vs setTimeout

| 对比项 | setInterval | setTimeout |
|--------|------------|------------|
| 执行次数 | **重复执行** | **只执行一次** |
| 用途 | 轮询、动画、实时更新 | 延迟操作、超时处理 |
| 清除方法 | `clearInterval` | `clearTimeout` |
| 典型场景 | 电子时钟、倒计时 | 延迟提示、防抖 |

---

**小结**

- `setInterval(fn, ms)`：每隔 ms 毫秒重复执行 fn
- `setTimeout(fn, ms)`：延迟 ms 毫秒后执行一次 fn
- `clearInterval(id)` / `clearTimeout(id)`：清除定时器
- 回调函数：作为参数传递的函数，定时器、事件处理都使用回调模式
- 实时时钟：先调用一次 + `setInterval` 每秒更新
