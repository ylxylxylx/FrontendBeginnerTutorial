# 数组进阶练习

> 综合运用 map、reduce、indexOf、replace 等方法，实现关键词搜索高亮显示。

## 一、reduce 回顾

### 无 initValue

```js
var nums = [2, 4, 6, 8];

// 没有 initValue 时：prev = 数组第1个元素，current = 数组第2个元素
nums.reduce(function(prev, current, index) {
    console.log(`第${index}次运行 prev=${prev} current=${current}`);
    return 100;
});
// 第1次运行 prev=2 current=4
// 第2次运行 prev=100 current=6
// 第3次运行 prev=100 current=8
```

### 有 initValue

```js
// 有 initValue 时：prev = initValue，current = 数组第1个元素
nums.reduce(function(prev, current, index) {
    console.log(`第${index}次运行 prev=${prev} current=${current}`);
    return 100;
}, 200);
// 第0次运行 prev=200 current=2
// 第1次运行 prev=100 current=4
// 第2次运行 prev=100 current=6
// 第3次运行 prev=100 current=8
```

### reduce 求和

```js
var sum = nums.reduce(function(prev, current, index) {
    console.log(`第${index}次运行 prev=${prev} current=${current}`);
    return prev + current;
}, 0);
// 第0次运行 prev=0 current=2  → return 2
// 第1次运行 prev=2 current=4  → return 6
// 第2次运行 prev=6 current=6  → return 12
// 第3次运行 prev=12 current=8 → return 20
console.log(sum);  // 20
```

## 二、新闻关键词搜索高亮

**需求**：在新闻标题数组中，找出含有指定关键词的标题，编号显示，并将关键词标记为黄色。

```js
var news = [
    '假期要问回顾：月饼事件惊动阿里高层',
    '上海中秋假期消费者投诉情况：网络销售和食品',
    '马龙登时尚杂志封面 秀胸肌单眼皮放电撩人',
    '阿里巴巴4名工程师 因"刷月饼"被开除',
    '过节出门没带钱？"手机变钱包"不会太远'
];

var keyWord = '月';
var num = 0;
```

### 第一步：用 map 标记是否包含关键词

```js
var mapArray = news.map(function(item) {
    var firstIndex = item.indexOf(keyWord);
    if (firstIndex > -1) {
        // 关键词存在：添加 mark 标签高亮
        return [true, item.replace(keyWord, '<mark>' + keyWord + '</mark>')];
    } else {
        // 关键词不存在：返回原内容
        return [false, item];
    }
});

console.dir(mapArray);
// [
//   [true, '假期要问回顾：<mark>月</mark>饼事件惊动阿里高层'],
//   [false, '上海中秋假期消费者投诉情况：网络销售和食品'],
//   [false, '马龙登时尚杂志封面 秀胸肌单眼皮放电撩人'],
//   [true, '阿里巴巴4名工程师 因"刷<mark>月</mark>饼"被开除'],
//   [true, '过节出门没带钱？"手机变钱包"不会太远']  ← 注意：此条不含"月"
// ]
```

### 第二步：用 reduce 筛选并拼接结果

```js
var result = mapArray.reduce(function(prev, current) {
    // current[0] 为 true 表示包含关键词
    if (current[0] == true) {
        return prev + num++ + '、' + current[1] + '<br>';
    } else {
        return prev;  // 不包含关键词，跳过
    }
}, '');

console.log('result：' + result);
document.write(result);
```

### 输出结果

```
0、假期要问回顾：<mark>月</mark>饼事件惊动阿里高层
1、阿里巴巴4名工程师 因"刷<mark>月</mark>饼"被开除
```

## 三、思路总结

| 步骤 | 方法 | 作用 |
|------|------|------|
| 1. 标记 | `map` | 遍历每条新闻，判断是否含关键词，返回 `[是否匹配, 处理后内容]` |
| 2. 高亮 | `replace` | 将关键词替换为 `<mark>关键词</mark>` |
| 3. 筛选拼接 | `reduce` | 遍历标记数组，只保留匹配项，拼接编号和 `<br>` |

### 关键方法

- `indexOf(keyword)`：查找关键词位置，`-1` 表示不存在
- `replace(old, new)`：替换字符串中的内容
- `map(callback)`：映射变换，返回新数组
- `reduce(callback, initValue)`：累计运算，返回最终结果

---

**小结**

- `reduce` 的 `initValue` 决定了第一次迭代时 `prev` 的值
- `map` + `reduce` 组合可以实现"先标记再筛选"的模式
- `replace` 配合 HTML 标签可以实现关键词高亮
- `indexOf` 返回 `-1` 表示未找到，`> -1` 表示找到
