# 事件入门

> 本节学习 JavaScript 中添加事件的三种方式，以及事件对象的基本概念。

## 什么是事件

事件是浏览器中的用户行为和客户端行为，它是浏览器规定好的行为。用户可以触发事件，浏览器再根据事件类型执行某些默认的操作。

**事件流程：**
用户触发事件 → 浏览器监听到事件已发生 → 执行默认操作 → 如果没有默认操作，可指定事件发生后的操作（回调函数）

## 添加事件的三种方式

### 1. 给元素设置 onclick 属性

在 HTML 标签上直接添加 `onclick` 属性：

```html
<button onclick="login(event);" type="button">登录</button>
```

```javascript
function login(ev) {
    console.dir(ev);  // 事件对象
}
```

**特点：**
- `onclick` 后面添加一段 JS 代码，点击标签时执行
- 在参数列表中可以传递任意类型的参数
- 可以使用 `event` 表示事件对象
- 可以传递 `this` 关键字表示元素本身

### 2. 使用 onclick 属性赋值

通过 JS 获取元素后，给 `onclick` 属性赋值：

```javascript
var regist = document.getElementById('regist');

// 事件被触发时，会默认传递一个参数 event，表示事件对象
regist.onclick = function(ev) {
    console.log('开始注册', ev);
};

// 移除事件：将 onclick 设为 null
regist.onclick = null;
```

### 3. 添加事件监听 addEventListener

```javascript
var regist = document.getElementById('regist');

// 添加事件
// eventType: 事件类型（如 click、mouseover），不带 on
// callback: 触发事件时执行的函数
regist.addEventListener('click', function(ev) {
    console.log(ev);
});

// 移除事件（需要引用同一个函数）
regist.removeEventListener('click', registClick);
```

**addEventListener 参数说明：**

| 参数 | 说明 |
|------|------|
| eventType | 需要监听的事件类型，如 `click`、`mouseover`，**不带 on** |
| callback | 触发事件时执行的函数 |
| useCapture | 布尔值，指定事件在捕获阶段还是冒泡阶段执行 |

## 三种方式的对比

| 方式 | 优点 | 缺点 |
|------|------|------|
| onclick 属性 | 简单直接 | HTML 和 JS 混合，不利于维护 |
| onclick 赋值 | JS 与 HTML 分离 | 同一元素同一事件只能绑定一个函数 |
| addEventListener | 可绑定多个事件，可控制捕获/冒泡 | 移除事件需要引用同一函数 |

## 事件对象 event

在触发事件的函数中会接收到一个 event 对象，包含以下常用属性和方法：

| 属性/方法 | 描述 |
|-----------|------|
| `target` | 返回触发此事件的元素（事件的目标节点） |
| `type` | 返回事件的名称 |
| `pageX / pageY` | 相对于整个文档的位置 |
| `clientX / clientY` | 相对于可视页面的位置 |
| `offsetX / offsetY` | 相对于点击元素的位置 |
| `screenX / screenY` | 相对于整个电脑屏幕的位置 |
| `preventDefault()` | 阻止事件的默认行为 |
| `stopPropagation()` | 阻止事件冒泡 |
