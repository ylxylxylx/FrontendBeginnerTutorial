# 事件的捕获和冒泡

> 本节学习事件传播的三个阶段：捕获、目标、冒泡，以及 addEventListener 的第三个参数 useCapture。

## addEventListener 三个参数

```javascript
addEventListener(eventType, callback, useCapture);
```

| 参数 | 说明 |
|------|------|
| eventType | 事件类型 |
| callback | 触发事件时执行的函数 |
| useCapture | 布尔值，`true` 为捕获阶段执行，`false` 为冒泡阶段执行 |

## 事件传播的三个阶段

当某个元素触发某个事件时，事件的传播分为三个阶段：

1. **捕获阶段**：事件由祖先元素向子元素传递（类似石子从水面向水底下沉）
2. **目标阶段**：事件到达真正触发这个事件的元素（目标元素）
3. **冒泡阶段**：事件由子元素向祖先元素传递（类似气泡从水底向水面上浮）

**传播顺序：** window → document → html → body → ... → 目标元素 → ... → body → html → document → window

## 代码示例

```javascript
var box = document.querySelector('.box');
var inner = document.querySelector('.inner');

// 捕获阶段：useCapture 为 true
window.addEventListener('click', function(){ alert('window 捕获'); }, true);
document.addEventListener('click', function(){ alert('document 捕获'); }, true);

// 冒泡阶段：useCapture 为 false
window.addEventListener('click', function(){ alert('window 冒泡'); }, false);
document.addEventListener('click', function(){ alert('document 冒泡'); }, false);
```

## onclick 与事件阶段

通过 `onclick` 添加的事件最终是在**冒泡阶段**触发：

```javascript
box.onclick = function() {
    alert('box click');
};
inner.onclick = function() {
    alert('inner click');
};
```

## 事件传播图示

```
捕获阶段                    冒泡阶段
   ↓                          ↑
window                    window
   ↓                          ↑
document                  document
   ↓                          ↑
body                      body
   ↓                          ↑
box                       box
   ↓                          ↑
inner ──── 目标阶段 ──── inner
```

## 关键要点

- **事件捕获**也叫"事件挖洞"，从外向内传播
- **事件冒泡**从内向外传播，是最常用的事件传播方式
- 最先得到通知的是 `window` 对象，然后是 `document`，依次而入直至目标元素
- 接下来事件从目标元素开始冒泡，依次而出直至 `window` 对象
- `onclick` 绑定的事件默认在冒泡阶段触发
- `addEventListener` 第三个参数控制事件在哪个阶段执行
