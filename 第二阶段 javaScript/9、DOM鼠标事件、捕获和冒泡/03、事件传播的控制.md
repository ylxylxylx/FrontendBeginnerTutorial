# 事件传播的控制

> 本节学习如何控制事件传播，包括阻止冒泡和阻止默认行为。

## 阻止事件传播

### stopPropagation — 停止事件传播

停止事件传播，不会影响同级别的事件监听：

```javascript
box.addEventListener('click', function(ev) {
    ev.stopPropagation();  // 停止事件传播
}, true);
```

### stopImmediatePropagation — 立即停止事件传播

立即停止事件传播，**会停止同级别多个事件监听的调用**：

```javascript
box.addEventListener('click', function(ev) {
    ev.stopImmediatePropagation();  // 立即停止，同级别的其他监听也不会执行
}, true);
```

### 两者区别

| 方法 | 是否影响同级别监听 |
|------|-------------------|
| `stopPropagation()` | 不影响，同级别的其他监听仍会执行 |
| `stopImmediatePropagation()` | 影响，同级别的其他监听也不会执行 |

## 阻止默认行为

### preventDefault — 阻止事件的默认行为

某些元素有默认行为，例如：
- `<a>` 标签点击后会跳转页面
- `<input type="reset">` 点击后会重置表单

```javascript
// 阻止 a 标签的默认跳转行为
a.addEventListener('click', function(ev) {
    ev.preventDefault();
    console.log('a click');
}, false);

// 阻止表单重置的默认行为
form.onreset = function(ev) {
    ev.preventDefault();
    console.log('开始重置');
};
```

### defaultPrevented — 获取默认事件是否被阻止

```javascript
a.addEventListener('click', function(ev) {
    ev.preventDefault();
    ev.defaultPrevented = true;  // 不能恢复已经被阻止的默认事件
    console.log(ev.defaultPrevented);  // true
}, false);
```

## 实际应用：阻止冒泡

### 示例：地址栏下拉框

点击按钮显示下拉框，点击页面空白处隐藏下拉框：

```javascript
var address = document.querySelector('.address');
var addressInfo = document.querySelector('.address-info');

// 点击地址显示下拉框，需要阻止冒泡
address.onclick = function(ev) {
    addressInfo.style.display = 'block';
    ev.stopPropagation();  // 阻止冒泡，否则会触发 body 的点击事件
};

// 点击空白处隐藏下拉框
document.body.onclick = function() {
    addressInfo.style.display = 'none';
};
```

**为什么要阻止冒泡？**
如果不阻止冒泡，点击地址时，事件会冒泡到 `document.body`，导致下拉框先显示后立即隐藏。

// 阻止冒泡兼容写法
event.stopPropagation ? event.stopPropagation() : (event.cancelBubble = true);
