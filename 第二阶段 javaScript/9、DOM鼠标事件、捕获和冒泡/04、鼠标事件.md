# 鼠标事件

> 本节学习各种鼠标事件类型，以及鼠标事件对象中的坐标属性和拖拽实现。

## 鼠标事件类型

| 事件 | 说明 |
|------|------|
| `onclick` | 鼠标点击事件（包含按下和松开两个动作） |
| `onmousedown` | 鼠标按下触发 |
| `onmouseup` | 鼠标松开触发 |
| `ondblclick` | 双击鼠标触发 |
| `onmousemove` | 鼠标移动时触发 |
| `onmouseenter` | 鼠标移入（**不支持冒泡**） |
| `onmouseleave` | 鼠标移出（**不支持冒泡**） |
| `onmouseover` | 鼠标移入（**支持冒泡**） |
| `onmouseout` | 鼠标移出（**支持冒泡**） |
| `onmousewheel` | 鼠标滚轮滚动时触发 |

### mouseenter/mouseleave vs mouseover/mouseout

- `mouseenter` / `mouseleave`：不支持冒泡，进入子元素不会重复触发
- `mouseover` / `mouseout`：支持冒泡，进入子元素会重复触发

## 鼠标事件对象中的坐标

```javascript
inner.onclick = function(ev) {
    // 相对于整个文档的位置
    console.log(ev.pageX, ev.pageY);

    // 相对可视页面的位置：pageY = clientY + scrollTop
    console.log(ev.clientX, ev.clientY);

    // 相对点击元素的位置
    console.log(ev.offsetX, ev.offsetY);

    // 相对于整个电脑屏幕的位置
    console.log(ev.screenX, ev.screenY);
};
```

### 坐标说明

| 属性 | 参照物 | 说明 |
|------|--------|------|
| `pageX / pageY` | 文档 | 相对于整个文档，包含滚动距离 |
| `clientX / clientY` | 可视窗口 | 相对于可视页面，不包含滚动距离 |
| `offsetX / offsetY` | 点击元素 | 相对于触发事件的元素 |
| `screenX / screenY` | 屏幕 | 相对于整个电脑屏幕 |

**关系：** `pageY = clientY + scrollTop`

## 拖拽实现

利用 `mousedown`、`mousemove`、`mouseup` 三个事件实现元素拖拽：

```javascript
var inner = document.querySelector('.inner');

// 1. 鼠标按下：记录初始偏移量
inner.onmousedown = function(ev1) {
    inner.style.cursor = 'move';
    // 当鼠标按下去的一瞬间，偏移量已经确定
    var offsetX = ev1.offsetX;
    var offsetY = ev1.offsetY;

    // 2. 鼠标移动：更新元素位置
    document.onmousemove = function(ev) {
        inner.style.left = ev.pageX - offsetX + 'px';
        inner.style.top = ev.pageY - offsetY + 'px';
    };
};

// 3. 鼠标松开：取消移动事件
inner.onmouseup = function() {
    inner.style.cursor = 'auto';
    document.onmousemove = null;
};
```

### 拖拽原理

1. **mousedown**：记录鼠标相对于元素的偏移量（offsetX, offsetY）
2. **mousemove**：用 pageX/Y 减去偏移量，得到元素的新位置
3. **mouseup**：将 onmousemove 设为 null，停止拖拽

## 鼠标滚轮事件

```javascript
document.onmousewheel = function(ev) {
    console.log(ev);
    // 垂直滚动：向下滚动返回正值，向上滚动返回负值
    console.log(ev.deltaY);
};
```

## click 事件的注意点

`click` 事件是按下鼠标松开时才会触发，包含**按下鼠标**和**松开鼠标**两个动作。如果出现双击的情况，会转化为两次单击事件。
