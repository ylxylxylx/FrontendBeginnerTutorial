# 作业

> 本节包含 DOM 事件相关的练习题，巩固事件绑定、冒泡控制和鼠标事件的使用。

##  作业一

### 1. 用 for 循环创建 table（6行 × 8列）

使用 JavaScript 动态创建表格，通过 for 循环生成 6 行 8 列的表格。

### 2. 用数组创建一个下拉列表

将数组数据动态渲染为下拉列表（select）元素。

### 3. 纚 JS 存款收益计算器

纯 JavaScript 实现存款收益计算器，使用 DOM 创建元素、添加到页面并美化样式。

**提示：**
- 使用 `document.createElement` 创建元素
- 使用 `appendChild` 添加元素
- 计算公式：收益 = 本金 + 本金 × 利率 × 期数

### 4. 电子时钟

使用 Date 对象和 setInterval 实现动态电子时钟。

**提示：**
- 使用 `setInterval` 每秒更新时间
- 使用 Date 对象获取年、月、日、时、分、秒
- 小于 10 的数字补前缀 0

##  作业二

### 1. 控制 div 属性

通过按钮控制 div 的宽、高、颜色、显示/隐藏等属性。

### 2. 网页换肤

通过切换 CSS 文件实现网页主题换肤功能。

### 3. 循环将三个 DIV 变成红色

使用 for 循环遍历 div，点击按钮将所有 div 背景色改为红色。

### 4. 鼠标移入移出改变样式

使用 mouseenter/mouseleave 或 mouseover/mouseout 改变元素样式。

### 5. 记住密码提示

鼠标移入提示图标显示提示信息，移出隐藏。

### 6. 百度输入法

模拟百度输入法切换效果，使用阻止冒泡控制下拉菜单的显示和隐藏。
